# 单镜提示词范例（8 秒）：

【场景】雨夜的公寓门口走廊，冷蓝色窗光从右侧斜射，地面有雨水反光；前景是半开的门框，左侧虚焦的门框占画面约 15%。

【人物】许念（米白针织开衫、黑色长直发、眼眶微红，清亮偏轻的女声）背靠墙站在画面左三分线；顾川（黑色长风衣、肩头被雨打湿、短发，低沉克制的男声）站在右侧门口，两人相距约一步半。

【0–2 秒】中景，透过门框前景拍摄。顾川抬手想碰许念的肩，手在半空停住。雨声持续，走廊灯轻微闪烁一次。

【2–4.5 秒】缓慢推近许念面部特写，她垂下视线，呼吸变重，停顿约 1 秒后轻声说：“你现在才来，还有什么用？”（轻声、哽咽、尾音发颤）

【4.5–6.5 秒】切顾川近景，他沉默 0.8 秒，喉结轻动，低声说：“我不是来解释的。”（低沉、克制、气声）他向前迈半步，两人距离缩短到一步。

【6.5–8 秒】回到许念特写，一滴泪从右眼滑落至下颌，在冷蓝光下反光；她没有抬头。雨声渐强，镜头停住不动。

【运镜与光线】85mm 等效镜头，浅景深，缓推平稳；冷蓝主光配极弱的暖色走廊顶灯作为边缘光；肤色自然，低照度但面部清晰。

【字幕】画面不出现任何文字或字幕，成片统一烧录。
