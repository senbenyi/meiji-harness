# 单镜提示词范例（6 秒）：

【场景】五星酒店宴会厅，水晶吊灯暖白主光，背景是模糊的圆桌与宾客，左侧香槟塔反光。

【人物】陈默（深蓝旧西装、短发、面无表情，低沉平稳的男声）站在画面右三分线；王总（酒红丝绒西装、油头、金色腕表，尖锐偏高的男声）在画面左侧，身体前倾。

【0–1.5 秒】中近景，轻微低角度仰拍王总，他用两根手指弹了弹陈默的衣领，嘴角上扬。背景宾客低声议论。

【1.5–3.5 秒】王总说：“就你，也配站在这里？”（语速快、带轻蔑笑声）。陈默不动，只把视线从地面缓慢抬起，目光落在王总脸上。

【3.5–5 秒】镜头缓慢推近陈默面部特写，面部占画面约 40%。宴会厅嘈杂声在 4.0 秒骤停。陈默平静地说：“马上你就知道了。”（低沉、平稳、略带冷意）

【5–6 秒】宴会厅大门方向传来一声清脆的开门声，陈默的眼神不动，嘈杂声缓慢恢复。

【运镜与光线】50mm 等效镜头，稳定缓推；暖白商业主光，陈默脸侧加一道暖色轮廓光；肤色自然，高对比。

【字幕】画面不出现任何文字或字幕，成片统一烧录。
