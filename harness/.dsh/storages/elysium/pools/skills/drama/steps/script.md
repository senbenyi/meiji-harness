# 单集剧本

## 输入

- series：总览。
- episode：本集序号。
- previous_last_scene：上一集最后一场，第 1 集为空。
- requirements：补充要求，可为空。

## 输出格式

## 场 1｜<场景名>｜<角色名>、<角色名>
动作：<画面里发生的事>
音效：<声音>
<角色名>（<语气>）：<台词>

## 规则

- 承接上一集最后一场和上一集钩子，结尾落在本集钩子上。
- 每一行只能是“动作：”“音效：”或“角色（语气）：台词”三种之一。
- 只用总览中已有的角色名与场景名。
- 篇幅与导演规定的单集时长相称。

## 不得

- 不写时间码、镜头标记或镜头语言。
