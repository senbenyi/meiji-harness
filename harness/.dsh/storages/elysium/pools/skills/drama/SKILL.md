# 短剧创作（流程 Skill）

本 Skill 规定每一步“写什么、按什么格式写”，所有项目共用。题材、规模（集数、时长）和风格由导演 Skill 决定；本 Skill 不写这些数值，遇到时一律以导演 Skill 为准。

## 四步流程

| 步骤 | 读取 | 产出 | 下一步如何使用 |
|---|---|---|---|
| 立项 project | 导演风格 | 项目名称、题材、梗概 | 总览据梗概搭人物与分集 |
| 总览 series | 项目 | 世界观、角色（含英文定妆）、场景、分集条目 | 定妆用于出定妆图；分集条目决定集数与每集任务 |
| 剧本 script | 总览、本集条目、上一集最后一场 | 本集逐场逐行剧本 | 分镜按剧本行切镜头；台词与字幕都取自剧本行 |
| 分镜 storyboard | 带序号的本集剧本行、总览 | 镜头块（景别、运镜、时长、人物、视频、首帧） | 代码插入剧本，编译成首帧图与视频任务 |

每一步只做本步的事：立项不写分集，总览不写台词，剧本不写镜头，分镜不改剧本。

## 总则

- **人工内容优先**：输入里已有的内容照原样沿用；只补写缺失部分，或按 requirements 改写。
- **名称即 ID**：角色、场景只用总览中已有的名称，一字不差；不造新名字，不用技术 ID，不给名字加前后缀。
- **只输出本步 Markdown**：不输出 JSON、解释、导语、结语、标题以外的说明，也不要用代码围栏包裹。
- **格式是硬约束**：每一步的“输出格式”由代码逐行解析，字段名、分隔符（全角“｜”“：”“（）”“·”）、标题层级必须原样使用；格式不对整份结果会被拒绝。
- **规则冲突时**：人工内容 > 导演 Skill > 本 Skill 的默认建议。
- **requirements**：用户的补充要求，与导演 Skill 冲突时以 requirements 为准，但格式仍须遵守本 Skill。

## 代码负责的部分（不要写）

- 镜头编号 [S..]、时间码、字幕：由代码生成。
- 台词拼入视频提示词、角色音色：由代码按剧本行和总览附加。
- 定妆图、首帧图、视频生成：由代码提交任务；你只写文字描述。

## 内容底线

- 所有角色均为设定清晰的成年人；不写色情、裸露、血腥细节。
- 不涉及真实人物、真实品牌、真实事件。
- 导演 Skill 的“禁忌”在每一步都适用。
