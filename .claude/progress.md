状态流转：未开始 → 调研完成 → 待计划 → 待批准 → 实施中 → 待验收 → 已完成。

- 失败回退：根因未确认 → 回调研；方案明确 → 回计划。
- 每阶段结束前重新读取进度，回写状态、日期和下一步。
- 归档由用户处理，AI 不移动、删除文档。
