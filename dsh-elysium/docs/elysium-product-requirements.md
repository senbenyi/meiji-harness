# 极乐世界产品文档

## 1. 产品目标

极乐世界将故事想法或原文自动生产为可验收、可追踪、可导出的长视频，支持 9:16 竖屏和 16:9 横屏。

主流程：

**故事 → 剧本与资产 → 长视频规划 → 文生图起始帧 → 故事关键帧 → 长视频章节 → 成片 → 人工终审**

正常情况下，用户只需：

1. 填写故事并授权生产。
2. 观看成片并验收。

现有“创作流程 / 素材项目 / 生产管理”合并为一个单集工作台。现有 UI 和交互可以完全重构。

## 2. 模型能力

- 使用 Wan2.2 Remix + SVI v2 Pro 生成长视频。
- 每章使用 1 张文生图起始帧、5 张后续关键帧和 6 段动作提示词生成长视频。
- 单集可包含多个章节，支持 10–600 秒；Qwen3.8 每次最多规划 5 章，长视频自动分批并传递上一批结尾状态。
- 支持预览、正式生成、章节级重试和断点续跑。
- 使用 Qwen 文生图生成定妆图和每个章节的起始帧。
- 使用 RealVisXL 与 IP-Adapter 基于定妆图生成每章人物一致性首帧。
- 支持多章节拼接、24fps 运动插帧、精确目标时长裁切和技术 QC。
- Remix v3.0 和音频暂不进入 P0。

`12 锚点 / 2 章节 / 不少于 40 秒` 是快速模式，不是模型上限。

## 3. 核心概念

| 概念 | 定义 |
| --- | --- |
| 项目 | 一部短剧或系列，保存统一风格和跨集资产 |
| 单集 | 从故事到成片的生产与交付单位 |
| 剧本 | 故事结构、场景、动作、台词和节奏 |
| 资产 | 角色、场景及其采用图 |
| 叙事镜头 | 剧情表达单元，不等于一次模型任务 |
| 故事锚点 | 驱动连续视频发展的关键画面和动作 |
| 起始帧 | 每个章节的第一个锚点，确定人物、场景和构图基准 |
| 长视频章节 | 一张一致性首帧与六段动作提示词的 SVI2Pro 生成单元 |
| 成片 | 一个或多个章节组成的单集视频 |

关系：

**叙事镜头 → 故事锚点 → 文生图起始帧 → 后续关键帧 → 长视频章节 → 成片**

起始帧是该章第 1 个故事锚点，不额外增加模型输入数量。

## 4. 自动化

默认使用托管生产：一次授权后自动运行到最终验收，只有异常才暂停。

系统自动完成：

- 生成并检查剧本；
- 提取、去重和生成核心资产；
- 根据目标时长规划故事锚点和章节；
- 为每个章节生成文生图起始帧；
- 基于起始帧和定妆图生成后续关键帧；
- 复用未变化的有效图片；
- 生成长视频章节、执行技术 QC 并采用有效版本；
- 自动重试可恢复错误；
- 合成、运动插帧、目标时长裁切和成片 QC；
- 上游变化后只重做受影响部分。

只在以下情况请求人工介入：

1. 首次确认内容权利和质量档。
2. 输入冲突、合规风险或连续失败。
3. 最终成片验收。

多个异常集中到“需要处理”，不逐项弹窗。用户也可切换到关键节点审阅或手动调试模式。

## 5. 生产流程

| 阶段 | 自动处理 | 完成条件 |
| --- | --- | --- |
| 故事 | 保存故事、目标时长、画幅和风格 | 输入与约束有效 |
| 剧本 | 生成故事骨架、改编策略和剧本 | 结构、时长和引用检查通过 |
| 资产 | 提取角色和场景，生成并采用有效图片 | 核心资产有采用图 |
| 长视频规划 | 拆解镜头、提取锚点，每 6 个锚点形成一章 | 锚点顺序有效且覆盖目标时长 |
| 文生图起始帧 | 为每章生成第一个锚点 | 每章有有效起始帧 |
| 故事关键帧 | 基于起始帧和定妆图生成其余锚点 | 所有章节锚点有效 |
| 长视频章节 | 生成预览/正式章节、QC、采用和重试 | 所有章节有效且总时长达标 |
| 成片 | 拼接、运动插帧、目标时长裁切和技术 QC | 技术 QC 与人工验收通过 |

最后一章不足 6 个锚点时，系统调整锚点密度；仍不足时必须记录补充、保持或复用策略，不能静默复制图片。

## 6. 状态与依赖

状态：草稿、自动处理中、排队中、生成中、待审阅、已采用、需更新、自动重试中、需要处理、验收通过。

依赖规则：

- 故事、时长或剧本变化：重新规划相关资产、镜头和章节。
- 资产变化：引用它的起始帧、关键帧和章节失效。
- 起始帧变化：所属章节的后续关键帧和视频失效。
- 锚点或章节边界变化：受影响章节失效。
- 章节版本变化：成片重新合成。
- 成片变化：旧人工验收失效。

保留历史和已付费产物，只重做受影响部分。

## 7. UI 结构

一级入口：

1. **项目**：项目、单集、最近进度和需要处理事项。
2. **单集工作台**：完成一集生产。

单集工作台：

- 左侧：故事、剧本、资产、长视频规划、文生图起始帧、故事关键帧、长视频章节、成片。
- 中间：当前阶段产物。
- 右侧：自动生产队列、AI 助手和异常，可收起。
- 顶部：项目、单集、目标时长、画幅、质量档和总体进度。

主要动作：

- 开始自动生产
- 暂停自动生产
- 处理问题
- 观看并验收

JSON、任务 ID、文件路径、ComfyUI 节点、原始日志和高级参数默认隐藏。

## 8. P0 范围

- 项目与单集管理；
- 10–600 秒故事输入；
- 剧本、角色和场景资产自动生成；
- 镜头、锚点和动态章节规划；
- 每章文生图起始帧、后续关键帧与长视频章节生成；
- 托管生产、自动重试和异常队列；
- 成片合成、技术 QC、人工验收和导出；
- 自动保存、版本历史、依赖失效和断点续跑。

不做无限画布、节点编辑、专业时间线、多 Agent 配置、多用户权限和供应商开发界面。

## 9. 验收标准

1. 用户可以从故事输入一键运行到最终验收。
2. 无异常时，中间没有必须点击的确认页。
3. 当前阶段、任务进度和暂停原因始终可见。
4. 用户不需要填写 JSON 或理解 ComfyUI。
5. 剧本、资产、起始帧、后续关键帧、章节和成片来源可追踪。
6. 常规重试、结果复用、阶段推进和版本采用自动完成。
7. 单项失败不影响其他章节，多个异常集中处理。
8. 已锁定、已付费和已验收产物不会被自动覆盖。
9. 技术 QC 未通过时不能进入人工验收。
10. 页签重开后恢复单集和任务状态。
