# 人物短剧单镜提示词范例

【场景】雨夜的旧公寓厨房，冷蓝窗光从左侧照亮瓷砖，右侧一盏暖黄吊灯低亮。狭窄过道、磨损木桌与半开的门保持位置一致。

【人物】林（深灰外套、湿发、略沙哑的低声线）站在桌旁；周（米色衬衣、短发、清亮偏轻的声线）在门边。保持各自面部、衣着和音色与角色定妆照一致。

【0–2 秒】中景固定机位，林握着未拆封的信，雨声占前景。周从虚焦门边进入清晰区域。

【2–4 秒】缓慢推近林的手，指节收紧。林低声说“你早就知道？”；口型与对白同步，音色克制而颤抖。

【4–6 秒】切周的近景，她停顿半秒后说“我只是想保护你。”；窗外雷声短促，吊灯轻微摇晃。

【运镜与光线】35mm 等效镜头，缓推平稳，冷蓝主光与暖黄边缘光分离两人；肤色自然。

【字幕】中文字幕逐句出现，与对白时间对齐，不遮挡面部。环境音为持续雨声与一次远雷，无音乐。
