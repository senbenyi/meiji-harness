# Drama 开发方向

当前只提供V2制作流程。运行字段以 src/project_runtime/project_document.js 为权威，文档契约见[项目数据契约](项目数据契约.md)。V1盒子、工具、横向旧页面和旧项目Model已经删除，不提供兼容入口。

## 制作阶段与盒子

左侧十二步对应 src/node_box 下十二个同名目录；registry.js 是服务端节点接口装配表，shared/production_stages.js 是浏览器与服务端共用的阶段目录。

| 阶段目录 | 业务职责 |
|---|---|
| project | 程序创建、导入、人工保存；项目弹框和原稿导入UI |
| source_analysis | 将整篇原稿复制为一条正文记录并逐字校验，不调用模型 |
| adaptation_plan | 全篇改编目标与原则、剧情方向、人物/场景/团队指导 |
| story_segments | 依据原著与指导自主分段定稿、读取前段状态、相邻段衔接复核 |
| shot_design | 文字分镜、稳定资产定义与素材需求 |
| asset_preparation | 人物/服装/道具/场景/组合造型图片生成与导入选用、稳定声线 |
| reference_binding | 将已选图片引用绑定到镜头 |
| clip_arrangement | 按节拍无遗漏组合4～15秒生成分片 |
| video_prompt | 分片提示词、参考图与声音引用 |
| video_render | 视频及原生声音候选、导入、技术校验与人工选用 |
| editing | 连续时间线、字幕、音轨、预览 |
| delivery | 最终分集范围、实际视频和字幕导出 |

文本节点 pipeline.js 维护单元准备、候选校验、写入和回读。story_segments/execution.js 维护故事专属执行钩子。程序节点 execute.js 维护实际步骤；图片/视频节点 executor.js 维护各自媒体生成。confirm.js 和 manual.js 维护节点确认及专属人工操作。相邻节点复用资产查找或剪辑函数时直接引用拥有该能力的节点，不把整套阶段业务搬回共用层。

六个AI节点的 skills 目录直接放四个英文文件：节点名-generate.md、节点名-review.md、节点名-revise.md、节点名-output-format.json。返回格式引用运行Schema，程序节点不造空规则。辅助记忆规则独立放 memory/skills/memory_maintenance-*。

## 共用执行框架

production/service.js 接受面板/会话任务，执行归属、幂等、并发、取消、续接与冻结输入检查；专属人工操作和确认交给节点。executor_registry.js 装配文本、图片、视频和程序执行器。文本/程序的共用执行器在 production；图片/视频的具体执行器由对应盒子拥有。

unit_executor.js 共用Task、单元manifest、检查点和完成状态；text_executor.js 共用生成、独立审核、修订循环，调用节点钩子；text_pipeline.js 共用候选保存状态与委派；model_loop.js 负责文本模型工具循环、有界读取与真实消息记录。不得在这些共用文件中新增阶段产物switch。timeline_renderer.js、media.js、audio_import.js、subtitles.js 提供实际媒体处理，不拥有阶段JSON产物。

每次Task仍保存不可变输入、候选、规则、记忆和工具记录。生成、审核、修订共享当次冻结资料，审核上下文独立。续接优先已保存候选及问题，历史只从当次Task/Step/artifacts恢复，不用现在的项目补造。保存与人工确认独立；图片、视频生成成功不会自动选用。

## 入口、存储和界面

插件 index.js 组装 ProjectWorkspaceService、ProductionService、设置和公共记录；session/index.js 仅注册当前制作及记忆工具。src/index.js 只导出当前文档Store、Schema和阶段API。

项目文档及不可变文件由 project_runtime/project_document_store.js 保存。当前项目、素材、记忆和已有执行记录不因目录整理改变。全局图片库仅id/url，成功生成或导入后立即入库；稳定形象资产及声音设定留项目。Project JSON始终是正式产物权威。

client/project-document-view.js 负责左侧十二步骤和右侧产物；workbench.js 直接装载当前页面。创建与编辑项目共用 project/ui/panel/project-forms.js，原稿由 script-import.js 提供本地/素材库导入。保持各阶段人工编辑、意见、规则和历史交互。模型过程展示发送目标、模型返回的工具名/用途和执行结果，展开可查当轮完整消息。

harness_server/client_assets.js 显式登记浏览器依赖；只公开UI及共享展示代码，不公开Service、Executor或Schema源码。面板和会话调用相同业务Service，HTTP名称按根指引区分 harness-http、llm-http 和 service-http。

## 长期记忆与验证

memory/ 维护仅面向视频创作的项目记忆和Drama跨项目偏好。整理/压缩是独立辅助Task，不算制作阶段、不放node_box。记忆只提炼有用户原话依据的要求；AI判断和审核意见不能自动变成用户决定。每次制作冻结适用版本，压缩保留原文及硬约束。

根执行 npm run test:drama；跨工程整合执行 npm test，隔离复制执行 npm run verify:copy -- drama。测试以模拟模型和真实本地ffmpeg验证，不能宣称供应商画面/声线质量已通过。production-architecture.test.js 约束目录/注册一致性、执行边界、文本续接、浏览器依赖与纯程序创建；完整流程和失败续接继续由production相关测试覆盖。
