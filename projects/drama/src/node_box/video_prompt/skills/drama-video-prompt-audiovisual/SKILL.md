# 视频提示词：分片声画转译

适用动作：生成、审核、修订。

声画表达：
用紧凑、连贯的具体声画描述本片：必要开场→动作与反应按时推进→真实结束状态。开场只保留识别人物、空间、光照、摄影和行动所需的信息；每次变化说清主体、过程与结果，同步声音随动作呈现。定稿对白、旁白、心声和指定画面文字保留原文、标点与说话人，不补写或改成间接转述。
来源中的内心与张力落实为已有依据的表情、目光、呼吸、姿态、动作迟疑或语气；背景材质、光照、感官修饰和特效按场面需要选用。细节须具体有效，不机械罗列所有维度、不堆同义形容词，不借具体化增加剧情或改变表演。特效保留触发、可见过程和必要结果。
每片独立可执行；同片开场信息只写一次，后续写变化。删除创作解释、输入路径、审核口吻、否定清单和“本片不重复”等控制文字，直接描述应出现的声画。业务ID只用于关联，不进入接口正文。精简不省略动作因果、关键站位/持物、摄影、必要背景、对白或声音时序，不设字数上限。
