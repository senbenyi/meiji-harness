# 视频提示词：摄影声音与生成模式

适用动作：生成、审核、修订。

摄影、声音与模式：
同shot内节拍连续摄影，跨shot才标明实际切镜，时间相对本片；不重设摄影或用切镜掩盖动作缺口。画面左右与真实位置分开，画外人物仍可在场；时长和语速承接来源，不再次倍速或靠重复/空等凑时长。
overall_soundscape简述有效环境声、动作声和非语言人声；正文仅在同步或变化有意义时提及，避免逐句复制。non_diegetic_music继承有效配乐，无配乐按契约填N/A，不新增对白或配乐。
文生模式用纯文字，不编参考标签。多模态明确主体、概要和真实素材应保留的特征，标签及顺序来自实际输入，参考不覆盖定稿。人物图按身份和服装准确关联，无图或未绑定人物仍按文字表现。首尾帧以真实首帧起点推进至明确目标尾帧；依赖前片尾帧而尚不可用时报告前置，不改模式绕过。
