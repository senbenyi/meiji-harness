# 视频提示词：分片起点与累积状态

适用动作：生成、审核、修订。

依据与起点：
只转译指定分片的来源镜头、完整节拍、相关资产和此前累积状态，保留已选模式、分片边界、摄影、事件与定稿原话。先从镜头开场逐拍推进到本片起点：已经发生的持物交接、移动、伤势、门/设备变化和声音进度覆盖开场旧状态，未变化的状态继承。此前动作和说完的对白仅作上下文，不重演；来源本身互斥或缺少本节点无权补全的关键依据时，指出来源，不编剧情圆场。
