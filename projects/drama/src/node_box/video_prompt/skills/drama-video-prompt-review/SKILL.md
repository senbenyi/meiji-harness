# 视频提示词：审核视频提示词

适用动作：审核。

只审核最新候选，不改写。先辨别上游资料能否成立，再核对分片与模式、实际起点、来源节拍、摄影切镜、逐字台词与声音时序、素材身份服装及有效细节。问题定位分片/字段并引用来源，给最小修正方向；候选错误由本节点修订，上游冲突或前置不足定位来源，规则互斥指出条款。已解决或错误的旧意见不沿用，不以个人审美、无图、无配乐或未重复历史状态拒绝，不臆断未提供的视频。无有据可核的问题即通过。

逐片对照实际来源与起点，检查充分性和忠实性；程序校验结构，审核关注声画内容。
