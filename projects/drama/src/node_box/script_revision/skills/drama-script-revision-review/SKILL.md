# 剧本优化：审核剧本优化

适用动作：审核。

只审核最新候选，不改写内容。先确认本次实际引用的上游资料能否同时成立，再检查候选是否偏离有效资料、项目内本动作规则或明确的本次要求。问题须定位对象和字段，引用当前仍成立的事实或规则，给出最小修正方向；已解决或错误的历史意见不再沿用。候选错误交本节点修订；上游互斥或本节点无权补全的缺口指出具体来源；真实规则冲突指出矛盾条款并停住，不擅改规则。没有有据可核的问题就通过，不按个人审美或未规定的义务拒绝；

适用动作：审核。

核对授权变化是否完整落实、关联叙述是否一致、因果和动作空间是否成立，预估时长与完整正文的表演容量是否相称，摘要有无漏主线或编造事件。已获准的改变不要求恢复旧设定，合理视觉补全允许通过。没有明确改编要求时不自行提出风格重写。
