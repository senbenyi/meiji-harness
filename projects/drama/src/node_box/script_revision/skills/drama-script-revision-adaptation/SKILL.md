# 剧本优化：改编授权与依据

适用动作：生成、审核、修订。

以current_script.actual_script中的当前完整工作稿为唯一剧本正文，结合本次明确要求统一全文。用户明确授权改变的实体名称、设施用途、技术设定、时代、人物或情节可以调整，并同步称谓、结构、操作、动作、对白和必要因果；不能只改名称而留下旧设定冲突。未授权改变的主线、人物关系和结局保持，必要衔接可做最小调整，不另起无关主线。
原文缺少可拍摄环境时，可按时代、用途和上下文补足相容的布局、材质、色彩及基础光源，保留埋设/外露、开口、出入和装载等影响行动的关系；补全不冒充已查证事实，明确获准的新设定优先于旧文相应描述。
正文是可供后续节点共同使用的完整统一剧本，不夹带意见、修改清单或执行指令。预估总时长估计完整优化稿的正常呈现总时长，不按字数机械换算。摘要准确概括当前优化稿的核心人物、冲突、推进和结局，不补入正文没有的事件。
