# 剧本优化：修订剧本优化

适用动作：修订。

依据最新完整基稿、本次明确意见和仍成立的审核问题修订，保留未涉及的有效事实及稳定标识，联动修改必要的前后关联。基稿中的旧错误不是新的上游事实。返回修订后的完整内容，不只返回修改说明；若问题必须改上游或规则才能解决，说明位置并停住，不编造事实绕过。

适用动作：修订。

修订正文时同步重新核对预估时长和摘要；即使只改摘要或时长，也返回三项相互一致的完整结果。不得为通过审核而撤销用户明确授权的改编。

适用动作：修订。

字段处理方法：
正文变化后重估受影响的表演时长并重写不再准确的摘要；只改摘要或估时也返回三者一致的完整结果。
