# 剧本优化：生成剧本优化

适用动作：生成。

按本次改编要求输出完整优化剧本、预估总时长和剧情摘要，三项描述同一个最新版本。

适用动作：生成。

字段处理方法：
先将本次授权改编统一到完整正文，再根据实际对白、动作和可并行声画估计总时长；最后从当前正文提炼人物、冲突、推进及结局摘要，三者必须对应同一版本。
