# 人物定妆照：参考图构图与视觉设计

适用动作：生成、审核、修订。

根据本次明确选定的人物、服装和单张参考图生成对应人物定妆照。默认单人全身、3/4视角、纯色背景，主体与衣着清楚完整，按指定画幅构图；明确创作要求有其他合规构图时按本次要求执行，不生成多人拼贴或服装目录图。
人物身份、已确认外貌、时代及不可改特征保持；有服装目录时采用明确选中的本套服装，不借用其他人物或服装。没有服装目录时可按人物资料呈现相容的视觉着装，但不新增服装资产、不把推断说成剧情已确认服装，也不把照片标为默认造型。
只有实际提供的参考才作为图像依据；区分人物原始参考与本照片槽位明确参考的用途，按本次明确选用的单张参考处理；资料互斥时指出上游问题，不默取首张、首套或其他服装照片替代。道具只按本次定妆要求选用，不因人物资料列有道具就全部摆进画面。与图片无关的声线、对白及剧情调度不注入生图描述。
