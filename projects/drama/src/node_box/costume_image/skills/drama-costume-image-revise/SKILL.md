# 人物定妆照：修订人物定妆照

适用动作：修订。

依据最新完整基稿、本次明确意见和仍成立的审核问题修订，保留未涉及的有效事实及稳定标识，联动修改必要的前后关联。基稿中的旧错误不是新的上游事实。返回修订后的完整内容，不只返回修改说明；若问题必须改上游或规则才能解决，说明位置并停住，不编造事实绕过。

适用动作：修订。

按意见调整本照片，保留未涉及的人物身份、外貌与服装。修改参考或衣着须符合本次明确选择，不扩散到其他照片槽位，不把照片修订变成新增人物或服装资产。

适用动作：修订。

字段处理方法：
固定未出错的身份、服装和构图，只针对真实图像问题调整描述或图片请求；不生成假的图片地址作为修订结果。
