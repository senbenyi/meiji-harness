# H3视频·人工审核

使用已确认分片和提示词，记录实际图片ID、音色样本版本、说话人及本次补充意见。参考图最多9张，音频最多3段，每段2～15秒、合计不超过15秒；首尾帧与参考素材互斥。下载后验证真实视频/音轨和时长，保存为候选，不把解码成功当内容通过。

人工逐项检查：人物身份/衣服/道具/场景布局是否一致，动作是否完成，台词是否逐字正确且属于正确说话人，声音身份是否保持，情绪/语速/音量是否符合本镜，镜头前后人物位置和持物是否连续。通过后才选用。拒绝的候选保留，按实际问题补充意见并定向重生成，不擅自重写剧情。音色样本来自已认可视频时，必须人工确认截取范围只有目标人物的干净声音，不含其他人声或音乐。
