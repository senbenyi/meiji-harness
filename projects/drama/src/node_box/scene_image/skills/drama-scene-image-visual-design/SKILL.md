# 场景参考图：参考图构图与视觉设计

适用动作：生成、审核、修订。

生成一张可跨镜复用的无人静态场景空间总览图，呈现已确认的地点身份、布局、材质、基础光源、出入口、通路和关键地标。使用远景或大远景的自然广角，按项目画幅拉远构图，主体设施与空间边界留余量；不以局部设施特写替代总体空间。
画面只呈现静态环境、设施和陈设，不包含人物、群演、人群、人体局部、人物剪影或倒影；参考图原有人物时移除并还原被遮挡背景。保留单幅真实透视，不用拼贴、分屏、剖面或夸张鱼眼强行塞进所有细节。
场景文字和实际引用的故事事实为依据，原图仅作为相容的环境参考。与明确事实或本次修正意见冲突的设施形制、方向和通路应纠正，未冲突的固定布局及已确认材质保持；不能因旧图而把专用设施换成普通物件。原图过近或裁切时可拉远重新构图，用户明确限定只改局部时按该范围执行。
使用可供不同镜头、昼夜和天气状态复用的基础环境，不把本次人物动作或短暂破坏固化到场景资产图。没有参考图时按有效场景资料生成，不编造参考来源。
