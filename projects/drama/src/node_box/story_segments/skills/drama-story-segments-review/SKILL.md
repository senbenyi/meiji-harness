# 故事大纲：审核故事大纲

适用动作：审核。

只审核最新候选，不改写。检查锁定要求、因果与人物转变、必要过程与定稿台词、全篇状态及字段一致。合理改编本身不是错误；问题定位段与字段，引用具体依据，说明观看或理解障碍及最小修正方向。只保留仍成立的问题，不以个人审美、固定套路或估时拒绝；无有据可核的问题即通过。

适用动作：审核。

审核判定门槛：
只判断最新候选当前存在的问题。审核意见和候选自设锚点都不是新增的用户锁定要求；不为维持旧意见而否决最新文本，也不因上一轮要求过某种改法就认定它正确。
每条未通过意见必须引用最新候选中的具体表述、对应的明确依据，并说明可验证的语义差异、内部矛盾或必要因果缺口，以及它如何妨碍理解。没有当前证据、只是措辞偏好、缺少冗余状态说明或合理新增细节，不列入issues。
先按完整句义核实数量与关系，前后引文相同或语义等价不能判为差异。对时间歧义区分“文本已经互相矛盾”与“文本没有规定到这个精度”；只有前者，或确实阻断理解的必要关系缺失，才提出最小修正。
撤回无依据的判断，不从已改正的问题换个措辞派生新问题。没有仍成立且有据可核的问题就passed；只输出当前未解决问题，不输出历史问题或修订指令执行情况。

适用动作：审核。

字段处理方法：
沿候选剧情检查人物选择与后果，再核对跨段状态、对白和字段；区分合理改编与违背锁定要求。

## 相关业务规则

根据本次问题选择相关规则，不将旧审核意见视为新增锁定要求。
