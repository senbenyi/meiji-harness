# 故事分段定稿·审核

对照原剧本与联合改编规划，核对定稿的剧情完整性、细节、观赏性和段间衔接。对有依据且影响正文质量的问题给出位置、证据和修改方向，按实时审核契约提交结论。

依据联合改编规划中的全篇创作约束、剧情发展及人物、团队、场景规划，将当前原剧本分段改编。按叙事推进自主安排段落，落实既定主线、人物动机与关系、场景作用和结局方向。

正文要详细、完整、有观赏性：写出具体行动、角色反应、自然且有角色差异的对白，以及必要的场景细节。围绕人物目标和冲突展开铺垫、递进与情感变化，按情节需要安排悬念和节奏起伏，使故事清晰、生动、适合观看。

各段前后连贯；continuity记录开场与结尾的人物状态、知情、位置、持物和未决信息。修改沿用已有稳定段ID。相邻段复核聚焦指定两段的承接与一致性，修订保持这两段的ID和顺序。
