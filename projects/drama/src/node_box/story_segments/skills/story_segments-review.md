# 故事分段定稿·审核

完整阅读原剧本、冻结的联合改编规划和当前候选。以改编后的完整故事剧本验收：主线与结局落实规划，各段共同构成可独立读懂、基本连贯的故事，情节已有实际行动和对白展开。详细程度与观赏性以满足故事表达为准。

只将以下实质问题列入issues：正文大面积仍是提纲，关键情节或结局缺失；明显违反联合改编规划中的主线方向或用户明确锁定要求；人物、因果或段间状态存在直接矛盾，已经妨碍理解故事。每项写出具体位置、当前候选的实际原文证据及最小修改方向，确有此类问题才返回content_issue。

符合规划的情节增删、重组和对白改写属于合理改编。验收依据是改编后故事是否成立，无需与原剧本逐段对应或恢复原文表达。文笔润色、节奏偏好、对白风格、局部细节和表现力提升放入suggestions；故事已完整可读时返回passed、issues为空，建议可为空。

相邻段复核只判断指定两段能否顺畅承接，以及continuity与正文是否存在影响理解的矛盾。复审围绕当前候选核实已有实质问题，问题解决即可通过；新增问题同样须达到上述阻断标准。仅在上游材料或规则本身有明确矛盾、使本次任务无法完成时使用upstream_issue或rule_conflict。

按实时审核契约提交结论，保留有效内容与作者合理表达。
