# 故事大纲：跨段连续性与辅助字段

适用动作：生成、审核、修订。

事实与辅助字段：
沿全文核对时间地点、人物在场与知情、持物交接、伤势、通路及行动结果；影响因果的移动、观察、告知和交接在正文中有依据。所有字段使用同一套最终事实，辅助字段不补造正文缺失事件、不保留被改掉的旧信息。
world_background仅提炼本段有效设定；characters_and_groups提炼参与者、动机与作用；scene_and_space提炼必要空间关系；emotion_and_rhythm提炼情绪变化与观看期待。它们是简短检索和约束，不复述整段正文、不重复完整资产资料，也不要求每段机械写满所有维度。
key_anchors提炼必须落实且容易遗漏的事实、程度、情绪、设定或伏笔；content写内容，expression写可见可听的落实条件。逐字要求引用唯一的定稿原文；除明确创作要求外，不预设摄影或镜头数。continuity只记正文真实起止状态及必要后续承接。
