# 故事大纲：修订故事大纲

适用动作：修订。

依据最新完整基稿、本次意见及仍成立的审核问题修订，可联动改编以修复叙事。保留未受影响的有效内容、锁定要求及稳定ID；同步正文、辅助字段、锚点与前后承接，返回完整集合，最后更新粗估时长。

适用动作：修订。

修订意见核实：
逐项核实review_issues中的全部意见，再决定是否修改；审核意见是待核对的问题报告，不是必须执行的创作指令或新增锁定要求。
以最新候选、工作剧本及用户明确要求复核每条意见的引文、数量、状态和时间依据。仅修仍成立的问题；已解决、引文或推断错误、要求冗余重申状态、或只因原稿未写而反对合理补充的意见，不据此改坏有效内容。全部意见均不成立时允许返回内容不变的完整候选，交下一次审核重新判断。
对成立问题先做最小修复，再同步实际受影响的正文、辅助字段、锚点与前后承接；不为迎合意见增加无必要的持续状态、精确秒点或无依据的新硬约束。

适用动作：修订。

字段处理方法：
先修正具体叙事问题，再同步全部受影响字段和前后段，保留有效内容。
