# 故事大纲：估时与时间边界

适用动作：生成、审核、修订。

时间：
本节点不接入时间预算。原稿时长、时间码、集数预算、basic_info.estimated_duration_seconds及旧估时均不约束分段或剧情取舍；有叙事作用的日期、期限、倒计时仍保留。内容定稿后，按正常对白、行动、反应及并行过程粗估duration_seconds，必须大于0；不沿用统一默认值、不平均分配、不按字数硬算，也不为秒数改戏。相同或整数估时本身不是问题，审核不设目标时长或误差阈值。
