# 故事大纲：正文分段与对白定稿

适用动作：生成、审核、修订。

正文与分段：
按行动因果和阶段结果分成有序故事段，body保留完整可表演剧情、关键对白与必要转场。通过处境、阻力、选择、行动及后果推进人物，情绪转变有触发与反应；允许省略、平行叙事和有意悬念，不强迫固定场数、每段反转或提前揭密。必要对话在body明确说话人和定稿原话，不能只写“请求、解释、劝说”留给下游补词；普通说明无需强造对白。指定逐字文字保留原文与标点。下游仅作资产与视听实现，不再改编剧情或重写台词。
