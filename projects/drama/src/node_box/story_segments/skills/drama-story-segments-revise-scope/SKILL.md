# 故事大纲：大纲整轮修订范围

适用动作：修订。

# 整轮修订
逐项核实review_issues中的全部意见，不得只核实第一项；只有最新候选中仍成立且有依据的问题才修改，审核意见不是必须执行的创作指令。已解决或无依据的意见不要求更改，全部意见不成立时允许保留内容不变。
对成立问题做最小修复，同步真正受影响的正文、continuity和辅助字段，不新增冗余状态声明或自行锁定精确时间。完成后通读全部故事段，核对当前真实问题与跨段衔接，返回完整集合。
