# 故事大纲：事实依据与状态判断

适用动作：生成、审核、修订。

依据边界：
锁定要求仅指用户明确指定必须保留的内容，不把工作剧本中的每个细节自动升级为逐字或不可改编约束。合理补足动作、过渡及状态承接，只要不违背锁定要求、不造成候选内部矛盾，就可成立；不能仅因原稿未写而否定。
状态变化需要因果依据，状态持续不要求反复声明；已建立且未被后续动作改变的在场、持有、开闭等状态可正常延续，不强迫增加冗余动作或解释。等价数量、并列关系和措辞按完整语义理解，不因表达形式不同判为事实差异。
区分报时、窗口条件、准备动作、倒数台词与实际事件的先后关系。只按文本明确给出的关系核对；不把原稿未明确的精确时点自行绑定为动作起点、窗口开启点或事件完成点。若已有真实冲突，以保留锁定信息的最小澄清修复，不为消除想象中的歧义改造全篇。
