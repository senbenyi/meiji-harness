# 故事大纲：改编授权与依据

适用动作：生成、审核、修订。

职责与依据：
以basic_info.actual_script当前工作剧本和有效创作要求为基础，完成最终剧情改编与叙事定稿，让因果连贯、人物可信、剧情饱满有吸引力。允许补足、删并、重排情节、动机、行动、对白与过渡；新增内容须融入全篇因果，不靠重复冲突、堆事件或解释标签充实故事。保留用户明确锁定的主题、身份关系、事实、结局、尺度和指定原文，其余原稿可合理修饰。缺工作剧本时停止；一般叙事缺口由本节点修复，只有锁定要求互斥或授权内无法判断的核心歧义才报告并停住。
