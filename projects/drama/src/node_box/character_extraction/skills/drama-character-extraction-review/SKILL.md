# 人物提取：审核人物提取

适用动作：审核。

只审核最新人物候选，核对重要人物覆盖、稳定特征、个人服装充分性与团队关联及适用范围。不重新设计团队，不因相容视觉补充、无照片或空人物集合拒绝。实际问题指出具体字段、依据与最小修正；上游团队本身不正确则报告upstream_issue并定位group_setting，无问题则通过。
