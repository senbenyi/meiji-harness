# 人物提取：个人服装补全

适用动作：生成、审核、修订。

服装补全与展示约定：
costumes始终为JSON数组，保留id、name、description及内部团队/适用段关联。每个需要穿着服装的出镜人物至少提供一套具体服装；即使剧本未介绍服装，也必须结合职业身份、年代、地域、气候及实际场景合理设计，不能返回空数组或仅写“普通衣服”“未交代”。原文明示的穿着、特殊无服装状态或非人角色设定优先，不强加不适合角色的衣物。
每套服装name用简短名称；独立服装description交代可视化的上下装/内外层、主要颜色与材质、轮廓及必要鞋帽特征，具体充分但不罗列无关细节。已引用团队制服时沿用该制服基础设计，description只补必要个人差异，完整展示由统一服装加个人差异组成，不把制服重复改造。不因换场或即时情绪机械增加套数，不虚构换装事件，道具不混作衣服。
审核时，未提供应有服装或描述空泛属于内容问题；与职业、年代和环境相容的合理服装设计可以通过，不能仅因原文未逐件写明而拒绝。UI仅在人物下级“服装”字段展示每套名称、描述，ID与关联信息为内部引用，不需写入描述正文。
