# 分镜设计：定妆与服装连续性

适用动作：生成、审核、修订。

人物定妆沿用：大纲或分镜未明确描述服装、换装或伪装时，沿用人物现有定妆照对应服装和外貌，不补新套装、不要求重新定妆。character_extraction.costume_references提供已有定妆照对应的人物与服装ID。人物服装story_segment_ids仅作为明确穿着段落的选装线索，不是禁止跨段沿用的边界；不得仅因当前段未列入而留空或判上游缺口。单套服装直接沿用；多套优先承接前镜已选穿着，其次结合现有定妆关联和剧情明确选择，不能盲取首项。只有剧情明确改变穿着时才切换到匹配的已有服装；确需新造型却无资料时报告上游问题。服装ID必须属于对应人物。生成、修订及审核均遵循本条，审核不要因未写服装而要求额外日常服或换装。
