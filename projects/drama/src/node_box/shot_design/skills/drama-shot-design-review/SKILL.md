# 分镜设计：审核分镜设计

适用动作：审核。

只审核current_shots最新候选。审核分为阻断问题issues和非阻断建议suggestions；没有有据的阻断问题就passed，允许同时给建议。

适用动作：审核。

阻断边界：
只阻断重要剧情或明确逐字对白遗漏/被改写、事件先后或结果错误、同一时间位置/行动的真实矛盾、明确不可执行的镜头剪辑、引用/资产与定稿冲突、确实无法兼容的规则冲突。摄影丰富度、表演细腻度、风声/特效是否足够充分、配乐偏好及非必要字段详略放suggestions，不触发修订。合法空字段、无图、未绑定资产和shot长于15秒不阻断。
画外反光、从窗内看窗外、人物准备离开不等于已经换场；只有当前文字明确跨越独立背景或暗藏实际剪辑才报告。时间推进及环境结果在任一适当字段已明确表达即可，不要求重复写满action/camera/scene_changes/effects/audio。

适用动作：审核。

证据与对白：
每个阻断项提供本次资料的source_path/source_quote及当前候选的candidate_path/candidate_quote，引用必须逐字存在于对应路径，不能凭记忆换字或引用旧候选。对白只以大纲明确引用的原话为逐字依据；大纲中的间接概述可用间接声音描述，不要求臆造逐字对白。遗漏时candidate_quote可为空，但先检查当前完整相关内容，已经出现的原话不能再称遗漏。不确定时给建议或不报，不能捏造证据。

适用动作：审核。

复审顺序：
先逐项检查previous_issues，在previous_issue_checks中给出resolved/unresolved、最新候选的路径/原文和原因；再检查新增硬错误。修过某字段不等于已经解决，旧意见也不是事实。仍成立的旧问题必须以previous_issue_index关联并重新引用当前证据，已解决项不得换说法继续阻断。不要重开剧情润色或要求无关内容变动。

适用动作：审核。

职责与字段处理方法：
以本次故事段body与锚点为剧情依据，现有人物/场景/团队为制作依据。大纲自身缺口或资料冲突返回upstream_issue；本节点遗漏/技术错误返回content_issue；确实规则冲突返回rule_conflict。核对真实事实与可执行性，给最小必要修正，不重审剧情审美、不改写分镜。
