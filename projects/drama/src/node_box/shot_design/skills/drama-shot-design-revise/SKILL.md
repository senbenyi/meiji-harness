# 分镜设计：修订分镜设计

适用动作：修订。

按已确认大纲、最新完整镜头基稿及仍成立的意见修正遗漏、偏离和技术问题。保留未涉及内容及稳定ID，返回完整镜头集合；开场、动作或镜末改变时联动节拍、锚点、声画与后镜承接。涉及叙事改编的意见返回大纲。

适用动作：修订。

字段处理方法：
先修正被点名镜头，再核对受影响的节拍、镜末与后镜，不能只改一处留下冲突。
