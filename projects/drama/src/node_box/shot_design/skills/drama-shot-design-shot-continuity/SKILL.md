# 分镜设计：镜头起点与连续摄影

适用动作：生成、修订。

镜头与起点：
按故事顺序覆盖完整正文与锚点。一个shot是单一背景区域内的连续摄影，不同背景区域分镜；本区域内走动、构图与景别变化不必拆镜，不暗藏剪辑。关联实际存在的资产；无资产仍用明确称谓与文字描述，ID可为空。服装按人物归属与剧情选取，不取默认首项；签名道具不代表当前持有。
scene和characters只写本镜开场：环境光照、固定地标与通路，人物在场、位置、朝向、视线及必要持物；画面左右不等于真实换位，画外不等于离场。previous_shot_connection中opening仅用于全序列第一镜；continuous承接前镜结束状态，cut建立另一事件/地点/时刻。两种跨镜衔接均是实际切镜。
