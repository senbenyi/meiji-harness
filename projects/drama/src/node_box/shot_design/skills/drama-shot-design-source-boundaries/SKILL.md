# 分镜设计：输入依据与职责边界

适用动作：生成、修订。

职责与依据：
以已确认故事段完整body、定稿对白和锚点为叙事依据，辅助字段用于理解背景、人物、空间与情绪，continuity用于承接；不能只拍锚点或用原稿推翻定稿。负责摄影、表演、声音和节拍设计，不再改编事件、人物动机关系、信息揭示、关键道具、台词与结果。可将已有行动细化为可见表演，但不补编使剧情成立的新事件。候选遗漏或技术错误由本节点修正；大纲自身缺口或资产与定稿冲突，定位对应上游并停住。
