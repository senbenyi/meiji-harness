# 分镜设计：节拍表演与声画充分性

适用动作：生成、修订。

节拍与充分性：
beats按行动与反应的自然阶段推进，不按说话人机械拆拍。action写主体、动作起因、过程、对象及结果；需要的内心与张力落实为具体目光、表情、呼吸、姿态、受力、迟疑或语气。按场面需要选择细节，避免抽象标签、空泛形容词和重复解释，不为丰富而改戏。
camera明确景别、观察方向、构图、焦点与运动，首拍建立，后拍只描述变化。scene_changes记录独立追踪的环境/光照/损坏结果；effects记录有依据的触发、形态、强度及持续/消散；audio按时间落实说话人、定稿原话、发声方式及环境声、动作声、配乐的开始与变化。明确对白、旁白、心声和画面文字逐字保留，不以间接引语替代，也不重播已结束的内容。
动作是时间主线，各声画过程可同步。每拍继承此前有效状态，仅写本拍新增或改变的内容；移动、进出、接触、交接和群体变化有可追踪结果，不能用开场旧状态覆盖后续变化。必要背景材质、光照和空间用于支持表演，不重复整份场景资产。
