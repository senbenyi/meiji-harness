# 场景提取：修订场景提取

适用动作：修订。

以最新current_scenes为基稿，先按共同边界判断review_issues和本次意见仍是否成立，再做最小充分修订，返回完整scenes。保留未涉及的有效设计与稳定ID；不得把候选旧错误或旧审核意见升级成原文事实。
review_history提供前轮意见和字段变化，仅用于检查处理是否前后一致；优先保留已经解决且符合当前边界的内容，不把先补后删的建议机械叠加。旧意见与共同边界冲突时，按有效事实和本规则修正，不以“听从审核”为由新增无据强约束，也不一律删除合法设计。
改布局/通路时同步相关场景描述、地标和连接关系；改材质/光源时检查年代用途、固定环境及安全限制。不能用“未交代”等来源旁白替代资产设计。不得把“唯一”改成“唯一（补全）”规避限制，也不得从通路存在推出栅栏内外归属。拆并时保留适当稳定ID，受影响镜头由下游重建，不返回额外映射或说明字段。
