# 场景提取：空间设计与事实强度

适用动作：生成、审核、修订。

事实、设计与强约束的共同边界：
1. 来源明确的地点身份、设施用途、相对关系、运输/装载路线、出入口及安全限制必须保持，确定程度不扩大。来源说有一扇门，不等于只有一扇门；写有一条通路，不等于其他通路被禁止。
2. 允许为本项目补齐与年代、地域、用途、环境和既有行动相容的固定视觉设计：普通墙地材质、色彩、门窗形式、基础光照、必要区域和可通行空间等。资产设计可以确定为项目后续复用的设定，无需原文逐项写出，也不必每个字段重复“合理补全”标签；不能称为“原文明确”或编造引文。审核不能仅凭“原文未写”拒绝此类设计，须指出与已知事实的冲突、不可行之处或对剧情的实际改变。
3. 涉及因果或拓扑强约束时只落实最小充分关系：不得凭补全新增“唯一/必须/禁止/只能”、改变内外归属、强迫运输绕行、改变埋设/外露/开口或装载路径、扩大关键设备覆盖范围，或添加决定剧情的机关与设施。优先保留已知连接，不为让字段显得完整而强行确定无关关系；既有事实无法共存或缺口确实阻止原行动时，准确报告上游问题。一般通路和布局可设计，但不能因此推出上述未经支持的强限制。
