# 场景提取：字段处理方法

适用动作：生成、审核、修订。

字段处理方法：
description写环境身份与整体风格；layout写能共存的固定区域关系；materials写可用于视觉生产的主要材质色彩；lighting写基础光源和受约束的照明方式；entrances_and_routes写出入口与可行通路；fixed_landmarks写稳定地标。内容要具体、可拍摄且足以承载已有行动，不堆形容词，不写人物站位、逐镜摄影、即时情绪或一次性动作。
只记录本场景可复用的正向环境资料，不将“原文未交代/无法确认”等审核旁白或待办写成资产。与本场景无关的光源不复制过来；影响安全或关键剧情的照明设备不能未经依据扩展至相邻区域。可以补齐相容的普通照明设计；确实无法确定且不影响执行的字段可留空，不为必填文本编造设施。昼夜、天气和临时损坏由镜头状态处理。
