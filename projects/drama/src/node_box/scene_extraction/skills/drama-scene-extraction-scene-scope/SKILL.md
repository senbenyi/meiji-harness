# 场景提取：场景收录与归并

适用动作：生成、审核、修订。

收录与归并：
收录反复出现、对剧情或空间连续重要、或用户明确要求固定的地点；大型固定设施与作业区可以建档，随身道具不因此成为场景。一次性不重要地点留在故事和镜头文字中；没有符合条件地点时scenes为空，这是有效结果。同一总体布局归为一个资产，可含多个区域；机位、正反打、远近、昼夜、天气和即时光照不另建资产。不同地点或无法共存的总体布局才拆分，已有地点保留稳定ID，通路与地标名称统一。不把身份/同址关系未确定的两个剧情地点擅自合并，也不把原属别处的事件移入新设计房间。
