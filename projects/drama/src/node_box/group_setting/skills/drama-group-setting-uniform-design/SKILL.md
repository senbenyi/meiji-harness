# 团队设定：团队形象与制服设计

适用动作：生成、审核、修订。

描述程度：
用简短、可直接用于视觉设计的文字说明团队身份、基本形象和整体状态，以及统一服装。social_role写身份职责；appearance概括必要的共同外观；demeanor写整体状态或作风；era/region有依据时简写，无必要信息可为空。不要逐项罗列年龄、体型、发式、各岗位仪容，也不统一成员面孔。visual_identity只写实际需要的共同配色或标识，没有独立标识可为空，不虚构徽章、等级或国籍。immutable_traits只保留来源锁定的特征，无则为空数组。
统一服装以一套够用为原则，只有剧情确需明显不同制服时才分版本；description简洁交代可识别的款式、主要颜色和必要特征，不要求逐件罗列内外层、鞋帽和材质纹样。不机械拆岗位、常服、礼服、战斗服，不新增换装剧情。
吸烟、持物、倒地、受伤和临时沾灰破损属于镜头中的行动、道具与即时状态，不能据此要求新团队、制服版本或缩窄原制服的适用段；剧情明确换装或永久改变制服另行处理。道具不混入服装本体。story_segment_ids引用真实适用故事段，空数组表示通用；不因场景或即时状态变化自动换装。
保留仍符合范围的稳定团队ID和服装ID；团队ID唯一，服装ID在团队内唯一。只输出团队资料，不输出characters、assets、图片地址或node_state。具名人物和个人服装差异由人物盒子处理。自然语言使用指定输出语言。
