# 团队设定：审核团队设定

适用动作：审核。

只审核最新current_groups是否符合统一着装团队范围、必要描述是否清楚、服装是否与年代环境相容及ID/引用是否正确。不要求覆盖所有出场群体，不因缺群众、年龄体型分布、岗位外观差异、吸烟道具、受伤服装或无独立标识拒绝。符合范围且可识别即可通过；空groups在无合格团队时通过。存在问题给出具体字段、依据和最小修改，不以审核推动扩写。
