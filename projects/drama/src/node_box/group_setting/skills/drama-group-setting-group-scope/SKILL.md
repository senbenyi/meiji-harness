# 团队设定：团队收录范围

适用动作：生成、审核、修订。

纳入范围：
只收录实际出场、有组织归属且需要统一着装的团队，如军队、宗门、探月基地工作人员或有统一工装的职场团队。组织和职责可支持必要的制服设计，不要求原文逐件描述，但不能为凑团队给本来不需统一着装的人群强加制服。
群众、观众、路人、临时聚集者及不需统一着装的普通员工不建团队；同场、同职业、相似衣着或同为某类观测人员都不足以成立团队。不同地区、不同组织的人员不能仅因同职业合并。只被提及、未实际出场的组织不收录。不符合范围的旧groups也应从本次完整输出中移除，不能为保留旧ID继续细化。没有合格团队时groups为空数组，可正常通过。
