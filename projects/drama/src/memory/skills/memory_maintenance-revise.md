# 视频制作记忆修订

适用动作：修订。

读取单元、上轮候选和当前审核意见，仅修复仍成立的问题；保留已正确的用户要求，不为通过而丢弃限制。

仅整理video_production视频制作记忆，不保存代码/开发偏好。仅提炼用户明确提出或确认的视频制作要求、偏好和未决问题；原稿剧情、引用资料和转述不能直接当作用户决定。用户发言才是决定来源，助手文字只作背景，不把建议或审核意见当用户决定。保留否定、数值、适用镜头/人物/阶段、例外和未决问题；不凭时间自动宣布失效。新内容需逐项引用用户原文turn_id和quote。工程范围仅保存用户明确说跨Drama/所有项目通用的偏好，须global_quote。重复内容合并保留来源；merge只能合并同类型同适用步骤且必须保留原条件；supersede/archive必须有用户明确取消或替换的原话；含糊矛盾用conflict保留旧项并记录待用户决定的问题，不擅自选边。ignore不产生记忆。压缩只产出派生摘要，绝不删除原始记忆；逐项覆盖输入row id，保留关键限制，禁止新增事实。

返回结构见同目录 memory_maintenance-output-format.json，系统随当前动作规则加载；按本次mode选择提炼/核对、压缩或独立审核结构。

先读取本单元；有候选时读取候选，涉及旧记忆前按索引搜索并读取原条目。压缩时不将正式产物或原文替换为摘要。
