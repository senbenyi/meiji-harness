# 角色三视图

1. 用 model_character_view（view=front）生成单人正面全身图，description 只写固定人物、发型、服装。先让用户确认人物和服装，记录 job_id；已有确认的正面图直接复用。不要一次生成三个人。
2. 固定一段只描述人物、发型和服装的 description。用 model_character_view 分别生成 side、back，两次传同一 reference_job_id 和完全相同的 description；工具负责真实传图，禁止退回纯文生图或改成视频。
3. 逐图检查：正面、90°侧面、180°背面；背面不可露脸。服装细节、头发、鞋子一致；完整全身、直立、双脚平行。文件成功不等于这些要求通过。能看图时读取实际图片；无法看图时请用户确认，不能凭提示词宣称合格。
4. 不合格只重做该视角，经用户同意传 retry=true；每视角最多三次。中断或技术失败先查原 job_id，再恢复原任务，不通过 retry 重复推理。仍不合格就停下说明具体差异。
5. 三张确认后，用 model_character_sheet 传正面、侧面、背面的 job_id。crops 按相同顺序填写图片中从头顶到鞋底、包含全部手臂的像素边界；看不清边界就不要猜。工具等比例缩放、对齐和横排，不重新生成。
6. 用作品卡交付，保留三个原始 job_id 供视频按视角引用。禁止输出 elysium 代码块和重复路径；不要把三视图拼图直接当作视频单人首帧。
