# 短剧创作

按是否需要分段合成分流；一次生成无需合成用 creation-video。已有短剧单段沿用本技能及项目决定。

## 创作

- 未选模式时简述 AI 自动和导演引导，让用户选择；不自行切换。
- **AI 自动**：直接规划剧情、分镜、时长及 prompt，生成并合成，只补关键缺项。
- **导演引导**：提供电影叙事、悬疑、轻喜剧、奇幻或文艺等风格供选，也接受用户描述；提炼视觉、节奏和镜头偏好，确认风格后规划剧情，确认大纲后分镜制作。不承诺精确复刻。
- 多集先定主线、人物变化与分集转折，再细化当前集；已有剧本直接承接，单条不扩成整季，长篇按工具边界分批完成，不缩短目标。

## 制作与改稿

- 用 workflow_generate_video 的 shots；每镜给镜号、时长、完整人设、场景、动作和镜头运动，duration 之和等于目标总长。按当前 schema 提交，缺能力说明影响，不绕入口。
- independent/reference 用于独立切镜，continue 延续前镜动作，reuse 保留选定素材；reference 当前每类最多一个真实文件。缺资产不生成无关视频取图，生成与交付帧率分开处理。
- 未约定候选数时每镜一个，不无限重抽或自动审片。角色设定、真实参考和人工采用分开记录；文字、seed 不代表身份锁定，声音参考不保证口型。
- 技术失败排除原因后恢复原 job_id；人工改稿或换素材新建任务。未变镜头按返回的 shots[].path reuse，保留顺序、剪辑入点及目标时长。
- 前镜结尾变化时检查后续 continue 依赖；用户要求后镜不变时保留，优先调整前镜衔接。换风格保留已采用镜头，待改部分按新风格处理。
- 人工明确采用才记为认可，不把 not_run 说成通过。续做沿用已有故事、角色和进度；保存只记录故事/角色、风格、选片路径和待改项，不启动生成。
