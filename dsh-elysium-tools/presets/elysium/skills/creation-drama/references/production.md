# 分段制作、合成与改稿

- 用 workflow_generate_video 的 shots；镜头 duration 之和等于目标总长，保留镜号、人物和素材。按当前 schema 执行；不支持时报告缺口，不缩短任务或绕过入口。
- independent/reference 用于独立切镜，continue 延续前镜动作，reuse 使用已选素材。参考当前每类最多一个文件；生成帧率与交付帧率分开处理。
- 每镜 prompt 包含完整公共人设、场景和本镜变化，引用真实路径。缺必要资产时说明影响，不生成无关视频绕路取图。
- 提交前核对参数，不自动审片。未约定候选数时每镜一个，不无限重抽。技术失败排除原因后恢复原 job_id；人工改稿或换素材创建新任务。
- 未变镜头用返回的 shots[].path 以 reuse 保留；前镜结尾变化需检查后续 continue 依赖。用户明确保留后镜时不静默重做，不擅自改变总长。
- 人工说"采用/通过"才记录认可；不把 not_run 说成通过。
- 合片支持顺序、入点与时长。
