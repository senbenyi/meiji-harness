# 制作节点规则

节点顺序见 [制作工作流](制作工作流.md)。本文写每个 AI 节点的前置条件、生成规则、返回结构和审核规则。文本节点的审核返回 `通过` 和 `原因`：通过时原因为空，不通过时写明问题。

## 项目摘要（`project-summary`）

**前置条件：**

1. 项目剧本正文非空。

**生成规则：**

1. 根据完整剧本写项目级简短摘要。
2. 只保留剧本已经写出的人物、事件和结局。
3. 剧本没有写明的动机、后传、画幅和总时长不写入摘要。

**返回结构：**

一段项目摘要。里面只写剧本已经写出的人物、事件和结局。

**审核规则：**

1. 摘要中的人物和事件都能在剧本中找到依据。
2. 摘要没有新增或改变剧情。
3. 表述比剧本短。

## 剧本重要角色（`project-characters`）

**前置条件：**

1. 项目剧本正文非空。

**生成规则：**

1. 按重要程度提取角色：主角、形成对比或施压的角色、剧情必需的配角。
2. 每个角色写明名字、定位、年龄段、身材、发型、服饰颜色、签名道具、不可改特征。
3. 每套服装写明名称、颜色、材质和随服装出现的道具。
4. 沿用项目角色库中已有角色；同一人只保留一个身份。
5. 只返回本次新增或变更。

**返回结构：**

```json
{
  "角色": [
    {
      "名字": "",
      "定位": "",
      "年龄段": "",
      "身材": "",
      "发型": "",
      "服饰颜色": "",
      "签名道具": "",
      "不可改特征": "",
      "服装": [
        { "名称": "", "颜色": "", "材质": "", "道具": "" }
      ]
    }
  ]
}
```

只列本次新增或变更的角色。没有变更时，`角色` 为空数组。同一人只出现一次，用名字对应角色库里已有的人。

**审核规则：**

1. 每个角色的身份和资料都能在剧本中找到依据。
2. 同一角色没有被拆成两人。
3. 不可改特征、签名道具和服装没有超出剧本依据。
4. 只审核本次变更。

## 定妆照

**前置条件：**

1. 目标角色存在，且这一套服装已经写在该角色资料中。
2. 人物资料足以确定身份、面相和体型。
3. 用户参考图可选。

**生成规则：**

1. 按这一套服装和该角色的人物资料生成一张定妆照。
2. 同一角色有多套服装时，每套各生成一张。
3. 主画面是该角色穿着这套服装的单一 3/4 视角，脸、体型和服装同时可见。
4. 表情、服装颜色、材质和签名道具与资料一致。
5. 有用户参考图时，用它确定面相和体型；服装以资料中的这套服装为准。
6. 同一角色的各套定妆照保持同一张脸、同一体型和同一不可改特征。
7. 画面不印角色名、服装名、说明文字和分镜标记。

**返回结构：**

这一套服装的一张定妆照。单一 3/4 视角，脸、体型和这套服装同时可见。不返回 JSON，画面上不写角色名、服装名或说明。

**审核规则：**

1. 画面是该角色穿着资料中的这一套服装。
2. 面相、体型、发型和不可改特征与人物资料一致。
3. 有用户参考图时，面相和体型与参考图一致，服装仍以这套服装资料为准。
4. 没有换成另一名角色或另一套服装。
5. 画面中没有说明文字、角色名贴片和多视图拼图。
6. 图片可读取、可解码。

## 展示摘要（`episode-summary`）

**前置条件：**

1. 本集剧情非空。

**生成规则：**

1. 只依据本集剧情提取简短展示摘要。
2. 不补充本集剧情没有写出的情节。
3. 不写入后续镜头或角色安排。

**返回结构：**

一段展示摘要。只写本集剧情里已经发生的事件。

**审核规则：**

1. 摘要中的事件都能在本集剧情中找到依据。
2. 摘要没有新增或修改剧情。
3. 表述比本集剧情短。

## 故事大纲（`outline`）

**前置条件：**

1. 剧本模式要求本集剧情非空。
2. 自由创作模式要求项目创作方向非空。

**生成规则：**

1. 剧本模式按本集剧情写成有序故事小段，覆盖其中的事件和因果。
2. 剧本模式不补充剧情没有写出的动机、缺陷、世界规则和台词。
3. 自由创作写明主角想要什么、需要什么、缺陷是什么，以及本集生效的世界规则。
4. 自由创作按因果关系排列故事小段，并标出需要在后面回收的情绪锚点。
5. 自由创作只在用户明确要求台词时写入台词节拍。
6. 各段时长合计等于本集参考时长。

**返回结构：**

剧本模式：

```json
{
  "小段": [
    { "序号": 1, "时长秒": 0, "事件": "", "因果": "" }
  ]
}
```

自由创作：

```json
{
  "想要": "",
  "需要": "",
  "缺陷": "",
  "世界规则": "",
  "小段": [
    { "序号": 1, "时长秒": 0, "因果": "", "情绪锚点": "", "台词节拍": "" }
  ]
}
```

两种模式的 `时长秒` 都是正数，合计等于本集参考时长。自由创作里，用户没有要求台词时不写 `台词节拍`。

**审核规则：**

1. 剧本模式的事实、因果和覆盖范围与本集剧情一致。
2. 自由创作中，危机来自主角缺陷，巧合没有直接解决问题。
3. 自由创作的结局回收了前面写出的情绪锚点。
4. 自由创作的台词在改变关系。
5. 各段时长合计等于本集参考时长，且每段都能按该时长呈现。

## 镜头表（`shots`）

一次生成本集全部镜头。这里只规划每一镜的内容、时间和跨镜关系，不写逐秒指令。逐秒动作留给后面的每秒分镜，每次只做一镜。

**前置条件：**

1. 本集故事大纲已有效生成。

**生成规则：**

1. 每个故事小段先作为剧情锚点，再拆成镜头。
2. 每镜 4–15 秒。更长就拆开。短于 4 秒的节拍并入相邻镜头。
3. 镜头总时长在本集参考时长 ±30 秒内。
4. `正文` 只写本镜事件：谁在画面里、做了什么、结果是什么。不写每一秒的动作、运镜和站位。
5. 每镜写连续性衔接：如何承接上一镜的结束画面、道具位置、眼神、姿态、声桥或情绪，以及如何为下一镜开场做准备。
6. 每镜写参考锚点：固定地标及其画面位置，每个出镜角色的画面位置、朝向、初始姿态和服装，上一镜有而本镜没有的角色及其离场原因，以及光位基线。
7. 每镜用中文写一个钩子，只从这八个里选：视觉笑点（靠画面好笑）、反转（结果和预期相反）、悬念（危险或疑问先悬着）、温情（柔和的情感停顿）、追逐（追、逃或赶时间）、揭示（揭开之前没看见的信息）、回扣（呼应前面的画面、台词或道具）、表情拍（重点是表情变化）。
8. 每镜定一个景别。景别在特写、大特写和其他景别之间交替。
9. 每镜写音频安排：有没有旁白、对白和关键音效，谁在说话。不写到某一秒。用户没有明确要求语言时，不锁定对白语言。
10. 单镜有动作或对白的重要角色不超过 3 人。
11. 同一场景的相邻镜头，固定地标和光位要么保持一致，要么写明如何变化。
12. 已经离场的角色至少再记录一镜。连续两镜明确不在场后，不再记录。
13. 眼神、人物位置、道具状态或光位发生翻转时，在连续性衔接里写明这是硬切或时间跳跃。
14. 出镜角色和服装使用角色库中的名字。

**返回结构：**

```json
{
  "镜头": [
    {
      "标题": "",
      "编号": "S01",
      "参考时长": 12,
      "景别": "",
      "钩子": "视觉笑点",
      "正文": "",
      "连续性衔接": "",
      "参考锚点": {
        "固定地标": "",
        "人物位置": "",
        "离场角色": "",
        "光位": ""
      },
      "音频安排": {
        "旁白": "",
        "对白": "",
        "音效": ""
      }
    }
  ]
}
```

`参考时长` 是 4–15 的整数秒。`钩子` 只用规定的八个词之一。没有旁白、对白或音效时，对应项为空字符串。

**审核规则：**

1. 每镜都有钩子。每连续 3 镜至少 1 镜是揭示、反转或回扣。
2. 开场镜和收尾镜的钩子是视觉笑点、反转、揭示、悬念、温情之一。
3. 没有镜头短于 4 秒或超过 15 秒。
4. 镜头总时长在本集参考时长 ±30 秒内。
5. 没有镜头超过 3 个有动作或对白的重要角色。
6. 同场景相邻镜头的地标和光位要么继承，要么有明确变化说明。
7. 按连续性衔接逐镜阅读，没有一镜从与上一镜结尾矛盾的状态开始。
8. 景别在特写、大特写和其他景别之间交替。
9. 人物和服装与角色库一致，镜头顺序覆盖各个故事小段。
10. 正文、衔接、锚点和音频安排停留在整镜层面，没有拆成逐秒动作。
11. 编号结构和时长由程序校验。审核不重复判定这两项。
12. 未通过的镜头表不能作为每秒分镜的输入。

## 每秒分镜（`seconds`）

一次只生成当前这一镜。镜头的时长、事件、景别、钩子、衔接、锚点和音频安排以镜头表为准，这里只把它们落到每一秒。

**前置条件：**

1. 目标镜头属于本集。
2. 本集镜头表已有效生成，且这一镜的时长、正文、景别、钩子、连续性衔接、参考锚点和音频安排都已写明。

**生成规则：**

1. 只为当前镜头写逐秒指令，从 0 秒覆盖到该镜最后一帧，中间不留空隙。
2. 不改这一镜的时长、边界、事件、景别、钩子、出镜人物、服装、地标和光位。
3. 第一秒从本镜连续性衔接写明的开场状态开始。最后一秒的交接，落到镜头表为下一镜准备的开场；已经是最后一镜时，落到本镜结尾。
4. 普通秒用 `0–1s`、`1–2s`。只有该秒本身是这一镜的钩子时，才追加 `2.0–2.5s` 这类亚秒节拍。
5. 每一秒都写动作、姿态和表情，包括身体、手持道具、眼神和表情变化。
6. 每一秒都写镜头运动：推、拉、摇、倾、横移、升降、环绕、跟拍、固定或手持晃动。运动留在镜头表已定的景别里。需要时写幅度和速度。
7. 每一秒都写空间位置，并落在参考锚点已写的地标和人物位置上。不新增地标，不把人物改到锚点以外的位置。
8. 每一秒都写音频线索。只把本镜音频安排里的旁白、对白和音效落到具体秒，不新增镜头表没有的台词。没有声音时写明无声。
9. 旁白所在的秒写明说话人嘴唇闭合。出镜对白所在的秒写明张嘴，并写眼神和身体动作。
10. 每一秒都写交给下一秒的状态。
11. 每一秒一格。只有钩子所在秒追加了亚秒节拍时，才可以多一格。
12. 角色名、服装和地标与镜头表使用同一名称。
13. 每一秒都写明身体、镜头或道具的具体变化。

**返回结构：**

```json
{
  "分镜": [
    {
      "时段": "0–1s",
      "动作": "",
      "镜头": "",
      "空间": "",
      "音频": "",
      "交接": ""
    }
  ]
}
```

从 `0–1s` 起逐秒覆盖到镜尾，中间不留空隙。每一秒一格。只有这一镜的钩子所在秒，才可以再加一格，时段写成 `2.0–2.5s` 这样。

`动作` 写身体、手持道具、姿态、眼神和表情。`镜头` 写推、拉、摇、倾、横移、升降、环绕、跟拍、固定或手持晃动，需要时写幅度和速度。`空间` 写人物位置、手持物和地标位置。`音频` 写这一秒的旁白、对白、音效、呼吸或无声，并写嘴部开合。`交接` 写交给下一秒的状态。

**审核规则：**

1. 从 0 秒到镜尾每一秒都有指令，没有时间空隙。覆盖时长等于镜头表的参考时长。
2. 每一秒都含动作或姿态或表情、镜头、空间、音频、交接这五项。
3. 事件、人物、服装、景别、钩子、地标、光位和台词与镜头表一致。没有改时长，没有拆镜或并镜。
4. 第一秒接得上本镜连续性衔接。人物和地标落在参考锚点写明的位置。
5. 动作能在该秒内做完，道具和人物位置能交到下一秒。
6. 说话的秒写明嘴部开合。离屏旁白为闭，出镜对白为开。
7. 没有新增镜头表中不存在的人物、服装、地标、事件和台词。

## 文本提示词（`storyboard`）

**前置条件：**

1. 目标镜头属于本集。
2. 本集镜头表和该镜头每秒分镜均已有效生成。
3. 镜头写了出镜角色时，对应服装的定妆照已有效生成。没有指定服装时，使用默认服装的定妆照。
4. 不是首镜时，上一镜尾帧已有效生成。

**生成规则：**

1. 只转写该镜每秒分镜，不改时间线、事件、角色、服装和时长。
2. 有出镜角色时使用全参考，六段顺序固定：`subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`。
3. 定妆照定义为 `<Subject N>`。它表示人物身份和这套服装，不表示这一镜的首帧。
4. 没有出镜角色且是首镜时，使用文生视频。三段顺序固定：`integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`。
5. 不是首镜时，上一镜尾帧对齐本镜 0.00 秒。有定妆照时，把这个对齐写进同一份全参考提示的 `<Picture N>`。没有定妆照时，使用首帧模式，第一行声明该图对齐 0.00 秒，后面仍是上述三段。
6. 一份提示只使用一种结构。
7. 描述总时长等于该镜时长。每秒分镜没有写切镜时，提示里不增加切点。有切镜时，切点严格递增并落在该时长之内，第一段不加时间戳。
8. 运镜写成完整英文动作，包含运动类型。幅度和速度只在每秒分镜写了的时候才写。
9. 说话人使用跨镜稳定的 `(S1)`、`(S2)`。对白和歌词放在 `<d>` 内并保留原文。旁白写明对应角色嘴唇闭合。
10. 画面上真实可见的文字保留原文。
11. `overall_soundscape` 用 1–4 句概括环境声、动作声和非语言人声，不重复对白。`non_diegetic_music` 用 1–3 句写角色听不见的配乐，只写乐器、速度、节奏和强弱变化。整段无声时，声景写 `N/A`。
12. 画面描述使用英文。对白、歌词和画面文字保留原语言。
13. 用具体的构图、主体、环境、动作、镜头和声音写提示。
14. 同一参考物只用一个标签，并且前后含义不变。`summary` 和 `retention_analysis` 不新增标签。
15. 提示中的画面描述不包含角色名贴片、时间码、钩子名称和分镜标记。

**返回结构：**

一份提示只使用下面一种。画面描述用英文。对白、歌词和画面文字保留原文，对白放在 `<d>` 里，说话人用跨镜稳定的 `(S1)`、`(S2)`。没有切镜时不写切点。`overall_soundscape` 用 1–4 句写环境声、动作声和非语言人声，不重复对白；整段无声时写 `N/A`。`non_diegetic_music` 用 1–3 句写乐器、速度、节奏和强弱。

有出镜角色：

```text
subject_definitions: <Subject 1> is this character in this costume. It is not the first frame.
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

不是首镜时，在同一份里增加 `<Picture 1>`，对齐本镜 0.00 秒，来源是上一镜尾帧。

没有出镜角色，并且是首镜：

```text
integrated_multimodal_description:
overall_soundscape:
non_diegetic_music:
```

不是首镜，并且没有定妆照：

```text
<Picture 1> aligns with 0.00 seconds. It is the previous shot's last frame.

integrated_multimodal_description:
overall_soundscape:
non_diegetic_music:
```

**审核规则：**

1. 字段名、段序和标签与本镜实际使用的那一种结构一致。
2. 描述总时长等于该镜时长，切点没有超出或倒退。
3. 每个参考标签都有定义，并且前后含义不变。
4. 定妆照被写成人物主体。上一镜尾帧只在不是首镜时写成 0.00 秒的帧锚点。
5. 对白、歌词和画面文字没有被翻译或改写。
6. 时间线、事件、角色、服装和素材与每秒分镜一致。
7. 提示中的画面描述没有角色名贴片、时间码、钩子名称和分镜标记。

## 视频（`video`）

**前置条件：**

1. 目标镜头属于本集。
2. 该镜头文本提示词已有效生成。
3. 文本提示词引用了定妆照时，该定妆照已有效生成。
4. 文本提示词引用了上一镜尾帧时，该尾帧已有效生成。

**生成规则：**

1. 按已审核的文本提示词生成这一镜，保留事件、顺序、结果和素材编号。
