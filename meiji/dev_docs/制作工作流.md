# 制作工作流

本文只写从剧本到成片的顺序，以及每个节点任务怎么轮次执行。各节点的前置条件、生成规则、返回结构和审核规则在 [制作节点规则](制作节点规则.md)。字段和状态以 [项目数据结构](项目数据结构.md) 为准；任务轮次和终态以 [任务步骤](任务步骤.md) 为准。

## 总顺序

```text
剧本（原始资料）
  → 拆分剧集（剧本模式）
  → 提取人物 → 按服装和人物资料生成定妆照
  → 各集：故事大纲 → 镜头表 → 逐镜制作 → 合片
```

逐镜制作按镜头顺序执行：每秒分镜 → 文本提示词 → 视频 → 尾帧。后一镜的视频使用前一镜尾帧作为开头画面。项目摘要和展示摘要不挡住主流程。

## 节点

每个节点对应一个任务。调用模型的节点，其前置条件、生成规则、返回结构和审核规则见 [制作节点规则](制作节点规则.md)。

### 项目

1. 剧本重要角色
2. 定妆照
3. 项目摘要，不挡住主流程

### 剧集

1. 故事大纲
2. 镜头表
3. 合片
4. 展示摘要，不挡住主流程

### 镜头

1. 每秒分镜
2. 文本提示词
3. 视频
4. 尾帧

## 任务步骤

1. 项目摘要、剧本重要角色、展示摘要、故事大纲、镜头表、每秒分镜、文本提示词：前置检查 → 生成 → 审核。未通过时带原因重新生成，再审核。
2. 定妆照、视频：前置检查 → 生成 → 审核。未通过时带原因重新生成，再审核。
3. 尾帧：前置检查 → 从该镜视频截取尾帧 → 确认截取结果可读取。不调用模型。
4. 合片：前置检查 → 按镜头顺序拼接 → 确认合片文件可读取。不调用模型。

## 任务轮次

所有节点任务先运行前置检查，再生成，再审核。审核未通过时，将审核原因带入重新生成，再审核。这一轮可以重复。一个任务内部最多自动修订两轮；任务最终未通过后，用户再次发起重新生成会创建新任务，因此可以跨任务继续多轮，直到通过。

各节点的前置条件、生成规则、返回结构和审核规则见 [制作节点规则](制作节点规则.md)。节点修改后哪些下游标为过期，见下一章。完整任务状态、修订轮数及终态行为见 [任务步骤](任务步骤.md)。

## 过期

节点修改并成为当前有效结果后，下表中的下游如果已经生成，标为已过期，内容保留。过期继续向更下游传递。未生成、未通过、失败、已取消的节点保持原状态。项目摘要、展示摘要、合片没有下游。

| 修改的节点 | 标为过期的下游 |
|---|---|
| 剧本重要角色 | 人物资料变化时，该角色的全部定妆照。只有某套服装资料变化时，该套定妆照 |
| 定妆照 | 引用这张图的文本提示词 |
| 故事大纲 | 该集镜头表 |
| 镜头表 | 该集每个镜头的每秒分镜 |
| 每秒分镜 | 该镜文本提示词 |
| 文本提示词 | 该镜视频 |
| 视频 | 该镜尾帧，以及本集合片 |
| 尾帧 | 下一镜视频 |
