# 制作工作流

本文只写从剧本到成片的顺序，以及每个节点任务怎么轮次执行。各节点的前置条件、生成规则和审核规则在 [制作节点规则](制作节点规则.md)。字段和状态以 [项目数据结构](项目数据结构.md) 为准；任务轮次和终态以 [任务步骤](任务步骤.md) 为准。

## 总顺序

```text
剧本（原始资料）
  → 拆分剧集（剧本模式）
  → 提取人物 → 按服装和人物资料生成定妆照
  → 各集：故事大纲 → 镜头表 → 逐镜制作 → 合片
```

定妆照按一套服装一张图生成。同一角色有多套服装时，每套各一张；镜头没指定服装时用默认服装那张。

逐镜制作按镜头顺序执行：每秒分镜 → 文本提示词 → 视频 → 尾帧；后一镜的视频还需要前一镜尾帧。项目摘要和展示摘要是独立节点，不挡住主流程。

## 任务轮次

所有节点任务先运行前置检查，再生成，再审核。审核未通过时，将审核原因带入重新生成，再审核。这一轮可以重复。一个任务内部最多自动修订两轮；任务最终未通过后，用户再次发起重新生成会创建新任务，因此可以跨任务继续多轮，直到通过。

各节点是否调用模型审核，见 [制作节点规则](制作节点规则.md)。完整任务状态、修订轮数及终态行为见 [任务步骤](任务步骤.md)。
