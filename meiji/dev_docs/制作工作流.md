# 制作工作流

本文只写从剧本到成片的顺序，以及每个节点任务怎么轮次执行。各节点的前置条件、生成规则、返回结构和审核规则在 [制作节点规则](制作节点规则.md)。字段和状态以 [项目数据结构](项目数据结构.md) 为准；任务轮次和终态以 [任务步骤](任务步骤.md) 为准。

## 总顺序

```text
剧本（资料）
  → 拆分剧集（AI，剧本模式）
    → 提取人物（AI） → 定妆照（AI）
  → 各集：故事大纲（AI） → 镜头表（AI） → 逐镜制作 → 合片（程序）
```

逐镜制作按镜头顺序执行：每秒分镜（AI） → 文生视频提示词（AI） → 首尾帧或多模态提示词（程序） → 视频任务（AI生成视频 → 程序截取并校验尾帧）。视频与尾帧属于同一个镜头节点、同一个视频任务；尾帧不是独立节点或任务。后一镜的视频使用前一镜视频任务生成的尾帧作为开头画面。项目摘要和展示摘要不挡住主流程。

## 节点与任务

一个业务节点对应一个任务。括号标明任务由模型完成还是由程序完成；节点内部可以包含生成后的程序步骤。调用模型的节点，其前置条件、生成规则、返回结构和审核规则见 [制作节点规则](制作节点规则.md)。

### 项目

1. 剧本重要角色（AI）
2. 定妆照（AI）
3. 项目摘要（AI），不挡住主流程

### 剧集

1. 故事大纲（AI）
2. 镜头表（AI）
3. 合片（程序）
4. 展示摘要（AI），不挡住主流程

### 镜头

1. 每秒分镜（AI）
2. 文生视频提示词（AI）
3. 首尾帧提示词或多模态提示词（程序）
4. 视频（AI；生成后由程序截取尾帧，作为视频任务的后置步骤）

视频生成和尾帧截取属于同一个视频任务：两个操作都成功后，才保存该镜视频及其尾帧并完成任务；尾帧用于下一镜的视频输入。
