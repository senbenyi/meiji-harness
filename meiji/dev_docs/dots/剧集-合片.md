# 剧集-合片（`assembly`，程序）

**固定属性：**

- 误差时长：无
- 重试轮次：0

按镜头顺序拼接本集视频。不调用模型。无程序审核，也无 AI 审核。

**步骤：**

1. 前置条件检查（程序）。
2. 按镜头顺序拼接（程序）。
3. 数据保存同步。
4. 下游节点 hash 检查。

**前置条件：**

1. 本集有镜头，每个镜头的视频均为 `generated`，结构有效，保存的依赖 hash 与当前资料一致。
2. 每个视频地址属于当前项目，文件存在、可读取，并通过完整解码检查。缺失、损坏或地址越界记为前置失败，不进入拼接，不覆盖旧合片。

**执行规则：**

1. 按镜头 `sequence` 顺序拼接。
2. 检查合片结果可读取、可完整解码；失败保留旧合片。
3. 不调用模型，不自动修订。输入检查属于前置步骤，输出检查属于生成步骤。

**生成返回结构：**

本集的一条合片。

**程序审核：**

不适用。

**AI审核：**

不适用。

**审核返回结构：**

不适用。

**依赖资料：**

- 本集各镜按 `sequence` 排列的 `video.address`、已保存的 `video.node_state.dependency_hash`，不以递归重算出的值替代。

**数据保存同步：**

成功后把地址写入 `episodes[].assembly.address`，状态为 `generated`、原因清空，保存本次依赖 hash。

`episodes[].actual_duration_seconds` 始终为当前正式镜头的 `actual_duration_seconds` 之和。镜头视频生成、导入或镜头集合变化后重新累计，不从参考时长推算；合片实测时长只记在本次任务步骤结果中，不覆盖该累计字段。人工导入整集合片也不反推或改写各镜头实际时长。

**下游节点 hash 检查：**

没有下游。输入视频或其顺序改变、必需上游失效时，本合片可以标为过期并保留旧媒体；合片成功不会使其他节点过期。
