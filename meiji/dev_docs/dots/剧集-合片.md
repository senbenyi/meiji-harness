# 剧集-合片（`assembly`，程序）

按镜头顺序拼接本集视频。不调用模型，也不进行模型审核。

**前置条件：**

1. 本集每个镜头的视频都已有效生成，且文件可读取。

**执行规则：**

1. 按镜头序号拼接。
2. 确认合片文件可读取。

**生成返回结构：**

本集的一条合片。

**审核返回结构：**

不适用。本节点不进行模型审核。

**依赖资料：**

- 本集各镜按 `序号` 排列的 `video.address`、`video.node_state.dependency_hash`。

**步骤：**

1. 前置条件检查（程序）。
2. 按镜头顺序拼接（程序）。
3. 数据保存同步。
4. 下游节点 hash 检查。

**数据保存同步：**

把地址写入 `episodes[].assembly.address`，并同步到本地项目 JSON。

**下游节点 hash 检查：**

没有下游。保存后不标过期。
