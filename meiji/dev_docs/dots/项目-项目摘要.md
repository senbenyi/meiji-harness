# 项目-项目摘要（`project-summary`，AI）

**步骤：**

1. 前置条件检查（程序）。
2. 生成（AI）。
3. 程序审核。本节点不适用，跳过。
4. AI 审核。未通过时，带审核意见和原内容重新生成（AI），再做 AI 审核。
5. 数据保存同步。
6. 下游节点 hash 检查。

**前置条件：**

1. 项目剧本正文非空。

**生成规则：**

1. 根据完整剧本写项目级简短摘要。
2. 只保留剧本已经写出的人物、事件和结局。
3. 剧本没有写明的动机、后传、画幅和总时长不写入摘要。

**生成返回结构：**

一段项目摘要。里面只写剧本已经写出的人物、事件和结局。

**程序审核：**

不适用。

**AI审核：**

1. 摘要中的人物和事件都能在剧本中找到依据。
2. 摘要没有新增或改变剧情。
3. 表述比剧本短。

**审核返回结构：**

```json
{
  "是否通过": true,
  "原因": ""
}
```

`是否通过` 为 `true` 或 `false`。为 `true` 时原因为空，为 `false` 时写明问题。

**依赖资料：**

- `script.body`。剧本不是节点。

**数据保存同步：**

AI 审核通过后，把摘要写入 `project_summary.body`，并同步到本地项目 JSON。

**下游节点 hash 检查：**

没有下游。保存后不标过期。
