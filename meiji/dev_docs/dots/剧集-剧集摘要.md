# 剧集-剧集摘要（`episode-summary`，AI）

**前置条件：**

1. 本集剧情非空。

**生成规则：**

1. 只依据本集剧情提取简短剧集摘要。
2. 不补充本集剧情没有写出的情节。
3. 不写入后续镜头或角色安排。

**生成返回结构：**

一段剧集摘要。只写本集剧情里已经发生的事件。

**审核规则：**

1. 摘要中的事件都能在本集剧情中找到依据。
2. 摘要没有新增或修改剧情。
3. 表述比本集剧情短。

**审核返回结构：**

```json
{
  "是否通过": true,
  "原因": ""
}
```

`是否通过` 为 `true` 或 `false`。为 `true` 时原因为空，为 `false` 时写明问题。

**依赖资料：**

- `剧集[].剧情`。剧情不是节点。

**步骤：**

1. 前置条件检查（程序）。
2. 生成（AI）。
3. 审核（AI）。未通过时，带审核意见和原内容重新生成（AI），再审核（AI）。
4. 数据保存同步。
5. 下游节点 hash 检查。

**数据保存同步：**

审核通过后，把摘要写入 `剧集[].摘要.正文`，并同步到本地项目 JSON。

**下游节点 hash 检查：**

没有下游。保存后不标过期。
