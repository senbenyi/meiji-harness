# 项目-角色定妆照（AI）

**固定属性：**

- 误差时长：无
- 重试轮次：0

本任务生成一张定妆照并写入 `定妆照` 数组。角色有明确服装时，本任务对应一套服装和一个 `服装id`；角色没有明确服装时，本任务生成一张未绑定服装的定妆照，`costume_id` 为空。图片生成接口一次请求只返回一张图，`n` 大于 1 时拒绝。本任务只发一次请求，只接收这一张。

**步骤：**

1. 前置条件检查（程序）。
2. 生成这一张（AI）。一次图片请求，只接收响应中的这一张。
3. 数据保存同步。
4. 下游节点 hash 检查。

**前置条件：**

1. 目标角色存在，且该角色的角色图已有效生成。
2. 有明确服装时，目标服装必须已写在该角色资料中；没有明确服装且 `costumes` 为空数组时，允许创建一张未绑定服装的定妆照任务。
3. 角色图是本节点固定且唯一的图像参考；不得改用用户参考图或其他图片。

**生成规则：**

1. 一次图片生成请求只生成一张定妆照，不在这次请求里生成其他服装。
2. 有明确服装时，按该套服装生成单一 3/4 视角，脸、体型和服装同时可见；服装颜色、材质和道具严格遵循该套服装资料。
3. `costumes` 为空时，依据角色的年龄段、定位、身材、发型、签名道具、不可改特征及角色图生成单一 3/4 视角定妆照；不要求或编造具体服装名称、颜色、材质、款式或道具，也不把图中生成的服装补写进角色资料。
4. 以角色图为固定图像参考；角色身份、脸、体型和不可改特征与角色图一致。所有定妆照保持同一张脸、同一体型和同一不可改特征。
5. 画面不印角色名、服装名、说明文字和分镜标记。

**生成返回结构：**

一次请求返回一张定妆照，不返回 JSON，画面上不写角色名、服装名或说明。响应里只取这一张。

**程序审核：**

不适用。

**AI审核：**

不适用。

**审核返回结构：**

不适用。

**依赖资料：**

- 有明确服装时读取该套 `服装` 的 `name`、`color`、`material`、`props`；`costumes` 为空时不读取或要求服装资料。
- 同一角色的 `名字`、`身材`、`发型`、`不可改特征`。
- 该角色 `character_image.address`、`character_image.node_state.dependency_hash`。

**数据保存同步：**

生成完成后，只写入 `character_library.characters[].costume_images[]` 中本任务对应的一条，并同步到本地项目 JSON。有明确服装时填写对应 `costume_id`；`costumes` 为空时添加 `costume_id: ""` 的唯一未绑定定妆照条目。不得为未绑定定妆照新建或补写服装资料。

**下游节点 hash 检查：**

影响使用这张定妆照的多模态提示词。多模态提示词按自己的依赖资料读取该条 `costume_images.address`、`costume_images.node_state.dependency_hash`。文生视频提示词不依赖定妆照，不检查。下游被标为已过期后，再检查它的下游。
