# 项目-角色定妆照（AI）

本任务只生成一套服装的一张定妆照，写入 `定妆照` 数组里对应该 `服装id` 的一条。图片生成接口一次请求只返回一张图，`n` 大于 1 时拒绝。本任务只发一次请求，只接收这一张。

**前置条件：**

1. 目标角色存在，且这一套服装已经写在该角色资料中。
2. 该角色的角色图已有效生成。
3. 角色图是本节点固定且唯一的图像参考；不得改用用户参考图或其他图片。

**生成规则：**

1. 一次图片生成请求只生成这一套服装的一张定妆照。不在这次请求里生成其他服装。
2. 这一张是该角色穿着这套服装的单一 3/4 视角，脸、体型和服装同时可见。体型与角色图一致。
3. 表情、服装颜色、材质和签名道具与资料一致。
4. 以角色图为参考生成该角色穿着这套服装的照片；角色身份、脸、体型和不可改特征与角色图一致，服装严格采用资料中的这套服装。
5. 同一角色的各张定妆照与角色图保持同一张脸、同一体型和同一不可改特征。
6. 画面不印角色名、服装名、说明文字和分镜标记。

**生成返回结构：**

一次请求返回这一套服装的一张定妆照，不返回 JSON，画面上不写角色名、服装名或说明。响应里只取这一张。

**审核返回结构：**

不适用。本节点不进行模型审核。

**依赖资料：**

- 该套 `服装` 的 `名称`、`颜色`、`材质`、`道具`。
- 同一角色的 `名字`、`身材`、`发型`、`不可改特征`。
- 该角色 `角色图.地址`、`角色图.依赖hash`。

**步骤：**

1. 前置条件检查（程序）。
2. 生成这一张（AI）。一次图片请求，只接收响应中的这一张。
3. 数据保存同步。
4. 下游节点 hash 检查。

**数据保存同步：**

生成完成后，只写入 `角色库.角色[].定妆照[]` 中本任务对应 `服装id` 的那一条的 `地址`，并同步到本地项目 JSON。没有对应条目时按这套服装补一条。

**下游节点 hash 检查：**

影响使用这张定妆照的多模态提示词。多模态提示词按自己的依赖资料读取该条 `定妆照.地址`、`定妆照.依赖hash`。文生视频提示词不依赖定妆照，不检查。下游被标为已过期后，再检查它的下游。
