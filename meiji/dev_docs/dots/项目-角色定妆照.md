# 项目-角色定妆照

程序审核：无。AI 审核：无。重试轮次：0。

人物提取只写资料；人物卡“生成定妆照”通过 submit-costumes 独立提交 workflow 组，按全部服装逐套生成。无服装则生成一张未绑定图片，不创建虚构服装资料。

首套读取人物、该套服装及可选用户参考图，第一张作为默认角色图。后续读取人物、该套服装，以首套定妆照为唯一参考。人物任一描述字段非空即可生成；后续各套要求首套有效。每任务生成一张单人全身、3/4 视角、纯色背景图片，无文字。

默认图不另存独立字段。首套更新使后续图片和实际引用视频过期；其余套更新只影响实际引用该图的视频。中途失败保留已完成图片，停止后从组卡片继续。

模板：`costume-image-generate.yaml`、`costume-image-regenerate.yaml`。
