# 镜头-视频（`video`，AI 生成并由程序完成尾帧后处理）

**前置条件：**

1. 目标镜头属于本集。
2. 该镜头文生视频提示词已有效生成，且 `生成视频类型` 已写成 `文生`、`首尾帧` 或 `多模态`。
3. 类型为 `多模态` 时，多模态提示词已写好，且绑定的角色图和定妆照已有效生成。
4. 类型为 `首尾帧` 时，首尾帧提示词已写好，且上一镜尾帧已有效生成。

**生成规则：**

1. 按 `生成视频类型` 取对应的一份请求生成这一镜，保留事件、顺序、结果和素材编号。`多模态` 发送多模态提示词。`首尾帧` 发送首尾帧提示词。`文生` 只发送 `model`、`prompt`、`seconds`、`size`，`prompt` 为文生视频三段。三种请求不合并，也不把另一类型的字段放进同一次请求。
2. 类型为 `多模态` 时，脸、服装和签名道具以定妆照为准，体型以角色图为准。
3. 不是首镜时，0.00 秒的画面以上一镜尾帧为准。
4. 成片不带分镜线稿、说明文字、角色名贴片、时间码、钩子名称、字幕和水印。用户明确要求字幕时除外。
5. 画幅使用项目已确认的画幅。时长等于该镜计划时长，并在 4–15 秒内。
6. 地标、人物进出方向和光位与镜头表锚点一致。

**生成返回结构：**

模型返回这一镜的一条视频。时长等于该镜计划时长，并在 4–15 秒内。不返回 JSON 或说明文字。视频任务随后由程序截取并校验该视频尾帧。

**审核返回结构：**

不适用。本节点不进行模型审核；视频文件与尾帧由程序校验。

**依赖资料：**

- `shots[].video_generation_type`。
- 类型为 `多模态`：`shots[].multimodal_prompt` 的 `model`、`prompt`、`seconds`、`size`、`reference_images`，以及 `multimodal_prompt.node_state.dependency_hash`。另读所绑定的 `character_image.address`、`character_image.node_state.dependency_hash` 和对应 `costume_images.address`、`costume_images.node_state.dependency_hash`。
- 类型为 `首尾帧`：`shots[].first_last_frame_prompt` 的 `model`、`prompt`、`seconds`、`size`、`input_reference`，以及 `first_last_frame_prompt.node_state.dependency_hash`。另读上一镜 `last_frame.address`、`last_frame.node_state.dependency_hash`。
- 类型为 `文生`：`shots[].text_to_video_prompt` 的三段，以及 `text_to_video_prompt.node_state.dependency_hash`。

**步骤：**

1. 前置条件检查（程序）。
2. 生成视频（AI）。
3. 校验视频文件可读取（程序）。
4. 从视频截取最后一帧，并确认图片可读取（程序）。
5. 同一任务中一起保存视频地址与尾帧地址，并同步到本地项目 JSON。
6. 下游节点 hash 检查。

**数据保存同步：**

视频和尾帧都成功并可读取后，把视频地址写入 `episodes[].shot_list.shots[].video.address`，把尾帧地址写入 `episodes[].shot_list.shots[].last_frame.address`，并同步到本地项目 JSON。生成或截帧任一步失败时，视频任务失败，不提交本轮新视频或尾帧，也不进行下游 hash 检查。

**下游节点 hash 检查：**

影响本集合片和下一镜视频。合片按自己的依赖资料读取本集各镜 `video.address`、`video.node_state.dependency_hash`。下一镜在使用首尾帧时，读取本镜 `last_frame.address`、`last_frame.node_state.dependency_hash`；因此本镜视频任务完成后，比较并更新该下游视频的依赖状态。下一镜文生视频提示词和多模态提示词不依赖尾帧，不检查。已经是最后一镜时，没有下一镜可检查。
