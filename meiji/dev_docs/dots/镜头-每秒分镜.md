# 镜头-每秒分镜（`seconds`，按节拍生成）

- 误差时长：无，末段结束必须精确等于镜头参考时长。
- 重试轮次：2，程序审核与AI审核共用。

节点名沿用每秒分镜。内容按主要动作或持续状态分拍，一个节拍承载一个主要动作或一段持续状态；普通短动作可短于1秒，有依据的停留可跨多秒，不规定固定秒长、格数或一秒一拍。节拍边界不是剪辑切镜。

## 前置与输入

本集镜头表、项目角色库有效。出镜人物/服装唯一继承本镜on_screen_characters，群演按background_characters与正文保留；没有独立角色识别任务，不要求定妆照。

首镜previous为null；后镜必须读取前镜有效且已审核的end_state、pending_actions、pending_dialogue、continuing_audio，以及与末尾3秒相交的完整节拍。窗口只用来选取整拍，不截断对白、动作或另写摘要。换场仍读取前镜资料，由本镜剧情决定继承范围。

整镜背景、摄影、景别、可见范围、方向、站位和光位由镜头表既有字段确定。节拍只细化既定意图内的执行进展，不自行换背景、机位、风格或运镜。旧表缺少不影响执行的细节不自动拒绝；必要缺口定位镜头表，不在本节点重新设计。

## 节拍与字段

从0连续覆盖本镜参考时长，不留空隙、不重叠。主要动作或持续状态转换时分拍；剪辑切镜、换说话人需要独立呈现时分拍，开口、接触、开合、到达、钩子等时点可在拍内写明，不机械拆格。计时或倒计时按真实时间推进，不因报秒而把整个镜头固定逐秒拆拍，不擅自补报原文没有的数字。

- `time_range`：本拍实际起止秒数，如0–0.2s、0.2–5s。
- `action`：本拍主要动作的起点、进展、结果，或持续状态及其连续变化；包含原有情绪、语气、节奏、可见嘴部状态和听者反应。
- `camera`：既定整镜摄影意图内的本拍执行；变化须有上游依据，不创造新机位。无变化可简洁沿用，不重复整镜设定。
- `space`：人物、持物、地标的相对位置与本拍变化，不瞬移、穿障碍或镜像地标。
- `audio`：发声时点、声源、非语言声音和静默/延续；不重抄台词，不把旁白原文放这里。
- `dialogue`：无对白为[]；每项仅speaker_id、speaker_name、mode、dialogue_text。目录内ID原样引用，未建卡人物及独立旁白ID为空。mode为画内、画外或心声，dialogue_text只放原话并逐字保留标点；不增加表演字段。
- `handoff`：本镜内部交给下一拍的已达状态；末拍为空，跨镜交接写顶层四字段。

对白可跨拍分配，拼接后原话、说话人及顺序完整，不能重复播放。同一人物画内转画外不表示说完一句；最终文生提示词须合回完整句放同一个d，不能因节拍、停顿或动作拆碎一句。不同人物不得合入一个d。

心声人物可见时不动嘴；画外声音和独立旁白不创造身体，也不让其他画内人物对口型。普通心理描写不自动转成心声。群演原有动作和对白保留，不要求建卡或配服装图。

## 返回与镜末交接

仅返回JSON：顶层storyboard、end_state、pending_actions、pending_dialogue、continuing_audio。每拍仅上述规定字段。

end_state必须明确最后一刻已知人物/物件/环境状态且非空；pending_actions记录切点未完成动作及进度，pending_dialogue记录未结束发言及说话人、发声进度，continuing_audio记录切点仍持续的声音与声源。无待续事项为空字符串，不补写下一镜。

## 审核、修订与保存

程序检查结构、连续覆盖、精确结束时间及明确原对白的逐字完整性；AI检查动作、状态、空间、音画和前后交接是否实际一致。简洁且能执行的表达可通过，不因描述短、没有逐秒切格、合理持续拍或非钩子亚秒拍拒绝。

生成、修订、审核共用同一节拍、字段和摄影边界。确有上游矛盾按声明来源引用真实连续原文，不能用其他来源归责；候选自身错误由本节点修正。公共上游阻断与无进展规则见制作工作流。

通过后保存seconds_storyboard及hash，同步项目JSON，更新本镜文生提示词和后镜节拍依赖。保留旧内容及候选的规则沿用制作工作流，不增加修订轮次。面板整镜设定只读投影自当前镜头表，不另存第二份。

画内与画外是同一人物实际发声的视听位置变化，不构成断句；心声与实际发声是不同通道，各自原有片段独立保留，不能合进一个d标签。
