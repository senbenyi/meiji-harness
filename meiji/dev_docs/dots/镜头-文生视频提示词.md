# 镜头-文生视频提示词（`storyboard`，AI）

**固定属性：**

- 误差时长：无
- 重试轮次：2

模型只生成这一份。首尾帧和多模态不在这一步生成。

生成、修订和审核同时携带本镜镜头表整镜设定、每秒时间线及参与角色的文字资料。参与角色包括已确认出镜人物与本镜实际发声人物，发声人物按已保存speaker_id及原称谓识别；仅提及或无关角色不发送。文字包含身份、年代、国籍、年龄、身高、体型、面部特征、发型、固定特征、服装和声线等现有内容；不要求未填写字段补造事实。不携带定妆照、参考图、图片地址、图片状态或Base64，不调用图片接口。画面仅呈现本镜可见特征，画外声人物不因此出镜，服装和表演以本镜已确定状态为准。

任务输入的 `storyboard.shot_setup` 是从当前镜头表派生的只读整镜资料（正文中的场景与摄影安排、景别、衔接、参考锚点和音频安排），不存入每秒节点。生成、修订和审核将其与已审核逐秒时间线共同使用：开头建立背景、构图、主体可见范围及光照基准，后续严格转写时间线变化。整镜正文不作为第二段剧情，不重复台词或提前执行结果。无 `shot_setup` 的直接接口调用仍按实际给定资料转写。任务输入和依赖指纹共用同一投影，不引入图片依赖。

**步骤：**

1. 前置条件检查（程序）。
2. 生成（AI）。
3. 程序审核。本节点不适用，跳过。
4. AI 审核。未通过且未达重试轮次时，把原因作为修改意见，带原内容重新生成，再做 AI 审核。达到重试轮次仍未通过则保留本轮内容，节点进入未通过，不更新下游。
5. 数据保存同步。
6. 下游节点 hash 检查。

**前置条件：**

1. 目标镜头属于本集。
2. 本集镜头表、项目角色库、该镜头角色/服装识别及每秒分镜均已有效生成；不要求定妆照。

**生成规则：**

1. 只转写该镜每秒分镜。不改时间线、事件、角色、服装和时长。
2. 不引用定妆照，也不引用上一镜尾帧。
3. 提示遵循镜头表参考时长和每秒分镜时间线。每秒分镜没有写切镜时，提示里不增加切点；有切镜时，切点严格递增并落在镜头参考时长之内，第一段不加时间戳。
4. 运镜使用设置的输出语言写成完整动作描述，包含运动类型。幅度和速度只在每秒分镜写了的时候才写。
5. 说话人使用跨镜稳定的 `(S1)`、`(S2)`。对白和歌词放在 `<d>` 内并保留原文。旁白写明对应角色嘴唇闭合。
6. 画面上真实可见的文字保留原文。
7. `overall_soundscape` 用 1–4 句概括环境声、动作声和非语言人声，不重复对白。`non_diegetic_music` 用 1–3 句写角色听不见的配乐，只写乐器、速度、节奏和强弱变化。整段无声时，声景写 `N/A`。
8. 三段正文的画面描述、运镜、声景及配乐说明使用设置选择的输出语言。对白、旁白、心声、歌词和画面文字保留原语言；固定段名、说话人标记及N/A不翻译。
9. 用具体的构图、主体、环境、动作、镜头和声音写提示。
10. 提示中的画面描述不包含角色名贴片、时间码、钩子名称和分镜标记。

**生成返回结构：**

只返回文生视频这三段：

```text
integrated_multimodal_description:
overall_soundscape:
non_diegetic_music:
```

三段正文及运镜使用设置的输出语言（简体中文或英文），固定段名不变。对白、旁白、心声、歌词和画面文字保留原文，对白放在 `<d>` 里，说话人用跨镜稳定的 `(S1)`、`(S2)`。没有切镜时不写切点。`overall_soundscape` 用 1–4 句写环境声、动作声和非语言人声，不重复对白；整段无声时写 `N/A`。`non_diegetic_music` 用 1–3 句写乐器、速度、节奏和强弱。

**程序审核：**

不适用。

**AI审核：**

1. 只有上述三段，没有定妆照标签，也没有尾帧对齐。
2. 提示遵循镜头参考时长，切点没有超出参考时长或倒退。
3. 三段正文及运镜说明符合设置的输出语言；固定段名和说话人标记不翻译。对白、旁白、心声、歌词和画面文字没有被翻译或改写。
4. 时间线、事件、角色、服装和素材与每秒分镜一致。
5. 提示中的画面描述没有角色名贴片、时间码、钩子名称和分镜标记。

**审核返回结构：**

```json
{
  "是否通过": true,
  "原因": ""
}
```

`是否通过` 为 `true` 或 `false`。为 `true` 时原因为空，为 `false` 时写明问题。

**依赖资料：**

- `episodes[].shot_list.shots[].seconds_storyboard.storyboard[]` 的 `time_range`、`action`、`camera`、`space`、`audio`、`handoff`、`dialogue`。
- `seconds_storyboard.node_state.dependency_hash`。

**数据保存同步：**

AI 审核通过后，把三段写入 `episodes[].shot_list.shots[].text_to_video_prompt` 的 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`，并同步到本地项目 JSON。重试轮次用尽后 AI 审核仍未通过时，仍保存本轮三段，节点进入未通过，原因写入 `text_to_video_prompt.node_state.reason`，不更新下游 hash。

**下游节点 hash 检查：**

影响该镜首尾帧提示词、多模态提示词和视频。首尾帧提示词按自己的依赖资料读取文生视频三段和 `text_to_video_prompt.node_state.dependency_hash`，以及上一镜 `last_frame.address`、`last_frame.node_state.dependency_hash`。多模态提示词读取文生视频三段和 `text_to_video_prompt.node_state.dependency_hash`，以及绑定的 `character_image.address`、`character_image.node_state.dependency_hash`、`costume_images.address`、`costume_images.node_state.dependency_hash`。视频按 `生成视频类型` 读取它这次实际使用的那一份提示词字段。某一项字段的 hash 仍一致时，不标该节点过期，也不从它继续向下传递。

每秒分镜输入还包含 end_state、pending_actions、pending_dialogue、continuing_audio。它们是本镜结束状态与未结束事项，必须与时间轴末尾一致地落实到提示词；不能将待续事项提前演完或重复已结束对白。相关字段变化参与本节点依赖指纹。
