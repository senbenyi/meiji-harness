# 项目-角色图（AI）

每个角色一张角色图。角色图裸露，展示肌肉和身材，不穿服装。

**前置条件：**

1. 目标角色存在，人物资料足以确定身份、面相、身材和肌肉。
2. 用户参考图可选：有则作为参考图传入，没有则仅依据人物资料生成；无参考图不阻止任务。

**生成规则：**

1. 生成一张角色图。单一 3/4 视角，脸和体型同时可见。
2. 裸露，展示肌肉和身材，不穿服装。
3. 有用户参考图时，只参考人物面相；身材和肌肉以人物资料为准。没有用户参考图时，按人物资料创作面相、身材和肌肉。
4. 画面不印角色名、说明文字和分镜标记。

**生成返回结构：**

一张角色图，不返回 JSON，画面上不写角色名或说明。

**审核返回结构：**

不适用。本节点不进行模型审核。

**依赖资料：**

- `character_library.characters` 的 `名字`、`定位`、`年龄段`、`身材`、`发型`、`服饰颜色`、`签名道具`、`不可改特征`。

**步骤：**

1. 前置条件检查（程序）。
2. 生成（AI）。
3. 数据保存同步。
4. 下游节点 hash 检查。

**数据保存同步：**

生成完成后写入 `character_library.characters[].character_image.address`，并同步到本地项目 JSON。

**下游节点 hash 检查：**

影响该角色的全部定妆照，以及使用该角色图的多模态提示词。定妆照和多模态提示词按自己的依赖资料读取 `character_image.address`、`character_image.node_state.dependency_hash`。文生视频提示词不依赖角色图，不检查。下游被标为已过期后，再检查它的下游。
