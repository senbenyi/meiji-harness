# Meiji

DeepSeek Harness 短剧制作插件。按项目 Model 保存剧本、角色与服装、分集剧情及镜头制作资源；会话和右侧面板使用同一任务服务。

创建项目选择自由创作或剧本模式。自由创作需要用户提供方向；剧本模式需要完整剧本。新增剧集填写时长与本集要求，之后可以编辑。制作顺序为项目摘要 → 剧情 → 镜头表 → 每秒分镜 → 文本提示词 → 视频 → 尾帧 → 合片；镜头表直接使用项目人物库。前置不足会记录具体失败原因，不自动补上游。

每个文本任务完成生成、程序审核、AI 审核和最多两轮修订。时长由程序审核，未通过进入未通过。人工编辑与人工放行不调用 AI。节点显示未生成、排队中、生成中、已生成、未通过、失败、已取消、已过期；状态与原因直接来自持久化 Model。上游变化保留旧资源并标记过期。输出语言、画幅、规则、角色声音和默认服装的修改只影响后续步骤。

同一项目串行执行。任务完成后自动下一项；失败、未通过或取消后停止。排队项可从面板开始或移除。组合任务包括本集每秒分镜与成片，继续操作创建新组和新任务，旧终态历史保持不变。会话关闭不会取消制作；程序通知可被模型读取，但不授权模型自主修复或继续。

面板保留项目概要、角色与服装、设置、任务记录和素材库，以及剧情、镜头表、成片、合成四个剧集标签。人物资料在项目角色区维护；镜头表直接参考项目人物库。规则替代旧生产技能入口。内部 ID 由程序生成，资料使用编号；未建卡说话人和独立旁白保留名称。

项目与任务历史保存在 `$DSH_HOME/storages/meiji/meiji.sqlite`（默认 `~/.dsh/storages/meiji/meiji.sqlite`）。使用 Node 内置 `node:sqlite`，运行要求 Node ^22.19.0 或 >=24；无需安装独立数据库服务。任务组 `task_groups` → 任务 `tasks` → 步骤 `task_steps` 通过外键关联；项目、幂等请求和通知同事务提交，启用 WAL、外键与 FULL 同步。媒体和独立素材仍保存为文件。

本次切换按用户要求清空旧项目及任务历史，不迁移。数据库首次启动自动建表；检测到尚未清理的 CURRENT 分代项目会拒绝启用，防止混用。数据库启用后只读写 SQLite，`projects/<p_UUID>/` 仅作为工作区目录。

备份运行中的 SQLite 应使用 SQLite 备份接口，或停服并关闭连接后复制数据库；不要只复制运行中的主文件而遗漏 WAL。

图片和视频沿用现有网关协议，尾帧和合片使用 FFmpeg，所有产物在保存前校验。停止视频任务只停止本地等待，网关不提供远端取消接口。不要同时运行多个写入同一 DSH_HOME 的实例。

在本目录执行 `npm test`；阶段测试文件以 stage01～stage08 命名。开发规则、模块边界、存储和接口见 [开发指引](../.agents/meiji-dev.md)，重构完成及真实走查证据见 [实施记录](../docs/implement/1010-实施-分阶段开发总纲.md)。
