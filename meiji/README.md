# Meiji

## 创建与剧本

创建只需标题、风格、画幅，可导入 UTF-8 TXT/TEXT 剧本（最多 1 MB、200000 字符），没有摘要预生成。无剧本与基调时，首集本次要求必填并默认保存为基调。剧集摘要保存后独立回写：首次建立剧本，只追加时自动保存，修改旧正文时逐条确认方案。剧本页支持编辑说明、版本对比、恢复为新版本、修改后续剧情；待回写或待确认方案会阻断剧情层制作。

项目摘要从当前剧本与基调生成，最多 1000 字；剧本升版后按需更新，失败可按原操作重试。剧本是创作参考，以已发生剧情为准。

## 三类项目库

概要中的角色、场景、道具库管理条目、变体、照片和跨集关联。通过审核的剧情卡片并库，关联卡片复用库字段与已确认图片；修改同步关联剧集，保存前提示集数和删除清单。年龄/造型、场景夜晚、道具样式变化可建新变体；可解除关联或合并条目。指定照片直接使用，AI 候选需人工确认。道具只收主要且反复使用的物件，或已有库条目。

## 数据保存与共享图片

项目主 JSON 使用递增的 `revision`。单个服务进程内按项目串行提交，剧集更新在锁内合并；生成任务按读取版本提交，冲突时保留新编辑并释放自己的运行状态。不要运行多个写入同一 DSH_HOME 的服务实例。

新生成的人物、场景、衣服、道具、发型和铅笔分镜先保存到 `storages/meiji/image-drafts/<draftId>/`，剧集的 `pendingImages` 记录待确认预览，不修改当前图片。用户点击“确认使用”后调用上传接口，取得 `imageUrl`，再保存到 `storages/meiji/assets/<category>/<assetId>/` 并更新关联。上传失败保留预览和原图。确认入口独立于模型工具，模型不能自动批准。人物归入人物素材，场景与铅笔分镜归入场景素材，衣服、道具和发型归入道具素材。项目保存 `assetId`、`assetCategory`、`imageUrl` 和预览地址；视频任务保存提交时的 `assetIds`。重新生成创建新预览，确认后创建新素材，不覆盖旧素材。

图片编辑区的“从素材库选择”可以关联已有素材；“删除图片”只解除当前关联。素材库七类卡片均提供“删除”，确认后仅从素材库列表及选择列表移除，保留原文件、项目已有引用与历史读取，不释放磁盘空间。旧项目图片继续兼容读取；提交视频时，会把所需的旧本地参考图登记为素材。素材库不自动删除未引用图片。项目内 images 目录仍可能保留生成缓存，共享引用指向素材库文件。

面板调用必须携带 `operationId` 并校验会话。多集制作操作必须提供 `episodeId`。上游变化在同次保存中按删除规则清理下游；参考图变化只删除引用该实体镜头的分镜、视频与合成，旧版本留历史。

网关图片使用异步 `POST /v1/images/tasks`，轮询完成后下载图片。面板“停止任务”会向当前图片或视频任务发送 `POST /v1/images/tasks/{id}/cancel` 或 `POST /v1/videos/{id}/cancel`；提交期间停止会等待返回任务 ID 后取消。取消请求有独立的 30 秒超时；失败（包括渠道不支持取消的 501）会记录任务 ID 和失败原因，不宣称远端已取消。已取消的视频保存终态，不再复用原任务。服务关闭或重启一律取消进行中任务：已提交的远端任务同样发送取消请求（重启时对遗留的视频任务补发），不续查、不自动恢复。生成任务经全局队列限流，文本、图片、视频的并发上限在 `config/models.json` 的 `concurrency` 配置。

Harness 外部插件，源码位于 `Meiji/meiji/`，不修改上游 Harness。测试：`npm test`。

## 目录与职责

模块职责与依赖方向见仓库根目录的 `.agents/meiji-dev.md` 第 1 节，开发流程见仓库根目录的 `AGENTS.md`。要点：`client/` 为面板界面，`shared/` 为前后端共用的领域模块（数据模型、门禁规则），`server/host/` 是唯一接触 Harness 的适配层，面板操作按领域位于 `server/flow/operations/`。

`server/data/project-store.js` 管理项目（存储布局由 `server/data/project-files.js` 负责），`server/data/asset-library-store.js` 管理素材文件与元数据，`server/http/asset-library-routes.js` 管理导入、读取与分段播放，`server/http/panel-routes.js` 组合鉴权后的 HTTP 路由。浏览器仅加载 `client/`、`shared/` 两个平铺目录中的模块。

## 页面行为

右侧栏标题为「极乐世界」，标题右侧是新建加号；最右侧提供片库与图标式收起/展开。点击标题进入正在进行的会话项目：顶部固定流程概要「剧情 / 分片 / 成片」。没有进行中项目时，概要下方显示大加号「创建项目」；已有则展示该项目。片库是独立模块，只有点击片库按钮时展示。

片库只有点击片库按钮时展示：顶层为「短剧 / 素材」。短剧下显示「进行中 / 已完成」，分别对应 `in-progress` 与 `completed`。一级使用贴顶下划线标签，二级使用紧凑分段按钮。当前不会自动执行生成流程或将项目标记完成。

素材下分为人物、场景、道具、声音、视频、指导提示词。前三类支持 PNG/JPG/WebP/GIF；声音支持 MP3/WAV/M4A/OGG/FLAC；视频支持 MP4/WebM/MOV。音视频是否可直接播放取决于浏览器对文件编码的支持，均可下载原文件。支持一次选择多个文件，逐个导入并报告每个失败项；媒体单文件最大 512 MB。

### 技能、本剧补充与指导

生成流程的技能按字段存放在 `skills/`（阶段技能、指导技能、共享模块），代码直接读取；Harness 只注册会话说明技能。结构与写法见 [skills/README.md](skills/README.md)。

剧情、镜头表、每秒指令、文本分镜和成片页的「查看 skill」进入技能详情页（设置页「技能库」列出全部技能）：

- **基础 skill**：按「通用 / 生成 / 审核 / 修订 / 协议」查看；编辑保存后替换内置，对所有剧生效（保存前确认）。可恢复内置、撤回上一版；内置更新后提示并可对比。协议由代码持有，只读。
- **本剧补充**：同样的字段，追加在基础内容之后，只对本剧所有集生效。
- **指导**：动作、武术、台词、表情、声音五个指导技能，默认启用动作、台词、表情、声音，武术按剧开启；启用的指导把本阶段要求加入生成请求，把验收条目加入自检与审核。
- **指导素材**：在「素材 → 指导提示词」按表情、动作、武术、特效、声音、对白、配乐或其他分类导入 UTF-8 TXT/Markdown（单文件最多 128 KB、正文 20000 字，保存在本地 `assets/guidance/<素材UUID>/`）。在技能详情页按指导分组勾选，每阶段最多 20 个、合计 60000 字，按剧保存。素材是参考例子，未全部使用不构成审核失败，不能覆盖本剧补充与输出协议。
- **预览**：用当前剧集的上下文组装生成、意见修改、审核、自动修订请求，按来源着色并显示字数，不调用模型。

优先级：输出协议 > 上游事实与本次任务 > 本剧补充 > 阶段技能 > 指导技能 > 指导素材。审核请求只带验收标准，不附整份生成技能与官方参考；文本分镜只注入当前模式的官方参考。组装细节见 [开发指引：提示词接口与 Model](../.agents/meiji-dev.md#prompt-models)。

| 素材分类 | 所属指导 | 最终视频提示词模块 |
| --- | --- | --- |
| 动作、特效 | 动作指导 | `detailed_description`；文生视频/首帧模式使用 `integrated_multimodal_description` |
| 武术 | 武术指导 | 同上 |
| 表情 | 表情指导 | 同上 |
| 声音、配乐 | 声音指导 | `overall_soundscape` / `non_diegetic_music` |
| 对白 | 台词指导 | 画面描述中对应说话人与时点，不放入背景音 |
| 其他 | — | 按语义融入对应模块 |

成片指导素材在生成文本分镜时一起编排并审核，同一素材不重复注入；视频接口收到整合后的分镜正文。更换成片指导素材按保存规则清理受影响下游；「依次生成全部成片」先更新分镜再提交视频。成片技能的基础要求与本剧补充追加在最终视频提示词后。

以前按集保存的补充 skill 与指导素材由 `scripts/migrate-custom-skills.js` 迁移为本剧补充（标注来源集，`configure-harness.sh` 启动前自动执行）；运行时拒绝剧集中的旧字段。

## 本地存储

- 技能的基础修改存于 `$DSH_HOME/storages/meiji/skills/<id>.json`，只存改过的字段；插件升级只更新内置技能，不覆盖基础修改。

源码与用户数据分开，持久化根目录是 `$DSH_HOME/storages/meiji/`，由当前运行 profile 的 DSH_HOME 决定。

```text
meiji/
├── models.json
├── projects/
│   ├── <项目UUID>.json          # 项目索引（layout 2）
│   └── <项目UUID>/episodes/     # 每集一个文件
└── assets/
    ├── characters/
    ├── scenes/
    ├── props/
    ├── audio/
    └── video/
        └── <素材UUID>/
            ├── metadata.json
            └── original.<扩展名>
```

各素材分类使用相同的 UUID 目录结构，文件名不作为存储路径，允许同名素材重复导入。元数据记录版本、ID、分类、原文件名、文件类型、字节数、导入来源和创建时间。项目索引以 UUID 为文件名，记录版本、唯一 ID、标题、整数秒时长、摘要、状态、阶段、工作流和创建/更新时间，每集内容存为 `<项目UUID>/episodes/` 下的独立文件；保存时只重写有变化的剧集，最后原子替换索引。点击创建后写入该文件，创建完成即展示项目 ID。

导入先流式写入 `<素材UUID>.upload/`，文件和元数据均成功写入后，原子重命名为正式目录。失败导入清理临时目录；进程意外退出残留的 `.upload` 不进入素材列表，可在服务停止后清理。素材是全局片库，目前不归属于某个项目；后续项目引用应保存素材 ID，不复制原文件。备份时复制整个 `storages/meiji/`，恢复到同版本的运行目录即可。当前短剧由工作区绑定决定，不记在浏览器里。

导入和读取均沿用 Harness 登录保护；写请求要求同源自定义请求头。文件格式按扩展名与分类校验，不做转码、内容识别或去重；不接收 HTML/SVG 等主动内容。原文件下载和音视频 Range 请求均需登录。

## 模型与工作流

网关地址、四个模型名与并发上限写在 `config/models.json`（入 git，不含密钥）；密钥写在本地的 `config/models.local.json`（git 忽略，覆盖同名字段）。网关接口说明见 [开发指引：网关 API 参考](../.agents/meiji-dev.md#gateway-api)。运行中的一份是 `storages/meiji/models.json`，文本、图片和视频都读它。密钥不返回给浏览器。

制作顺序由 `shared/generation-gates.js` 的门禁决定：简报、大纲、角色、场景、镜头表、每秒指令、文本分镜，然后逐镜交给 MiniMax H3。铅笔分镜在镜头详情里生成，成片拼接仍只保留卡片。

右栏左边缘可拖拽调整宽度，聊天区域同步适配；宽度记入浏览器 localStorage，刷新、收起后展开均恢复。窗口缩小时自动限制宽度，拖拽手柄也支持左右方向键。

## 短剧工作区

每部短剧通过主 JSON 的 `workspaceId`、`workspacePath` 关联专属 Harness 工作区。工作区目录是 `storages/meiji/projects/<projectId>/`，项目索引为 `storages/meiji/projects/<projectId>.json`，剧集文件与媒体保存在项目目录内。

创建或从片库选择短剧时，创建或复用该目录对应的工作区，打开已有未归档会话；没有会话则新建。浏览器通过 Harness 的持久化会话选择刷新进入目标工作区。短剧改名同步工作区名称，同名冲突添加项目 ID 后缀。

旧 `workspaceIds` 和旧映射仅保留，不自动迁移历史会话；只有主 JSON 的 `workspaceId` 与当前会话所属工作区一致时，才允许执行该短剧的操作。

## 通用自检与人工审核

标准数据结构为 `schemaVersion: 2`。一部剧对应一个根 Model，每集包含剧情、镜头集合和合成结果；每镜包含每秒指令、文本分镜、铅笔分镜和视频节点。所有生成节点就地保存 `status/check/review/draft/operation`，不再保存独立 feedback 映射。

- 状态统一为未生成、生成中、未通过、已通过。AI 自检通过即通过，人工意见可选。
- 失败保留生成内容、自检原因和人工意见；成功仅清理本次处理的意见，新输入的意见保留。
- 文本编辑草稿和意见均持久化；直接保存正文会再次自检。
- 图片候选必须确认、上传成功后入素材库；文本分镜保存并展示实际素材引用顺序。
- 运行时拒绝旧结构、旧存储布局与按集保存的补充 skill。部署前停止服务，依次执行 `node meiji/scripts/migrate-model.js <DSH_HOME>`（数据结构）、`node meiji/scripts/migrate-layout.js <DSH_HOME>`（按剧集拆分存储）与 `node meiji/scripts/migrate-custom-skills.js <DSH_HOME>`（补充 skill 与指导素材按剧保存）；后两者由 `configure-harness.sh` 启动前自动执行。脚本先完整备份再迁移，不能用运行时兼容替代迁移。

结构、执行步骤及验证见 [开发指引：历史迁移记录](../.agents/meiji-dev.md#model-migration-history)。

## 剧情统一生成

剧情页包含摘要、大纲、角色卡、场景卡和道具卡，不再单设角色场景一级页。outline 操作使用 `skills/task/generate-story-outline-skill.md`、`extract-story-characters-skill.md`、`extract-story-scenes-skill.md` 三份基础规则，依次生成并审核大纲、提取人物、提取场景；每步独立调用模型并保存到当前集 plot.outline / plot.characters / plot.scenes 节点，保留同名卡片稳定 ID 和已确认素材，清空镜头及下游。审核失败保留完整内容与意见，不能继续生成镜头表。角色与场景的图片仍独立生成、确认；不会因统一生成文本而调用图片接口。

面板始终从 Harness 的当前会话选择读取日志目标。切换或新建会话后，新任务写入最新选中的会话；已启动任务的后续日志仍写入发起会话。纯任务日志保存在该会话中；首次真实聊天回合前，Harness 仍将其视为空白会话，不列入非空历史列表。日志不创建聊天回合。

剧情页使用顶部统一的“生成剧情”和审核卡片，整包生成或修改大纲、角色与场景；各内容卡片只展示文字，图片操作保留。自审失败时，统一审核卡片同时展示失败原因并允许补充修改意见。

### Harness 会话制作

默认「短剧制作」预设通过 `session.js` 注册 11 个 meiji 工具与会话说明；standard 看不到这些工具。预设配置来自 `cordis.patch.yml`，configure 只链接原配置。主机 index.js 提供公开运行服务，不全局注册业务工具。

会话工具按操作定义派生，覆盖摘要、剧情、镜头表、每秒指令、批量图片、成片、项目摘要与剧本修改；查询/项目管理/图片等待另行注册。旧 content_generate/task_control 已删除。顺序与依赖维护在 [工具图谱](skills/tool-graph.json)，会话说明见 [panel.md](skills/session/panel.md)。

生成立即返回 jobId/operationId；Harness job_wait/job_read/job_output 获取结果。项目占用、图片确认、剧本处理分别登记等待 job，取消等待不改业务。面板生成也登记 job，模型不能停止面板任务；owner 或 jobs 服务销毁只脱离观察。失败的项目摘要前置按同一操作参数重试，会话自动重试一次。

查询包含剧本版本、方案、阻断、项目摘要新鲜度、库目录和缺图清单；库中已有图不算缺图。会删除产物时先返回清单，取得用户授权后带 confirmDelete。图片确认和人工放行仅在面板。

原始返回在步骤详情按需查看，密钥与 Base64 脱敏。`scripts/export-session-log.js` 合并公开会话 JSONL/ZIP 与项目历史，按 callId 和时间关联；不读取 Harness 内部存储。任务、状态与记录结构见[开发指引](../.agents/meiji-dev.md#task-records)。
