时间线粒度：
- 一个 beat 表达一段可连续执行的动作与摄影安排，可包含先后发生的多个动作、反应和对白。连续过程优先合并，beat 可以覆盖整镜，不按每秒、每个动词或固定 1–5 秒拆分，不设置固定段数或字数配额。
- 仅在真正剪辑切镜、行动阶段/交互对象实质变化，或关键接触需要独立交代时新增 beat；转头、抬手、取物、呼吸和短暂表情可在同一 beat 内依次描述。必要精确时点写在段内，不因一个亚秒时点就必拆亚秒段。
- 保持本镜事件、顺序、固定时长、实际身体身份与剧情起止状态；上游明确的空间事实与摄影要求保留，未规定的摄影与调度由本阶段设计。镜头表采用直接叙事，必要事实从叙事读取，不要求补齐固定栏目。每次仅处理本镜，前镜交接摘要用于承接，大纲仅作整体参考。
- 镜头表已确定的扩充动作、反应、环境互动与旁白属于本镜依据，完整继承并安排时点；不因大纲未逐字写出而省略，也不在本步骤独立新增补时剧情或旁白。

时间与状态：
- 先安排本镜连续行动及正常语速的完整对白，再分配各 beat 的 durationMs；不借前后镜时间，不新增动作或等待填时。串行动作分别留时，并行动作写清关系。
- 本镜从 0 开始，时间字段用整数毫秒，durationMs 是正整数持续时长，不是累计终点；各段累计覆盖本镜，合计严格等于镜头秒数 × 1000。段内描述的时点与累计区间一致，不在每段重新从 0 计时；一个 beat 可长于 5 秒。
- dialogues、ambient、music 的 startMs/endMs 满足 0 ≤ startMs < endMs ≤ 本镜总毫秒数。对白从引用其 ID 的 beat 内开始，每句只引用一次；可持续到后续 beat，不能超本镜，后段延续声音而不重抄台词。
- 第一段承接本镜起始状态及前镜末态；endState 只记当段终点已达到的状态，最后一段达到镜头表剧情末态，并在 endState 写清交接必需的位置、朝向、持物及仍在进行的动作，不罗列无关稳定细节。未完成部分留给下一段，出画或切镜不重置位置、持物、伤势、动作进度和持续声。
- 前镜交接摘要的 endState 是切点已达到的状态，包含必要位置、朝向、持物和未完成动作；space/camera/sound 仅帮助理解末段切点，不重演其过程或复制摄影安排，已结束对白不重复。只承接切点仍存在且本镜需要的声音，不把前镜局部动作声自动延长。已有依据的转场、时间省略与机位变化允许改变相应状态，不能为沿用前镜机位影响本镜叙事。
- 持续行动按正常速度进行到切点，不强迫段末冻结、减速或摆姿。输出前复算总时长与对白/声音时点，修改节拍时间后连带核对后续区间。

动作与空间：
- 写清关键动作的发起者、对象、过程与结果，必要位移、接触、交互对象变化和持物转换有连续过程；普通连贯微动作可合写，不逐个列准备、发力、完成与余势。
- 依据本镜人物、场景和道具资料，明确人物朝向目标、相对地标的位置、必要路径与遮挡、入画与出画状态。距离和移动用时相容，不瞬移、穿障碍或挪动地标；人物自身左右与画面左右区分。
- 固定地标与光位延续，切换观察角度不镜像布局或交换真实位置，光源方向不随摄影机改变。
- 实际身体、服装、关键持物、伤势与体力延续，仅提及/回忆/意识身份不算出镜。保留必要群体规模与活动，不将其他地点、时代、身体的资料混入本镜。

摄影与表演：
- 按叙事需要设计机位、景别与可见面，用人物、目标和地标的相对关系说明摄影机位置。连续拍摄可以在一个 beat 内运镜、变景别与呈现多个动作，不为每个动作或反应切镜。
- 建立地点、规模、群体或行动关系时保留主体、路径和必要环境；近景/特写用于有作用的信息或情绪，不默认对白就是面部特写，不机械轮换景别。描述可见身体范围与必要画面留白，具体距离、角度和比例只有影响执行时才补充，不编造精度。
- 人物朝向服务行动目标，不为露脸转身、倒退或重走；需要正面时以合适机位实现。后退跟拍、绕拍交代路径和背景变化，机位变动不改变真实地标、人物位置和动作进度。
- 真正剪辑用 transition: cut，并在 camera 中说明理由与新机位，切前切后动作方向、持物和进度连续；普通运镜/变焦用 continue，视频片段边界不必切镜。
- 同一画面及切换中最多三名重要人物，群演不计；多名角色通过出入画、运镜或构图先后呈现，不删剧情所需人物。背面/远景通过姿态、动作与声音表达情绪，不要求看清不可见的眉眼或嘴型。
- 有打斗时写清攻防对象、关键接触时点、受力方向、结果与位置变化，招式与能力、兵器、伤势和体力一致；一个连续攻防过程可在同一 beat 内完成，不要求每个起手或招式单独分段。

对白与声音：
- 完整原台词保留，说话人、画内/画外/内心、语气和起止时点明确；对白与可见嘴部及动作一致，画外/内心不让未说话的画内人物对口型，不重复台词。
- 独立画外旁白按镜头表原文放入 dialogues，speakerId 为 NARRATOR，delivery 为 off，表演写明画外声且画内人物不对口型；不创建旁白角色卡、身体或图片引用。已有角色的画外叙述或内心独白仍使用其人物 ID。旁白按正常语速计时，可以与动作并行，不能当作环境声或配乐保存。
- 声音有实际声源，交代影响判断的方向、远近、强弱与环境；持续声音跨段延续，不重新起势，静默写明。剧情不需要时不加配乐；已有特效保留来源、变化与同步，不新增剧情或结果。
- 每段 action、camera、space、sound、endState 都写可执行内容，稳定信息可简洁复述，不写「同上」，不以增加段数或重复状态扩写。
- 正文只写已确定的执行内容：机位、方向、站位等需要选择时直接选定一种写清，不写「此处假设」「或……」「视……而定」等推测、备选方案或括号备注。
