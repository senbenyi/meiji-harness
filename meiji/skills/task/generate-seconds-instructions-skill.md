本阶段把已通过镜头表细化为时间线：只在镜头表已确定的事件、切镜点、出镜身份和起止状态之内安排动作、机位、空间与声音；镜头 ID、顺序、时长和身体身份保持不变，参考图片、视频模式和最终视频提示词由后续步骤决定。同编号的镜头表是本镜依据：其起始状态对应本镜 0 秒，结束状态在本镜最后时点达成。

整体统筹：
- 整集生成时统一规划镜头之间的动作进度、对白、人物位置、机位与交接，按清单覆盖全部镜头，先为每镜安排篇幅，不把篇幅耗在前几镜。
- 每镜以 350–650 字为篇幅参考，完整台词和关键动作需要时可扩展；事件、对白与连续性信息完整保留，时长由镜头表事件撑起，不新增动作填时。

分段：
- 按有效动作节拍分段：稳定且无剧情变化的内容合并为 1–5 秒；转向、入场、对白、切镜和关键动作需要时细分到一秒或亚秒。各段首尾相接，覆盖本镜完整时长。
- 每段把持续的动作、机位、空间和声音交代一次，写明持续到何时；需要的信息每段写全，不用“同上”代替，也不逐秒重复同一状态。

起止与交接：
- 第一段承接上一镜末态和本镜起始状态；最后一段在切点达到镜头表规定的末态。末态可以是动作进行中的瞬间：写清动作速度、运动相位、机位运动及持续声音，下一镜从此接续。
- 每段 endState 只记录该段结束时已完成的动作、位置、朝向、姿态和持物，尚未完成的部分留给下一段；跨段、跨镜沿用已知状态，出画、切镜或景别变化不重置人物状态。
- 紧张段以剧情正常速度持续到切点；只有上游明确要求时才安排慢动作、冻结、放松姿态或声音渐弱。
- 切镜发生在镜头表规定的位置，transition 写 cut 并交代新机位；其余为 continue。

动作（action）：
- 写清人物的动作、姿态、表情、身体与头部朝向、视线目标、持物与动作进度，以及动作的发起者、对象、方向、过程与结果；准备、发力、完成与余势连续。
- 转身、起立、倒地或更换交互对象时写清触发、过程与结果；位移写出路径和用时。动作力度与速度符合人物身份、体能、伤势和情绪，伤势、疲惫与持物状态持续延续；表演幅度服从项目风格。
- 视线、手势、道具和移动方向指向同一明确对象，对象移动有轨迹。

机位与可见面（camera）：
- 每段写明：人物面向哪个目标或地标 → 摄影机在人物哪一侧、高度、俯仰、距离与景别 → 画面看到人物哪一面。绝对方位只作补充。
- 人物朝行动目标行动，摄影机负责取景：需要其他角度时移动或切换机位，人物不为露脸转身、停步、倒退或改换目标；对手各有目标，不朝同一摄影机排队展示。
- 正面镜头来自镜头表的安排：切到人物前方后摄影机朝人物后退跟拍，人物继续朝原目标前进；保持相对距离时人物画面大小基本稳定，距离或景别变化要有对应的速度差或机位运动。切到前方后背景是人物走过的区域，原目标位于摄影机后方或画外；切回后方时承接已到达的位置、步态与持物。
- 移动机位写出路径、方向、速度和起止位置，区分移动机位与变焦；连续绕拍写清绕行哪一侧、路径和背景变化。

空间与环境（space）：
- 写明人物相对地标的位置、画面左右及前中后景，多人之间的距离、遮挡、朝向和出入画状态；人物自身左右与画面左右分开表述，切换机位时以固定地标说明真实位置不变。空镜以环境主体为参照。
- 固定地标、光位与人物位置随运镜合理变化，保持轴线、连续位移与实体阻挡。
- 环境连续：把镜头表确定的场景细节落实到各时段，包括背景人物或群体的活动、地标、行动路径、光影与声源变化，按机位说明它们在画内或画外的方向与状态；稳定背景连续沿用，不为填时添加事件。
- 只采用本镜实际所在时空的地面材质、建筑、服装、装备与声源；整集其他时代、地点与身体的资料只作背景。

出镜身份：
- 同一画面同时最多三名重要人物，群演不计；整镜更多人物通过运镜或出入画先后呈现。保留剧情要求的群演规模、行动和位置。
- 中途入场人物写明实际身体、入口、出现时段与离场去向；退场人物交代方向、状态和原因；仅在记忆、台词或下一镜中出现的人物不算本镜出镜。服装、道具和身体身份沿用角色资料。

景别与构图：
- 继承镜头表的景别意图和必须可见的环境；动作关系镜让行动主体、目标和路径可辨，展示规模时保留地标、群体与前中后景。描写外貌、情绪或对白时保持既定景别。
- 写明可见身体范围（全身、膝上、腰上、面部等）、必要的头顶与脚下留白和环境边界；需要控制人物大小时补充主体约占画面高度的比例，与景别、画幅和裁切相容。景别稳定时保持人物相对大小，确需近景时说明关注的信息与时段。
- 远景与背面机位通过姿态、肩背、手部动作、动作节奏与声音传达情绪，看清眉眼、嘴型的要求只用于正面且距离合适的机位。

打斗（剧情有打斗时）：
- 逐段写清出招方与受招方的动作、接触时点、受力方向与反应，步法带来的位置变化和双方朝向；关键招式细分到亚秒，稳定对峙合并。
- 招式符合人物身份、功夫门类、体能、伤势、兵器与时代设定；距离、站位与兵器持握连续，伤势、破损与体力消耗延续；写实或夸张程度由项目风格决定。

对白与表演（有对白时）：
- 每句对白写明说话人、画内/画外/内心独白、语言、起止时点、语气与强弱，与嘴部动作、表情和动作同步；已确定台词保留原文，每句只出现一次。
- 内心独白与画外旁白时画内人物不对口型，内心独白对应人物嘴部闭合；画外声音不配给未说话的画内人物。
- 表情来自剧情情绪与处境，写明变化的触发、时段与程度，多人分别设计反应；只写当前机位能看见的面部。

声音（sound）：
- 写当段实际声音及声源，区分环境底声、近处动作声和远处事件声，交代方向、远近、强弱、质感、遮挡与混响；持续声音跨段、跨镜延续，不每段重新起势；有意静默明确写出。
- 配乐只在剧情需要时安排，不覆盖对白与关键声响。
- 剧情需要的特效写明来源、位置、发生时间、强度、运动和消退，与动作、声音同步。
