依据：
- 保持本镜事件顺序、剧情起止状态、实际身体与固定时长；保留镜头表明确的空间和摄影要求，未规定的摄影与调度由本阶段设计。
- 镜头表已确定的扩充动作、反应、环境互动与旁白属于本镜依据，完整继承，不在本步骤独立新增补时剧情或旁白。

未具名角色：
- 上游未给姓名、角色表以“我”登记时，沿用我和该角色实际 ID，不编造姓名、另建角色或改称旁白。第一人称称谓不代表必须使用主观镜头，按本镜行动与摄影需要呈现其身体。
- 非台词正文按实体清单原样引用；例如角色我的 ID 为 C01 时写 我【我|C01】，名字与标记紧贴，不写 “我”【我|C01】 或 “我”我【我|C01】。C01 仅为示例，实际使用清单 ID；上游带引号的称谓在此规范为上述写法，不改变角色身份或剧情。
- 台词原文中的“我”保留原文，不插标记；speakerId 使用实际说话人的 ID。该角色的画外声或内心独白仍用其 ID，不因出现“我”就改成 NARRATOR。

分段与时间：
- 一个 beat 表达连续动作与摄影，可含多个动作、反应和对白，beat 可以覆盖整镜。不按每秒、动词或固定秒数拆段，不设置固定段数或字数配额；仅在真正切镜、行动阶段/交互对象实质变化或关键接触需独立交代时拆段。微动作合写，精确时点可写在段内。
- 先安排完整行动和正常语速的原台词，再分配 durationMs；串行分别留时，并行写清关系，不借前后镜时间，不用新增剧情、重复动作或等待填时。
- 时点从本镜 0 开始，与 beat 累计区间一致。声音满足 0 ≤ startMs < endMs ≤ 本镜总毫秒数；对白在引用它的 beat 内开始，可跨段延续，不重抄。修改时长后复核总时长及后续动作、对白和声音区间。
- 第一段接本镜起点与前镜切点，endState 只写当段已达到的状态，最后一段符合镜头表末态。持物转移、归位、开合、入场不得提前完成；切镜、出画不重置位置、朝向、持物、衣伤或动作进度。正常行动持续到切点，不强迫段末冻结、减速或摆姿。
- 前镜只承接切点仍存在且本镜需要的状态和声音，不重演其过程或复制摄影安排，不重复已结束对白或延长局部动作声；有上游依据的转场和时间省略按新状态承接。

动作与空间：
- 关键动作写清发起者、对象、必要过程和结果，位移、接触与持物转换连续；微动作不逐项列准备、发力和余势。打斗交代攻防对象、接触时点、受力、结果与位置变化，符合能力、兵器、伤势和体力，可在一个 beat 内完成。
- 按本镜关联资料写朝向目标、相对地标位置、路径、遮挡和出入画；距离与用时相容，区分身体左右和画面左右，不瞬移、穿障碍、交换位置或镜像地标。固定光位不随摄影机变化。
- 保持实际身体、服装、持物与伤势，保留必要群体规模和活动；提及、回忆或意识身份不算出镜，不混入其他地点、时代或身体资料。

摄影与表演：
- 机位用人物、目标和地标的相对关系说明；景别、可见身体范围和留白服务叙事，保留必要环境、路径与群体。近景须有信息或情绪作用，不默认对白配面部特写，不机械轮换；距离、角度、比例仅在影响执行时补充。
- 人物朝向服务行动，不为露脸转身、倒退或重走；正面由机位实现，跟拍/绕拍交代路径和背景变化。背面或远景用姿态、动作、声音表现情绪，不要求不可见的眉眼和嘴型。
- 真正剪辑用 cut，camera 写理由与新机位，切前后方向、持物和动作进度连续；运镜/变焦用 continue，视频片段边界不必切镜。
- 同一画面及切换中最多三名重要人物，群演不计；用出入画、运镜或构图先后呈现，不删剧情所需人物。

对白与声音：
- 保留完整原台词、说话人、画内/画外/内心、语气及时间，与动作和可见嘴部一致；画外声不让画内人物对口型。
- 旁白原文放 dialogues，独立旁白 speakerId 为 NARRATOR，delivery 为 off，不创建可见身体、角色卡或图片引用；角色画外声/内心用其人物 ID。正常语速，可与动作并行，不放环境声或配乐。
- 声音有声源，按需说明方向、远近、强弱；持续声跨段延续，静默写明，无要求不加配乐。已有特效保留来源、变化与同步，不改剧情结果。
- action、camera、space、sound、endState 写简洁可执行内容，不用「同上」或重复状态扩写；直接选定机位、方向与站位，不写假设、备选方案或括号备注。
