人物与参与清单：
- 先完成本镜每秒分镜，再从【本集角色卡人物清单】选取实际参与的 participants，不列全部卡。每项返回 name、presence、outfit；同一卡名与登记别名对应同一人物，只列一次。有可见身体用 visible，全镜只发声用 voice；仅提及人物和独立旁白不列入，无卡内参与者返回 []。
- 卡外剧情人物不进 participants，但保留上游必要动作、出镜和对白；speakerName 沿用实际称谓，delivery 按画内/画外/内心填写，不删台词、不改成 NARRATOR、不要求建卡。卡内说话人必须列入清单，画内对白为 visible。本步骤不生成身份、外貌、固定声线或实体 ID，不为换装或情绪另建角色。
- 沿用上游人物称谓，正文直接使用名称。无姓名且以“我”叙述时保留“我”，不编真名或改称旁白；第一人称不强制主观镜头。台词原文不插标记，角色的画外声/内心声仍归属其实际名称。

剧情依据：
- 保持镜头表的事件顺序、起止状态、实际身体和固定时长，保留完整台词。镜头表已确定的扩充动作、反应、环境互动与旁白属于本镜依据，完整继承，不在本步骤独立新增补时剧情或旁白。明确的空间和摄影要求保留，未规定的摄影与调度由本阶段设计。
- action、camera、space、sound、endState 简洁可执行；直接选定机位、方向和站位，不写「同上」、重复状态、假设、备选方案或括号备注。

分段、时间与交接：
- 一个 beat 可承载连续动作、反应和关联对白，beat 可以覆盖整镜；微动作合写，精确动作时点写在段内，台词用 dialogueIds 关联。仅真正切镜、行动阶段/交互对象实质变化或关键接触需要时拆段，不按每秒、动词或固定秒数拆分，不设置固定段数或字数配额。
- 先安排完整行动和正常语速的原台词，再分配 durationMs。串行分别留时，并行说明关系；不用新增剧情、重复动作、等待或前后镜时间填补本镜。
- 时间从 0 开始，与 beat 累计区间一致；声音满足 0 ≤ startMs < endMs ≤ 本镜总毫秒数。对白在引用它的 beat 内开始，可跨段持续，不重抄；修改时长后复核总时长、动作、对白和声音区间。
- 首段接本镜起点及前镜切点，endState 只写当段已达到的状态，末段符合镜头表终点；持物转移、归位、开合、入场不得提前完成。切镜/出画不重置位置、朝向、持物、衣伤或动作进度；行动正常持续到切点，不强迫冻结、减速或摆姿。
- 前镜只承接本镜所需且切点仍有效的状态与声音，不重演其过程或复制摄影安排，不重复已结束对白或延长局部动作声。有上游依据的转场和时间省略按新状态承接。

动作与空间：
- 关键动作写明发起者、对象、必要过程和结果，位移、接触、持物转换连续；微动作不逐项列准备、发力和余势。打斗交代攻防对象、接触时点、受力、结果及位置变化，符合能力、兵器、伤势和体力，可在一个 beat 内完成。
- 按关联资料交代朝向目标、相对地标位置、路径、遮挡和出入画，距离与用时相容；区分身体左右和画面左右，不瞬移、穿障碍、交换位置或镜像地标。固定光位不随摄影机变化。
- 保持实际身体、服装、持物、伤势及必要群体规模与活动；提及、回忆、意识身份不算出镜，不混入其他地点、时代或身体资料。

摄影与表演：
- 机位以人物、目标和地标的相对关系说明；景别、可见身体范围和留白服务叙事，保留必要环境、路径与群体。近景须有信息或情绪作用，不默认对白配面部特写，不机械轮换；距离、角度、比例仅在影响执行时补充。
- 人物朝向服务行动，不为露脸转身、倒退或重走；正面由机位实现，跟拍/绕拍说明路径和背景变化。背面或远景用姿态、动作和声音表现情绪，不要求不可见的眉眼或嘴型。
- 真正剪辑用 cut，camera 写理由及新机位，切前后方向、持物和动作进度连续；运镜/变焦用 continue，视频片段边界不必切镜。
- 同一画面及切换中最多三名重要人物，群演不计；通过出入画、运镜或构图先后呈现，不删剧情所需人物。

对白与声音：
- 台词原文只写入 dialogues.text，不在 action、camera、space、sound、endState、summary 或 ambient 中重复。每条对白用 speakerName 明确实际说话人，startMs/endMs 确定时间，delivery 明确画内/画外/内心方式，performance 描述当句表演；对应 beat 用 dialogueIds 关联。action 明确谁在说话、说话行为、情绪和听者反应，不抄台词，不用含糊的“有人说”代替已知人物。例：action 写“老板从后厨画外戏谑回击，陈浩听后身体僵住”，dialogueIds 引用 D01，D01 的 speakerName 为“老板”，text 保存原话。
- 保留完整原台词、说话人、发声方式、语气和时间，与动作及可见嘴部一致；画外声不让画内人物对口型。独立旁白放 dialogues，speakerName 为 NARRATOR，delivery 为 off，不创建身体、角色卡或图片引用；角色画外声/内心声使用人物名称。旁白按正常语速可与动作并行，不放环境声或配乐。
- 声音有声源，按需说明方向、远近和强弱；持续声跨段延续，静默写明，无要求不加配乐。特效保留来源、变化和同步，不改剧情结果。

服装状态与当下表演：
- participants.outfit 为每名出镜人物的一段非空着装描述，仅声音人物为空字符串；无变化写当前穿着，有变化在同一段按顺序概括起点及变化后状态，不新增起始/结束字段。具体过程和完成时点写 beat.action/endState，两处一致；跨镜只承接已完成末态，不复制起点或重演穿脱。
- 首次出镜或换装时，按上游交代必要上衣、下装、内外层、款式、颜色、敞开/扣合及衣伤，写入 action/space；后续简洁沿用，不逐段重复，也不用“换了衣服”省略关键差异。未知衣物可说明“沿用上游已知着装，具体衣物未明确”，不编造服饰或新增穿脱剧情。
- 穿衣、脱衣、换装依剧情交代“变化前着装 → 对哪件衣物做什么动作 → 完成时点 → 剩余穿着及衣物去向”，action 与 endState 连续，未完成动作不能写成完成，衣物不无故消失、恢复或更换。裸露状态须有明确剧情及完成动作依据，不能凭参考图、身体资料或笼统“脱衣”推断裸体。上游已明确裸体/已脱衣开场或允许时间省略、场外换装时准确承接，不强迫重演；无依据则保持已知穿着，不编造动作解释状态跳变。
- 参考图只提供固定身份外貌，不决定本镜衣着、姿态或表情。情绪通过动作、姿态和神态变化写 action，对白语气、节奏及嘴部状态写 dialogues.performance，符合本镜事件和上游情绪推进，不改变固定声线，也不留待最终提示词补写。
