本阶段规划剧情事件、片段时长与边界、片段内切镜点、实际出镜身份及起止状态；逐秒动作、表情细节、声音参数、参考素材与视频生成方式由后续步骤决定。

整体规划：
- 先统筹全集事件、场景转换、实际出镜身份及片段首末状态，再决定片段数量与各自时长；相邻的简单事件在同一镜内连续呈现，每镜承担一个主要叙事任务。
- 按大纲因果顺序规划“触发 → 行动 → 结果”。已完成的事件不再重演，后续事件留到对应镜头；时长由事件本身撑起，不用重复站起、举刀、深呼吸等动作填充。
- 单片段 1–15 秒，按事件和连续性分配，15 秒是上限而非固定长度；编号从 S01 顺序递增。Hook 与反转从大纲的真实事件提炼，不按固定间隔安排。

片段边界：
- 优先在场景、时代或身体身份变化处，以及完整对白、关键反应、因果动作完成处分段；一句话或一个关键动作放在同一镜内。事件较长时在可连续承接的中间状态拆段，写明未完成的动作和下段起点。
- 同场连续动作可以跨片段；新场景、机位大跳变、时代或身体切换时，在边界处重新交代人物与场景状态。
- 片段边界与剪辑切镜相互独立：一个片段内可以有有依据的剪辑，跨片段也可以是连续行动。

起止状态：
- 起始状态承接上一镜结束状态：地点、时间、身体身份、位置、朝向、姿态、视线、持物手、伤势、服装、动作进度和持续声音。
- 结束状态写出切点瞬间可复现的状态：位置、朝向、姿势、持物、动作进度与速度趋势、持续声音，并写明下一镜从哪里开始。
- 末态是切点瞬间的动态状态：追击、打斗等持续动作按剧情速度切出，写明下一镜接续的运动相位与速度；只有剧情要求停顿、慢动作或淡出时才安排静止收尾。
- 场景转换交代去向和移动过程，或写明有依据的时间省略。

出镜身份：
- 分清实际出镜、途中入场、离场、纯画外声音和仅被提及的人物；出镜名单只含画内出现的身体，不含仅在台词、记忆或下镜预告中提及的身份。重要人物中途入场时写明入画时机与位置。
- 角色外形、身份或状态变化须有剧情依据；意识换到另一具身体时按实际身体出镜，两种身体的脸和体型分开描述。
- 同一时刻画内最多三名重要人物，群演不计；整镜人物更多时用运镜、出入画或构图切换先后展示，正文保留整镜全部角色，写明谁在画内、谁在画外及出入画时机。
- 群演按剧情保留，写明数量或规模、位置、动作和稳定身份；不需要独立辨识的群演不建卡。

场景与空间：
- 写明主体、其他人物、交互对象与地标的相对位置、朝向和遮挡。按场景卡布局安排移动：距离、障碍与移动用时相容，地标位置全集保持一致。
- 让场景参与叙事：交代地点特征、背景活动、必要群体及规模；“宏大、辽阔、密集”等要求落实为可见的前中后景、地标、群体规模与空间纵深。背景服务当前事件，不新增人物或剧情。
- 保留大纲中承载强度、速度、规模、质感、情绪或氛围的描述，落实到剧情、空间和声音中。

机位与构图：
- 用“人物—剧情目标—摄影机”的相对位置规划朝向与可见面，东南西北只作已有场景坐标的补充。人物朝向由剧情动作决定，展示角度由机位决定：需要正面表情时切到人物前方或后退跟拍，人物继续朝原目标行动，不为露脸转身、倒退或重走。
- 按叙事任务选景别：建立地点、展示规模、群体行动及人物与目标的关系时用远景、全景或中远景；近景和特写用于有意义的反应、关键细节或信息揭示，写明观众要看见什么。对白不自动对应面部特写，连续近景各有新增信息；需要恢复行动全貌时安排有依据的宽景。景别按叙事需要选择，不按固定轮换或数量配额。
- 每镜写明主要景别、主体可见范围和必须保留的环境信息；切镜后背景对应新机位所见区域。

切镜：
- 在动作结果、人物反应、视线目标变化、新信息揭示或有依据的时空转换处切镜，写明理由和切前、切后承接。动作中切镜匹配运动方向、持物与动作进度；交互对象变化要有可见的发现和动作过渡。普通运镜不算切镜。

动作与表演：
- 每镜写清动作的发起者、对象、起始相位、完成点和留给下一镜的部分；转身、起立、倒地等状态变化写出触发与过程。动作力度与速度符合身份、体能、伤势和情绪，伤势、疲惫与持物在后续镜头延续。
- 写明每镜需要观众看见的情绪信息及承载它的景别；只写当前机位能看见的面部，背面或远景用姿态、步态和动作表达。反应镜写明新增的情绪作用。

打斗（剧情有打斗时）：
- 按攻防回合划分镜头，每镜承担一个回合或关键招式；写明回合开始时双方位置、距离与持械状态，以及回合结果；在招式结果、受击反应或局势转折处切镜。
- 招式符合人物身份、功夫门类、体能、伤势、兵器与时代设定，同一人物风格前后一致；距离、站位与兵器持握连续，伤势与体力消耗延续，胜负取决于大纲给出的原因。

对白与声音：
- 有对白时写清每句所在镜头、说话人、画内或画外；已确定台词保留原文，一句完整对白放在同一镜，确需跨镜时注明延续。画外声音不配给未说话的画内人物。
- 写出推动事件或营造氛围的声源及其跨镜延续；配乐只在剧情需要时安排；有意静默明确写出。特效从剧情、环境和项目风格推导，写明来源与位置。
