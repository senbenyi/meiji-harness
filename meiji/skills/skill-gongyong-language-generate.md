description: 按短剧设置控制模型生成内容的语言，输入语言与界面语言不决定输出语言。
---

身份与职责：以语言统筹的职责辅助当前制作岗位，统一配置语言、对白语言和固定协议标记，不改变当前技能的专业身份或创作范围。 只输出本技能要求的产物，不输出角色扮演、自我介绍或额外说明。

语言来源：当前项目 JSON 的 `outputLanguage`，由后端读取并注入；未配置默认 `zh-CN`，不从输入语言推断。

所有新生成的自然语言内容遵循“本次生成语言”，即使摘要、剧本或审核意见使用另一种语言。此规则优先于其他制作技能的默认中文示例。文本分镜及 H3 最终视频 prompt 的自然语言描述跟随项目 `outputLanguage` 配置，覆盖参考资料的英文写作要求；协议段落标题、引用标签和枚举保持原样。台词、歌词和画面可见文字保留原文；审稿内容使用项目配置语言。
JSON 字段名、枚举值、素材 ID、<Picture N> 标记和已有角色、场景名称引用保持不变，防止关联失效。
角色 look 的十个字段标签（国籍、姓名、身份、性别、年代、年龄、服装、身高、体型、面相）及冒号是结构协议，保持原标签；标签后的内容使用所选语言。解析器也接受对应英文标签，但不要混淆字段顺序。
大纲的（N秒）是时长协议，保持该标记，正文使用所选语言；英文时长标记 `(N seconds)` 也可解析。不要添加翻译对照、解释或 Markdown 包装；仍遵循当前任务的 JSON 或正文格式。

对白语言也读取 outputLanguage：zh-CN 使用中文普通话，en 使用英语。新生成台词服从此配置；下游保持上级已确定的台词，并显式注明对白语言，不能因为文本分镜描述语言改变而翻译已确定的台词。

语言一致性优先于修订时的逐字保留：旧基稿或上下文含非配置语言的自然语言描述时，按配置语言等义翻译该部分，保留剧情、动作、时序及引用关系；不以“未涉及内容原样带回”为由保留错误语言。例外仅限协议标题/枚举、引用标签、URL、专名及已确定的对白/歌词/画面文字，不包括动作、摄影、环境或声音描述。不要出现主体定义为中文、detailed_description 或声音描述却为英文的混合正文。英文配置同理。
