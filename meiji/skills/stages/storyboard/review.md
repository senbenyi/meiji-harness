以下为生成前自查及独立审核的语义标准，不进行 JSON 字段级校验。

1. **剧情保真**：每秒指令中的关键事件、对白、反应、因果和结果有对应表达，无漏项、擅改或新增事件。
2. **时间完整**：动作顺序、切镜时点与总时长相容，起止状态能衔接上下镜，不提前演后续剧情。
3. **身份与素材**：按名字核对本镜角色和当前集场景，已有图片不能漏关联；任一已关联图片存在时须采用多模态六段结构，Picture 编号须与程序 URL 列表逐项一致。人物没有混脸或混用身体身份；所选图片用途清楚，Subject 与 Picture 的关系和正文一致，不引用未提供的素材。
4. **调度连续**：切镜及入画后的身份、衣着、情绪/可见表情、姿态、持物、朝向与动作进度清楚并承接上游；人物、摄影机和背景地标使用同一方位基准，场景图观察方向与当前取景关系明确。不能编造未知绝对方位、无故重置状态、镜像背景，或用人物转向代替运镜。
5. **环境与风格**：地标、光位、场景规模、群演和适用特效未被删减或弱化，符合项目风格。景别、可见身体范围和人物占比保持上游意图；新增的近景、特写、正面反应或为露脸改变机位必须有每秒指令明确依据，不能因表情描述或参考图改成人像构图。必要环境没有被裁掉或虚化，不要求背面或远景显示不可见表情。
6. **声音与语言**：台词原文、说话人、声源和语言正确；嘴部状态符合画内/画外身份，声音与动作同步且无重复对白。
7. **模式与可执行性**：正文遵循程序指定模式和真实素材；分镜标签不作为画面元素；参考特征保留说明不存在自相矛盾。
8. **修订范围**：旧意见已解决，未涉及内容保持等义，修改没有破坏其他已成立的剧情或连续性。

判定规则：只报告能指出上游依据与当前内容差异的明确遗漏或冲突，并给出位置和修正要求。等义翻译、合理合并、不同措辞、段落标题排版差异及“可以更详细”不构成失败；已满足项不列入失败意见。没有实质问题即通过。

- 提交前逐段核对所有自然语言描述均为配置语言，尤其 detailed_description 的风格、分段动作、镜头调度，以及声音与配乐描述；不能只翻译主体定义和摘要。

- 按尾帧协议的连续剧情与转场两类关系检查：连续剧情无故重置状态、展示静帧或重复动作，转场先展示旧场景、强行继承旧构图，均指出具体冲突。转场未复刻尾帧、合理弱化旧场景参考、尾帧缺失均不构成失败；不要要求额外停留或过渡镜头。

开场核对：检查最终提示词是否擅自增加主角特写、参考图展示或无来源的首帧约束。存在这些与已审核起始镜头不符的要求时，指出具体差异并退回文本分镜修订；不把剧情明确要求的特写判错。

氛围核对：仅针对与上游明确要求的冲突或遗漏，例如将紧急行动改成悠闲行走、弱化既定威胁声源或抹去应有的人物反应。指出具体差异并退回文本分镜修订，不以个人偏好的“还不够刺激”阻塞，也不在提交时擅自改写剧情。

- H3 文本分镜：只检查语义，包括图片实际对应的人物/场景是否正确，以及已有每秒内容的事件、对白和时间顺序是否保留，允许连续稳定动作合并表述；不要求逐字复述。风格进入配置语言描述。文本分镜自然语言正文跟随项目 `outputLanguage` 配置，协议标题、Subject/Picture 引用和既定其他语言台词不因保留原文判失败。不做 JSON 字段级校验，也不假定程序已经核对素材语义。结合实际有序 URL 列表检查 Subject/Picture 指向是否正确、是否虚构图片或错误绑定身体身份；段落排版差异不判失败。

- 文本分镜：审是否保留每秒指令的剧情、关键时点、切镜、机位与末态；核对图片与实际可见身体，不把意识、画外提及或下一镜角色当成本镜外观参考。首尾帧与角色图用途分开，无真实关键帧不能声称关键帧补全。

- 文本分镜切镜状态：核对每次切镜及人物入画后的身份、情绪/可见表情、剧情衣着及已知损伤、姿态、视线、持物和动作进度，不能切镜后无原因换装、变干净、改变身体或坐骑朝向。稳定属性可明确沿用主体定义；不要求重复角色卡，不要求背面或远景展示不可见的面部细节，不强制编造未知状态。

- 文本分镜朝向：人物面向、摄影机所在侧与观察方向、背景地标朝向及画面位置须在同一空间基准下相容；使用背景图时说明参考视角与当前机位的关系，不允许为正脸构图镜像或旋转场景。绝对方位未知时接受基于已知地标的相对方向，不要求猜测东西南北。近景、特写、正面反应镜头或为了露脸进行的推镜、变焦、绕拍，只能来自每秒指令明确安排；表情、对白或正脸参考图不构成新增依据。

- 文本分镜生成后及手工编辑后的审核，均比较前一镜已通过的最终提示词与本镜待审文本：检查结束→开始的人物身份、站位、朝向、姿态、表情、服装、持物、动作进度、场景方向、机位及声音。结合每镜独立的素材映射核对身份，不能以 Subject/Picture 编号相同或不同直接判断身份相同或变化。

- 前镜未生成、未通过或已过期时，只依据已有上游资料检查，不宣称最终文本跨镜审核完成；缺少前镜本身不作为本镜剧情错误。明确的转场、时间省略和合理机位变化不判连续性失败，只有无解释的状态冲突才报具体原因。
