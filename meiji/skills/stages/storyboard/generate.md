## 朝向优先于参考人像姿态

- 参考人像只绑定身份、体型及指定外观，不继承正面站姿、视线、持物动作、裁切与背景。剧情服装或姿势不同，应说明部分保留，不用 fully_preserved 暗示整张图照搬。
- 首段明确摄影机、人物、剧情目标的相对位置，人物面向目标，以及镜头实际看到哪一面。后续保持关系，切换机位时才更新可见面。
- 背后机位删除与之冲突的可见眉眼、正脸、嘴型特写要求，通过背部姿态、动作和声音保留情绪；不为展示表情让人物转向摄影机。
- 未有上游依据时，不直视镜头、朝镜头摆拍或举枪。对峙目标位于主体前方，不为展示双方脸部把对手移到主体背后。剧情明确要求正面机位时，按该机位执行。

## 行进中的机位转换

- 将上游的相对空间关系直接写入最终提示词：人物面对的目标、摄影机相对人物的位置、实际可见面、行进方向与跟拍方式。不能只保留东南西北而省略背面、侧面或正面构图。
- 上游已安排从后方切到正面时，用明确的切镜标识和时点承接：摄影机切至人物前方、朝人物拍摄，沿其行进方向后退跟拍；人物继续朝原目标行进，不转身、不倒退、不重启动作。只有上游明确要求时才直视镜头。
- 正面镜头的背景改为人物已走过的区域，原前方目标按实际位置处于摄影机后方或画外；保持真实地标与人物位置，不照搬背面镜头的前后景。切回后方时承接位移和动作进度，不让人物回到开场位置。
- 同距跟拍保持人物画面大小基本稳定；接近、远离、推拉或变焦须与上游运动一致。不得为突出表情新增正面镜头、绕拍或推近，也不得把上游允许的正面镜头误改为全程背面。

### 剧情与时间线

- 每秒指令中的事件、动作对象、人物反应、情绪变化、对白、关键物件、因果、转折和段末结果，必须全部进入最终正文。
- 允许等义翻译和合并稳定动作，但不能把具体剧情缩成概述，不能丢失细节、改变顺序或提前演下一镜。
- 镜头表的切镜意图及每秒指令的起止状态不可更改；已确定的关键动作时点和机位变化须保留，稳定段允许等义合并，不把时间线缩成剧情摘要。
- 正文按时间推进，覆盖完整镜头时长；时间可写入动作叙述，不将时间码画在视频上。
- `[Shot 1]` 开始交代风格、人物、环境和起始构图。只有真实剪辑切镜才增加 `[Shot 2]` 等编号，并写明递增的切镜时间；连续移动机位不增加编号。
- 项目风格优先，不套用示例的真人、卡通或配乐风格。

### 人物、空间与机位

- 保留场景丰富度：将上游有叙事作用的环境特征、背景活动、群体规模、空间层次及氛围细节写入视频提示词，明确它们与主体、机位的关系，不压缩成泛泛的地点名称或装饰背景。空场景参考图只提供环境依据，不能据此删除剧情所需的人物或群体；无需独立辨识的群演没有个人参考图也应按剧情保留。不得为丰富画面凭空增加事件，或让无关细节遮蔽主体动作。
- 写清人物面向的地标或对象、机位所在侧与距离、画面可见的身体面；分别描述人物运动和摄影机运动。
- 每个起始画面及切换机位后的画面，都交代「人物面向哪个固定地标或目标 → 摄影机位于人物哪一侧并朝哪里看 → 看见人物正面、背面或哪侧 → 目标与行动方向在画面中的位置」。已有明确关系可连续沿用，不必逐秒重复；不能仅用“保持方向一致”代替具体方位。参考场景图的拍摄角度不强制成为视频机位，换视角时不得镜像地形。
- 逐段继承位置、身体与头部朝向、视线、姿态、服装、持物和动作进度。只有每秒指令已明确要求改变观察角度时，才沿其规定移动或切换机位；不能为了展示人物正脸自行绕拍，更不能让人物无故转身。
- 明确交互的发起者、对象、相对方位、指向和结果；转移目标或改变状态须有过程。切镜不重置人物动作或身份。
- 保留地标、光位、群演规模和出入画状态。同一画面同时最多三个重要人物，群演不计；整镜可以先后呈现更多人物。
- 保留上游形容词的含义与程度；

### 切镜后的状态与背景朝向

- 每个 `[Shot N]` 开始和重要人物中途入画时，在正文中明确当前可见人物是谁、位于哪里、正在做什么。交代情绪与可见表情、身体紧张或疲惫状态、头部与躯干朝向、视线目标、站/坐/跪/骑乘等姿态、双手持物和动作完成程度。
- 衣着按剧情说明主要服装、颜色、装备与适用的穿戴状态；上游已有的伤势、破损、湿润、尘土、血迹、汗水等必须延续，不能切镜后自动恢复洁净或完好。不为凑齐描述而新增伤势、污损、配饰或换装。人物参考图中的中性衣着不得替代剧情服装。
- 多人分别说明状态，不把同一种表情或姿态套给所有人；交代彼此距离、面向谁、谁在遮挡谁，以及画外人物仍在哪个方向。头部转动、躯干转向、坐骑/载具朝向和摄影机运动分开描述，不把转头写成整个人或坐骑转身。
- 稳定外形与衣着可在主体定义中完整描述，切镜正文明确沿用该主体的既定衣着及当前状态；变化必须写明原因、发生时点和变化后的结果。不能只写“同上”或“保持一致”，也不必在每个时间段重复整张角色卡。
- 使用场景图时，在场景主体定义中写明该 `<Picture N>` 的观察方向、关键地标的朝向和相对布局，例如入口面向交锋空地、道路由入口向远处延伸；不能只写“参考背景图”。只采用上游明确或已核实的方向，单张图片无法确定东西南北时用入口内/外、建筑正面/背面及固定地标作相对基准，不猜测真实方位。
- 每次切镜正文将人物和背景绑定到同一空间基准：人物面向的目标或地标、摄影机所在侧及朝向、人物可见哪一面、背景地标落在画面哪侧或画外哪个方向。参考图视角与当前机位不同，应说明当前从哪一侧观察原场景；不能把背景当平面贴图随人物旋转、镜像，或为露正脸交换入口与人物的位置。
- 结尾节奏：将每秒指令的末段动作速度、运动相位和声音明确写入最终视频提示词，动作按剧情速度持续至切点，切出不等于停下。未明确要求时，不在最后几秒减速、慢动作、缓出、叠化、冻结或渐弱声音来凑结束画面；不添加站定、松肩或摆姿收尾。静止机位不等于人物停止，明确的剧情停顿则正常保留。上一镜尾帧参考只约束本镜开场，不是本镜要逐渐过渡到的终点；角色/场景参考图也不是结尾目标。
- 每镜末尾保留下一镜所需的姿态、朝向、衣着损伤、持物、人物相对位置、运动进度和环境状态。下一镜从这个结果继续，不能把正在移动写成重新起步、已放下的物品重新拿在手里，或让紧张表情无原因变成平静。

### 构图保真

- 将每秒指令的景别、可见身体范围、人物相对画面高度、留白及必须可见的环境转写到对应时段；已有比例保留近似含义，不另造统一比例。不将远景/全景改为中近景，也不因描述面部身份而追加推镜。
- 近景、特写、正面反应镜头、面向摄影机以及为此进行的推镜/变焦/绕拍，必须有每秒指令对应时段的明确依据。台词、情绪描写、角色参考图正脸或“电影感”都不是擅自增加这些处理的理由。未指定时保持上游景别和朝向，不添加开场露脸镜头、插入式特写或结尾正脸定格；即使有正面近景，也不能因此让人物停止原动作、换目标或转身，除非上游明确要求。
- 空间关系、行动路径、群体规模和环境纵深属于剧情信息，不能被人物大幅占画或背景虚化抹去。上游要求清晰的地标与目标须保持可辨，不无条件添加浅景深或人像构图。
- 人物参考图用于身份与外形一致性，不复制其拍摄景别、裁切、人物占比或背景；在 subject_definitions 与 retention_analysis 按需明确这一区别。实际构图遵循已审核每秒指令，真实首帧的构图约束另行核对。
- 远景不为显露面部微表情而改变机位；情绪保持上游规定的姿态、动作和声音表达。发现上游构图互相冲突时指出来源，不在转写阶段重新设计镜头。

### 图片与主体绑定

- 先根据每秒指令识别实际可见的身体身份、出入画时段，再按角色卡原名核对本视频项目角色和当前集场景卡；名字被提及不等于人物出镜，记忆中的身份、纯画外声源和下一镜人物不自动成为外观参考。同一意识的不同身体身份按各自角色名匹配，不混用角色图片，不跨集借用同名场景。无名字依据时不猜测别名或图片归属。
- 程序按名称匹配并提供有序 URL 列表；任一匹配角色或场景有已确认的图片 URL，即采用 reference 多模态六段结构。没有图片的主体保留文字描述，不虚构 URL；待确认图片不能作为已确认素材使用。
- URL 绑定链必须完整：角色/场景名字 → 程序列表中的真实 URL → `<Picture N>` → `<Subject N>` → 正文中该主体的动作或环境。URL 由程序随视频请求按原顺序提交，正文使用 Picture 引用，不要求视频模型通过正文中的 URL 自行取图。

- 仅使用程序提供的有序图片列表，`<Picture N>` 对应其第 N 张图片；不增删、重排或自行返回 URL 列表，不引用不存在的素材。
- 在 `subject_definitions` 中说明每个 `<Subject N>` 是谁或什么、来自哪些图片、分别参考哪些特征。主体编号与图片编号是不同体系；一个人物可同时参考主图、服装图和道具图。
- 人物主图锁定身份、面相和体型；已提供服装/道具/发型图按指定用途参考。中性角色主图的姿势与服装不自动覆盖剧情要求。
- 场景主体参考布局、地标、材质和光位；保持镜头要求的环境规模，不能只生成角色特写而丢失场景信息。
- 在 `detailed_description` 的实际动作或场景位置复用每个已定义的 Subject；场景主体也必须在具体镜头中引用，不能只在 summary 或 retention_analysis 出现。正确选中的素材应按真实用途引用；候选素材多余或错误时指出关联冲突，不为使用图片编造出场或“意识参考”。
- `retention_analysis` 说明保留或改变的参考特征及依据，不承诺同时完全保留与剧情冲突的状态。没有真实音频/视频素材时不虚构 Audio/Video 引用。

### 关键帧与中途人物

- 首尾帧约束起止构图和状态，角色图约束人物外观，不能互相替代。逐一核对中途新出现的重要人物，即使首尾帧都看不到他，也需要外观参考。
- 仅按程序明确提供的模式、真实关键帧及接口能力编写提示词。不因存在图片就添加 keyframe completion；普通角色图不是首帧或尾帧。
- 程序确认接口支持组合输入时，分别说明首帧、尾帧和角色参考的用途，保持输入顺序；能力未提供时不得假定支持。
- 不支持组合且关键帧无法覆盖中途人物时，明确报告素材与模式冲突，提出改用角色多模态参考或在入场处拆分并补确认关键帧的需求；不自行拆镜、改剧情或假装已解决，不声称正文 URL 能代替真实图片输入。
- 连续动作接帧必须同时继承运动方向、姿态、动作进度和声音；明确切换机位的镜头不强行保持上一尾帧构图。
- 穿越或变身后只使用当前可见身体的外观，原意识不能成为旧角色图片的使用理由，不拼接两个人的脸和身体。

### 开场与氛围

开场执行：从文本分镜指定的第一个剧情动作、人物状态、景别和机位直接开始。未要求主角特写时，不添加露脸、人物展示、定妆照停留或先特写再拉远的开场，不为展示角色面貌延后剧情。
首帧来源：text/reference 模式不得杜撰首帧图片，不将第一张角色、服装、武器或场景参考图自动当作视频首帧。参考图只提供已定义的参考特征，第一画面的构图和动作由文本分镜决定。只有明确选择 first_frame 且实际提交有效首帧时，才按该首帧接续；不得凭空声称存在首帧或替换已指定的首帧。
剧情氛围：以当前片段的事件、人物目标、危险程度和情绪阶段为依据，落实已审核文本分镜的氛围，不用项目整体风格覆盖局部剧情。即使全剧有喜剧元素，危险、追击或对峙段落也不能默认拍成轻松散步、摆拍或人物展示。紧迫感应体现在有目标的行动、警觉与应激反应、动作和剪辑节奏、威胁所在的空间关系，以及声音的距离、力度、密度和停顿中；安静、舒缓或克制的段落则保留相应节奏。不能只用“紧张、刺激”等抽象形容词代替可见可闻的表现。
氛围服从剧情：沿用已给出的光线、声源和动作，不为增强刺激擅自添加敌人、枪战、爆炸、伤亡、对白或改变事件结果；不通过全程近景、无理由晃动、快速切镜或配乐堆叠替代剧情张力。保持既定景别、人物朝向、行动路线和镜头连续性，保留上游对声音、动作及环境强度的有效描述。
