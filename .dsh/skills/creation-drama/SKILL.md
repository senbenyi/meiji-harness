# 短剧创作

以是否需要多段合成区分，15秒仅作默认分流依据；一次生成且无需合成时使用 creation-video。短剧单段沿用本技能和项目决定，不重新规划。

## 模式选择

用户未指定时，简要说明两种模式并请用户选择：

- **AI 自动**：一句话描述 → AI 全自动规划分镜、生成、合成。适合已有明确想法、追求效率的场景。
- **导演引导**：先选风格模板 → 确认风格方向 → 逐步规划分镜 → 逐镜生成并合成。适合想要创意引导、注重风格统一的场景。

选定后进入对应流程，中途不切换模式。

## AI 自动模式

从用户描述直接规划：拆镜头、分配时长、生成完整 prompt、逐镜生成并合成。只补关键缺项，不额外确认。

## 导演引导模式

### 第一步：选择风格

提供风格模板供用户选择，每个模板包含视觉基调、叙事节奏和典型场景处理方式：

| 模板 | 特点 |
|---|---|
| 电影质感叙事 | 大景深、自然光、沉稳节奏、情绪留白 |
| 悬疑紧凑 | 低调打光、快切、封闭空间、紧张氛围 |
| 都市轻喜剧 | 明亮色调、生活化场景、轻快节奏、对话驱动 |
| 奇幻史诗 | 宏大场景、浓烈色彩、慢动作、仪式感 |
| 文艺情感 | 柔和色调、特写、安静节奏、内心独白 |

用户也可以描述自己想要的风格（如"参考王家卫的色调"），AI 提炼为可执行的视觉和叙事指令，不承诺精确还原。

用户选择或描述后，输出一段风格摘要（视觉、节奏、镜头偏好），请用户确认后再继续。

### 第二步：剧情规划

按确认的风格方向，组织剧情结构：
- 明确人物、冲突和结局走向
- 拆分为有叙事作用的场次
- 多集时规划故事弧线和分集节奏，单条短剧不扩成整季

输出剧情大纲，请用户确认。

### 第三步：分镜与制作

按确认的大纲逐场拆镜头：
- 每镜给时长、动作、对白、镜头运动和风格指令
- 风格模板的视觉和节奏要求贯穿每镜 prompt
- 按 [制作规则](references/production.md) 提交和合成

## 通用规则

- 从已有故事、素材与人工选择继续，不重复已认可的部分。
- 角色设定、真实参考、人工认可版本分开记录；文字或 seed 不代表身份锁定，声音参考不保证口型。缺能力如实说明。
- 改稿复用已采用镜头，只重做受影响部分。
- 保存最小交接：已定故事/角色、风格模板、选片路径、待改项。
