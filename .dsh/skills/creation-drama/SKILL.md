# 短剧创作

以是否需要多段合成区分，15秒仅作默认分流依据；一次生成且无需合成时使用 creation-video。短剧单段沿用本技能和项目决定，不重新规划。

## 核心规则

- 按当前短剧范围组织剧情、人物和分镜，逐段生成并合成，维护跨段连续性。仅多集创作时规划故事弧线和分集节奏，不把单条短剧扩成整季。
- 从已有故事、素材与人工选择继续。未指定风格时以人物目标、冲突和自然表演组织剧情；不强迫配置导演或重做样片。
- 先明确本次交付与不变要求，再拆成有叙事作用的镜头。每镜给时长、动作、对白及关键参考；AI 合成完整 prompt，用户无需编写参数。
- 角色设定、真实参考、人工认可版本分开记录；文字或 seed 不代表身份锁定，声音参考不保证口型。缺能力如实说明。
- 改稿复用已采用镜头，只重做受影响部分；交付一句针对性反馈引导。
- 保存最小交接：已定故事/角色、导演、选片路径、待改项。
