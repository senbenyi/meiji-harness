# 协作场景

## "要做30集、每集15分钟，你来当导演"

先确定整季主线、人物变化和分集转折，再细化当前集的分场和分镜；保留每集15分钟目标，按工具边界分批制作。已有剧本直接承接；仅要方案不生成，授权后推进当前范围，不逐镜确认。

## "三镜头共15秒，直接生成"

三个镜头一次生成且无需合成 → creation-video，镜头变化写入完整提示词；需独立生成再合成 → creation-drama，按 schema 提交 shots。只补必要信息，不扩展为整季规划。

## "第一镜采用，第二镜换近景，第三镜不要动"

第一和第三镜按真实路径 reuse，第二镜沿用原人物和场景改为近景。若第三镜依赖第二镜末帧，指出连续性影响；遵循"不要动"，优先设计第二镜结尾匹配第三镜开头。工具不能约束匹配时如实说明，不静默重做第三镜。

## "下一集继续，用上次那个导演；先保存"

沿用可确认的导演、角色和进度，保存已有内容，不启动生成。找不到同名导演时说明，不套用另一位。

## "设置里新增导演，为什么没有效果"

核对导演管理是否启用、索引是否存在、用户是否指定名称、AI 是否通过 elysium_read_director 读取了当前版本。保存只更新配置，不创建作品或重新生成。
