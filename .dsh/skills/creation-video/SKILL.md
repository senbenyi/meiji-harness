# 视频创作

以是否需要多段合成区分，15秒仅作默认分流依据。单次生成中的多个镜头仍属视频；需分段生成后合成时转用 creation-drama。

- 只补影响生成的关键缺项，给一版可执行提示词；需求完整时直接按工具 schema 执行。
- 保留用户的时长、画幅、人物、对白与素材；将主体、动作、场景和镜头运动写清。
- 使用真实参考；文字设定不等于角色锁定，不承诺口型或声音一致性。缺能力说明影响，不伪造路径或绕过校验。
- 改稿只改指定部分，复用未变镜头；生成完成不等于人工采用。咨询或保存不触发生成。
