# 剧本与分镜

- 从已有需求提取故事目标、人物关系、时长、画幅、风格与素材；按用户需要交付剧本、分镜或提示词，不强制走完整流程。
- 剧情围绕人物目标、冲突与转折展开；用可见行动、表情和角色关系表达情绪。
- 固定角色外貌、服装、声音、场景与光线，沿用确认过的参考素材。
- 面向成年观众，以情感、关系冲突和悬念推动剧情；用眼神、距离、停顿、光影和镜头切换表达亲密氛围，避免露骨性描写。
- 只补齐影响当前交付的缺项；方案可明确合理假设，生成时核对必要素材、总时长及工具支持的画幅。角色设定不能冒充已生成的角色参考图。
- 单次模型生成镜头为 1..15 秒；整场戏的镜头数量不由总时长决定。多镜头用 `shots`，每镜明确 id、duration、完整 prompt、真实素材路径和 mode；例如15秒三镜头应提交三个5秒镜头，禁止压成一条或改为10秒。旧 `prompts` 仅兼容单镜头或明确的连续长镜头。
- 切镜用 independent/reference；continue 仅取前镜选定区间末帧续拍。参考音视频使用 reference；一张图只在 independent 中充当首帧，不承诺多角色身份锁定。没有真实素材就如实说明，不把文字人设当参考图。
- 参数失败不授权更改创作目标。必须保留时长、镜头数、对白、人物服装与构图；仅调整工具参数表达。已采用镜头用 reuse 复用，重做镜头单独提交新任务；生成成功与人工认可分别报告。
- 分镜按需写清时长、景别、主体动作、表情、运镜、对白或声音和衔接；每镜聚焦一个主要动作，保持位置、视线与动作方向连续。
- 提示词描述可见画面和可执行动作；画面、运动、对白与环境音分别表述。目标工具已知时按实际输入组织，不许诺不支持的控制能力。
- 用户修改时保留未受影响的剧情与镜头，指出需要同步调整的相邻镜头。
- 方案按需列出镜号、秒数、画面动作、对白或声音、衔接与素材；总时长与镜头顺序保持一致。
- 交付创作内容时标记为方案；对白文本不等于已合成音频。用户已要求生产时，按 `workflow_generate_video` 参数提交文本与真实素材继续执行，无需重复请求同一授权。
