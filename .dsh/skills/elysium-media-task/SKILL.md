# 媒体任务

## 选择工具

下表用于匹配任务；仅调用本轮实际提供的工具，参数以其定义为准。

| 需求与输入 | 工具 |
|---|---|
| 文字生成图片 | `model_generate_image` |
| 角色图片与 1–6 段连续提示词生成长视频 | `model_generate_long_video` |
| MiniMax H3 T2VA：文字生成带声音的视频 | `model_generate_minimax_h3_t2va` |
| MiniMax H3 FL2VA：起始图片生成带声音的视频 | `model_generate_minimax_h3_fl2va` |
| MiniMax H3 REF2VA：参考图片、视频或音频生成音视频，至少一项素材 | `model_generate_minimax_h3_ref2va` |
| 视频插帧，提高帧率 | `model_interpolate_video` |
| 视频超分，提高分辨率 | `model_upscale_video` |
| 根据视频生成环境音与拟音 | `model_add_video_audio` |
| 明确指定整条短视频工具工作流 | `workflow_adult_short_video` |

## 执行

- 复用已有素材；路径必须符合工具的共享产物目录要求。本地文件或 URL 不冒充服务器路径，缺少可用上传入口时说明缺口。
- MiniMax 按素材与用户指定模式选择入口，不默认忽略参考素材；不自创通用工具名或未声明参数。
- 环境音工具不用于对白合成；只有选定入口明确支持对白字段时才提交对白，不以工作流的可选对白能力推断存在独立配音工具。
- 多项处理按依赖顺序执行，每步使用上一步真实产物路径；已由工作流处理的步骤不重复执行。
- 生成工具通常等待完成后返回 `job_id`、`status`、`path`、大小和哈希；成功返回后直接交付，不重复提交或无意义轮询。
- 任务尚未完成且已有真实 `job_id` 时，用 `model_job_status` 查询，成功后用 `model_job_result` 获取产物。请求中断不等于任务失败，先核对原任务。
- 失败报告错误、任务标识和日志路径。脚本缺失属于执行环境问题，不通过安装插件或调用底层脚本补救。

## 验收

工具成功只证明任务完成。按实际查看结果报告画面一致性、动作衔接、音画配合及目标时长、画幅、帧率或分辨率；无法查看的项目标记待验收。
