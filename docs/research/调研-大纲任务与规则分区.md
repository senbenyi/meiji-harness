# 大纲任务与规则分区

- AC-1：本次任务只说明依据、动作和规则引用，不复制生产规则与输出协议。
- AC-2：基础约束在基础规则，当前集当前节点补充 skill 在补充规则；保留来源标识、冻结快照和节点隔离。
- AC-3：审核只验收，修订边界与输出协议仍由编排代码提供；其他步骤不改变。
- AC-4（追加要求）：剧情生成及审核角色仅说明职业；审核标准与补充资料的执行边界放入审核范围。

取证：`StoryModel.creation` 将 outline.target 整段拼进任务，重复技能中已有的事件、着装、地点、道具、节拍和时长要求。`generationParts/reviewParts` 已读取当前节点补充并放入 system，但标题仍为本节点补充要求/验收依据。Model 可以保留正文与来源、统一大纲补充标题。

待用户决定：无。
