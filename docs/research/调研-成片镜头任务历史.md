# 成片镜头任务历史调研

## 结论与规格
- AC-1：每张成片镜头卡片标题旁有任务历史入口，收起时仍可点击；成片顶部不再展示该入口。
- AC-2：点击后只列对应镜头的成片相关任务，包含整集任务中该镜头的步骤与快照；刷新仍保留筛选。
- AC-3：其他阶段历史入口和筛选保持原行为。
- 目标：将成片历史入口移动到镜头卡片并绑定镜头。
- 非目标：更改任务存储、生成流程或接口。

## 调用链与证据
- `client/stages.js:renderStage` 当前给所有阶段统一添加顶部历史入口；`renderFilm` 按镜头构建卡片。
- `client/execution-history.js:historyEntry/renderTaskHistory` 使用字符串 scope 导航，仅按 action 筛选。
- `client/app.js:actions.openHistory` 原样传递 scope，无需修改。
- `server/data/task-store.js:createTaskRecord` 历史不保存 operation.track；`steps.target` 和 `artifacts.target` 保存精确镜头 ID。
- `client/shot-card-state.js:decorateShotCard` 标题区域在收起时保留。

## 判定
三项标准的实现路径已确认，当前 AC-1/2 未满足；使用 `film:Sxx` 的字符串 scope 和既有目标信息，无需调整接口。
