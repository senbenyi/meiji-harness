# 自动提取视频尾帧调研

## 结论
已确认：运行项目 S01 的尾帧错误为「本机未安装 FFmpeg」，本机 PATH 也无 FFmpeg。当前代码在视频步骤内提取并吞掉错误，任务计划没有尾帧步骤。

## 规格
- 目标：视频保存后自动执行独立尾帧步骤，成功保存本地图片，失败可见且保留视频。
- 非目标：重新生成视频、调整提示词和视频接口。
- AC-1：单镜、整集、逐镜制作均在生成视频后记录 `tail_frame` 步骤。
- AC-2：提取失败时视频仍 ready，尾帧与任务失败；单独重试不提交新视频。
- AC-3：已完成视频缺尾帧时整集/逐镜操作补提取，成功结果供下一镜使用。

## 调用链与证据
`registry.video → opFilm/opFilms → video_generate → saveFilmResult → saveTailFrame → saveLastFrame`。`films.js` 中 saveTailFrame 捕获错误不抛出；`registry.js` 视频计划仅提交、生成两步；FFmpeg 本地缺失。GitNexus 当前索引已绑定本仓库，saveFilmResult 的直接调用方为 opFilm、opFilms。
