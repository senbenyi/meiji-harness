# 项目详情内边距调研

## 结论
- AC-1 — 已确认 — 详情工作流 `margin:0 -18px` 抵消了 `.elysium-panel-body` 的左右内边距，阶段卡片贴齐面板左右边。
- AC-2 — 已确认 — 总览滚动区 `.elysium-series-workflow .elysium-step-detail-body` 左右 padding 为 0，负边距取消后仍依赖面板内边距才能离开边缘。

## 规格
- 目标：项目详情有整体内边距，阶段卡片不再贴边。
- 非目标：不改卡片内部布局、不改收起态导轨。
- 验收标准：
  - AC-1：展开的项目详情中，阶段卡片左右不贴齐面板边框。
  - AC-2：标题栏与卡片共用同一套整体内边距，不因负边距再次贴边。
