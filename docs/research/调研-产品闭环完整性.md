# 产品闭环完整性调研

## 结论

- AC-1 — **已确认** — 部署→启动→访问→创作→出片 主链路完整，无断点
- AC-2 — **已确认** — 失败→自动重试→手动恢复→出片 容错链路完整
- AC-3 — **已确认** — 四个预设各有人格、规则和工具配置，切换即生效
- AC-4 — **待实施** — 成片无导出出口 → 方案：卡片加下载按钮 + 服务端代理下载端点
- AC-5 — **待实施** — 创作历史无回溯入口 → 方案：右侧可收起/拖拽资产面板
- AC-6 — **待实施** — 导演模式缺少分镜管理闭环 → 方案：本地 JSON 分镜 + 面板内分镜标签页

## 规格

- 目标：从产品使用角度审核所有流程是否形成闭环，假设代码质量 OK，只关注体验完整性。
- 非目标：
  1. 不评估代码质量、性能或安全性
  2. 不评估部署脚本的健壮性
  3. 不提出架构重构建议
- 验收标准：逐条列出产品闭环的完整/断裂状态及依据。

### AC-4：成片下载

**变更范围**：2 个文件（服务端 1、客户端 1）。铁律不变。

**铁律澄清**：铁律"不允许下载方法"禁止的是 AI 自动将所有视频批量下载到本地文件系统。用户在卡片上主动点击下载按钮属于正常交互，不违反铁律。铁律文档无需修改。

#### 服务端：新增 download 端点

文件：`dsh-elysium-tools/src/http/media-jobs.js`

在现有 `status/video/image/credentials` 四个端点之后，新增 `/download` 端点。逻辑复用 `createMediaHandler` 的 token 校验和 call→job 查找，但响应方式不同：不做 302 重定向，而是代理请求 `comfyui_view_url`，以 `Content-Disposition: attachment` 返回文件流。

```
GET /plugins/dsh-elysium/media/download?session=X&call=Y&t=TOKEN
```

处理流程：
1. 复用现有 token 校验（`timingSafeEqual`）
2. 查找 job，确认 `has_video || has_image`
3. 用 `fetch` 请求 `comfyui_view_url`，流式转发到客户端
4. 设置 `Content-Disposition: attachment; filename="elysium-{job_id}.mp4"`
5. 转发上游的 `Content-Type` 和 `Content-Length`

为什么代理而非 302：302 重定向到 ComfyUI 内网地址，浏览器无法直接访问（隧道环境下）。代理方式确保下载可达。

注册方式：在现有 `for` 循环的 suffix 列表中加入 `'download'`：
```js
for (const suffix of ['status', 'video', 'image', 'credentials', 'download'])
```

#### 客户端：卡片加下载按钮

文件：`dsh-elysium-tools/src/client/media/card.js`

1. **移除限制**：删除 dialog video 的 `controlsList: 'nodownload'`（第 106 行）
2. **新增下载按钮**：在 `.elysium-info > .elysium-heading` 区域添加下载图标按钮

下载按钮位置：`.elysium-heading` 右侧，与标题同行。仅在 `video` 存在且 `mediaReady` 时显示。

```js
// 下载 icon（向下箭头 + 托盘）
const downloadIcon = h('svg', { width: 16, height: 16, viewBox: '0 0 24 24',
  fill: 'none', stroke: 'currentColor', strokeWidth: 1.7,
  strokeLinecap: 'round', strokeLinejoin: 'round', 'aria-hidden': true },
  h('path', { d: 'M12 3v12m0 0-4-4m4 4 4-4M4 17v2a2 2 0 0 0 2 2h12a2 2 0 0 0 2-2v-2' }))
```

下载行为：
```js
const downloadUrl = mediaUrl('download', sessionId, callId)
// <a> 标签 + download 属性触发浏览器下载
h('a', { href: downloadUrl, download: '', className: 'elysium-control elysium-download',
  'aria-label': '下载视频', title: '下载视频' }, downloadIcon)
```

按钮样式（追加到 styles.js）：
```css
.elysium-download {
  position: static; display: inline-grid; width: 28px; height: 28px;
  border-radius: 6px; color: var(--media-muted);
}
.elysium-download:hover { color: var(--dsw-alias-label-primary, #fff); }
```

### AC-5：资产面板

**变更范围**：服务端新增 1 个列表端点，客户端新增 3 个模块（面板容器 + 资产列表 + 样式）。

#### 数据源

资产列表的数据来自 `$ELYSIUM_TOOLS_STATE_ROOT/jobs/` 目录。每个 `{jobId}/status.json` 包含完整的任务信息。

#### 服务端：资产列表端点

文件：`dsh-elysium-tools/src/http/media-jobs.js`（或新文件 `src/http/asset-list.js`）

```
GET /plugins/dsh-elysium/media/list?t=TOKEN&limit=50&offset=0
```

处理流程：
1. Token 校验（复用现有逻辑）
2. 扫描 `jobs/` 目录，读取每个 `status.json`
3. 按 `status === 'succeeded'` 过滤，按创建时间倒序
4. 返回 `jobSummary` 数组 + 分页信息

响应格式：
```json
{
  "items": [
    { "job_id": "...", "status": "succeeded", "media_info": {...},
      "profile": "regular", "specification": {...},
      "comfyui_view_url": "...", "has_video": true,
      "created_at": 1726099200000 }
  ],
  "total": 42,
  "has_more": true
}
```

性能考量：
- 首次扫描可能慢（文件系统遍历），但 jobs 数量有限（创作工具场景，通常 < 500）
- 后续可加内存缓存 + 文件 watch 刷新，但首版不做

注册方式：加入现有端点循环，或单独注册一个 `list` 路由。

#### 客户端：面板组件

**架构**：

```
src/client/
├── media/
│   ├── ...（现有文件）
├── panel/                    # 新增
│   ├── asset-panel.js        # 面板容器（收起/展开/拖拽）

│   └── panel-styles.js       # 面板样式
```

新模块需加入 `scripts/client-source.mjs` 的模块列表。

**面板容器** (`asset-panel.js`)：

布局方式：通过 CSS 注入改变 Harness 页面布局。面板作为 `position: fixed` 的侧边栏叠加在右侧。

```
┌──────────────────────────┬─────────┐
│                          │ 资产    │
│     Harness 主界面       │ 面板    │
│    (自然缩进)            │ (固定)  │
│                          │         │
└──────────────────────────┴─────────┘
```

状态管理：
- `collapsed`：布尔值，控制展开/收起。默认收起。
- `width`：面板宽度，默认 `10vw`（展开时），最小 180px，最大 50vw。
- 状态存储在 `localStorage`，键名 `elysium-asset-panel`，跨刷新保持。

切换按钮：
- 位于页面右上角（`position: fixed; top: 12px; right: 12px`）
- 图标：折叠时显示展开箭头（←），展开时显示收起箭头（→）
- 面板展开时，按钮吸附在面板左边缘

拖拽调宽：
- 面板左边缘有 4px 宽的拖拽手柄，`cursor: col-resize`
- `mousedown` → `mousemove`（更新宽度）→ `mouseup`
- 拖拽期间设置 `user-select: none` 和 `pointer-events: none`（防止 iframe 干扰）
- 松手后将宽度写入 `localStorage`

主界面适配：
- 面板展开时，在 `<body>` 上设置 `padding-right: {panelWidth}px`
- 收起时移除 padding
- 通过 `useEffect` 管理 body style 的生命周期

注册方式：
- 使用 `document.body.appendChild` 挂载独立 DOM 容器（不依赖 slot）
- 在 `apply()` 中创建容器并 `ReactDOM.createRoot().render()`
- 切换按钮同理，挂在独立容器中

**资产列表** (`asset-list.js`)：

数据获取：
```js
async function fetchAssets(offset = 0, limit = 50) {
  const config = window.__ELYSIUM_MEDIA__
  const query = new URLSearchParams({ t: config.token, limit, offset })
  const res = await fetch(`${config.base}/list?${query}`, { cache: 'no-store', credentials: 'same-origin' })
  return res.json()
}
```

列表项渲染：
```
┌────────────────────────┐
│ ▶ [缩略图]             │  ← 视频首帧或 poster
│ 视频 01                │

├────────────────────────┤
│ ▶ [缩略图]             │
│ ...                    │
```

每个列表项：
- 缩略图：使用 `<video>` 标签 + `preload: 'metadata'` 显示首帧，src 为 `comfyui_view_url`
- 标题：`视频 {序号}`（倒序编号）
- 元信息：档位 + 分辨率 + 时长（复用 `specificationLabel`）
- 时间：相对时间（"3 分钟前"、"2 小时前"、"昨天"）
- 操作：下载按钮（链接到 `/download` 端点，需要 sessionId+callId 或直接用 comfyui_view_url）
- 点击列表项：在面板内展开播放

滚动加载：
- 面板内容区 `overflow-y: auto`
- 滚动到底部时自动加载下一页（`IntersectionObserver`）
- 首次展开面板时触发加载

```json
      "prompt": "一家温暖的街角咖啡馆...",
      "job_id": "abc123...",
      "status": "succeeded",
      "notes": "光线偏暗，考虑重拍"
    },
    {
      "index": 2,
      "label": "近景 · 主角入座",
      "prompt": "...",
      "job_id": null,
      "status": "pending",
      "notes": ""
    }
  ]
}
```

字段说明：
- `id`：8 位随机 hex
- `shots[].index`：镜号，从 1 开始，支持插入/重排
- `shots[].job_id`：关联的视频任务 ID。`null` 表示未生成
- `shots[].status`：`pending`（未生成）、`generating`（生成中）、`succeeded`（已出片）、`replaced`（已被替换）
- `shots[].notes`：用户或 AI 的审片备注

#### 服务端：分镜端点

新文件：`dsh-elysium-tools/src/http/storyboard.js`

```
GET    /plugins/dsh-elysium/storyboard/list?t=TOKEN
GET    /plugins/dsh-elysium/storyboard/get?t=TOKEN&id=X
POST   /plugins/dsh-elysium/storyboard/create   { title }
POST   /plugins/dsh-elysium/storyboard/update   { id, title?, shots? }
DELETE /plugins/dsh-elysium/storyboard/delete?t=TOKEN&id=X
```

所有写操作通过 POST body（JSON），读操作通过 query string。Token 校验复用媒体 token。

操作逻辑：
- `list`：扫描 `storyboards/` 目录，返回所有 manifest 的摘要（id、title、镜头数、created_at）
- `get`：返回完整 manifest
- `create`：生成 ID，创建目录和空 manifest
- `update`：合并 patch 到现有 manifest，更新 `updated_at`
- `delete`：删除整个 storyboard 目录

注册方式：类似 `registerMediaRoutes`，在 `src/index.js` 中调用。

#### AI 工具集成

分镜管理需要与 AI 工具协同：

1. **读取分镜** — 新增 `read_storyboard` 工具，让 AI 了解当前分镜计划
2. **绑定镜头** — `workflow_generate_video` 完成后，如果上下文中有活跃分镜，自动将 `job_id` 写入对应 shot
3. **更新备注** — AI 审片后可通过 `update_storyboard` 工具写入 notes

这部分属于后续增强，首版面板可仅做展示和手动管理，不依赖 AI 工具。
