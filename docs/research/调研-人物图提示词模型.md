# 人物图提示词模型调研

## 结论
- AC-1 — 已确认：新增 `server/prompts/models/character-image.js`，仅保存人物资料、规则正文、自定义像素画幅；可 JSON 往返。
- AC-2 — 已确认：现有逗号串不带字段名，基础转换采用具名资料和 Markdown 分节。实际图片理解准确率未验收。
- AC-3 — 已确认：用户指定正文在 `skills/constraints/character/generate-character-image.md`；由调用方提供字符串，完整保留，不在本次接入加载器或筛选年龄分节。
- AC-4 — 已确认：基本函数应支持任意正整数像素宽高，无默认画幅；不代表网关支持该尺寸。
- AC-5 — 已确认：用户追加说明只定义结构和基础函数，后续统一接入；已撤回本次对四个现有逻辑文件的接入改动。

## 规格
- 目标：定义人物图提示词 model 与基本转换函数。
- 非目标：接入已有接口、加载器、预览、网关或 UI；改变已有年龄分支；修改规则正文或场景逻辑；实际调用图片模型。
- 验收标准：AC-1 三个具名顶层属性且可 JSON 往返；AC-2 具名人物外观资料；AC-3 完整正文/空正文；AC-4 自定义画幅与输入校验；AC-5 现有逻辑不变。
