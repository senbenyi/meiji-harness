# 剧情重新生成清除旧数据调研

## 结论
- AC-1 已确认：prepareChecks 只标记开始，generateStoryPackage 从旧卡片初始化，opOutline 又通过 preserveStoryAssets 按姓名继承图片。
- AC-2 已确认：finish 的无草稿接口失败回退会恢复旧内容，必须为本次用户明确的清空重生语义调整。
- AC-3 未验收：需验证同名卡片无旧图、阶段失败无旧数据恢复、其他剧集和意见修改不受影响。

## 规格
- 目标：outline 的 regenerate 在请求前清空本集旧剧情及其下游，重新提取卡片不继承旧素材。
- 非目标：不删除全局素材库文件、任务历史、其他剧集、摘要或节点补充；按意见修改仍以原稿为基础。
- AC-1：重新生成请求开始时大纲、人物/场景/道具、旧图关联、候选图、镜头和合成都为空；成功后只含本轮结果。
- AC-2：首请求故障、阶段失败或取消后，不恢复上次剧情；已生成的新阶段按既有规则保留。
- AC-3：修改模式、其他剧集和补充保持不变；全量不得新增无关失败。
