# 项目驱动视频创作调研

## 结论

2026-09-19：已确认现有模式依赖 Harness 预设，项目页面主要是手工编辑与浏览；目标闭环需要跨预设、数据、工具、路由和前端修改。以下 AC 均尚未完成新流程验收。

## 规格

目标：聊天发起创作后自动打开项目，由用户配置素材，依次生成剧情、分镜，经人工提交后生成成片。

非目标：本轮不区分不同项目模式的生成策略，不改模型原始工作流模板，不重新清空素材库。

- AC-1：Harness 不再用导演/自由/教学预设决定创作流程；项目保存模式，默认导演，各模式流程一致。
- AC-2：聊天提出创作需求后创建项目，自动展开侧栏并定位该项目，提示“请配置项目素材”；历史消息回放不抢导航。
- AC-3：配置支持男主单选、女主单选、配角多选、道具多选、场景单选、主题单选、导演单选，以及粘贴/导入剧情或小说文本。所有素材均可不选，未选项保存为空。
- AC-4：配置下一步才调用 AI，结合创作需求、选中素材及参考文本生成不超过 200 字的剧情，保存并展示，允许人工修改后继续。
- AC-5：业务流程纵向展示，点击剧情可展开具体内容，刷新后仍可恢复当前项目阶段。
- AC-6：剧情下一步调用 AI 生成可编辑分镜，使用当前剧情和素材；不自动执行视频生成。
- AC-7：人工审核点击提交后才生成视频，提交绑定审核版本；修改上游后旧分镜标记需更新，旧审批不能授权新版本，重复提交不重复启动。
- AC-8：复用已有任务、失败恢复和合片能力，显示进度、失败原因及最终可播放视频；通过真实 Harness 页面验收。
- AC-9：兼容历史项目与会话，保留原数据、任务和现有未提交修改，媒体继续使用服务器 URL。

解释待确认：“选择了素材模式”按“选择了素材”处理；男主/女主各一个，配角多个；文本首期为粘贴或 UTF-8 TXT/Markdown 导入，导入在浏览器读取为文本，不新增媒体上传存储。

## 调用链

当前：Harness preset → agent/projection 工具可见性 → project_create（强制导演）或自由模式隐藏工作区 → 手工项目/锚点/分镜/成品页面 → video_generate → 参数校验 → 平台工作流 → 成片。

目标：聊天需求 → project_create → 当前会话实时事件打开项目 → 素材配置 → 用户下一步 → AI 剧情写入 → 展示/修改剧情 → 用户下一步 → AI 分镜写入 → 人工审核提交 → 服务端版本及参数校验 → 现有视频任务 → 交付。

失败分支：AI 失败保留已保存内容；过期 AI 回写拒绝；素材失效提示重选；视频失败保留 job/backend 并走已有恢复链路。

## 证据表

| 来源 | 已确认事实与边界 |
|---|---|
| `src/tools/agent/presets.js`、`projection.js` | 只有导演预设开放项目工具，自由/教学另行处理。路径均相对 dsh-elysium。 |
| `src/tools/project/context.js`、`src/tools/prompts/creation.js` | 自由/教学指向隐藏内部项目；提示词要求不同流程，必须同步修改。 |
| `src/tools/project/project.js`、`src/database/managers/projects.js` | 创建必须指定导演，项目写入没有目标的剧情生成/审核阶段。 |
| `src/database/schemas/projects.js` | 分镜现有字段不足以承载时长、景别、运镜及素材绑定；项目没有目标配置和剧情结构。 |
| `src/client/workbench/projects.js`、`index.js` | 当前横向步骤及手工编辑；侧栏开闭/项目选中为本地状态，没有创建项目自动导航桥接。 |
| `src/client/commands/creation.js` | 宿主输入指令可通过 actx.get('conversation').send 发起对话；独立侧栏获取当前会话的具体公共 API 尚未确认。 |
| `src/client/workcard/card.js` | 已通过 uiConversation.events 处理工具结果，可作为实时项目导航集成线索；历史回放防重需补充验证。 |
| `src/server/workflows/videos/service.js` | 已有会话启动锁、任务绑定和恢复，没有人工审核版本约束。 |
| `src/models/providers/autodl/workflows/minimax-h3/director.js` | 支持多镜头、续接、参考和音视频合片，可复用；引用素材仍受平台输入限制，不能承诺任意数量图片直接进入单镜头。 |
| `harness/.dsh/.agent-presets/`、`harness/.dsh/settings.yaml`、`harness/scripts/install.mjs` | 模式入口来自预设目录与默认值；安装只覆盖不清除旧目录，仅删除模板不能移除已安装旧选项。 |
