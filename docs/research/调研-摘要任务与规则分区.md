# 摘要任务与规则分区

- AC-1：角色只保留身份，任务一句说明项目摘要/剧本、指定集、生成或修订动作及规则引用。
- AC-2：基础 skill 在基础规则，summary 节点补充在补充规则；语言在 system 只出现一次，输出协议独立。
- AC-3：user 按项目摘要、剧本、时长/风格、前集已发生事实、后集衔接排列；上下文只展示资料，不重复通用规则。
- AC-4：首次、重新生成、人工/自动修订及审核沿用数据隔离、固定用户时长、保存协议和预览同源。

证据：`buildEpisodePrompts → interfaces/episode → EpisodeSummaryModel → request.js`。Model 角色夹带职责；任务含模式及重复边界；contextSegments 混合故事标题、语言、参数与跨集创作要求。基础 skill 已具备跨集衔接、悬念、剧情容量规则。语言经 generationParts/reviewParts 解析但接口没有传给 Model；现输出仅 summary，时长由程序保留用户设定值。

待用户决定：无。
