# 移除调用持久索引调研

## 结论

- AC-1 — 已确认 — 完成后的工具结果已经由 Harness 会话日志提供 `call_id → job_id`。
- AC-2 — 已确认 — 任务执行中的工作卡仍需短期关联，可使用 Harness 主进程内存保存。
- AC-3 — 已确认 — Job、Task 和 Driver 有独立持久化，不依赖 `runtime/calls` 保存任务实体。

## 规格

- 目标：删除 Elysium 对工具调用关系的重复磁盘记录，以 Harness 会话日志作为完成结果的事实源。
- 非目标：不修改 Job、Task、Driver、工作卡接口和任务复用规则。
- 验收标准：
  - AC-1：完成调用可从 Harness 日志定位原 Job。
  - AC-2：运行中调用可在当前 Harness 进程内定位原 Job。
  - AC-3：源码、构建产物和运行目录不再出现 `runtime/calls`。

## 调用链

```text
工具受理 → 进程内绑定 call_id → job_id → 工作卡轮询
工具完成 → Harness 写入工具结果 → 日志优先查询 → 清除进程内绑定
```
