# 任务步骤调用链与冗余清理调研

## 结论
- AC-1 — 已确认：入口、全部注册操作的领域分派、文本/图片/视频步骤与结束路径已按源码核对，见下表。
- AC-2 — 已确认：expandStage 只有预留测试使用，reviewKinds 没有使用者；executeOperation 重复执行 runOperation 已完成的项目鉴权；storyboard 只是 binding 的转发。
- AC-3 — 未验收：清理后应保持权限、步骤顺序、任务状态、后台等待、取消和历史行为，需测试验证。

## 规格
- 目标：按真实调用链删除无调用实现、重复检查与无意义中转，收窄模块导出。
- 非目标：不重设计生成流程、不修改数据结构或用户数据、不修复既有技能/剧情测试失败，不删仍使用的后台执行路径。
- AC-1：每种注册操作均能定位入口、领域处理函数和步骤执行路径。
- AC-2：删除的实现无生产调用，重复路径收敛后仍执行原有工作；无残留引用。
- AC-3：实际操作的授权、步骤、取消和历史行为保持；全量测试不新增失败或取消。

## 调用链
| 操作/分支 | 实际链路与步骤 |
|---|---|
| 面板生成 | client/api → http/routes POST /turn → tasks.start → validateOperation → createTaskRecord(planSteps) → queue.run → beginTask(刷新计划) → runOperation |
| 面板直接操作 | routes 的 directActions、图片确认接口 → runOperation；创建先建项目，编辑/删除/确认不经生成队列 |
| 会话生成/任务控制 | session-content-generate-tool → tasks.start；session-task-control-tool → get/wait/cancel；session-project-manage-tool 创建走 runOperation，打开走 links.ensureProject/selectProject |
| 操作分派 | runOperation（会话校验、项目锁、项目归属检查）→ startExecution → executionContext/checkContext → executeOperation：pre → project → 剧集作用域 → review → prepareChecks → episode |
| create/open/overview/episode-add/edit/delete/project-delete/library-import | projectOperations；无 plan 的操作由 runnerStep 整体包装 execute/save；删除不持久化任务 |
| episode-summary-draft/episode-generate | projectOperations → generateEpisode → runTextSteps；草稿额外 save 到未发布 artifact；正式生成写入剧集 |
| outline | storyOperations → generateStoryPackage → 大纲、人物、场景、道具各一组 runTextSteps，失败停止后续 |
| characters/scenes/props | storyOperations → regenerateCardGroup → runTextSteps |
| shots/revise-shot/seconds | storyOperations → generateShots/reviseShot/generateAllSeconds → runTextSteps；每秒指令原文另记 artifact |
| shot-seconds | 注册表仍保留，但 validateOperation 明确拒绝外部提交；内部生成函数及测试仍使用，不能据此删整个生成模块 |
| shot-storyboard/storyboard-bind/storyboard | storyOperations → generateShotStoryboard/generateStoryboard → compileVideoPrompt（generate）→ reviewStep（程序审核）；无模型修订步骤 |
| shot-boards | 先生成每秒指令，再按镜头执行上项分镜流程 |
| source/outline-text/character-text/scene-text/storyboard-text/shot-assets/prop-delete/review-override | storyOperations；按定义包装 save、save+review 或 override，保留人工权限限制 |
| image/revise-image | imageOperations.opImage → startImage → deps.defer(submitAssetImage) → image_generate/image_download/image_save → stageImageDraft；仅生成候选 |
| pencil | imageOperations.opPencil → submitPencilBoard → 图片三步骤 → 候选保存 |
| confirm-image/discard-image/import-image/set-reference/clear-reference/clear-image/part-import/part-text/use-asset | imageOperations，对应 review/episode 分派；confirm 或 save 步骤；只有人工确认才入素材库 |
| film | opFilm → video_submit → defer(video_generate → tail_frame)；后台错误写入步骤并记日志 |
| films | opFilms 顺序逐镜执行视频三步骤；已完成视频跳过提交，仅在缺尾帧时补提取 |
| produce/produce-all | produceShots → executeSteps(shotSteps) → 嵌套 runOperation(shot-storyboard/film/tail-frame)，共用任务并分 scope；每镜等待视频和尾帧后再继续 |
| tail-frame/assemble | opTailFrame/opAssemble，入口整体包装 tail_frame/assemble |
| 通用文本步骤 | runTextSteps → executeSteps(textSteps)：generate → review（程序/模型 attempts）→ 最多一次 revise → re_review；runTextRequest → 网关；每步由 runStep 记录 |
| 结束/失败/取消 | runStep 写步骤结论；runOperation 等后台完成后 releaseOperation → endExecution → finalizeSteps；runner.settle 读终态，未开始任务走 abandonTask；重启 interrupt/restart 取消本地任务 |
| 展示/状态 | deriveTaskStatus 从步骤推导；runner.current/get/wait 和历史接口 → client current-task/execution-history → task-steps |
