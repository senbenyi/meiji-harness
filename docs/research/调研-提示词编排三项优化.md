# 提示词编排三项优化调研

## 结论
AC-1 已确认：shot-prompts 混合任务与事实，空上下文仍输出；人物图首次生成未使用 Model。
AC-2 已确认：generateShots 在流程结束后校验总时长；整集每秒失败被复制到每镜。
AC-3 已确认：大纲缺少可核对的标题骨架，提取任务未突出可见身体与空环境边界。

## 规格
目标：落实建议文档的三个优先项，保持现有保存协议和制作门禁。
非目标：新增调用阶段、自动确认素材或绕过审核。
验收标准：AC-1 分离任务、事实、上下文、规则、意见与输出；AC-2 校验参与步骤结论且反馈去重；AC-3 大纲分节，提取边界生成与审核一致，新项目复测。

## 调用链与证据
Models → skill-prompts → text-steps → shot-text/story → projectStore。
shot-prompts.shotContext 固定输出空上下文，遗漏场景 landmark/light；textSteps 已支持 check；generateShots 未传入 check；generateAllSeconds 将全局 check 写给每镜。
GitNexus 标记 runTextSteps 为共享关键路径，沿用现有执行器，仅增加调用方校验与反馈归属。
