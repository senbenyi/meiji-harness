# 双来源可选自审调研
## 结论
用户明确无需界面开关，按流程声明可选程序审核/模型审核。现有validate在生成阶段抛出，check在自审合并但依赖模型审核；模型审核强制执行，不支持程序独立或无审核流程。
## 规格
目标：内容程序检查与模型检查统一为自审结论，按流程配置0/1/2种来源。
非目标：界面设置、放宽内容映射、把网络故障伪装成内容问题、修改历史数据。
AC-1 程序失败仍完成生成，进入自审，记录不通过并至多修订一次。
AC-2 程序/模型均可独立缺省，未配置不请求、不伪造通过；无修订函数不自动修订。
AC-3 两类审核执行记录可见、失败合并；原文保存任务草稿，无法解析不发布。
AC-4 现有API失败/取消及合法内容保存语义保持；各调用方不再由旧validate提前中断。
