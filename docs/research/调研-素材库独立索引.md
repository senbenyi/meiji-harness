# 素材库独立索引调研

## 结论
- AC-1 — 已确认 — 当前素材列表通过遍历项目任务和导入目录临时组装，没有全局素材库索引。
- AC-2 — 已确认 — `projects/<id>/materials.json` 仅保存项目引用，不是全局素材库。
- AC-3 — 已确认 — 现有删除通过任务目录内的 `asset-deleted.json` 分散记录。

## 规格
- 目标：在 `pools/materials.json` 建立全局素材库索引，保留原媒体的项目或导入归属。
- 非目标 1：不复制、移动或删除媒体文件。
- 非目标 2：不改变项目素材引用结构和三类素材筛选语义。
- AC-1：首次读取素材库后，`pools/materials.json` 包含已有成功创作与导入素材的身份、来源和删除状态。
- AC-2：新导入素材会写入全局索引；新生成的成功任务在素材库下次读取时被无损补入。
- AC-3：移出素材库只更新全局索引，任务、原文件和项目引用保留；旧删除标记能迁入。
- AC-4：创作素材、项目素材、导入素材的筛选、搜索和分页行为不变。
- AC-5：不新增 Elysium 一级目录，索引归属 `pools/` 跨项目主数据。

## 调用链
`GET /media/list` → 发现成功任务与导入素材 → 同步全局索引 → 按索引删除状态与原有筛选返回。

`POST /media/upload` → 原文件落入 `uploads/` → 写入全局索引。

`POST /media/delete` → 校验已完成素材 → 标记全局索引中的删除状态。
