# 分镜与 H3 提示词输入参数调研

日期：2026-09-19

## 结论

- AC-1 — 已确认：新流程通过 `shots` 阶段生成结构化分镜，再通过 `inputs` 阶段生成每个 Segment 的最终 H3 Prompt。
- AC-2 — 已确认：两个阶段共享项目要求、风格、画幅、总时长、完整剧情、项目共享素材及目标片段上下文；`inputs` 还在 request.target 中携带实际视频后端与模型描述。
- AC-3 — 已确认：素材经工具返回为 JSON 文本，图片 URL 不自动转成图像消息；旧配置的主题、导演库详情、男主女主槽位没有由新 context 函数单独展开。
- AC-3 — 未确认：某次模型回复是否实际遵循了所有字段，以及聊天历史或额外工具读取补充了什么；本轮核对的是固定传参路径。

## 规格

- 目标：说明当前分镜及最终 H3 提示词生成时，程序实际传给 AI 的参数。
- 非目标：修改业务实现、触发剧情/分镜/视频生成。
- AC-1：追踪页面按钮到聊天工具读取与结果回写。
- AC-2：列出固定输入字段和两阶段差异。
- AC-3：区分数据传入、图片视觉输入、模型遵循及未接入字段。

## 调用链

```text
生成分镜信息 / 生成全部分镜
  → generateProduction(project, 'shots', segmentId?)
  → production-request：校验剧情与片段时长、会话、修订号
  → conversation.send：阶段、request_id、项目总时长
  → project_production_read → production.context：JSON 文本资料与阶段说明
  → 会话 AI → project_production_complete → shotValues 校验并保存

生成 H3 输入沿用该路径，将 stage 改为 inputs，并添加 request.target。
```

## 固定输入

| 层级 | 字段 | 说明 |
|------|------|------|
| 项目 | original_request / requirements | 原始需求和当前编辑后的创作要求。初始化 requirements 会拼入已有 configuration.reference_text。 |
| 项目 | style / aspect_ratio / target_seconds | 风格文本、画幅、全片目标秒数；初始 style 取 project.director 字符串，不自动查询导演库风格和作品。 |
| 剧情 | story.text / story.scenes | 完整剧情及全部 Scene；Scene 包含 id/title/description/location/time/duration。 |
| 目标片段 | id / scene_id / title / description / duration / character_count | 目标片段身份、所属场景、名称、剧情动作、时长、出镜人数。 |
| 衔接 | start_state / end_state | 片段开始和结束状态。 |
| 七类素材 | materials.characters/clothing/props/scene/music/ambience/dialogue | 人物、服装、道具、场景、背景音乐、环境声音、对白与声音。 |
| 各素材类别 | description / intent / asset_ids | 描述；auto/specified/none 意图；指定的项目素材 ID。 |
| 共享素材 | assets | 整个 production.assets 数组，不只当前片段选中的条目。包含 ID、名称、分类、描述、URL，以及已有状态、任务、版本等属性。 |
| 已有分镜 | segments[].shots | 重新生成时旧分镜也保留在上下文；首次生成是空数组。包含 start/duration/action/framing/camera/lighting/dialogue/sound 等。 |
| 流程控制 | project_id / request / 修订状态 | 请求 ID、阶段、会话、目标片段 ID、版本等。用于绑定、校验，非画面创意。 |
| 仅 H3 输入阶段 | request.target.backend / request.target.model | 解析当前视频后端和模型描述。shots 阶段没有自动加入同样的视频模型目标信息。 |

分镜阶段 instructions 要求返回 `duration/action/framing/camera/lighting/dialogue/sound`，覆盖全部目标 ID，段内时长之和等于 Segment 时长，人物服装道具继承项目和片段。首次生成时，景别、运镜、光线没有独立的片段级字段，由 AI 结合已有文字生成；后续编辑后的旧分镜会作为上下文传入。

H3 输入阶段 instructions 要求每段返回 `prompt/mode/reference_asset_id`，覆盖人物服装道具、分镜时间、对白、环境声音乐、风格、开始结束状态，并限制 t2va/i2va。新 context 会移除目标片段的旧 inputs 和 generations；不会直接带入此前视频内容或旧 H3 Prompt。它仍会保留其余片段属性，如 selected_generation ID。
