# 镜头表、每秒指令与成片优化调研

## 规格与结论

目标：每个生成目标一个纯约束文档，由独立 Model 编排资料、模式与协议，并落实节点 skill、意见修改、历史及实时步骤。

| 验收项 | 判定与实际证据 |
|---|---|
| AC-1 约束与编排分离 | 已确认：shots/seconds 接口复用片段，仍读取 common/generate/review/revise/protocol 多文件；shot-prompts.js 拼接任务资料和格式 |
| AC-2 独立 Model | 已确认：镜头表、每秒指令、文本分镜未有对应 Model；video.js 在视频提交前追加技能与意见 |
| AC-3 节点补充隔离 | 已确认：node-skills.js 可映射相关目标，但 skill-entry.js 只将摘要及剧情三节点转入节点管理；其他阶段仍走项目补充 |
| AC-4 每秒执行范围 | 已确认保留整集调用并按单镜意见局部修订：generateAllSeconds 一次生成并审核整集；registry.js 禁止面板 shot-seconds 单独提交 |
| AC-5 成片完整链路 | 已确认包含文本分镜与视频提交：produceShots 逐镜执行文本分镜与视频，film 流程含提交、等待下载、保存及尾帧处理；最终提示词在文本分镜阶段形成 |
| AC-6 预览与历史一致 | 已确认缺口：preview.js 对 seconds 使用第一镜预览，video 使用占位提示词；需匹配真实目标与素材 |
| AC-7 数据与验证 | 未验收：计划阶段不运行生成或修改代码；后续需验证失败保留、成功意见消费、修改范围与旧数据迁移 |

## 调用链

页面/工具 → registry/run → story 或 films 操作 → shot-text/film → shot-prompts 与 interfaces → 网关及项目保存。

文本阶段复用生成、自审、自动修订一次、复审。成片逐镜先通过文本分镜，再提交视频；前镜尾帧参与后镜实际素材选择。
