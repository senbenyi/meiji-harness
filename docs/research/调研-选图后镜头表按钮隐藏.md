# 选图后镜头表按钮隐藏调研

## 结论
- AC-1 已确认：paintShotTable 仅在 canGenerate 为真时创建按钮，前置资料未通过就隐藏入口。
- AC-2 已确认：use-asset 经 pictureRecord 仅修改 image，保留文字资料及审核；需回归验证完整保存链。
- AC-3 已确认：当前已有多个剧集缺少 plot.props，门禁要求道具审核通过；页面与服务端错误未具体说明缺哪一项。

## 规格
- 目标：选图后镜头表入口稳定可见，前置审核不被选图改变，阻塞原因明确。
- 非目标：不自动审核、不放行缺失道具、不修改用户运行数据或绕过制作门禁。
- AC-1：有无图片、前置条件是否通过，镜头表生成按钮都可见；未满足时禁用，全部通过时启用。
- AC-2：人物、场景选用素材图片后，已有大纲、人物、场景与道具的审核结果保持，镜头表可生成状态不变。
- AC-3：缺少道具提取或其他审核时显示对应节点与状态，服务端拒绝理由一致；完成前置后恢复可用。

## 调用链
人物详情选素材 → use-asset → pictureRecord → projectStore.save。
镜头表页 → paintShotTable → canGenerate(shots) → 大纲/人物/场景/道具审核条件。
