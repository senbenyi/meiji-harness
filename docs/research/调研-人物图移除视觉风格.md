# 人物图移除视觉风格与语言调研

## 结论
- AC-1 已确认：interfaces/character-image.js:generate 注入项目风格；modify 给 model 传 style。两个入口均须移除。
- AC-2 已确认：models/character-image.js 包含 style 属性、规范化和视觉风格分节，应整体删除。
- AC-3 已确认：人物提示词、模型及通用图片技能测试包含风格断言，需要同步；其他图片阶段保留原断言。

## 规格
- 目标：人物图生成、参考和修改提示词不再注入项目视觉风格，model 不再定义 style 属性。
- 非目标：改变用户规则正文或人物资料，修改其他阶段的风格逻辑。
- 验收标准：AC-1 人物接口不传递/注入 style；AC-2 model 忽略 style 输入且最终文本无风格分节；AC-3 全量测试无新增失败。

## 调用链
人物 generate → segment；人物 modify → model → toPrompt/toSegments。
