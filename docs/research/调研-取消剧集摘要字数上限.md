# 取消剧集摘要字数上限调研

## 结论
- AC-1 — 已确认：共享校验、手工保存及弹窗均有 500 字上限，须统一取消。
- AC-2 — 已确认：生成规则、审核规则、输出协议及 Model 属性仍声明上限。
- AC-3 — 已确认：非空和用户时长有独立校验，可以保留；项目总摘要限制不属于本次范围。

## 规格
- 目标：取消剧集摘要字数上限，长摘要完整生成、回填和保存。
- 非目标：不修改项目总摘要限制、时长设置、输出结构或其他阶段。
- AC-1：超过 300、500 字的摘要可生成、手工新增、编辑及 source 保存，不截断；页面只显示字数。
- AC-2：生成、修订、审核及预览提示词不再要求摘要字数上限。
- AC-3：空白或非字符串摘要仍拒绝；用户设定时长及剧情容量规则保持。

## 调用链
摘要生成 → generateEpisode → episodeSummaryFailures / normalizeEpisodeDraft → 保存。
剧集弹窗 → episode-add/edit → episodes.js 的 episodeSummary；source 保存共用该校验。
EpisodeSummaryModel → 基础规则、审核规则与协议 → 实际请求及预览。
