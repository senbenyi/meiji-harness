# 项目列表封面与剧集解耦调研

## 结论
- AC-1 — 已确认 — `list()` 经 `load()` 调用 `ensureEpisodes`，无 `episodes[]` 的项目抛 409「项目缺少剧集结构，请新建项目」，整表失败。
- AC-2 — 已确认 — 列表只需项目目录即可摘要；封面、集数、剧情不依赖旧剧集结构。
- AC-3 — 已确认 — 现有封面只认图片 `cover_job_id` / 锚点图；视频任务 `has_image=false`，列表 `ShotPreview imageOnly` 无法展示第一帧。
- AC-4 — 已确认 — 卡片现展示制作阶段而非集数与剧情摘要；素材栏 CSS 隐藏封面图。

## 规格
- 目标：项目列表不要求剧集结构，有项目即展示；已有视频时用第一帧作封面；卡片展示封面、标题、集数、剧情摘要。
- 非目标：
  1. 不改 Scene/Segment 制作流程。
  2. 不恢复旧分集工作台到主客户端。
  3. 不要求用户手工选封面。
- 验收标准：
  - AC-1：磁盘上存在无 `episodes` 的项目时，`list` 返回该项目，不返回 409。
  - AC-2：摘要含 `title`、`episode_count`、`plot_summary`；集数取项目计划集数或合片集数。
  - AC-3：片段或成片已有成功视频时，列表封面为该视频第一帧（本地 ffmpeg 抽帧并缓存）。
  - AC-4：展开的项目列表卡片可见封面、标题、集数、剧情摘要；收纳后仍只显示标题。

## 调用链
```text
GET /project/list
  → store.list()
    → load(id) → 现：ensureEpisodes → 无 episodes 则 409，整表失败
    → 目标：读 JSON 即摘要，缺剧集不拒绝
  → projectSummary
    → 现：封面=图片 cover / 锚点；meta=制作阶段
    → 目标：封面=指定图片或成功视频 job；plot_summary；episode_count
GET /media/image?job=&frame=first
  → 视频任务抽第一帧 PNG 并缓存
ProjectList 卡片
  → img.elysium-project-cover + 标题 + N 集 + 摘要
```
