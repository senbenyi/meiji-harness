- 只返回 JSON：`{"summary":"本集完整摘要","durationSeconds":120}`。　〔6 处，如 episode:regenerate/generation〕

- 由 AI 按剧情容量决定实际时长，必须在 40–80 秒内；　〔6 处，如 episode:regenerate/generation〕
- 摘要非空且最多 300 字（不计空白，标点计入）。　〔9 处，如 episode:regenerate/generation〕

| 删除或移出的内容 | 去向或理由 |
|---|---|
| common 中的编剧身份 | model 的【角色与职责】保持，消除第二次角色定义 |
| 带 durationSeconds:120 的 JSON 示例 | 删除固定时长锚定；protocol.md 改为明确 summary、durationSeconds 两个字段及类型 |
