# 文件访问集中化调研

## 结论
AC-1 — 已确认 — `src` 曾有 40 个 `database` 外源码文件直接导入 Node 文件系统模块，存在系统性边界漂移。

AC-2 — 已确认 — 既有架构测试仅检查目录和依赖方向，没有禁止文件系统入口回流。

AC-3 — 已确认 — 媒体读取还通过原始文件句柄进入 Server 和 Runner，需要保留接口兼容并隐藏真实句柄。

## 规格
- 目标：所有源码文件读取、保存和修改统一经过 `dsh-elysium/src/database`。
- 非目标：不改变业务状态机、存储布局、Provider 协议和用户数据。
- 验收标准：
  - AC-1：`src/database/files.js` 是 `src` 唯一允许导入 `node:fs` 的文件。
  - AC-2：架构测试能阻止新的直接文件系统入口。
  - AC-3：现有配置、任务、媒体、Provider 和发布行为保持通过测试。

## 调用链
业务模块 → `database/files.js` → Node 文件系统

媒体调用方 → Worker 媒体接口 → Database 托管句柄 → Node 文件系统
