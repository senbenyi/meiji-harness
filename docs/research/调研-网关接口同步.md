# 网关接口同步调研

## 结论
- AC-1 — 已确认 — 文本 `POST chat/completions`、Bearer 鉴权、`finish_reason` 处理与新文档一致，无需改动（`gateway.js:completeChat`）。
- AC-2 — 未确认 — 文生图仍走已删除的异步接口 `images/tasks`（`gateway.js:generateGatewayImage`），且不传 `seed`，网关默认 666，重新生成总是同一种子。
- AC-3 — 未确认 — 带参考图生图把 data URL 放进 JSON `image` 字段；新文档要求 multipart `POST /v1/images/edits`，字段为 `image[]`。
- AC-4 — 未确认 — 视频参考图为 `/v1/files` 返回的 URL，新文档只接受 data URL；未传 `size`，横版项目会得到默认的竖版 576x768。
- AC-5 — 未确认 — 停止、查询超时、服务重启都会调用 `…/cancel`，新文档已没有取消接口。
- AC-6 — 未确认 — 确认图片、导入图片、导入配件、提取尾帧、提交视频前都会调用 `uploadGatewayFile`（`/v1/files`），新文档已没有文件接口。
- AC-7 — 未确认 — 门禁以 `imageUrl` 作为图片通过条件（`drama-model.js:cardModel`、`image.js:pictureRecord`），尾帧也以它作为承接条件（`tail-frame.js:previousTail`）。
- AC-8 — 未确认 — 没有迁移脚本；旧数据仍含 `imageUrl` / `file`。
- AC-9 — 未确认 — 人物详情的「人物图片 URL」与参考图预览都从网关文件接口读图（`image-access.js`、`routes.js`）。
- AC-10 — 未确认 — `meiji/docs/gateway-api.md` 仍是旧接口文档。

## 规格
- 目标：插件调用网关的方式与 `下游接入接口文档.md` 一致。
- 非目标：不改 Messages 接口（插件不用）；不改阶段技能正文（分镜参考列表仍以「URL」称呼程序提供的有序地址，只把远端地址换成本地地址）；不迁移任务历史里记录的旧请求参数。
- 用户决定：
  - 彻底删除 `imageUrl` / `file`（图片远端地址与文件记录），并提供迁移脚本。
  - 视频尺寸按项目画幅：`1344x768` → `1024x576`，`768x1344` → `576x1024`。
  - 没有取消接口：只停本地，如实记录远端任务可能仍在运行。
- 验收标准：
  - AC-1：文本请求保持 `POST /v1/chat/completions`。
  - AC-2：无参考图生图发送 `POST /v1/images/generations` JSON `{model,prompt,size,seed}`，读取 `data[0].b64_json` 得到图片；停止任务时中断请求。
  - AC-3：有参考图生图发送 multipart `POST /v1/images/edits`（`model`、`prompt`、`size`、`image[]` 文件），不带其他字段。
  - AC-4：视频提交 JSON 含 `size`（按画幅），`reference_images` 为从本地读取的 data URL（素材库图片、旧版剧集图片、上一镜尾帧）；请求体超过 64 MiB 时本地报错，不发送。
  - AC-5：任何流程都不请求 `…/cancel`；视频停止或查询超时的错误信息写明「网关不提供取消接口」及远端任务 ID；重启时节点错误同样写明。
  - AC-6：任何流程都不请求 `/v1/files`。
  - AC-7：新写入的数据不含 `imageUrl` / `file`；图片有 `localPath` 或 `assetId` 即算通过；尾帧有 `localPath` 即可被下一镜承接；读取仍含 `imageUrl` 的剧集时拒绝，提示执行迁移脚本。
  - AC-8：`scripts/migrate-image-url.js <DSH_HOME>` 迁移前备份，剥除 `imageUrl` / `file`，把分镜参考快照的远端地址换成本地地址，写后读回核对；可重复执行；`configure-harness.sh` 启动前调用。
  - AC-9：人物详情不再显示「人物图片 URL」，删除 `/character-image-url` 接口与 `image-access.js`；参考图预览从本地读取；「更换 / 删除」按钮只看本地图片。
  - AC-10：`meiji/docs/gateway-api.md` 与新文档一致；`architecture.md` 同步。

## 调用链
- 文本：`chat.js:askModel` → `gateway.js:completeChat` → `POST chat/completions`。
- 图片：`operations/images.js:startImage / startPartImage / opPencil` → `image.js:submitAssetImage / generateStillFile / submitPencilBoard` → `gateway.js:generateGatewayImage` → `POST images/tasks`，轮询 `images/tasks/{id}`，下载 `…/content`；中止时 `cancelOnStop` → `POST …/cancel`。
- 确认图片：`images.js:opConfirmImage` → `uploadGatewayFile` → `savePicture(…, { imageUrl })`。导入：`opImportImage`、`opPartImport` 同样上传。
- 分镜：`shot-text.js:generateShotStoryboard` → `shotReferenceImages`（优先 http `imageUrl`）+ 尾帧 `tail.imageUrl`；要求全部为 http 地址，否则报「请先确认并上传本镜参考图片」。
- 视频：`films.js:opFilm / opFilms` → `publishLocalReferences`（上传本地图片并写回 `imageUrl`）→ `filmSubmit`（`referenceImages = snapshot url`）→ `film.js:submitH3` → `gateway.js:submitGatewayVideo`（无 `size`）→ `retrieveGatewayVideo` 轮询与下载；中止时取消远端任务。
- 尾帧：`films.js:saveTailFrame` → ffmpeg 抽帧 → `uploadGatewayFile` → `tail.content.imageUrl`；`tail-frame.js:previousTail` 要求 `imageUrl`。
- 重启：`index.js:cancelRemote` → `cancelGatewayTask`；`restart.js:interruptRunning`。
- 预览：`routes.js /reference-preview`、`/character-image-url` → `image-access.js:readGatewayImage`（只允许网关 `/files/` 地址）。
