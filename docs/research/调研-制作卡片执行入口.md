# 制作卡片执行入口调研

## 结论
- AC-1 — 已确认 — 当前流程只出现在横幅「AI 生成 片段规划」，标题栏只有项目名。
- AC-2 — 已确认 — 卡片按钮是「下一步：生成剧情」等，动作挂在上一张卡，不在本卡。
- AC-3 — 已确认 — 会话模型写在项目描述卡正文，不是标题下的次级文字。

## 规格
- 目标：标题右侧展示当前执行流程；各卡用「执行」跑本卡流程；需要大模型的卡在标题下显示「大模型：xxxxx」。
- 非目标：
  1. 不改服务端生成协议。
  2. 不改详情页内「保存 / 提交当前 Segment」等编辑按钮。
  3. 不取消进行中横幅的继续/取消。
- 验收标准：
  - AC-1：总览标题右侧显示当前流程（如「片段规划」），与标题有间隔且颜色/字重不同。
  - AC-2：总览卡不再出现「下一步：…」；「执行」在本卡（生成剧情卡执行剧情，片段卡执行 Segment，以此类推）。
  - AC-3：需要大模型的卡在标题下显示「大模型：…」。
  - AC-4：点击执行后标题右侧流程更新为该阶段。

## 调用链
```text
ProjectWorkflow 标题栏 h1
  → 现：仅 project.title
```
