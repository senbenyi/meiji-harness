# 香港中转网络调研

> 2026-09-21 修订：原方案把香港当作 SSH 跳板，本机仍自建 `-L` 隧道；现改为**香港网关**，本机只访问香港 HTTP 地址，不再依赖任何隧道。修订原因见"问题"表 P-3。

## 结论
- AC-1 — 已确认 — 两台 GPU 反向隧道运行，GPU 端或香港端断开后约 10s 自动恢复。
- AC-2 — 已确认（模拟） — `~/.bashrc` 登录钩子 + `flock`，登录一次即拉起且单实例。
- AC-3 — 已确认 — `veo-comfyui` / `veo-qwen38` 经 `veo-hk` 登录（仅运维用途）。
- AC-4 — 未确认 — 网关链路香港侧已通（E-22），nginx 与项目配置切换待实施。
- AC-5 — 未确认 — 反向服务端口已绑 127.0.0.1（E-22）；公网 16016/18000（gost-gateway，临时）待撤除，80 待由 nginx 监听。
- AC-6 — 已确认 — `-direct` 别名直连可用。
- AC-7 — 已确认 — comfyui 经香港 7890 访问 GitHub/HuggingFace 返回 200。
- AC-8 — 未确认 — nginx 未安装；安全组已放行 80（E-21）。
- AC-9 — 已确认（代码） — `settings.js`、`servers.js` 已支持聊天 `transport: 'http'`，相关测试 20/20 通过；专项单测待补。

## 规格
- 目标：香港 43.154.247.11 作为网关——GPU 服务经 GPU 主动建立的反向隧道汇聚到香港回环端口，由 nginx:80 按路径对外；本机 Harness 只访问 `http://43.154.247.11/comfy`、`http://43.154.247.11/qwen/v1`，本机不建立任何 SSH 隧道，消除本机 → seetacloud 跨境丢包。
- 非目标：
  1. 本期不做鉴权与 TLS（用户 2026-09-21 决定，后续处理）。
  2. 不追求降低往返延迟下限。
  3. 不引入 WireGuard/Tailscale（容器无 `/dev/net/tun`）。
  4. 不重启任何服务器（香港、两台 GPU 容器），不中断 ComfyUI 与 llama-server；nginx 只 `reload`。
  5. 不删除 SSH 中转别名与 `-direct` 别名（保留运维登录与回退）。
  6. 不删除项目 `ssh` 传输实现（其他登记仍可使用）。
- 验收标准：
  - AC-1：两台 GPU 机向香港建立反向隧道；杀掉 GPU 端隧道进程或断开香港端 `tunnel` 会话后，60 秒内无人工介入自动恢复。
  - AC-2：隧道进程全部停止后，经任一入口（直连 SSH、AutoDL 网页终端）登录一次即自动拉起且只运行一份；不重启服务器，以模拟方式验证。
  - AC-3：本机 `ssh veo-comfyui` / `ssh veo-qwen38` 经 `veo-hk` 跳转登录成功（运维用途），主机密钥校验不降级。
  - AC-4：本机 Harness 的 ComfyUI 与聊天模型均直连 `http://43.154.247.11/...`；设置页"连接"成功后本机 `pgrep -fl 'ssh -M'` 为空；本机对 `/comfy/system_stats` 与 `/qwen/v1/models` 各连续 100 次请求 0 失败、p95 < 1s。
  - AC-5：香港公网只监听 22、80；`22001/22002/26016/28000/7890` 均绑 127.0.0.1；`tunnel` 密钥不能取得 shell，comfyui 密钥只能监听 22001/26016，qwen38 只能监听 22002/28000。
  - AC-6：`veo-comfyui-direct` / `veo-qwen38-direct` 直连可用。
  - AC-7（可选）：`veo-comfyui` 经香港代理访问 GitHub、HuggingFace 返回 200。
  - AC-8：nginx `/comfy/` → comfyui 6016、`/qwen/` → qwen38 8000，其他路径 404；关闭缓冲、超时 600s，流式输出与大文件上传下载不被截断。
  - AC-9：`chat.tunnel` 为 `{ alias, transport: 'http' }` 时通过校验、不解析 SSH 身份、`ensureConnection` 不建隧道；`transport: 'ssh'` 行为不变。

## 调用链
```text
本机 Harness
  ├─ ComfyUI：resolveServer → backend.base_url = http://43.154.247.11/comfy
  │    → ensureConnection：transport 'http' → 直接返回（transport.js:72）
  │    → ComfyClient/media-reference 以 base_url + '/' 相对拼接（保留 /comfy 前缀）
  └─ 聊天：legacyTunnelBackend → chat.backend.base_url = http://43.154.247.11/qwen/v1
       → chat.tunnel.transport 'http' → 不计算 ssh_identity，不建隧道
  ↓ HTTP（本机 → 香港，0% 丢包，E-2）
香港 nginx:80
  ├─ /comfy/ → 127.0.0.1:26016 ⇐ -R ⇐ veo-comfyui 127.0.0.1:6016
  └─ /qwen/  → 127.0.0.1:28000 ⇐ -R ⇐ veo-qwen38  127.0.0.1:8000
       └─ 反向隧道断开 → GPU tunnel.sh 10s 重连；香港 ClientAlive 清理旧监听
历史任务素材：media.js:88-91 对 job.server 快照调用 connectBackend
  └─ 快照为旧 ssh 登记 → 会重建本地 -L 隧道   [待验证点，AC-4]
```
