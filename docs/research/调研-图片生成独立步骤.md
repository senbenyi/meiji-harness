# 图片生成独立步骤调研

## 结论
AC-1 — 已确认：registry.js imagePlan、part-image、pencil 目前只计划 image_generate。
AC-2 — 已确认：gateway.js POST、URL 下载、Base64 转换目前在单函数内；task-store.js runStep 支持按 kind+target 独立记录及错误状态。
AC-3 — 已确认：image.js 保存后 images.js stageImageDraft 登记候选，client/task-steps.js 集中中文标签。

## 规格
- 目标：四个独立任务步骤反映实际工作。
- 非目标：修改提示词、输入协议、存储 schema、视频或确认流程。
- AC-1：图片、修改、部件及铅笔分镜计划依次包含调用 API、下载图片、转 Base64、保存候选图片，目标匹配且不产生计划外步骤。
- AC-2：URL 分支四步顺序执行，失败和取消定位到当前步骤，后续不执行；旧 b64_json 和 ComfyUI 不需要的步骤正常跳过。
- AC-3：保存步骤覆盖图片处理、候选文件保存与项目候选登记；UI 显示四步中文名称；输入、确认使用和生成结果保持原有行为。

## 调用链
registry 计划 → images 操作 → image 生成及保存 → gateway 请求/下载/转换；task-store.runStep 记录状态；client/task-steps 展示。
