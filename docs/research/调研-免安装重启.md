# 免安装重启调研

## 结论与规格
- 目标：在已配置的本地 Harness 中直接加载当前 meiji 代码与 skill。
- AC-1 — 已确认：不安装、不构建、不重新注册；现有 web profile 已通过软链接指向本仓库。
- AC-2 — 已确认：重启后读取新代码与技能；`meiji/skills/load.js:95` 的缓存仅在进程内，`meiji/index.js:49` 启动注册会话技能。
- AC-3 — 待验证：只停止指定 Harness 的 3080 监听进程，等待正常退出后启动；无服务则直接启动。
- AC-4 — 待验证：依赖、构建或源码链接不正确时，在停止服务前报错。
- 非目标：首次安装、更新上游源码、迁移历史数据、清除面板保存的技能修改层。

## 调用链与证据
- `configure-harness.sh`：安装 / 构建 → plugin add → 检查 3080（已运行即退出）→ 迁移 → web。
- `../deepseek-harness/apps/cli/src/profile-boot.ts:280`：SIGTERM 调用正常关闭，执行资源清理。
- `meiji/index.js:39`：关闭时释放任务管理器；重启不恢复进行中任务。
- 本机 `~/.dsh/profiles/web/node_modules/@meiji/harness-plugin` 指向当前源码目录。
