# 恋爱短剧五类素材库调研

## 结论
2026-09-19 已确认：当前索引 136 条有效素材（创作 133、导入 3），按来源筛选；不支持独立的文字素材记录。导演库有 5 条记录，部分被历史项目引用。本次需要同时修改存储、接口和工作台。

## 规格
- 目标：清空当前素材列表，按人物、场景、道具、主题、导演管理可复用恋爱短剧素材。
- 非目标：删除历史项目及远端媒体文件；自动生成完整短剧；重构视频执行链路。
- AC-1：旧素材从新素材库列表消失，重启及扫描后不重新出现；历史项目引用仍可读取。
- AC-2：素材页显示五个分类，支持图片与文字资料的查看、搜索、编辑和分类管理。
- AC-3：首批人物、场景、道具含真实可访问参考图与文字描述；主题包含故事设定；不把待生成图片计为完成。
- AC-4：导演分类展示真实导演名称、代表作、风格，与项目选导演使用同一来源；作品事实有核验来源。
- AC-5：角色和道具有稳定 ID、固定描述与参考地址，修改资料不自动改写历史生成任务；不承诺模型绝对一致性。

## 调用链
MaterialList → media/list → discoverMaterials 扫描项目任务与导入记录 → syncMaterials → pools/materials.json → 媒体摘要。
删除 → deleteAsset → removeMaterial → deleted=true；不删除任务及媒体。
DirectorList → director/list → pools/directors.json；删除被项目引用的导演会拒绝。
