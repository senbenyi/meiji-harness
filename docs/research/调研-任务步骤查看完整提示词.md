# 任务步骤查看完整提示词调研

## 结论
- AC-1 已确认：task-steps.js 为当前任务和历史共享组件，适合统一添加按钮。
- AC-2 已确认：task-store 仅记录输入输出快照，未保存请求提示词；须在文本/图片/视频发出前记录精确内容。
- AC-3 已确认：history 路由已有会话与项目鉴权，可扩展任务步骤快照读取。
- AC-4 已确认：步骤内 attempts 支持续传，多次请求需逐项记录；不应在点击时用当前资料重建。

## 规格
- 目标：生成、自审、修订、复审、图片生成、视频提交步骤可查看实际完整提示词。
- 非目标：不改变提示词编排、API payload、生成顺序及审核门禁；不从 Harness 私有日志补造旧记录。
- AC-1：当前/历史步骤均有查看入口，记录存在才可打开，未执行/跳过/旧记录状态明确。
- AC-2：新请求在发送前持久化全部 system/user 或图片/视频 prompt；多次请求保留独立快照，失败也可看。
- AC-3：按项目、任务、步骤读取，沿用会话鉴权，不保存请求头、密钥和参考图片 Base64。
- AC-4：弹窗完整显示、支持复制、错误重试；任务列表仅加载快照引用。

## 调用链与证据
runStep → runTextRequest/completeChat、generateGatewayImage、submitGatewayVideo → 请求；task-store.steps → history/current → app → renderSteps。

| 来源 | 结论 |
|---|---|
| server/data/task-store.js | 可原子保存独立记录并关联当前 stepId |
| server/generate/gateway.js | 三种提示词实际请求入口 |
