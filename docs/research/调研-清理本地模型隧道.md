# 清理本地模型隧道调研

## 结论
- AC-1 — 已确认：聊天、图片、视频当前运行设置均为香港 HTTP 网关；设置页仍显示连接按钮并调用旧连接接口。
- AC-2 — 已确认：图片和视频下拉框只暂存选择，点击“连接”才经 `switchServer` 写入 `selection.selected`。
- AC-3 — 已确认：模型传输层仍允许 SSH 服务登记并创建本机 `ssh -M -L`；任务与历史媒体读取也会调用该路径。
- AC-4 — 已确认：仓库默认聊天地址、手工提供者和 AutoDL 示例仍指向本地 SSH 隧道。
- AC-5 — 未验收：旧任务快照可能保存本地 URL；移除隧道后，其远程媒体若未迁移或另有本地副本，将无法通过旧 URL 访问。

## 规格
- 目标：聊天、图片、视频模型只使用远程 HTTP(S) 地址，清理本地模型隧道和设置页“连接/重新连接”功能。
- 非目标：香港网关所需的 GPU 到香港反向转发、运维 SSH 登录、第三方渠道选择。
- AC-1：设置页不显示三个私有模型的连接按钮，不再发起连接状态或连接请求。
- AC-2：图片、视频模型下拉选择可直接保存，刷新后回读一致；聊天模型继续显示配置值。
- AC-3：模型服务登记仅接受 HTTP(S)；新任务、恢复任务及历史媒体读取不创建本机 SSH 隧道。
- AC-4：仓库默认配置、示例、说明与测试不再引导本地模型隧道。
- AC-5：现有运行设置可加载；旧任务本地 URL 的处理结果明确且经过验证。

## 调用链
```text
设置页下拉 → 页面暂存 → model-connect → switchServer → selection.selected
聊天连接按钮 → tunnel-connect → legacyTunnelBackend → checkBackend → adapter.connect
模型执行/历史媒体 → connectBackend → adapter.connect → ensureConnection → ssh -M -L
新任务地址 → registry serviceUrl → HTTP base_url 或 127.0.0.1:local_port
```
