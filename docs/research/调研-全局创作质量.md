# 全局创作质量调研

## 结论

原“预览创作 / 常规创作 / 高清创作”属于同一业务能力的质量档位，不应注册为聊天命令，也不应由图片、视频或短剧工具分别接收质量参数。统一入口应位于 Elysium 设置，作为所有创作任务的全局策略。

## 业务名称

- 设置项：创作质量
- `fast`：快速创作
- `regular`：常规创作
- `high`：高清创作

“预览创作”改为“快速创作”，避免把低成本档位误解为一种独立业务或固定三秒视频。

## 职责边界

- Client 设置页只负责选择和展示全局档位。
- Settings Store 负责持久化、校验和并发修订。
- Worker 在任务准备阶段读取档位并交给模型适配器。
- Provider 将统一档位转换成真实分辨率、步数等供应商参数。
- 图片、视频、短剧工具不暴露 `quality`、`profile`、`preset` 或预览变体。
- 历史任务和媒体仍可读取旧 `profile`，仅用于兼容展示，不再作为新入口。

## 删除范围

`src/client/commands`、命令加载与注册、输入触发器、预设中的斜杠命令说明以及对应命令测试均应删除；设置页成为唯一用户入口。
