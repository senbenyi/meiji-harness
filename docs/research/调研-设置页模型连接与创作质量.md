# 设置页模型连接与创作质量调研

## 结论

- AC-1 — 已确认缺陷：私有图片、视频行没有连接按钮，选择下拉项会立即发起 `model-connect`；聊天行在未配置时整行消失。
- AC-2 — 已确认缺陷：聊天连接成功仅保存在组件内存；页面重开后无法显示当前连通状态。图片、视频虽有 `model-status`，页面未调用。
- AC-3 — 已确认缺陷：创作质量下面额外显示一行描述，与用户指定的简洁布局不符。
- AC-4 — 已确认缺陷：默认配置有图片模型而服务器清单为空时，`resolveServer('image')` 直接报未配置，页面仍会显示可选模型。当前运行设置已登记 `autodl-comfyui`，这个缺陷主要影响尚未登记服务器的安装。
- AC-5 — 已确认缺陷：私有模型重复连接仍走切换及选择写入；同一目标重连的检查与默认目标变更未分开。
- AC-6 — 已确认缺陷：连接结果没有逐行成功/失败状态；全页共享错误使用户难以对应目标，固定三列布局在 280px 侧栏中没有窄宽度适配；409 冲突后只回滚本地值，未重读最新 revision。
- AC-7 — 未验收：三方模型和创作质量持久化、私有模型运行时路由已有实现，须在实施后核对页面、接口、持久化和新任务行为。

## 规格

- 目标：设置页的三个私有模型类别都有明确的连接操作，成功显示绿色“连接成功”及“重新连接”，移除创作质量描述，并修复相关交互与连接链路。
- 非目标：不新增三方渠道凭据配置或模型登记表单；不修改已运行任务的后端快照。
- 验收标准：
  - AC-1：聊天、图片、视频每行都有连接按钮；未配置时明确显示“未配置”且按钮不可用；切换下拉项本身不发起连接，也不改变新任务默认选择。
  - AC-2：点击可用目标的“连接”后，连接检查成功才显示绿色“连接成功”和“重新连接”；失败显示该行错误，旧默认选择不变。
  - AC-3：刷新或重新打开设置页后，当前目标由只读探测恢复实际连通显示；探测不建立隧道、不切换模型、不写配置。
  - AC-4：创作质量只保留标签及“快速创作、常规创作、高清创作”下拉选择，不显示解释小字；选择保存、刷新回显并只影响新任务。
  - AC-5：已登记服务器时，图片和视频连接命中模型所指目标；缺少目标服务器时明确显示不可连接且不假报成功；同一模型重连不修改选择版本，新模型连接成功后原子更新默认选择。
  - AC-6：窄侧栏与移动端布局可看清每行标签、选择、按钮、状态及错误；加载、无配置、连接中、失败、并发点击等状态可辨；409 冲突后重读页面数据。
  - AC-7：三方图片/视频选择及其回退语义保持可用；接口不暴露密钥、SSH 信息或原始上游错误。

## 调用链

```text
设置页 Settings → GET /settings/models → 读 settings.json 的模型/创作质量/选择
├─ 聊天连接 → POST tunnel-connect → legacyTunnelBackend → checkBackend → SSH + /models 检查
├─ 私有图片/视频选择 → 当前立即 POST model-connect → resolveServer → checkServer/switchServer → selection 写入
│  ├─ 有服务器登记：检查通过后切换默认选择
│  └─ 无服务器登记：image 在 resolveServer 被拒；video 使用旧 ComfyUI 后端，检查后不写选择
├─ 三方选择 → POST third-party-select → selection 写入 → 新任务回退读取
└─ 创作质量 → POST creation-quality → settings.json.creation 写入 → 新任务准备时读取
```
