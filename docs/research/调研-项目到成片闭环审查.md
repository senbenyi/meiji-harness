# 项目到成片闭环审查

- 日期：2026-09-21
- 范围：工作台「项目 → 剧本 → 锚点 → 分镜 → 成片」全流程；聊天 Agent 本轮不做。

## 结论

自有模型（AutoDL/RunPod ComfyUI）路径未闭环：前序步骤可走通，最后「合成本集」必然失败。人工点击量过大（3 集 × 10 镜约 180+ 次），且首帧与锚点出图方式直接压低成片质量。

## 断点与问题

### P0 闭环断点
1. **ComfyUI 镜头不落本地**：`src/server/projects/film.js:composeEpisodeFilm` 只接受 `local_media_path`；`src/worker/models/protocols/comfyui/artifacts.js` 仅返回 `comfyui_view_url`，只有百炼/BytePlus 调用 `saveMedia`。受 `.claude/standards.md` §5「不保存文件」铁律阻塞——用户已于 2026-09-21 批准修订。
2. **新建项目强制封面**：`src/client/workbench/projects.js:150` `requireCover: true`、`src/database/managers/projects.js:339`；素材库为空时无法建项目。

### P1 人工干预
3. 逐镜提示词逐个「选镜 → 生成 → 定稿」，无批量（`planning.js:165`）。
4. 逐镜「采用此镜」（`storyboard.js:98`）。
5. 时间线逐集定稿、分镜逐集生成+定稿、锚点参考图逐个生成。

### P1 质量
6. **首帧 = 角色定妆照**：`src/server/projects/service.js:productionPlan` 把角色锚点图直接作为 i2va 首帧；同角色所有镜头首帧相同，景别/运镜/场景失效；场景锚点图从未使用；多人镜头仅取第一个角色。AutoDL 仅开放 t2va/i2va（`minimax-h3/plan.js:46`）。
7. **锚点出图提示词**：`generateAnchorImage` 把中文「名称。外观；音色；性格」直接送 RealVisXL（SDXL CLIP 基本不理解中文），无定妆构图约束。未实测出图，推断。
8. **无字幕**：`shot.subtitle`/对白已存，合成既不烧录也不导出 SRT。

### P2 简洁性
9. 分镜两套编辑入口：规划版本表单 + `StoryboardView`（改动作/字幕、增删幕和镜），后者不回写规划版本，与定稿分叉；按集分镜固定一幕，幕操作无意义。
10. 旧「不分集」路径残留：`episode === undefined` 分支、`composeFilm`（`-c copy`）、`productionPlan` 的 `planned=false`。依赖旧项目迁移决定（计划-短剧生产级 人工决策 3）。
11. 「继续」放行条件比依赖更严：锚点只依赖总览却要全部时间线定稿；成片按集却要求全部集镜头采用。

## 目标

人工节点收敛为：①剧情总览定稿 ②（可随时介入修改）③成片审看；其余自动推进直到每集成片。

## 非目标

- 聊天 Agent 闭环工具。
- 新增视频模式（r2va/fl2va 续接）或更换模型。

## 验收标准

- AC-1：AutoDL/RunPod 视频与图片任务成功后，产物保存在所属项目 `media/` 并登记；已有未落本地的成功镜头在合成时自动补存；本集合成成功。
- AC-2：不选封面可创建项目；无封面项目卡片用锚点图兜底。
- AC-3：剧情总览为角色/场景输出英文 `image_prompt`；锚点出图使用它并带定妆构图；旧数据无该字段时回退原描述。
- AC-4：每个镜头先按 `keyframe_prompt` + 主角锚点图生成本镜首帧，再以该首帧 i2va；首帧比例与视频一致；无角色镜头用纯文生图首帧。
- AC-5：本集成片烧录中文对白字幕，同时登记 SRT 交付物；时间轴按各镜实际时长累计。
- AC-6：总览定稿后自动为缺图锚点出图；「一键生产」后自动依次完成各集时间线、分镜、逐镜提示词的生成与定稿、镜头提交、成功镜头采用、本集合成；失败时暂停并显示原因，可继续；用户可随时暂停；已人工定稿的版本不被覆盖。
- AC-7：按集分镜页只保留生成/恢复/采用/预览；「继续」按钮按真实依赖放行。
