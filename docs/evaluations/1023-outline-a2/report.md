- **更短但未解决问题**：栅门样本两版均让关闭状态与穿门冲出并存；月界第3轮新版最终正文仍含“不扩写回应原话”等控制解释。不能只因减少文字就判为改善（E01、E08）。

完整链路中也仍有旧状态残留：武松第3轮此前已开门、官差进入、哥哥走近并抓臂，新版最终描述却把哥哥放回“尚未完全打开的后门边”（E09）。这说明仅强调状态累积，尚不能保证模型可靠合并公共开场与此前节拍。

月界同行对话的本次固定输入里，两版都生成了方向合理的请求。不能拿上一轮旧版曾写反来宣称新版稳定修好；当前来源只有转述，真正应当先把台词在大纲和镜头中定稿，再交给视频节点原样执行（E10）。

## 推广决定

**保留原A作为默认，A2保留为实验候选。** 这不是认定规则必须长，而是本次整体精简方案没有在用户看重的内容质量上稳定胜出，还出现实际信息退化与覆盖问题。三份skills已恢复到本轮修改前快照，未撤回此前已完成的大纲等业务改动，未迁移已有项目规则，也未重启。

后续值得采用的方向是：去掉重复解释和审核口吻，但保留明确的内容约束；精简是合并相同事实，而不是删除给定有效细节。优先解决台词定稿、明确实际分片起点和镜头覆盖，再比较简洁程度。当前结果不足以把“短规则导致退化”作为单一因果结论，也不支持全面压缩后直接推广。
