# 故事大纲双规则真实对照测试

测试日期：2026-10-23。结论限于本次规则版本、模型服务及文本链路，不把字段数量视为唯一因果变量。

## 选型建议

**当前保留多字段方案A作为基线，不直接切换到精简方案B。**

这不是因为A更长，也不是因为独立情绪字段天然更好。逐项复核的最终提示词中，两套方案都能表达表情、内心变化、空间、动作与特效，B也有比A更细的片段；但没有证据显示B在这些质量目标上持续胜出。本次首次输出的直接可用性又以A较好。因此，不能依据“字段少、重复少”就认定B的最终效果更稳定。我此前倾向直接精简字段的建议，应据此收回。

优先改进的应是：关键对白在大纲中真正定稿；分片起点正确承接此前持物、站位、伤势和声音；镜头层把情绪落实为可见表演与合适的背景/光照/动作细节。这些问题在两方案中都有出现，不能靠删字段自动消除。

- 桌面《月界旅行》《武松：兄长不死》原始文件的副本，哈希一致，原文件未修改。
- 新作《最后一班潮汐》，包含双时间线、姐妹关系、知情差异、红/蓝钥匙交接、受水压控制的门、必须持续按压的泄压轮和并行救援；已另存桌面。
- A：10字段，正文外保留背景、人物、空间与情绪说明；大纲和镜头各自有适配此结构的规则。
- B：6字段，保留id、title、body、key_anchors、duration_seconds、continuity；把必要背景、人物、空间与情绪直接落实到正文。大纲和镜头规则均单独改写，绝非先生成A再删字段。
- 每剧本每方案3轮独立生成，共18次大纲及18次完整镜头表。相同模型别名codex-gpt、相同原稿及创作要求，不设剧情时间预算，不挑选失败后的最佳重采样。

正式最终提示词阶段：A在8条可继续的链路中6条结构通过、2条JSON失败；另1条被上游阻断。B在6条可继续的链路中3条结构通过、3条JSON失败；另3条被上游阻断。故从原稿一路到正式提示词可直接读取的组数为A **6/9**、B **3/9**。这些是本次首轮直接可用数，**不是生产盒子经过审核与修订后的最终成功率**。

正式阶段共14次提示词调用，返回37条可逐字阅读的视听描述，其中23条属于通过契约的输出。格式失败的可读文字也作内容复核，但不冒充成功结果。一个不匹配实际攻防阶段的抽样被排除，剩余36条可读描述用于定性检查。

## 对字段设计的建议

1. 现阶段保留A的结构，body仍是完整剧情定稿；其他字段作简短的约束与重点说明，不用另一套事实复述全文，也不能用它们代替正文必要动作。
2. 先解决台词定稿：发生关键对话时在body写出明确说话人和原文，后续节点只落实，不重新猜台词。
3. 把镜头层的充分性要求落在可见细节：表情、视线、呼吸、姿态、动作受力、空间路径、背景材质与光照，以及合适的声画效果；不重新改编人物动机和事件。
4. 分片输入优先提供明确的实际起点状态，避免把镜头原始开场与此前动作未经消解地一起交给提示词模型。至少应核对关键持物、脱困状态、受伤、门/设备状态和已说完的对白。
5. 若以后再精简字段，以修正这些共同瓶颈后的同场面配对作为下一轮依据。当前数据不足以证明“独立情绪/空间字段本身提升或损害了最终质量”。

本次只完成实验和选型建议，**没有迁移生产结构、修改现有项目规则快照或重启服务**。

## 方法边界与误报处理

- 当前镜头和提示词没有完整生产执行器，本实验直接调用现有规则组装器、真实模型及输出契约，是隔离的文本生成研究；没有调用视频生成接口或评价真实画面，也未接入人物/场景图片或独立资产提取。
- 比较的是两套完整规则方案，不是控制住同一最终正文后仅改变字段的单变量因果实验。独立改编、镜头划分和时长范围会变化。
- 三轮是独立首轮生成对照，不是各自review/revise业务循环运行到底；自动评审使用同一份匿名对照规则，不用于自动修订候选。因此本次不验收两套审核/修订工作流的生产效果。
- 3剧本×3轮、同一模型别名、服务默认采样，没有固定种子，不足以作普遍统计定论。模型具体底层版本及token用量未由当前客户端暴露，未编造成本或token数据。并发耗时含排队，不作为选型主指标。
- 最终提示词是预先定义主题的压力抽样，不是全剧全部分片。只抽取单个4–15秒完整节拍；未抽到不代表短节拍不能合并成合法分片。不同片段可能是同一主题的不同阶段，只比较各自来源是否充分落实，不拿更长的剧情范围当质量优势。
- 探索版词匹配曾误选茶碗记忆，已停止，探索最终文本全部排除正式选型。正式版增加阶段/动作过滤；事后又发现武松第3轮A打斗样本受“遮挡”误匹配，仅为入场，已排除该主题，不重抽好样本。记录见sampling-qc.json。
- 自动主链路评审多次错误引用正文、把正常继承当漏项或把“杪→秒”当单位错误；正式提示词成对评审的3次调用也只有1次返回有效评审JSON。因此**不采用自动均分或胜率宣布方案优劣**，只把自动意见当查找线索，再对照来源复核。原始评分保留但明确标记未验证。
- 一份完全相同的复杂剧本A提示词输入，在探索阶段与正式阶段一次格式通过、一次失败；不能把单次格式波动简单归因字段结构。
