# 分集工作台交互设计

- 状态：**已确认（U1～U5）**。已并入 `docs/plans/计划-短剧创作闭环设计.md`（第四版），该计划第 5 节只列字段、Skill 与约束，界面细节以本文为准。
- 范围：只设计交互和它对数据的要求，不改代码。

## 1. 现在为什么难用

以“把第 3 集写好，并检查分镜和画面”为例，现在的操作路径：

```text
[剧本] → 页签[分集时间线] → 目录选[第 3 集] → 改文本 → 保存
[分镜] → 再选一次[第 3 集] → 页签[分镜] → 改整集文本 → 保存
       → 页签[提示词] → 下拉选[镜 1] → 改 → 定稿 → 下拉选[镜 2] … 重复 8 次
       → 页面下方的镜头列表 → 点镜头 → 看画面 / 重拍
[成片] → 再选一次[第 3 集] → 播放
```

| 问题 | 原因 |
|---|---|
| 切换次数多 | 同一集的内容被拆到 3 个页面、4 组页签、1 个下拉框里 |
| 对照困难 | 分镜是照着剧本拆的，但剧本和分镜从来不在同一屏出现 |
| 反复选集 | 剧本、分镜、成片三个页面各自记一个“选中第几集” |
| 提示词藏得深 | 每个镜头的提示词要先切页签、再从下拉框选中才能看到 |
| 编辑负担重 | 整集是一个大文本框；切换时频繁弹出“有未保存修改”；还要保存、定稿两步 |

根本问题是**页面按“步骤”划分，而人工作时是以“一集”为单位的**。

## 2. 新的交互：一集一屏的“双栏脚本”

影视行业常用的 **A/V 两栏脚本**格式是：左栏写听到的（台词、动作、声音），右栏写看到的（镜头）。在这个格式里，镜头直接挨着它所对应的剧本行。新设计把剧本、分镜、提示词、镜头画面和成片**合并到“分集”一个页面**：左栏是剧本，右栏是镜头，镜头与它覆盖的剧本行横向对齐。

### 2.1 页面结构

项目页签从 5 个减为 3 个：

```text
[项目]  [总览]  [分集]
          │       └─ 本文主体：剧本 + 分镜 + 提示词 + 镜头画面 + 成片
          └─ 剧情总览 + 角色定妆图（原“锚点”页并入这里，见第 5 节）
```

### 2.2 分集页（桌面）

```text
┌──────────────┬────────────────────────────────────────────────────────────────────────────┐
│ 分集          │ 第 3 集 · 一半的真相                    84 秒 · 8 镜 · 画面 5/8 · 成片 —      │
│              │ 梗概：林晚搬回母亲家……  钩子：林晚犹豫是否原谅            [展开] [全文编辑]    │
│ 01 未署名的信  │ [🤖 生成剧本] [🤖 生成分镜] [▶ 生产本集] [▶ 播放成片]                           │
│    ✓ 成片      ├───────────────────────────────────┬────────────────────────────────────────┤
│ 02 雨夜       │ 剧本                               │ 镜头                                    │
│    ✓ 成片      │ ▍场 1｜咖啡馆｜林晚、苏晴           │                                        │
│▶03 一半的真相  │   动作：苏晴把旧照片放在桌上，       │ ┌ S01  00:00–00:06 ──────── [画面缩略] ┐│
│    画面 5/8    │         林晚没有伸手。              │ │ 双人近景 · 缓推 · 6 秒      ✓ 已完成   ││
│ 04 真相       │   苏晴（低声）：她已经不在了。       │ │ 视频：【0–2 秒】照片推过桌面…   [展开] ││
│    分镜 ✓      │                                   │ │ 首帧：Two women face each other…      ││
│ 05 重逢       │ ─────── ✂ 从这里开始新镜头 ──────── │ └ [▶ 播放] [重拍] [⋯] ─────────────────┘│
│    剧本 —      │   音效：雨声压住尾音。              │ ┌ S02  00:06–00:11 ───────── [生成中] ┐│
│              │   林晚（发颤）：那我算什么？         │ │ 特写 · 固定 · 5 秒                    ││
│              │                                   │ │ 视频：…                               ││
│              │ ▍场 2｜母亲家｜林晚                 │ └───────────────────────────────────────┘│
│              │   动作：林晚翻出旧信。               │ ░ 未入镜  [+ 为这几行建镜头]              │
└──────────────┴───────────────────────────────────┴────────────────────────────────────────┘
```

| 区域 | 内容 |
|---|---|
| 左侧分集目录 | 全部集，每集一行，显示最靠后的进度：剧本 — / 剧本 ✓ / 分镜 ✓ / 画面 x/y / ✓ 成片。**整个项目只有一个“当前集”**，所有页面共用 |
| 顶部 | 集标题、合计时长、镜头数、画面进度、成片状态；梗概和钩子（只读，可折叠，点击去总览修改）；4 个一键按钮 |
| 左栏：剧本 | 场标题（场景、出场角色）下面是一行行的动作、对白和音效，每一行都能直接点击编辑 |
| 右栏：镜头 | 每个镜头卡片的上边缘，与它覆盖的第一行剧本对齐，并在纵向上覆盖到最后一行；卡片内有时间码、景别、运镜、时长、状态、缩略图、视频和首帧描述，以及操作按钮 |
| 未入镜 | 没有被任何镜头覆盖的剧本行，右侧显示浅灰色的“未入镜”，并提供一键建镜头 |

### 2.3 分集页（手机）

```text

▍场 1｜咖啡馆｜林晚、苏晴

│ 视频/首帧 [展开]   [播放][重拍]    │

│ 音效：雨声压住尾音。……           │
```

屏幕太窄时两栏合为一栏：镜头卡片直接包住它的剧本行，交互保持不变。分集目录收进顶部的“第 3 集 ▾”下拉。

## 3. 交互细节

### 3.1 编辑：原地编辑，失焦自动保存

| 操作 | 方式 |
|---|---|
| 改一行 | 点击这一行 → 变成输入框 → 离开时自动保存 |
| 加一行 | 在行末按回车，在下方插入新行 |
| 删一行 | 在空行上按退格 |
| 行类型 | 按前缀识别：`动作：` / `音效：` / `角色（语气）：`；角色名自动补全；未知的角色名标红（只提示，不拦截） |
| 场 | 场标题上可以改场景（下拉）和出场角色；在“场”之间可以插入新场 |
| 镜头字段 | 景别、运镜、时长是卡片里的小输入框；视频和首帧默认显示一行，点击展开编辑 |
| 全文编辑 | 顶部的“全文编辑”会把整集显示为一段 Markdown，方便大段粘贴或整体改写；离开全文编辑时自动保存 |

- 保存即生效，与“不分版本”的口径一致。页面上没有“保存”按钮，也不再弹出“未保存，确定离开吗”。
- 页面右上角显示“已保存 / 保存中”。
- 保存失败时，这一行标红，内容保留，可以重试。

### 3.2 镜头边界：拆、并、插、删

| 操作 | 方式 | 生产数据 |
|---|---|---|
| 拆镜 | 鼠标移到两行剧本之间 → “✂ 从这里开始新镜头” | 后半段成为新镜头，待生成 |
| 并镜 | 镜头菜单 ⋯ → “合并到上一镜” | 保留上一镜的画面，由人决定是否重拍 |
| 为未入镜的行建镜头 | 未入镜区域点击“+ 为这几行建镜头” | 新镜头，待生成 |
| 空镜 / 插入镜头 | 镜头菜单 ⋯ → “在后面插入空镜” | 不覆盖任何剧本行的新镜头 |
| 删镜 | 镜头菜单 ⋯ → “删除镜头” | 被覆盖的行变回未入镜；已生成的视频留在素材库 |

- **镜头不能跨场。** 每个“场”开始时，上一个镜头自动结束。
- 镜头覆盖的是**连续的若干行**，一行只属于一个镜头。这样对齐关系始终清晰，不需要人去写 `L1-L2` 这类行号引用。

### 3.3 自动生成入口

| 按钮 | 作用范围 | 已有内容时 |
|---|---|---|
| 🤖 生成剧本 | 本集全部剧本行 | 先确认覆盖；本集的镜头随之清空 |
| 🤖 生成分镜 | 按当前剧本切分镜头，并写出每镜的视频和首帧描述；**只插入镜头，不改剧本行** | 先确认覆盖已有镜头 |
| 🤖 重写这一镜（镜头菜单 ⋯） | 只重写本镜的景别、运镜、时长、视频和首帧 | 只影响这一镜 |
| ▶ 生产本集 | 提交本集所有还没有任务的镜头；全部完成后自动合成 | 不改动任何文字 |

项目列表上的“一键补全”和“一键生产”保持不变，它们只是对所有集依次执行上面这些动作。

### 3.4 画面与成片就在原地查看

- 镜头卡片：
  - 显示缩略图和状态（待生成 / 排队 / 生成中 / ✓ / 失败 + 原因）。
  - “▶ 播放”在卡片内直接播放。
  - “重拍”换新种子重新生成。
  - “⋯ → 查看实际提示词”显示编译后发给模型的完整内容。
- 顶部“▶ 播放成片”：从右侧滑出播放器，提供视频和字幕下载，不离开当前页面。
- 看成片时发现某一段不对：播放器下方列出全部镜头，时间码与播放进度同步；点击某个镜头，就定位到页面中这个镜头的卡片。

### 3.5 一次完整操作的对比

| 操作 | 现在 | 新设计 |
|---|---|---|
| 写好并检查第 3 集 | 3 个页面 + 4 组页签 + 8 次下拉选镜 + 3 次选集 + 多次“保存/定稿”和确认弹窗 | 在目录中点“第 3 集”，全部在一屏内完成 |
| 某句台词太长 | 改剧本 → 切到分镜页找对应镜头 → 切到提示词页签 → 找镜头 → 改 | 直接在左栏改这一行，右侧对应的镜头就在同一行 |
| 某个镜头画面不对 | 去成片页找 → 去分镜页找对应镜头 → 去提示词页签改 → 回来重拍 | 在卡片上展开“视频”改描述 → 点“重拍” |

## 4. 对数据的要求：推荐把剧本和分镜合进一个文件

双栏的核心是“镜头覆盖连续的若干行”。数据有两种存法：

| | A：两个文件（计划第三版） | B：一个文件，镜头标记插在剧本行之间（推荐） |
|---|---|---|
| 文件 | `script.md` + `storyboard.md` | `episodes/N/script.md` 一个文件 |
| 关联方式 | 镜头写 `L1-L2`，每一行剧本都要带行号 | 镜头从它的标记开始，到下一个镜头标记或下一场为止 |
| 需要的概念 | 行号 `[L..]`、镜头号 `[S..]`、“引用已删除” | 只需要镜头号 `[S..]` |
| 改剧本时 | 删行、合并行可能让镜头的引用失效 | 不会失效；删掉的行自然从所在镜头中消失 |
| 职责分离 | 按文件分离 | 按 Skill 分离：剧本 Skill 只写行，分镜 Skill 只输出“从第几行开始 + 镜头字段”，由代码插入镜头标记，**剧本行保持不动** |

B 的文件长这样（全文编辑时看到的就是它）：

```text
## 场 1｜咖啡馆｜林晚、苏晴
### [S01] 双人近景｜缓推｜6 秒
视频：【0–2 秒】苏晴把照片推过桌面……【2–6 秒】缓推至林晚近景，2 秒处苏晴开口。
首帧：Two women face each other across a cafe table by a rain-streaked window…
动作：苏晴把旧照片放在桌上，林晚没有伸手。
苏晴（低声）：她已经不在了。
### [S02] 特写｜固定｜5 秒
视频：……
首帧：……
音效：雨声压住尾音。
林晚（发颤）：那我算什么？
```

- **字幕**：取自每个镜头下面的对白行。
- **编译**：视频描述加上本镜的对白行（带音色）。
- **时间码**：由各镜时长累加得出。

推荐 B 的理由：

- 少了行号和“引用失效”两个概念（M6）。
- 双栏对齐由文件结构直接决定，不需要额外的对齐计算。
- 剧本写作和分镜仍然由不同的 Skill 负责，并且代码保证生成分镜时不会改动剧本行。

B 会修改口径 1。原口径是“剧本与分镜分开”，修改后变成“**职责分开，存在同一个文件里**”。它仍然满足你当时的核心诉求：分开之后不会出现不一致，也不需要重复维护。

## 5. 顺带合并：锚点并入总览

原“锚点”页只剩角色定妆图（计划 S5），而定妆描述本来就写在总览的角色里。把定妆图直接放进总览的角色卡片，又能少一个页签，也省掉“去总览改定妆 → 回锚点出图”的往返：

```text
总览
 一句话故事 / 世界观                                   （点击编辑，失焦保存）
 角色
 ┌ 林晚（主角） ───────────────────────────── [定妆图] ┐
 │ 简介：28 岁插画师，外柔内刚……                        │
 │ 定妆：adult Chinese woman, about 28…     [🤖 出图] [替换] │
 │ 音色：清亮偏轻，激动时哽咽                             │
 └────────────────────────────────────────────────────┘
 场景 ……
 分集：01 未署名的信 · 02 雨夜 · …   （点击某集 → 跳到分集页的这一集）
 [🤖 生成总览] [为缺图的角色出图]
```
