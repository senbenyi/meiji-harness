## 迁移与数据边界

v24 不重写依赖指纹，不把已有本地文件标为过期。服务端地址只在本次生成或新上传时变化：重新截取同一文件时不传该字段，原地址保留。合片不增加下载步骤。远端任务 ID 留在生成步骤结果里，不写入项目 JSON。
