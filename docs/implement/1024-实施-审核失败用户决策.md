## 改动
- 独立失败决策卡片，显示真实保存事实、审核/执行失败原因、停止步骤和用户选择；内容终态拒绝或执行失败等待用户，不自动唤醒主Agent。
- 继续读取最后候选和审核意见；重新生成读取当前项目资料；可信harness-http来源、会话/项目归属、输入指纹、稳定请求ID及队列保持约束。
- 每次有效生成/修订立即写入项目，并在步骤记录saved。失败/取消不撤销已保存结果；结构无效、迟到及并发覆盖仍拒绝。审核通过才清除意见；节点内容状态和任务结束摘要分别投影。
- 大纲审核本来已接收完整集合，无首错即退出；新增强制全篇遍历与跨段状态检查、一次性汇总全部问题和逐项修订后全文回归的约束。保留用户持久化业务规则。
