## 阶段 2–7：步骤模型、执行器、操作定义、人工忽略、面板、文档

### 已修改文件
- `meiji/shared/steps.js`（新增）— 步骤与任务状态、`deriveTaskStatus`、`reviewPassed` / `reviewFailures`、`groupByTarget`、`currentStep`、顺序执行器 `executeSteps`（`when` 可异步）。
- `meiji/server/data/task-store.js`（原 `task-records.js`）— 任务文件 `schemaVersion: 2` 与 `steps`；删除 `tracked` 白名单（只有无项目或会删除记录目录的操作不写记录）；`createTaskRecord`（入队写计划）、`beginTask`（出队重写计划、第一个步骤「准备中」）、`startExecution`（嵌套操作复用外层任务与作用域）、`runStep` / `stepAttempt` / `finalizeSteps` / `endExecution` / `abandonTask`、`expandStage`（整集一键预留）、`liveTask`；旧格式读取报 `OLD_TASK_RECORDS`。
- `meiji/server/data/operation-context.js`（新增）— `checkContext` 从 `review-checks.js` 移出；`markApiFailure`、`apiFailed()`、`inTextStep()` 从步骤推导。
- `meiji/server/data/review-checks.js`、`operations/finish.js`、`operations/execute.js` — 删除 `textDraftSaved`、`deferCheckFailure`、`textNodeSaving`、`reviewHistory` 标志；接口失败回退改为「步骤记有接口失败或失败原因带接口失败，且没有已保存草稿」。
- `meiji/server/generate/text-steps.js`（原 `text-workflow.js`）— 删除 `runTextWorkflow`，提供 `textSteps` / `runTextSteps` 与单步 `generateStep` / `reviewStep`；`shot-text.js`、`story.js`、`review.js`、`operations/images.js` 改为声明带 `target` 的文本步骤；续传记为同一步骤内的尝试。
- `meiji/server/flow/operations/registry.js` — `definitions`：`label / scope / queue / plan / step / agent / task`；`planSteps`、`runnerStep`、`queueOf`、`agentAllowed`；`validateOperation` 拒绝会话发起人工专属操作（403）。
- `meiji/server/flow/operations/run.js` — 开始时写计划；无计划的操作整体作为一个步骤；嵌套子操作不另加锁、不单独结束任务；会话来源的操作一律校验。
- `meiji/server/flow/operations/films.js` — `produce` / `produce-all` 处理函数与 `shotSteps`（原 `server/workers/shot-film-worker.js`，已删除）；视频准备（上传参考图、开场帧）并入 `video_submit` 步骤；`video_generate` 记远端任务编号。
- `meiji/server/flow/operations/images.js` — 图片与铅笔分镜生成记为 `image_generate` 步骤。
- `meiji/server/flow/operations/story.js` — 人工编辑保存记为 `save` 步骤；新增 `review-override`（人工忽略自审）。
- `meiji/shared/feedback.js` — `overrideNodes`、`overrideBlocker`、`overriddenBy`、`overridable`。
- `meiji/server/flow/tasks/runner.js`、`tasks/queue.js`、`tasks/restart.js`（原 `flow/tasks.js`、`queue.js`、`interrupt.js`）— 入队按发起顺序写记录与计划；状态、`reviewPassed`、`failures` 全部从步骤推导；排队中取消与启动前出错由 `abandonTask` 落定；队列类别来自 `queueOf`，可查询排队位置；新增 `current()`。

- `meiji/scripts/migrate-task-steps.js`（新增）与 `configure-harness.sh` — 启动前迁移旧任务记录（先备份）。
- `meiji/client/task-steps.js`、`current-task.js`（新增）、`execution-history.js`、`workflow-review.js`、`app.js`、`styles.css` — 步骤清单组件；「当前任务」页（排队位置、停止、当前步骤高亮、已用时间、尝试、远端任务编号，收到 `/events` 推送刷新）；状态栏「查看当前任务」；「忽略并通过」按钮与「人工放行」标记。

- 测试：新增 `task-steps.test.js`、`fixtures/steps.js`；更新 `task-store`、`tasks`、`queue`、`gateway-cancel`、`prompt-nodes`、`reviewed-generation`、`session-log`、`project-generation-review`、`episode`、`model-ui`、`architecture`；`shot-film-worker.test.js` → `produce-shots.test.js`，`interrupt.test.js` → `restart.test.js`。

### 与原行为的差异
- 逐镜成片遇到文本分镜自审不通过时，任务状态为「审核未通过」（原为「失败」），其后步骤记为已跳过。
- 图片、铅笔分镜生成在后台失败时，任务状态为「失败」（原任务仍显示完成）。
- 逐镜成片在整个执行期间持有面板运行锁（原只在各子操作期间持有）。
- 图片、确认图片、铅笔分镜、忽略自审等所有项目内操作都写入任务历史。
