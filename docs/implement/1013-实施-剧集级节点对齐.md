## 已修改文件

以下仅说明本轮职责内的改动；工作区还包含此前项目级未提交改动，未将全部 Git 差异归入本轮。既有项目级计划、实施记录和用户已有删除均保留。

- `meiji/shared/node-definitions.js`、`node-state.js`、`project_contract.js` — 大纲开启程序审核；结构与程序业务审核分离；小段时长允许有限正数和小数，大纲与镜头表按本集参考 ±30 秒审核。人工放行只跳 AI，仍检查结构与程序规则；人工编辑保留结构校验流程。
- `meiji/server/handlers/text-handler.js`、`handler-registry.js`、相关 `meiji/dev_docs/in_puts/` 文本模板 — 注入真实参考时长、最后候选及当前原因，补齐摘要审核与大纲修订输入；程序和 AI 审核共用两次修订；保持镜头表九字段及单镜 4–15 整数秒。
- `meiji/shared/node-dependencies.js` — 新增统一的 `shotCharacterContext` 和 `isNodeCurrent`。大纲依赖参考时长，镜头表依赖完整小段、参考时长和实际角色文字，每秒分镜依赖镜头九字段；上游使用保存的 hash。有效节点必须 generated、结构有效且非空保存 hash 与当前资料一致，不兼容空 hash。
- `meiji/server/runtime/app-runtime.js`、`server/handlers/content.js`、`deletion-handler.js` — 参考时长、角色和服装资料的正式修改触发依赖检查；删除后避免定位已删目标。成功产出更新 hash 并传播；rejected 候选保存不主动改下游状态、hash 或媒体，新任务仍按当前正式资料校验，不回退历史正文。
- `meiji/shared/models/episode_model.js`、`migrate_project_model.js`、`meiji/server/data/sqlite-store.js`、`schema.sql` — 当前数据库升级至 v5。累计镜头实际时长，合片实测值不覆盖累计字段；一次性数据修订核对旧依赖，保留正文、媒体、原成功 hash 和终态历史。升级前备份，失败整体回滚；已有 expired 节点和 queued 的恢复快照也继续传播，防止重启恢复错误有效状态。
- `meiji/server/flow/tasks/task-service.js`、`precheck.js`、`meiji/server/data/model-repository.js`、`meiji/shared/task_contract.js` — 成片组 `generate` 补缺、`regenerate` 重跑所选逐镜节点；跳过前同时模拟上游重生成的影响。等待同集成片队列全部结束且所有视频有效，由最后完成的组追加唯一合片；已有有效合片不重跑。合片以本组 episode ID 定位，其他成员继续校验镜头范围和顺序；冲突、幂等和继续均保留旧终态。
- `meiji/server/handlers/media-handler.js` 及合片前置接入 — 拼接前检查项目内路径、存在、可读和完整解码；失败落在前置步骤，保留旧合片；输出也通过媒体完整性检查。合片无 AI 和自动修订。
- `meiji/client/task-panel.js`、`project-ui.js`、`meiji/tools/task-tools.js` — 大纲展示 causal，镜头表只展示九个业务字段，秒数在标题旁，列表直接展开且不重复显示下游；合片按钮显示“生成合片”，面板与会话工具的生成、重新生成传递不同组动作。
- `meiji/dev_docs/制作工作流.md`、`step_model.md`、`dots/剧集-故事大纲.md`、`dots/剧集-镜头表.md`、`dots/剧集-合片.md`、`project_detail.json` — 同步审核、保存、依赖、人工操作和编组职责。JSON 只调整说明值，没有新增字段。
- `.agents/meiji-dev.md`、`meiji/skills/session/panel.md` — 同步成片 action 和合片语义；明确当前代码中的视频/尾帧仍独立，视频类型分支和时长审核留待镜头级对齐，不宣称本轮已实现。
- `meiji/tests/fixtures/project.js` 与相关 stage01–stage08 用例 — 测试资料按上游顺序记录真实依赖 hash；新增大纲审核、逐字段过期、迁移、成片组和剧集命令集成回归。主要证据见下表。
