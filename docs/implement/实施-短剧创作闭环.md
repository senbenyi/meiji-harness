## 与计划不一致及原因

- 阶段 1 的 H3 A/B 按本次指示留给人工验收；当前先使用 S4。`drama/steps/storyboard.md` 是 H3 分秒写法的唯一 Skill 位置。模型曾在生成的“视频”中重复对白，后续生成增加了去除对白的处理；已提交的测试项目镜头可能仍带生成时的旧描述，应在 AC-2 检查实际提示词。
- 删除镜头时，`script.md` 用 `<!-- 未入镜 -->` 标记边界，使原剧本行确实变为未入镜，不被上一镜接管；重新生成分镜会清除该标记。
- 项目对账在服务注册处增加独立定时调度；本机旧任务队列存在时，原任务驱动没有及时推进 fill。旧项目不做数据兼容，也未删除；电影对账跳过没有新 `project.md` 的旧目录。没有修改 `worker/`。
- 计划 AC-10 写“第 3 集”，与两位导演固定 2 集冲突；人工验收同一交互应在第 2 集进行。
- 为实现页面上的替换定妆、提示词预览、生产本集、手动合成与打包下载，项目路由增加 `anchor-import`、`shot-preview`、`produce-episode`、`film-compose`、`films-download`。
