# 接口独立提示词实施记录

## 已修改文件
- `meiji/server/prompts/interfaces/`：七个文本阶段、四个图片阶段、视频分别拥有独立的结构定义；registry 只做严格分发，text-context 提供可选的上下文工具。
- `meiji/server/prompts/skill-prompts.js`：原统一结构改为具名可选片段，最终角色和顺序由接口决定。
- `meiji/server/prompts/text-prompts.js`：仅分发、序列化，保留日志阶段标记，不推断 JSON 输出或自动追加本次要求。
- `meiji/server/generate/image.js`、`meiji/server/flow/operations/films.js`：使用对应独立接口；视频衔接提示词移入 video 模块。
- `meiji/server/prompts/preview.js`：复用实际组装模块，图片和视频字符数按实际渲染内容计算。
- `meiji/tests/prompt-interfaces.test.js`：新增 6 项回归测试，验证独立角色与格式、无公共注入、接口隔离、预览一致、覆盖层与视频衔接。
- `.agents/architecture.md`、`.agents/development.md`、`meiji/docs/tasks-and-steps.md`、`meiji/docs/prompt-interfaces.md`：同步架构、开发约束和编辑指南。
