- 隔离 DSH_HOME 与 3081 启动实际 Harness，Chrome headless 打开实际页面，创建项目、工作区/会话绑定、切换到项目面板通过，浏览器 pageerror 为 0。

- 真实生产网关使用独立临时项目，依次完成项目摘要、重要角色、剧情、本集资产、镜头表、每秒分镜、文本提示词、视频、尾帧、合片十项任务。最后媒体通过 FFprobe/FFmpeg 校验。

- 真实链是无人静物镜头，没有单独调用生产图片模型；图片生成/参考图/取消协议以 mock HTTP 和真实媒体执行测试覆盖。真实模型输出内容质量不是这次架构验收的全面保证。
