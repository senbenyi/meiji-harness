### 提示词差集核对
使用 `tests/fixtures/prompt-scenarios.js` 的 scenarioProject 采集镜头表、单镜修订、每秒指令 × regenerate/modify 的 6 个场景；每场景采集生成、审核、自动修订，共 18 个请求。运行 `scripts/prompt-diff.js` 后逐项核对 15 类删除语句，不修改脚本的通用分类。

| 删除内容 | 去向或理由 |
|---|---|
| 人物卡的 ID/name/look/identity JSON | 前期移除；成片的 storyboardContext、角色提取与素材编译使用 |
| 自然名称、同一人物稳定称谓 | 合入阶段生产/审核基础规则；输出协议仍要求自然名称 |
| speakerName、NARRATOR 与对白原文要求 | 每秒指令协议、生产/审核技能已持有，取消在镜头表等请求中的重复注入 |
| 只有声音的人物不虚构身体 | 原有旁白及可见身体的生产/审核规则保留；成片提取不建声音人物卡 |
| 成片才提取角色、生图和绑定等流程说明 | 由 run-planner 和成片准备执行，不再注入前期模型上下文 |
| 审核依赖人物卡资料的说明 | 替换为大纲、镜头叙事中的人物事实和必要环境/道具资料 |
| 强制实体 ID 标记与画外声人物 ID 的旧规则 | 替换为自然名称及 speakerName，避免审核把新协议判成漏标 |

镜头表各请求 user 减少 287 字，单镜修订减少 293 字，每秒指令减少 289 字；角色模型、成片绑定和原指令数据未修改。
