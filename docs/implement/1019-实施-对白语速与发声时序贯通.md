# 对白语速与发声时序贯通实施记录

## 已修改文件
- `meiji/shared/prompt-models/common.js`：唯一dialoguePaceRule，默认自然交流语速约1.1倍，正常声线音调，短句不拖长、不逐层累乘、余下用已有画面承接，不按字数机械计时。
- `meiji/shared/prompt-models/seconds.js`：三动作共用语速目标；既有audio明确发声起止，拍长可大于发声，余下动作反应另述。
- `meiji/shared/prompt-models/storyboard.js`：三动作共用目标；原位替换发声继承规则，明确转写起止，区别对白和画面停留，澄清首段不加的是剪辑时间戳，不排斥对白相对秒数。

- `meiji/shared/video-inputs.js`：videoSpeechTiming从有对白的原节拍投影time_range/audio/去重说话人；不复制台词、不解析自由文本、不编新时间。
- `meiji/server/handlers/media-handler.js`、`meiji/shared/node-dependencies.js`：视频输入及hash共用投影；无对白不新增时序依赖材料。
- `meiji/server/http/nodes/video.js`、`video-request.js`：可选临时业务参数speechTiming，三模式和保存packed前附原时序依据；既有三段不改、未新增供应商语速字段，最终仍经长度和模式校验。项目/task/step/group固定字段不变。
- `meiji/tests/speech-timing.test.js`：新增6项行为测试；`ui-project.test.js`同步前轮剧本显式入口的旧“无按钮”断言。
