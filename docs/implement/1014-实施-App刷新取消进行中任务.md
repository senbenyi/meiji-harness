## 验收标准核对
| AC | 状态 | 验证方式与证据 |
|---|---|---|
| AC-1 | 通过 | 运行任务和节点变为 cancelled，DOM 显示已取消，正文保留 |
| AC-2 | 通过 | 并发首次刷新只发一次 cancel；普通、事件、恢复可见刷新不取消后续任务 |
| AC-3 | 通过 | signal.aborted，晚到结果不改写取消终态和正文；既有 S4-07 回归通过 |
| AC-4 | 通过 | 取消连接失败时不渲染伪取消，下一次刷新重试成功后读取 Model |
| AC-5 | 通过 | 无运行任务不取消；独立排队项保留 |
