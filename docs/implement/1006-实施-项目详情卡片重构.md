# 项目详情卡片重构实施记录

## 已修改文件

- `meiji/client/project-overview-view.js` — 自由模式隐藏剧本卡片；移除 AI 创作方向说明；编辑动作改为标题旁图标；项目库卡片补充分类布局内容和分类轨道标识。
- `meiji/client/asset-cards.js` — 为道具卡增加独立样式标识。
- `meiji/client/panel-styles.css` — 调整剧集、角色、场景、道具及项目库卡片布局和响应式样式；剧集封面固定 16:9，剧集区域一屏约展示 3.5 张卡片，角色/道具/场景卡使用稳定宽度和紧凑间距避免少量卡片拉满。
- `meiji/tests/script-ui.test.js` — 更新 AI 创作方向入口断言。
- `meiji/client/shot-card-state.js` — 区分正在自动修订的镜头状态，修订期间显示“修订中”；真正结束且审核失败时仍显示“自审未通过”。
- `meiji/server/runtime/review-checks.js` — 将文本任务的步骤类型和生成模式写入节点操作，供前端准确识别修订阶段。
- `meiji/tests/model-ui.test.js` — 补充“修订中”与已结束“自审未通过”的状态断言。
- `meiji/client/run-labels.js` — 根据步骤目标生成“生成摘要”“自审每秒指令”等详细步骤标题。
- `meiji/client/run-detail.js` — 任务步骤卡及提示词、HTTP、快照详情页统一使用详细步骤标题。
- `meiji/client/run-progress.js` — 任务进度中的步骤标题同步显示具体目标。
- `meiji/tests/run-view.test.js` — 增加生成/自审目标化标题断言。
- `meiji/client/run-labels.js` — 步骤标题继续补充目标编号，区分“生成每秒指令 · S01”等同类镜头步骤。
- `meiji/tests/run-view.test.js` — 增加镜头编号显示断言。
- `meiji/tests/run-service.test.js` — 覆盖每秒指令中间镜头审核暂停、提交修改后接续后续等待镜头的同任务恢复链路。
- `meiji/shared/run-planner.js` — 整集每秒指令带意见修订从第一个未通过/未完成镜头开始，保留前面已通过镜头；无未完成镜头时不错误回退到第一镜。
- `meiji/tests/run-service.test.js` — 增加顶部“带意见修订”入口的续跑测试，确认已通过镜头不重复生成。
- `meiji/client/project-session-view.js` — 移除剧集流程导航中的“一键做到…”按钮及其一键跑完整流程逻辑。
- `meiji/tests/model-ui.test.js` — 断言流程导航不再展示一键做到入口，也不会触发任务。
- `docs/plans/1006-计划-项目详情卡片重构.md` — 记录目标、验收标准和改动计划。
