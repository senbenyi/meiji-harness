## 具体规则

1. 同地点连续时间内的看书、发现、走近、对视、拥抱保留在一个 Scene；不能按动作阶段或总时长平均拆场景。真实时空变化仍拆场景，单 Scene 可以长于 15 秒。
2. 一个 Scene 可以归属多个 Segment。即使一镜到底，单次生成仍是 4～15 秒；不靠增加换景、动作重启或剪辑来凑分段。开始/结束状态描述人物位置、运动方向与相机衔接。
3. 连续镜头中的动作和渐变景别记在同一 shot 内；适合连续拍摄时每段一条 shot。确有反应、空间信息或明确正反打/交叉剪辑要求时保留必要多镜，不强制所有故事一镜到底。每次剪辑切换单列 shot，不能把多个机位切换塞进一条 framing/camera。
4. 单条连续镜头的 H3 Prompt 要求 continuous single take, no cuts；时间标记表示动作推进。多镜只按已有镜头边界切换，不擅加交替特写或蒙太奇。
