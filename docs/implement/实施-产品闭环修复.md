## 实现

1. 删除旧导演设置插件、部署入口及其引用；导演人设继续由 `harness/.agent-presets/elysium-director/persona.md` 提供。项目仅保留工具插件。
2. 视频卡片加载就绪后显示下载按钮，弹窗播放器保留浏览器原生控件。`GET /plugins/dsh-elysium/media/download` 验证 token 后 fetch 上游并流式转发，设置附件文件名，不重定向、不保存媒体文件。上游失败返回错误。
3. `GET /plugins/dsh-elysium/media/list` 扫描状态目录的 `jobs/*/status.json`，仅返回成功任务，按 mtime 降序。默认 50 项、最多 200 项，offset 从 0 开始，响应包含 items、total、has_more，条目包含 created_at（mtime 毫秒）。资产侧栏可折叠、拖宽和滚动分页，状态存于 `elysium-panel-state`。
4. 分镜 API 前缀 `/plugins/dsh-elysium/storyboard`，GET list/get、POST create/update/delete；与媒体共用 token。分镜存储于 `$ELYSIUM_TOOLS_STATE_ROOT/storyboards/{8位hex ID}/manifest.json`，临时文件写入后 rename，写操作串行执行。镜头序号在保存时重排，输入字段及 ID 校验失败返回 400。
5. README 和项目约定同步更新，README 三条铁律原样保留。

媒体卡片继续使用 session/call 查找任务。资产列表与分镜通过经过认证的 `job` 参数读取任务，ID 必须为 32 位 hex。客户端 URL 均从注入的 `window.__ELYSIUM_MEDIA__` 配置构建，不硬编码隧道端口。

删除分镜前显示含标题的确认提示，取消不会发送删除请求。分镜列表显示镜头总数及状态为 succeeded 的完成数。镜头状态由用户设置；关联任务 ID 用于显示产物预览，不会自动启动或重新生成任务。“替换”清空关联并恢复 pending。文字在失焦后提交，其他变更立即提交，保存失败显示错误。资产和分镜预览通过带 token 与 job ID 的同源 `/media/video`、`/media/image` 端点加载；服务端流式代理上游并转发 Range/If-Range，保留 206/416、Content-Range、Accept-Ranges 与 HEAD 行为。

客户端使用 React.createElement；新面板模块采用命名 load 定义，由 `scripts/client-source.mjs` 转换为宿主的对象式模块注册。模块依赖排列于入口之前，使用宿主提供的 React 与 react-dom/client。

- 镜按 role 查找锚点并展示名称、描述和参考素材；有 job_id 时显示同源认证预览。保存 acts 时服务端按跨幕顺序重新编号，最多 1000 镜。

### 阶段 6：交付与文档

- “交付”子视图显示成片/字幕类型图标、标签、时长、帧数、大小和下载链接；空列表和缺少下载来源均有提示。README 与 `.claude/standards.md` 更新为素材 → 项目 → 交付结构。
- 交付登记复用 `/project/update` 的 deliverables 数组。条目支持 `type`、`label`、`job_id` 或 `url`，可选 `duration_sec`、`frame_count`、`size_bytes`、`created_at`；规格数值为非负数。示例：

```json
{
  "id": "a1b2c3d4",
  "deliverables": [
    { "type": "film", "label": "六分钟预览", "job_id": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa", "duration_sec": 360, "frame_count": 8640, "size_bytes": 32505856 },
    { "type": "subtitle", "label": "字幕 SRT", "url": "https://media.example.com/third-cup.srt" }
  ]
}
```

- 任务交付复用既有 `/media/download` 代理；服务器 URL 交付不携带本机 token，浏览器直接访问。跨域服务器应返回附件响应头以直接下载，否则浏览器可能打开文件供保存。遵循媒体 URL 铁律，不采用调研示例中的本地 path，不新增任意本地文件下载或媒体落盘功能。
- 本轮执行范围不包含素材标签端点、自动按项目归属分流、自动生成/绑定、拼接成片或交付登记界面；公共素材仍列出成功任务，引入项目保留原素材。上述内容不能视为已经完成的自动化闭环。
- 验证：构建通过，95 个 Node 测试、2 个 Python 测试通过；覆盖交付 URL/规格、拒绝本地路径和无效规格、失败写入不破坏已存数据、高清筛选参数与筛选切换重置分页。
- 项目级验证：`PYTHONDONTWRITEBYTECODE=1 python3.13 -m pytest tests -q -p no:cacheprovider` 通过（17 个测试、12 个子测试）。
