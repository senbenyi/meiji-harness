# 产品闭环修复实施记录

日期：2026-09-12。按计划阶段 1→5 实施，每阶段均执行 `pnpm build && pnpm test`。

## 实现

1. 删除旧导演设置插件、部署入口及其引用；导演人设继续由 `harness/.agent-presets/elysium-director/persona.md` 提供。项目仅保留工具插件。
2. 视频卡片加载就绪后显示下载按钮，弹窗播放器保留浏览器原生控件。`GET /plugins/dsh-elysium/media/download` 验证 token 后 fetch 上游并流式转发，设置附件文件名，不重定向、不保存媒体文件。上游失败返回错误。
3. `GET /plugins/dsh-elysium/media/list` 扫描状态目录的 `jobs/*/status.json`，仅返回成功任务，按 mtime 降序。默认 50 项、最多 200 项，offset 从 0 开始，响应包含 items、total、has_more，条目包含 created_at（mtime 毫秒）。资产侧栏可折叠、拖宽和滚动分页，状态存于 `elysium-panel-state`。
4. 分镜 API 前缀 `/plugins/dsh-elysium/storyboard`，GET list/get、POST create/update/delete；与媒体共用 token。分镜存储于 `$ELYSIUM_TOOLS_STATE_ROOT/storyboards/{8位hex ID}/manifest.json`，临时文件写入后 rename，写操作串行执行。镜头序号在保存时重排，输入字段及 ID 校验失败返回 400。
5. README 和项目约定同步更新，README 三条铁律原样保留。

媒体卡片继续使用 session/call 查找任务。资产列表与分镜通过经过认证的 `job` 参数读取任务，ID 必须为 32 位 hex。客户端 URL 均从注入的 `window.__ELYSIUM_MEDIA__` 配置构建，不硬编码隧道端口。

分镜列表显示镜头总数及状态为 succeeded 的完成数。镜头状态由用户设置；关联任务 ID 用于显示产物预览，不会自动启动或重新生成任务。“替换”清空关联并恢复 pending。文字在失焦后提交，其他变更立即提交，保存失败显示错误。媒体预览沿用服务端返回的 URL。

客户端使用 React.createElement；新面板模块采用命名 load 定义，由 `scripts/client-source.mjs` 转换为宿主的对象式模块注册。模块依赖排列于入口之前，使用宿主提供的 React 与 react-dom/client。
