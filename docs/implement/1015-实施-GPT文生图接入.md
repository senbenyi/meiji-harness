# GPT 文生图接入实施记录

## 已修改文件
- `meiji/shared/models/settings_model.js` — 图片增加 GPT（Codex 套餐），值为 `gpt-image`。
- `meiji/models/model-config.js` — 仅 `gpt-image` 使用 `textBaseUrl` 与占位密钥 `ollama`。
- `meiji/server/http/llm-server/params.js` — 组装 `POST /v1/images/generations`：`model=gpt-image`，`size/quality=auto`，`output_format=png`，参考图 data URL，画幅写入提示词。
- `meiji/server/http/llm-server/client.js` — 发送文生图请求，脱敏记录，空图或失败抛错，60 分钟超时并透传取消。
- `meiji/server/http/ai-routes.js` — `gpt-image` 走上述客户端；`elysium-image` 仍走媒体网关。
- 设置路由、设置页选项与 `tests/stage20-gpt-image.test.js`；制作工作流、开发指引和 README 补上该选项。
