# 提示词编排验收建议

测试项目：提示词验收-雨夜失物-1001（2026-10-01），第一集实际 62 秒。实际请求全文保存在 meiji/reports/prompt-audit-1001/实际请求.json，各步骤可在页面任务历史查看。

## 建议编排

Model 分成：角色职责 → 本次任务（根据什么做什么）→ 输入事实 → 必要上下文 → 基础规则与节点补充 → 本次意见及修改边界 → 输出结构。生成、修订、审核分别编排，审核只验收最新稿。

JSON 用于摘要时长与人物/场景字段；大纲、镜头表、每秒指令正文保留标题、段落和真实换行。当前大纲保留 outline 包装即可，没必要为展示取消包装。

## 真实请求发现

| 位置 | 已观察问题 | 建议 |
|---|---|---|
| 摘要 | 首集同时收到全部跨集通用规则和“无前集/无后集”条件；时长、篇幅在规则和协议重复 | 通用底线保留一份，条件由 Model 选取；动态数值只在参数及输出校验出现 |

| 镜头表输入 | 首次生成仍有空的完整镜头表及相邻每秒指令标题；讨论首帧模式却禁止本阶段选择模式 | 只注入真实非空上下文；未来阶段的模式选择留到对应 Model |

## 清理范围

本轮清理重复任务句、模式说明和大纲中的逐招/机位级规则；保留身份、因果、空间、画幅和无人要求。场景图输出要求归 Model，大纲增加正文分节与换行要求。后续编排改造以上述真实证据为准。

每秒指令新增发现：首次审核和复审同时混入真实动作矛盾与主观建议（如要求雷声必须提前增强、环境必须动态变化）。复审确认 S01 在 0–2 秒已写“刚拾起”，实际拾起却位于 2–4 秒。修改意见在每张卡重复保存，下一次整集修订请求增长到 30,776 字。建议 Model 按镜头归属收集问题并去重，保留一份整集基稿；交接明确指当前时间段末态，审核区分真实矛盾和可选增强。整集失败不应把同一全文问题无差别贴给所有镜头。
