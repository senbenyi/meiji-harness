## 真实生成与部署边界

本轮使用真实本地模拟网关传输和实际媒体处理，没有请求真实供应商付费出图/出视频；供应商的画质、对白/音色/口型一致性未验收，实际候选仍需人工检查选用。字幕时间由节拍估计，可人工修SRT，不声称自动语音强制对齐。淡入淡出不包含交叉叠化。部署需要ffmpeg/ffprobe、libx264/AAC及中文字体；缺字体会明确报错，也可设置`DRAMA_SUBTITLE_FONT`。
