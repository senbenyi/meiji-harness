# 剧本素材导入与摘要提取

## 改动

- 素材库新增剧本分类，导入 UTF-8 TXT/TEXT，支持预览与下载；文件最多 1 MB、200000 字符。素材列表不携带完整正文。
- 创建页支持导入新剧本或选择已有素材，移除选择恢复手填摘要。创建与会话入口共用 `project-creation.js`，绑定工作区后自动启动项目摘要提取。
- 新增 `ProjectSummaryModel`、对应接口、独立操作/任务及生成/审核 skill，严格校验项目摘要非空且最多 500 字。生成、自审、修订及历史快照沿用三层模型。
- 剧集摘要有剧本时按原文顺序与本集时长提取，无剧本时根据项目摘要创作；前后集用于进度和衔接，提取到原剧本结尾时保留结局。
- 项目概要新增提取状态、历史、skill 和重试入口。失败保留剧本与候选稿；停止或重启释放占用，支持重新提取。
- 更新 `.agents/meiji-dev.md`、README 和提示词测试场景。
