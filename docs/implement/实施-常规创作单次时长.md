# 常规创作单次时长

`workflow_generate_video` 在 `profile=regular` 时支持 `duration_seconds`，必须为大于 0 的有限数值；插件不额外设置 15 秒硬上限，省略时仍为 5 秒。T2VA 和 I2VA 均使用单个 H3 生成节点，不拆分拼接。预览、高清及兼容档不接受此参数。

保持 576×768、24fps、8 步和联合音频生成。帧数仍按现有 `17k+5` 规则对齐：5 秒为 124 帧，10 秒为 243 帧，15 秒为 362 帧（约 15.08 秒）。结果分别记录请求时长及实际规格时长，卡片按实际值展示，不宣称成片严格小于等于 15 秒。

最终帧数由现有 ComfyClient.validate 读取当前服务器节点的 min/max 校验。当前节点声明 5–3600 帧，但注明训练范围约 124–362 帧（约 5–15 秒），更长未测试；接口接受范围不等于已验证生成能力。菜单说明单次生成、时长按需，模型指令不主动延长到训练范围之外。测试覆盖默认规格、两种模式的时长映射、非法值及其他档位拒绝时长参数；不代表已在服务器实测 15 秒生成耗时或画质。
