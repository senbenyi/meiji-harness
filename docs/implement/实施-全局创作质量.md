# 全局创作质量实施

## 已实施

- 统一设置新增 `creation.quality`，默认常规创作，并支持旧设置无损补全。
- 设置页新增“创作质量”下拉框，统一提供快速创作、常规创作和高清创作。
- 图片、视频与短剧任务在 Worker 层读取全局设置，各 Provider 在提交前转换为实际分辨率、步数和输出规格。
- 新工具 schema 不再暴露质量、项目档位、图片预设或预览变体；新项目不再保存质量档位。
- 素材与任务卡使用统一质量名称，历史 `profile` 只用于旧数据兼容。
- `dsh-elysium/src/client/commands` 已物理删除，加载器、客户端注册、预设规则和测试不再保留三个创作命令。

## 验证结果

- 创作质量相关专项测试 98/98 通过。
- 插件全量测试 191/192 通过；唯一失败为沙箱禁止读取完整进程命令行的既有 Worker 身份测试，与本次改动无关。
- Harness 全量测试 10/10 通过。
- 插件构建和 Registry 打包通过，源码、构建产物与发布包均无命令目录或三个斜杠命令引用。
- 本机安装被沙箱以 `EPERM` 阻止写入 `~/.dsh`，因此未重启运行实例。
