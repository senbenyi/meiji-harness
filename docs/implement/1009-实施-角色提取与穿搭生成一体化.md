# 角色提取与穿搭生成一体化实施记录

## 已修改文件
- `meiji/shared/run-planner.js` — 全剧提取后按本轮可见角色展开库图片自动入库；剧集提取即使文字就绪仍检查缺图，独立生图维持确认。
- `meiji/server/flow/steps/shared/image-files.js` — 先独立基准图，再逐套统一参考；自动补齐时复用基准及已完成穿搭的原像素，只为缺图调用模型。
- `meiji/server/flow/steps/shared/image-generation.js`、`step-generate-library-image.js` — 两入口传递复用和自动保存策略，项目库入口补齐自动保存。
- `meiji/server/data/library-image-storage.js` — 库图片共享入库事务、快照保护、取消检查及失败清理。
- `meiji/server/flow/operations/direct/operation-project-library.js` — 人工确认复用同一事务，删除被替换的重复保存逻辑。
- `meiji/shared/seconds-content.js`、`meiji/skills/output-protocols.js` — 注入本集服装目录并选择/校验 costumeId。
- `meiji/server/prompts/video-prompt-renderer.js` — 绑定指定完整穿搭图，缺失/过期不回退到不匹配的主图；保存服装ID与图片快照。
- `meiji/tests/{project-characters,character-wardrobe,run-planner,character-pipeline}.test.js` — 更新集成规格，新增服装绑定、像素复用及失败保护验证。
- `.agents/meiji-dev.md`、`meiji/README.md`、对应计划 — 同步流程及旧指令补齐规则。

## 验收标准核对
| AC | 状态 | 验证方式与证据 |
|---|---|---|
| AC-1 | 通过 | 无剧集项目的真实 Run 完成角色资料、图片入库，待确认集合为空；只展开本轮 visible |
| AC-2 | 通过 | 两套衣服需基准加两套共3次生成；每套参考相同基准，主图ID独立 |
| AC-3 | 通过 | 本集独立提取与项目提取测试，范围隔离 |
| AC-4 | 通过 | 已有完整角色跳过，部分缺失只请求缺图；保存失败/取消/过期保留原图并清理新增素材 |
| AC-5 | 通过 | 提取 Run 无 wait_confirm；手动图片仍保留确认 |
| AC-6 | 通过 | 视频仅引用选中衣服图；ID变化、图片过期阻止提交；原指令不改写 |
