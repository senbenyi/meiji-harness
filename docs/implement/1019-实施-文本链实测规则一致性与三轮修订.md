## 修改
- project-characters：三动作复用人物纳入、可空国籍、必填外貌/声线、服装规则，审核不再使用缺少边界的独立简表；position对齐既定“核心身份及剧情作用”，头饰沿用原props配件含义，不新增字段。
- common、seconds及节点契约、storyboard：连续摄影与剪辑分开，去掉强制“机位未变”和将该简称转成固定机位的歧义；明确群体分区成员可并行；服饰归属与个体细化由common共享。
- review-policy：先独立核对上游能否自洽，不把待审候选当上游，候选自身矛盾按模型问题修；拒绝基于完整上下文的具体证据。
- shots：审核以实际数组位置及原title定位新镜头，减少临时ID诱导；既有patch协议不变。
- node-definitions、task_contract：文本统一首次生成后最多3次修订，步骤round允许0至3。媒体/程序仍0；原阻断与无进展提前停止机制保留。
- schema.sql、sqlite-store：v28原子重建步骤表，只扩大round约束，全部列逐字复制，保留外键和索引；不重写项目JSON、revision、任务、请求和历史记录。
- node-inputs：原task.opinion保持不变，发送时将可识别旧拒绝诊断与本次要求分开；round>0不把原任务旧诊断重复作为执行要求，只带最近待核实诊断及本次要求。坏patch后完整基稿与场景拆并历史机制保留，历史标作核查记录。
- 相关测试及业务文档：同步3次预算、v28、审核语义和输入边界。未使用新Model字段或自动人工放行。
