## 使用边界

- 三方单镜头模型走标准生成参数；多个分镜需要当前后端支持多镜头合片。限制在提交前明确报错，不改时长、不删镜头、不擅自换模型。
- 一个分镜的画面参考图受当前后端输入数量限制；其余选中人物、道具等经分镜描述传入，视觉一致性仍取决于模型。
