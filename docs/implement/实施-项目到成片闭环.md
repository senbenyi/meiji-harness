# 实施-项目到成片闭环

- 计划：`docs/plans/计划-项目到成片闭环.md`
- 日期：2026-09-21
- 状态：代码与自动化测试完成，待用户按「用户验收清单」在 AutoDL 真实验收。

## 与计划的偏差

1. **阶段 3 范围缩小（调研结论更正）**：`job:` 参考图在 ComfyUI 路径本就由 `worker/manager/manager.js:dispatch → resolveReferences` 在派发时解析为被引用任务的 view 地址，调研中「提交即 422」的判断有误。实际缺口只有「导入素材 / 其他服务器的图片」，因此只做了：`referenceUrl` 同服务器直接引用，否则从本地上传到 ComfyUI `/upload/image`（`protocols/comfyui/client.js:uploadImage`，固定子目录、同名覆盖）；解析结果仍随 `input/request.json` 保存，恢复沿用。TaskContext 未新增 `mediaSource`。
2. **阶段 2**：下载在 `runner.js:execute` 的 `collect` 之后统一执行，所有 ComfyUI 平台（AutoDL、RunPod 标准适配器）一致；新增执行阶段 `download`。
3. **首帧比例**：图片计划新增 `purpose: 'keyframe'`，尺寸取同质量档 H3 档位比例、长边 1152（快速/常规 864×1152，高清 840×1152）；有主角参考图时走 `workflow_generate_image_reference`（IP-Adapter FACE）。
4. **重拍幂等**：镜头新增 `take`；提交 ID 与种子均由（项目、集、镜、take）确定，重启后同一 take 重放得到同一批任务，新 take 换新种子。
5. **提示词不再要求画面字幕**：成片统一烧录字幕，若提示词仍要求画面出字幕会叠两层字幕，因此同步修改了通用 `shot-planning`（SKILL.md、步骤、清单、范例）以及两位导演 `director-cad24a59`、`director-dbfbfbea` 的 `shot-prompt-example.md` 中的【字幕】一行（仓库与本机两处）。
6. **锚点手工增删与素材库「用作项目锚点」移除**：锚点只来自剧情总览；素材只能替换角色参考图。聊天项目工具只保留列表、读取、创建（封面可选）与项目资料修改。
7. **分镜质量约束**：分镜校验新增「每镜台词字数 ≤ 时长 × 5」。

## 主要改动

- 数据：`database/managers/projects.js` 重写为只按集存储（无根级分镜/交付物、无「采用」）；新增 `auto.json`、`changeAuto`、`planningBasis`；规划写入同样推进 `updated_at`。`database/schemas/projects.js` 定义新锚点/镜头/交付物/自动状态字段。
- 服务：`server/projects/service.js`（锚点同步与出图、`produceShot` 首帧+视频、`reshootShot`、`retryShot`、自动开关、sink）；`planning.js`（总览定稿触发出图与复位确认、提示词变更重置镜头）；`planning-schema.js`；`film.js`（字幕、响度、SRT、删除不分集合成）；新增 `pipeline.js`；`routes/projects.js`；`index.js` 组合 `driveProjects`。
- Worker/模型：`runner.js` 下载落本地；`client.js` `download`/`uploadImage`；`manager.js` 参考图上传回退；`routes/media.js` 本地优先；图片 `purpose: keyframe`；视频计划透传 `seed`。
- 工作台：项目页生产面板（范围、一键生产、暂停、继续、去处理）、锚点确认、分镜只读+重拍/恢复、成片版本与 SRT 下载；删除批量时间线、采用、手动合成、镜头编辑等入口。
- 规范：`.claude/standards.md` §1、§5 按人工决策修订。
