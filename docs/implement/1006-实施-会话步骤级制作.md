## 验收标准核对
| AC | 状态 | 验证方式与证据 |
|---|---|---|
| AC-1 | 通过 | 实际模型请求计数、节点 kind 和待审核结果；修改带基稿/意见，重新生成不带旧稿 |
| AC-2 | 通过 | 大纲、场景、摘要、镜头表、每秒指令、项目摘要独立审核；正文/内容版本和下游保留，审核接口失败不覆盖结果 |
| AC-3 | 通过 | 审核不通过时 job 完成、stepCompleted=true、reviewPassed=false；目标可按“取得结论”标准完成 |
| AC-4 | 通过 | 面板生成、自审、自动修订/复审、视频、尾帧和回写回归；会话缺前置时不增加未授权任务 |
| AC-5 | 通过 | 真实 Harness goal/todo/job 工具配合可控规划适配器：一项审核、两项生成审核、单项生成失败；分别 complete/complete/blocked，0 额外目标续跑 |
| 文件组织补充 | 通过 | 每个业务生成/审核/修订及媒体步骤有 step 文件，任务注册表接入实际调用；架构依赖测试通过 |
