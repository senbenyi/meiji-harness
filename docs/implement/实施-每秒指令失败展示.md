# 每秒指令失败展示

## 结果
每秒指令尚无可用正文时，执行或自审失败仍显示详情。整集审核问题与单镜问题合并去重，整集失败状态不再被单镜“未生成”覆盖。无正文时不提供人工放行或意见输入，提交修改禁用；保留重新生成与任务历史入口。

## 根因
失败稿节拍时长不符合镜头表，只保存为未发布任务草稿。原 UI 以“已有正文”为展示条件，隐藏了保存在整集 error 中的复审意见；整集反馈聚合还遗漏了整集审核原因。

## 改动
- `workflow-review.js`：真实失败不依赖正文展示；无正文操作限制。
- `feedback.js`：保留整集失败状态和意见，兼容运行及暂停状态。
- `model-ui.test.js`、`all-seconds.test.js`：覆盖首次生成格式失败、无正文渲染、重新生成、成功刷新、审核去重。
- `.agents/meiji-dev.md`：补充失败展示要求。
