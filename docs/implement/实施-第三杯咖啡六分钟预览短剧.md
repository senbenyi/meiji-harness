# 《第三杯咖啡》六分钟预览短剧实施记录

状态：实施中，尚未交付完整六分钟成片。对应 [计划](../plans/计划-第三杯咖啡六分钟预览短剧.md)、[制作资料说明](third-cup-preview/README.md)、[120镜分镜表](third-cup-preview/分镜表.md)。

## 执行位置与边界

所有制作脚本从本地项目执行：`scripts/third-cup-preview.mjs` 顺序调用既有插件单镜任务链；参考帧提取通过 ComfyUI API 的已有节点完成；`scripts/third-cup-edit.py` 在本地读取结果 URL、叠加中文字幕、逐段裁切和拼接。没有通过 SSH 执行提帧、剪辑、字幕脚本，没有部署新模型或服务。用户明确要求 SSH 仅用于故障排查修复与日志监控。

生成原片与角色参考图仍使用服务器 URL；独立本地制作脚本输出至 `out/third-cup-preview/`，不属于插件媒体上传/下载接口。静音中文字幕是交付选择，模型仍进行了联合音频采样和解码。

## 审核及修复

- 原脚本启动 worker 后才保存回执：已改为先保存 job_id，再启动，回执原子写入；同一回执加互斥锁，避免重复启动。已完成回执不会重新采样。
- 120×73帧并非360秒：本地每镜裁切到72帧/24fps，最终目标8640帧。
- 服务器API报告总内存约54GB、当时可用约11GB：不在服务器构建一次性载入6分钟帧张量的拼接图，改为本地逐镜编码后无重编码拼接。
- 本机 ffmpeg 未提供 subtitles/drawtext：使用已有Pillow及Arial Unicode字体绘制透明字幕层，由现有overlay滤镜叠加，没有安装新框架。
- 78项JavaScript测试与2项Python测试通过；新增覆盖已完成回执复用、错误请求不分配任务、不同请求不能复用回执。
- 120镜编号、6段剧情、8640帧目标和字幕时间线已检查。所有生成重试按镜头累计，最多3次本地调用，不删除原回执。

## 初步观察

前四镜技术成功并本地拼成12秒：场景23.468秒、林夏34.195秒、陈默34.395秒、周予33.881秒服务器执行。均发生真实采样；每镜73帧，剪辑后72帧。三位虚构成年角色外观可辨，观察到转头、低头、擦杯动作，中文字幕可读。

场景生成未严格执行“两杯咖啡”约束，桌面杯子偏多；作为预览构图缺陷记录，暂不为此反复生成。尚未完成120镜身份一致性、字幕剧情节奏和最终成片检查，不能把前四镜成功表述为全片验收。

## 实时记录

`third-cup-preview/progress.json`记录已完成镜头数；脚本重启会核对已有回执，completed取已完成最大编号，不会因核对旧镜头倒退，checked_shot记录本次核对位置。`attempts.json`不是新视频数量，job_id才是逻辑视频身份。完整验收结果将在制作完成后补充。
