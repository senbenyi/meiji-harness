## 改动对照
| 位置 | 原文 | 新文 |
|---|---|---|
| 首尾帧前缀 | 不将首帧误作本镜目标尾帧 | 本镜结尾画面落在分镜的最后一拍 |
| 场景参考行 | 机位变化不改变固定空间；不复制图中人物，不把参考图强制作为首尾帧 | 机位变化时固定空间保持一致；此图只提供空间，画面人物以分镜为准，开场与结尾画面按分镜生成 |
| 参考图总说明 | 不能把定妆照背景带入场景。不交换身份，不增加出镜人物；参考图不是本镜首帧或尾帧 | 人物所处背景以场景图片和分镜为准……每张人物图固定对应其标注的人物，出镜人物以分镜所写为准；开场与结尾画面按分镜生成 |
| 场景图 | 无人物；不做拼图、分屏、多视图或文字标注；不为昼夜、机位或天气另建 | 空镜，画面只有空间与陈设；单幅完整画面、单一视角；以基础光照呈现供各镜共用 |
| 场景一致性 | 不额外增加人物…；不能用同名物件替代；不能画成斜卧野战炮；不因石丘补造山脉；不补造 | 画面只包含资料写明的空间、设施和道具；严格按资料呈现专用设施实际结构；地貌只按资料明确写出的样子 |
| 定妆照 | 不加文字；不将生成的服装补写到资料中 | 画面中只有人物本身；（删除） |
| storyboard | 只拍手和袖口时不露脸，只有画外声时不创造可见身体；不添加角色名贴片… | 写明画面只见手和袖口；写明为画外声，画面只呈现在场人物；画面文字只保留原分镜已有的；三段正文用正向描述 |
