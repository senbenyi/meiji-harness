# AI 节点路由与提示词模型实施记录

## 已修改文件
- `meiji/server/http/nodes/*.js`：10 个节点、27 个动作的唯一输入/输出契约及节点绑定；生成和修订共用输出定义，分镜三段式标题也由路由定义。
- `meiji/server/http/ai-routes.js`、`task-routes.js`：统一执行入口与 HTTP 注册；正文为明确业务参数，query 校验会话项目绑定；根据一次配置快照编排并调用来源，校验返回候选，不直接写项目。
- `meiji/server/http/{elysium,llm-server}/{client,params}.js`、`chat-transport.js`：两个无任务状态的文本请求单例、独立来源参数及共用重试/取消/脱敏留痕。
- `meiji/server/prompts/models/*.js`、`composers/*.js`、`inputs.js`、`render.js`、`providers.js`、`parse-json.js`、`parse-sections.js`：迁移角色和各动作要求、节点独立业务参数编排；输出从路由引用；保留资料边界和占位符单次展开。
- `meiji/server/handlers/{node-inputs,text-handler,media-handler,handler-registry,content}.js`：任务按节点提取显式参数并调用统一执行器；自动修订使用最新候选及本轮意见；人工编辑使用相同输出校验；媒体保存/归一化仍留在任务流程。
- `meiji/server/runtime/app-runtime.js`、`server/gateway/model-gateway.js`：接入统一执行入口，移除旧 completeChat；图片、视频来源协议沿用。
- 删除 `meiji/server/prompts/yaml-prompts.js` 与 `meiji/dev_docs/in_puts/` 的 27 份旧模板；`package.json`、`package-lock.json` 移除不再使用的 yaml 依赖。
- `meiji/scripts/prompt-diff.js`、`.agents/meiji-dev.md`、`meiji/README.md`、`meiji/dev_docs/制作工作流.md`、`meiji/skills/README.md`：同步节点路由与 PromptModel 开发入口和调用示例。
- `meiji/tests/stage13-ai-routes.test.js`、`tests/fixtures/ai.js`，及受影响的 stage01、stage05、stage06、stage09、stage11 测试：接入新入口，增加协议和并发/取消/契约检查。
