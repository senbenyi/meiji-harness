# 网关接口同步实施记录

## 已修改文件
- `meiji/server/generate/gateway.js` — 生图改为同步接口：无参考图走 `images/generations`（JSON，带 seed），有参考图走 `images/edits`（multipart `image[]`），解码 `b64_json`；删除 `uploadGatewayFile`、`cancelGatewayTask`、`cancelOnStop` 和图片任务轮询；视频请求增加 `size`，只接受 data URL 参考图，请求体超过 64 MiB 时本地报错；停止或超时只结束本地等待，报 `REMOTE_NOT_CANCELLED`，写明远端任务 ID；日志隐藏 multipart 文件内容和 base64 数据。
- `meiji/shared/project-rules.js` — 新增 `videoSizeOf`：`1344x768` → `1024x576`，`768x1344` → `576x1024`；网关和面板共用。
- `meiji/index.js`、`meiji/server/flow/tasks/restart.js` — 删除启动时的远端取消；遗留视频任务记录「网关不提供取消接口，远端任务（id）可能仍在运行」。
- `meiji/server/generate/image.js` — 参考图生图改为传 `referenceBytes` / `referenceMime`；生成、铅笔分镜、配件图都传入 seed；`pictureRecord`、`imageAsset`、`importAssetImage` 不再生成 `imageUrl` / `file`，有 `localPath` 或 `assetId` 即算通过；删除 `isLocalPicture`。
- `meiji/server/flow/operations/images.js` — 确认图片、导入图片、导入配件都不再上传网关，也不再要求先配置视频网关。
- `meiji/server/data/pictures.js` — 素材引用不再含 `imageUrl`；新增 `readReferenceImage`（读取素材库图片、旧版剧集图片或尾帧）和 `referenceImageData`（按顺序转为 data URL）。
- `meiji/server/data/library.js` — 素材元数据不再写入 `imageUrl`。
- `meiji/server/flow/operations/films.js` — 删除 `publishLocalReferences`；提交视频时把本地参考图转为 base64，任务记录和日志只写本地地址；尾帧不再上传；提交参数展示用 `size` 代替 `quality`。
- `meiji/server/generate/shot-text.js` — 文本分镜的参考列表只保留 `<Picture N> 标签`，不含地址和图片；尾帧快照地址改为 `tail-frame:<视频文件>`；只要求参考图有本地地址。
- `meiji/shared/tail-frame.js` — 尾帧有 `localPath` 即可承接；新增 `tailFrameUrl`。
- `meiji/shared/reference-images.js`、`meiji/shared/drama-model.js` — 只使用本地地址；新增 `hasGatewayFileFields`；读取仍含 `imageUrl` 的剧集时报 `OLD_IMAGE_URL`，并提示执行迁移脚本。
- `meiji/server/generate/story.js`、`meiji/server/data/story-package.js`、`meiji/server/data/task-store.js` — 删除 `imageUrl` / `file`；模型返回的图片字段一律丢弃。
- `meiji/server/http/routes.js` — 删除 `/character-image-url`；`/reference-preview` 改为读取本地文件。
- 删除 `meiji/server/generate/image-access.js`。
- `meiji/client/character.js`、`asset-cards.js`、`overview.js`、`app.js`、`styles.css`、`stages.js` — 删除「人物图片 URL」段落和 `imageUrl` 判断；请求预览显示 `size`，并注明参考图提交时转为 base64。
- 新增 `meiji/scripts/migrate-image-url.js`；`configure-harness.sh` 在启动前调用它。
- 文档：`meiji/docs/gateway-api.md` 替换为新接口文档；`.agents/architecture.md`、`.agents/development.md`（铁律中的取消与文件规则）、`meiji/docs/tasks-and-steps.md` 同步更新。
- 测试：`gateway-cancel.test.js` 重写为 `gateway.test.js`；新增 `migrate-image-url.test.js`，以及 `production.test.js` 中「参考图从本地读取并转为 base64」的测试；删除 `image-access.test.js`；其余测试改用本地地址断言。
