## 已修改文件

- `meiji/server/prompts/models/episode-scenes.js` — 统一连续室外场地的收录粒度，禁止无新事实要求反向拆并。
- `meiji/server/handlers/node-inputs.js` — 场景审核读取本任务此前审核意见，跨任务隔离。
- `meiji/shared/scene-inputs.js`、`meiji/shared/node-dependencies.js` — 共用场景图片原始剧情投影，输入和指纹同源。
- `meiji/server/handlers/media-handler.js`、`meiji/server/http/nodes/scene-image.js`、`meiji/server/prompts/models/scene-image.js` — 图片实际请求加入原始剧情，用于约束地理和装置结构；参考图只画固定空间。
- `meiji/server/http/nodes/shots.js` — 引用校验聚合所有错误人物/服装位置和真实ID，并同时暴露候选时长不合规；不自动替换引用。
- `meiji/tests/stage29-scenes.test.js` — 覆盖历史反馈隔离、图片真实编排及输入指纹、错误引用定位、多错误与时长同时反馈。
