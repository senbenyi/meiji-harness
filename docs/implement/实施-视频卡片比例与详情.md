# 视频卡片比例与详情

预览比例依次使用视频元数据中的实际尺寸、`media_info`、任务 `specification`、调用参数及默认尺寸。预览保留完整画面，不通过裁剪消除留边。历史任务缺少尺寸时，视频元数据加载后同样会校正比例。

详情显示任务 ID、`timings.total_ms` 换算的一位小数秒数，以及档位、尺寸、视频时长、步数和音频信息。缺失字段不编造；任务耗时和视频时长分别展示。完成的工具结果及状态轮询恢复的卡片均支持这些字段，状态接口传递 `timings`、`profile` 和 `specification`。

通过媒体卡片及 HTTP 测试验证 384×512 预览、实际尺寸校正、两种结果来源和缺失字段行为。
