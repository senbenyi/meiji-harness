## 迁移与数据边界

v22已用于步骤执行方式/记录拆分，最近关联采用v23：按历史queue_order回填每节点最近任务、整集/单镜成片与定妆照组；不重建任务ID，不重写原结果、提示词或节点依赖hash，迁移事务失败回滚。已有v22数据库也能升级，重复启动不再次迁移。

整组尚未结束时允许其已完成成员留在工作快照，满足原有成员/序号校验；整组终态后全部移出。提示词/HTTP暂存只属于当前执行任务，任务结束释放；旧历史不再常驻任务/步骤数组。面板快照的runtime仅发送revision，幂等结果中的旧组摘要和通知记录不随面板刷新；回归断言序列化面板不含旧任务ID。幂等requests及通知outbox仍按原设计存放，这是计划明确非目标，不能宣称所有历史内存占用已归零。

客户端缓存最近摘要与用户打开过的详情；服务端历史列表只临时读取组/任务表，未改为SQL层聚合分页，不读取步骤/大记录。节点最新状态与失败原因来自真实任务，不从当前节点内容猜测。
