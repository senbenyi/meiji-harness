- `dsh-elysium/src/server/projects/workflow.js`：全剧剧情/分镜请求、所有分集原子校验回写、全部视频预校验与逐集提交、任务复用和失败恢复、成片完成确认；读取结果消除 undefined，明确空素材的引用规则。
- `dsh-elysium/src/database/managers/projects.js`、`src/index.js`：列表返回关联会话，提示词注入当前项目，工具拒绝其他项目目标。
- `dsh-elysium/src/tools/project/workflow.js`、`src/tools/prompts/creation.js`：全剧回写 schema、单集修改工具与人工审核边界。
- `dsh-elysium/tests/{workbench,project-panel,episodes-ui,series-workflow,project-session,project-tools}.test.js`：布局、全剧推进、会话工作区关联及项目隔离测试。
- `dsh-elysium/README.md`：更新四区布局和全剧审核操作说明。
