# 设置页模型连接与创作质量

- 类型：Bug 修复
- 目标：让三个私有模型类别都能显式连接、重连并显示真实状态，简化创作质量行，修通选择与运行时链路。
- 调研来源：`docs/research/调研-设置页模型连接与创作质量.md`

## 人工决策

无。采用“下拉先选择待连接目标，按钮再连接；连接成功后设为新任务默认目标”的交互，与现有后端的先检查后切换语义一致。

## 执行步骤

### 阶段 1：连接和状态接口

1. `dsh-elysium/src/server/routes/settings.js:models` — 修改：只返回模型清单与选中项 → 一并返回各私有模型是否有可解析的目标服务器；缺少登记目标时标记不可连接，避免默认模型清单造成“可选却永远连接失败” → AC-1、AC-5。
2. `dsh-elysium/src/worker/models/catalog/check.js:switchServer` — 修改：同目标重连也写选择 → 先检查，目标未变化时返回成功且不递增 revision；新目标才写入选择 → AC-5。
3. `dsh-elysium/src/server/routes/settings.js:model-status/model-connect` — 修改：复用现有只读探测，增加聊天只读状态；私有连接成功后返回当前选择，缺少登记目标时给出明确错误；失败保留旧选择及脱敏错误 → AC-2、AC-3、AC-5、AC-7。

验证：`node --test tests/server-routes.test.js tests/server-panel.test.js`（在 `dsh-elysium/` 执行）及针对默认/登记两模式的后端测试；确认探测零写入、缺少服务器时按钮不可用、失败零切换、成功回读和同目标重连零版本变化 → AC-2、AC-3、AC-5、AC-7。

### 阶段 2：设置页交互与布局

1. `dsh-elysium/src/client/workbench/settings.js:Settings` — 修改：聊天/图片/视频始终保留行和连接按钮；下拉只改待连接目标，按钮执行连接；每行独立显示连接中、绿色“连接成功”、失败信息和“重新连接”；页面加载后只读探测当前目标，切换目标清除旧成功状态；操作中禁用有冲突的控件，409 后重读模型、选择和 revision，避免过期状态 → AC-1、AC-2、AC-3、AC-6。
2. `dsh-elysium/src/client/workbench/settings.js:Settings` — 删除：`qualityDescriptions` 和质量行 `<small>`；保留已有质量存储及下拉项 → AC-4。
3. `dsh-elysium/src/client/workbench/styles.js` — 修改：连接状态绿色文本、逐行错误、按钮对齐与设置页窄容器布局；保证 280px 侧栏和移动端换行、不裁切 → AC-2、AC-6。

验证：更新 `dsh-elysium/tests/server-panel.test.js`，覆盖未配置、待选、连接/重连成功失败、刷新探测、质量无小字、三方回归；构建后在实际设置页检查常规侧栏、最窄侧栏和移动端 → AC-1、AC-2、AC-3、AC-4、AC-6、AC-7。

### 阶段 3：运行时闭环与打包

1. `dsh-elysium/tests/server-routes.test.js`、`dsh-elysium/tests/media-http.test.js` — 修改：覆盖模型连接后的 `/models` 回读和持久化 `selection`、质量独立 revision、状态接口鉴权和脱敏，并同步更新路由注册断言；补足默认配置及已登记目标测试 → AC-3、AC-4、AC-5、AC-7。
2. `dsh-elysium/tests/server-panel.test.js` — 修改：把“选择即连接”的旧断言改为“按钮连接”，核对页面和接口返回一致 → AC-1、AC-2、AC-6。

验证：运行聚焦测试、`npm run build` 和 `npm test`；在已安装 Harness 上手动点击三类连接/重连、刷新回显、创作质量与三方选择，并检查 `settings.json` 选择写入和新任务后端快照。安装/重启与远端实时连通性若未执行，单独标注未验收 → AC-1 至 AC-7。

## 验收标准

逐条引用调研文档 AC-1 至 AC-7，以上各阶段按对应编号验收。

已实施。`npm test` 232/232 通过；聚焦面板与设置路由测试 7/7 通过；`npm run build`、`npm run package:registry`、`git diff --check` 通过。当前运行配置下，聊天、图片、视频模型检查均成功，选择版本与内容未变化；本机 HTTP 设置接口返回两个私有模型可连接，三个状态接口均为 `connected: true`，新任务路由仍选择 `autodl-comfyui`。Harness 已重启，新路由的匿名访问返回 401。浏览器中窄栏和移动端视觉效果未人工验收。
