# 提示词输入资料按字段包装

- 类型：完整流程。
- 目标：资料输入按具名对象包装；按用户追加要求，所有大模型文本生成与修订返回 JSON 对象，解析后正确保存和展示正文。
- 非目标：不迁移用户数据，不改变图片/视频二进制接口及程序编译的 H3 成品结构，不把规则、任务和意见变成数据字段。

## 验收与调研

| AC | 输入 → 结果 | 调研依据 |
|---|---|---|
| AC-1 | 摘要、剧本、大纲、参数及跨集资料 → 各标题下可解析的字段对象，保留原文与归属 | 摘要/StoryModel 当前直接拼文本；卡片部分已经 JSON |
| AC-2 | 镜头、关联卡片、连续性与素材清单 → 字段可区分，镜头 ID、秒数、资料范围保持 | shot-text-prompts、storyboard-context 当前混合自由文本与数组 |
| AC-3 | 人物/场景/道具图片资料与画幅 → 命名字段对象，参考图只写顺序/用途，不含 Base64 | 图片 Model 当前使用中文标签拼接 |
| AC-4 | 修订基稿、最新失败稿、最新待审正文 → 文本按类型字段包装，已有对象不重复编码 | baseSegments/reviewParts/Model 目前不统一；摘要 JSON 已有结构 |
| AC-5 | 换行、引号、反斜杠、空输入 → 资料原文可无损读回，任务/规则仍为文本，预览与实际请求相同 | segment 当前直接 String(object)；共享调用面需相关回归 |
| AC-6 | 大纲生成/修订 → 只返回 outline 对象，解析后存七小节正文并保留换行；非法结果不覆盖有效大纲 | storyKinds.outline 当前 json:false；generateStoryPackage 直接 required(text) |
| AC-7 | 镜头表及单镜修订 → shots 对象，字段为 shotId/durationSeconds/title/content；编号、时长与范围校验，存为现有卡片正文 | readShotSections 当前读 Markdown 标题；reviseShot 直接保存响应 |
| AC-8 | 所有文本 Model → 生成/修订 json:true，已有摘要/提取/每秒/审核协议保持；图片提示词返回 prompt 对象 | textSteps 的 shots/shot-revise/image-prompt 为 json:false；文本分镜只由程序编译，模型只审核 |
