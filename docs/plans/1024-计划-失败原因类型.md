# 失败原因类型

- 类型：完整流程，审核终态原因投影及独立卡片展示。
- 目标：去掉黄色边线；未通过原因类型和正文取最后一轮审核，修订轮次仅为执行信息。
- 非目标：改变自动保存、修订上限、用户操作及历史任务事实。

## 验收标准
| AC | 状态→结果 | 调研依据 |
|---|---|---|
| AC-1 | 失败卡片→无黄色左边线，显示最后审核的原因类型 | failure-decision.js当前border-left为warn色，未展示类型 |
| AC-2 | 三轮未通过→content_issue等最后审核类型，不是revision_limit_reached | 两Executor写入轮次stop_code，projectExecutions优先显式码 |
| AC-3 | 历史任务已含轮次码→当前会话/节点摘要仍显示真实最后审核结论及问题，不写改历史任务 | boxReport已读取最后review，但reason和displayContext仍使用旧end_reason |
| AC-4 | 最后一轮原因由内容转为上游/规则→以最后类型和意见为准；失败/取消非审核状态准确 | 按真实Task与Step投影，保留现有失败类型处理 |
