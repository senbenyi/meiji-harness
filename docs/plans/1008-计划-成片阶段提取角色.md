# 成片阶段提取角色

- 类型：完整流程 / 制作流程调整
- 目标：镜头表与每秒指令使用人物名称，直接成片时从最终指令提取人物、复用或补图并绑定视频提示词。
- 非目标：重写动作、台词或时点；删除旧项目；改变视频网关；取消手动角色管理。

## 调用链与证据
面板/会话 → createRunService → planRun → 文本生成/审核 → 每秒指令保存 → 成片人物提取/审核 → expand 补图 → compileVideoPrompt → filmSubmit。
