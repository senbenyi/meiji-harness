# 项目 → 剧本 → 锚点 → 分镜 → 成片

- 类型：新功能
- 目标：把项目流程改为「项目 → 剧本 → 锚点 → 分镜 → 成片」；在「剧本」步骤就按导演 Skill 生成完整剧情（集数、每集按秒时间线与对白），由运营审核、修改、重新生成并定稿，然后才进入锚点和分镜。
- 调研来源：`docs/research/调研-短剧生产级产品审查.md`（AC-1、AC-2、AC-4）；在 `docs/plans/计划-短剧生产级.md` 阶段 4–6 已实现的规划引擎上调整。

## 人工决策

已定（2026-09-21）：
1. 步骤顺序与名称：项目 → 剧本 → 锚点 → 分镜 → 成片。
2. 「剧本」= 剧情总览 + 逐集时间线；时间线内含对白，即为剧本，不再单列“单集剧本”步骤。
3. 总览定稿后，由运营点击“生成全部集时间线”，不自动开始。
4. 规划 Skill 按职责拆为两个：`drama-planning`（剧本：总览、时间线）与 `shot-planning`（分镜：分镜、逐镜提示词）；导演 Skill 仍注入两者，并可用 `references/steps/` 为任一步追加补充要求（不替换通用步骤）。
5. 聊天 Agent 暂不操作项目：项目流程先只在工作台完成，项目稳定后再回头优化聊天入口；本计划隐藏聊天侧全部项目与导演工具，聊天只做自由创作。
6. 镜头增加人工“采用”状态，合成要求本集全部镜头已采用（闭环缺口 12 并入本计划）。

需要确认：无。当前运行数据中没有任何 `planning.json`（已核对），不需要迁移旧规划数据；旧项目 `storyboard.json` 仍按现有逻辑作为第 1 集分镜读取。

7. 导演页分三个页签「导演风格 / 导演剧本 / 导演分镜」统一配置，每页签直接编辑对应 Markdown 全文；导演补充从“按步骤文件”改为“按阶段文件”，取代 S2、S3 中的 `references/steps/<step>.md` 做法（阶段 2A，2026-09-21 追加，阶段 1–2 已完成后插入）。

## 设计要点

### 规划步骤

| 步骤 ID | 页面 | 范围 | 输入 | 输出 |
|---------|------|------|------|------|
| `series` | 剧本 · 总览 | 项目 | 项目名、题材、梗概、导演 Skill | 一句话梗概、题材、世界观、集数、单集秒数、角色表、场景表、`episodes[{number,title,summary,hook}]` |
| `timeline` | 剧本 · 分集时间线 | 单集 | 总览定稿、本集梗概、上一集时间线定稿（若有） | `beats[{start,end,scene_id,roles[],plot,emotion,dialogue[{role,text,tone}]}]` |
| `storyboard` | 分镜 | 单集 | 本集时间线定稿、角色/场景 | 镜头列表（不变） |
| `shot-prompt` | 分镜 · 提示词 | 单镜 | 本集分镜定稿 | 单镜提示词（不变） |

删除步骤：`outline`（并入 `series.episodes`）、`script`（并入 `timeline`）。

### Skill 分工

| Skill | `metadata.kind` | 步骤 | 内容 | 模型参数 |
|-------|-----------------|------|------|----------|
| `drama-planning` | `planning` | `series`、`timeline` | 剧情结构、集数判断、时间线与对白规则、剧情审核清单 | 自带 `metadata.llm`（沿用 max_tokens 8192） |
| `shot-planning` | `shot-planning` | `storyboard`、`shot-prompt` | 景别运镜、单镜 1–15 秒、H3 音画联合生成约束、提示词结构与范例、镜头审核清单 | 自带 `metadata.llm`（提示词上限 20000 字，max_tokens 需大于 8192，初值 16384，由《计划-短剧生产级》阶段 0 的 qwen3.8 实测修正） |

每一步的系统提示词（以阶段 2A 为准）= 本步所属 Skill 正文 + 导演 `SKILL.md`（导演风格）+ 所属 Skill 的步骤文件 + 导演阶段补充（`series`/`timeline` 用 `references/script.md`，`storyboard`/`shot-prompt` 用 `references/storyboard.md`）+ 范例（仅 `shot-prompt`：导演 `references/shot-prompt-example.md` 优先，否则用 `shot-planning` 的）+ 所属 Skill 的 `checklist.md`。模型参数取所属 Skill 的 `metadata.llm`。

### Skill 优先级（2026-09-21 冲突审查补充）

| 冲突 | 规则 |
|------|------|
| S1 规则相互矛盾 | 硬约束（代码校验、规划 Skill 标注为“硬约束”的条目：输出结构、ID 引用、单镜 1–15 秒、对白逐字保留、时长总和）＞ 导演 Skill ＞ 规划 Skill 的默认建议。两个规划 Skill 正文开头写明此顺序，硬约束条目统一放在“硬约束”小节 |
| S2 导演步骤文件整份替换 | 改为追加，且按阶段而非按步骤：导演 `references/script.md`（剧本阶段）与 `references/storyboard.md`（分镜阶段）只写该导演的补充要求，与通用步骤文件一起注入。阶段 1–2 已实现的 `references/steps/<step>.md` 由阶段 2A 替换 |
| S3 范例从未注入 | `shot-prompt` 步骤注入范例文件；导演自带 `references/shot-prompt-example.md` 时优先使用 |
| S4 聊天可见项目 Skill | 聊天暂不操作项目期间，Agent 不挂载 `pools/skills/`；项目稳定后再恢复 |

### 时间线校验（代码，安全边界）

- `beats` 非空、按 `start` 升序、首段 `start = 0`、相邻段 `end = 下一段 start`、每段 `end > start`。
- 末段 `end` 与总览 `episode_seconds` 相差不超过 10%（容忍模型取整）。
- `scene_id`、`roles`、`dialogue.role` 必须在总览角色/场景表中；`plot` 非空；`dialogue` 可为空数组。

### 闭环规则（2026-09-21 流程审查补充）

| 编号 | 缺口 | 规则 |
|------|------|------|
| L1 | 工作台不能生成定妆照 | 锚点页“生成参考图”：按锚点描述提交图片任务，binding `{ type: 'anchor', role }`，复用已有 `anchor` sink 回写 |
| L2 | 场景锚点不参与生成 | 生成计划把 `scene_id` 对应场景锚点的名称与描述拼入提示词前缀 |
| L3 | 批量时间线前后集断裂 | `timeline` 参考上一集**最新版本**（草稿也可），版本记录所参考的上一集版本号；上一集之后再改，本集标需复核 |
| L4 | 总览重定稿锚点只增不改 | 同步锚点：新增角色建锚点；外观/音色变化更新描述并标“参考图需复核”；删除的角色锚点标 `retired`（不删）；集数减少时多出的集标 `retired` |
| L5 | 分镜重定稿整集覆盖 | 按镜头顺序与内容（场景、角色、动作、对白）匹配旧镜头，未变镜头保留 ID、任务、提示词；变化镜头清空任务与提示词；本集有 `pending/queued/running` 镜头时拒绝重新定稿 |
| L6 | 需复核只提示不拦截 | 提交生成、合成前检查：本集时间线/分镜/所选镜头提示词有需复核，或镜头引用 `retired`/不存在的锚点 → 409 并指明步骤与镜头 |
| L7 | 图生/文生在定稿时固化 | `mode` 不再在分镜定稿时写入；提交时按角色锚点当前是否有参考图决定 |
| L8 | 换导演不触发复核 | 项目 `director` 变化 → 所有已定稿规划标需复核 |
| L9 | 生成期间上游被改 | 每个版本记录所依据的上游定稿版本号（`based_on`）；定稿时依据已过期则拒绝并提示先复核 |
| L10 | 对白在传递中丢失 | 代码校验：分镜每条对白须与时间线对应时间段对白一致（说话人 + 文本）；定稿提示词须逐字包含本镜全部对白文本 |
| L11 | 时长漂移 | 分镜 `duration` 限 1–15 整数秒；本集镜头时长之和与时间线总长相差不超过 10% |
| L12 | 成功≠合格 | 镜头新增 `accepted`（布尔）；只有 `succeeded` 镜头可采用；重新生成或任务变化自动取消采用；合成要求本集全部镜头已采用 |
| L13 | 项目完成判断错误 | 项目 `completed` = 总览集数内每一集都有成片；`active` 含 `pending+job_id` |

### 复核联动

- 总览重新定稿 → 所有已定稿的时间线、分镜、提示词标“需复核”，并按新角色/场景表更新锚点（沿用 `createAnchorsFromCast`）。
- 某集时间线重新定稿 → 该集分镜与提示词标“需复核”；其他集不受影响。

### 阶段 2A：导演三页签（导演风格 / 导演剧本 / 导演分镜）

导演 Skill 文件约定：

| 页签 | 文件 | 内容 | 注入步骤 |
|------|------|------|----------|
| 导演风格 | `SKILL.md` | frontmatter；风格与题材、人物塑造、声音与对白基调、禁忌、代表作参考 | 全部 |
