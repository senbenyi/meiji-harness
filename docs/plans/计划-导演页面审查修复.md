- 类型：Bug 修复

2. `dsh-elysium/src/client/workbench/styles.js:.elysium-director-copy` — 修改：移除有序列表缩进和标记 → AC-1。

验证：`node --test tests/director-panel.test.js`；页面人工核对作品呈现 → AC-1、AC-4。

### 阶段 2：名称修改和项目引用
1. `dsh-elysium/src/client/workbench/directors.js:DirectorList` — 修改：编辑时开放名称输入并提交原名称；保存后用原名称替换当前卡片 → AC-2。
2. `dsh-elysium/src/client/api/directors.js:updateDirector`、`dsh-elysium/src/server/routes/directors.js:createDirectorHandler` — 修改：更新请求传原名称，路由协调导演和项目的引用更新 → AC-2、AC-3。
3. `dsh-elysium/src/database/managers/directors.js:createDirectorStore.update` — 修改：按原名称定位，校验新名称唯一性并保留排序位置 → AC-2。
4. `dsh-elysium/src/database/managers/projects.js:createProjectStore` — 新增：受控更新引用该导演的项目元数据，处理部分写入失败后的恢复 → AC-3。
5. `dsh-elysium/tests/director.test.js`、`dsh-elysium/tests/director-panel.test.js` — 修改：覆盖改名、重名、已使用项目和重载结果 → AC-2、AC-3。

验证：`node --test tests/director.test.js tests/director-panel.test.js tests/project.test.js`；读取 `pools/directors.json` 和项目 `project.json` 核对名称；Harness 页面人工验收 → AC-2、AC-3。

## 验收标准
- AC-1：打开导演卡片，作品按原顺序展示且不显示数字序号。
- AC-2：编辑导演名称，保存和重载后显示新名称；重名、空名报明确错误。
- AC-3：已有项目引用被改名的导演时，改名后项目详情和导演选择仍指向有效导演。
- AC-4：输入含顿号、数字的作品名称，保存和重载后文本不被错误拆分或剥除。
