# 计划：审核返回规则统一

## 背景
审核返回格式已有统一协议 `shared/review-result.js` 的 `reviewProtocol`，但多处仍各自重复或补充返回规则，同一请求里出现两到三套说法。

## 改动
1. `reviewProtocol` 改为正向说明 + 示例，集中定义：JSON 结构、通过/未通过写法、issues 三字段含义、逐项/按镜头编号列出、issues 语言。
2. `reviewMethod` / `shotReviewMethod`（skill-prompts.js）只保留判定方法，逐镜列出规则移入协议。
3. 删除各 Model 角色中重复的「只审核，不生成或修改原文」「审核意见使用本次参数指定的语言」「实际审核只返回统一的 passed/issues JSON」「每项引用…最小修正方向」（story-model、episode-summary-model、text-step-model、interfaces/outline、text-storyboard-model、text-prompts）。
4. 大纲审核的结构段改名【大纲结构（核对依据）】，避免被当作回复格式。
5. 人物/场景修订基稿只保留卡片内容字段，去掉 check.passed、review、operation、draft 及空值等内部状态（story-prompts.js）。

## 验证
- 全量测试失败集与基线一致（27 个既有失败）。
- 场景快照扫描：全部审核请求中【本次审核协议】各出现 1 次，协议段之外不再出现返回格式规则。
