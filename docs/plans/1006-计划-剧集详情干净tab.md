# 剧集详情干净 tab

- 类型：小改动
- 目标：剧集详情页阶段 tab 只显示阶段名称，移除 tab 行中多余的进度数字和合成终点下拉框。
- 非目标：不改变阶段切换和一键制作的执行逻辑。
