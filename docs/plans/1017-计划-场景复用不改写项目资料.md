# 场景复用不改写项目资料

- 类型：Bug 修复
- 档位：完整流程（共享合并逻辑、保存与过期、提示词、测试、文档，超过 3 个文件）
- 目标：提取场景时，已有场景从项目场景库直接取用，本集只记 ID；只有新地点生成资料并加入项目。
