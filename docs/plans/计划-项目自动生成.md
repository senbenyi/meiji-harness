# 项目自动生成

- 类型：新功能
- 目标：创建项目先选导演，以可复用的机器人按钮生成可编辑的项目草稿。
- 调研来源：用户 2026-09-21 的项目流程需求及本轮源码核对。

## 人工决策

无。用户已确认执行本轮规划。

1. `dsh-elysium/src/server/projects/planning-schema.js:projectDraftSchema` — 新增：定义项目草稿三字段结构与服务端校验 → AC-3、AC-4。
2. `dsh-elysium/src/server/projects/planning.js:createPlanningService` — 修改：按所选导演 Skill 和剧本参考生成项目草稿，不写项目数据 → AC-3、AC-4。

4. `dsh-elysium/src/client/workbench/styles.js` — 修改：项目表单右上角按钮布局 → AC-3。
5. `dsh-elysium/tests/project-suggest.test.js`、`dsh-elysium/tests/project-panel.test.js`、`dsh-elysium/tests/media-http.test.js` — 新增、修改：覆盖表单、生成与路由注册 → AC-1 至 AC-5。

验证：客户端构建、定向测试及完整测试 → AC-1 至 AC-5。

## 验收标准

- AC-1：新建项目时导演位于第一项，默认选择排序第一位，不显示占位选项。
- AC-2：字段显示“项目题材”，项目表单不提供封面选择，创建请求不包含封面。
- AC-3：点击右上角机器人按钮，按当前导演生成并填入名称、题材、梗概，生成动作不创建项目。
- AC-4：生成内容仍可编辑；失败保留原输入；服务端拒绝无效内容。
- AC-5：剧本及分镜规划使用相同机器人按钮，沿用原有版本生成、手改和定稿流程。
