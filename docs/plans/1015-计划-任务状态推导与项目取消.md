# 任务状态推导与项目取消
- 类型：完整流程，任务调度与持久化重构。
- 目标：删除 queue_stopped，从 queued/running 任务推导当前队列；取消停止本项目全部当前任务并保留历史。
- 非目标：删除历史、实现远端视频取消、改变推理并发。
## 验收标准
- AC-1：取消运行或排队任务 → 本项目全部未结束任务已取消，其他项目不受影响，旧结果不得写回。
- AC-2：取消/失败后新提交 → 自动执行，无隐藏暂停；旧请求清理期间新任务等待，保持串行。
- AC-3：执行失败/未通过 → 剩余排队任务已取消，历史与失败原因保留。
- AC-4：v13数据库迁移至v14删除暂停列，项目与历史不丢失；重启与重新加载清空未结束任务。
