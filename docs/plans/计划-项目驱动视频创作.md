# 项目驱动视频创作

- 类型：新功能
- 日期：2026-09-19
- 目标：模式归项目，聊天建项目并打开侧栏，配置 → AI 剧情 → AI 分镜 → 人工提交 → 视频。
- 调研来源：`docs/research/调研-项目驱动视频创作.md`
- 状态：2026-09-19 已完成。

## 人工决策

确认本计划。按“选中的素材才传入、未选项为空”实现；项目模式沿用导演/自由/教学，默认导演，首期流程一致。男主、女主各单选，配角和道具多选，场景/主题/导演单选。参考文本支持粘贴和 TXT/Markdown 导入。

## 执行步骤

以下 src 路径均相对 `dsh-elysium/`。保留当前 settings.js、styles.js、server-panel.test.js 等已有修改，仅合并本需求必要变更。

### 阶段 1：模式与项目数据

1. `harness/.dsh/.agent-presets/`、`harness/.dsh/settings.yaml` — 修改：三个业务模式预设 → 统一创作入口；标准工具预设保持原职责。兼容历史会话预设标识 → AC-1、9。
2. `harness/scripts/install.mjs`、新增 `harness/scripts/migrate-creation-presets.mjs` — 修改/新增：覆盖安装不足以移除旧入口 → 定向备份并迁移默认值和预设规则，关闭 ui-agent-preset 会话选择界面；保留旧预设身份以便历史会话加载 → AC-1、9。
3. `src/tools/agent/presets.js`、`projection.js`、`src/tools/project/context.js`、`src/tools/prompts/creation.js` — 修改：按预设分流及隐藏项目 → 统一显式项目流程，保留宿主权限和计划策略 → AC-1、2、7、9。
4. `src/database/schemas/projects.js`、`src/database/managers/projects.js` — 修改：强制导演、薄分镜 → 可选素材配置、mode、brief、参考文本、剧情、阶段及版本、完整分镜和提交快照；旧数据补默认值，不覆盖已有内容 → AC-1、3～9。
5. `src/tools/project/project.js` — 修改：创建依赖导演 → 只需创作需求/标题即可创建，默认导演模式，返回可导航项目身份 → AC-1、2。

验证：项目 schema/store/tool 测试覆盖空素材、分类与选择数量、旧数据读取、稳定镜头 ID、默认模式；预设安装测试验证旧入口迁移和旧会话兼容。

### 阶段 2：项目导航与配置页面

1. `src/client/workbench/index.js`、`src/client/workcard/card.js`、`src/client/index.js` — 修改：手工打开 → 当前会话新项目工具结果自动展开并定位；事件按会话/调用去重，历史回放不切换 → AC-2、9。
2. `src/client/workbench/projects.js`、新增 `src/client/workbench/project-configuration.js` — 修改/新增：横向锚点流程 → 纵向配置、剧情、分镜、视频步骤；角色分组和素材选择、参考文本、阶段状态 → AC-3～6、8。
3. `src/client/workbench/materials.js`、`src/client/workbench/styles.js`、`scripts/loader.js` — 修改：补齐按类别单选/多选与已选状态，注册新增模块和纵向样式，不改变素材库实体归属 → AC-3、5、9。实施时核对素材选择器实际所在模块并只改对应实现。
4. `src/client/api/projects.js`、`src/server/routes/projects.js`、`src/server/projects/service.js` — 修改：补阶段操作、配置保存及带版本的读取接口，共用现有鉴权 → AC-3～8。

验证：组件测试和真实浏览器验证输入需求后自动打开正确项目，所有选择可留空、道具可多选、场景不可多选，刷新恢复阶段，导入文本展示完整内容。长文本超出模型上下文时明确提示或先提炼，禁止静默截断。

### 阶段 3：AI 剧情与分镜

1. 新增 `src/client/workbench/project-generation.js` — 新增：将下一步动作关联当前项目/会话和服务端生成请求；先查验宿主公共会话 API，再通过现有 Harness 模型发起生成，避免虚构接口 → AC-4、6。
2. 新增 `src/server/projects/workflow.js`、`src/tools/project/workflow.js`，修改 `src/index.js` 及工具注册入口 — 新增/修改：阶段请求、结构化剧情/分镜写回工具、版本检查；只接受当前阶段和版本结果 → AC-4、6、7。
3. `src/tools/prompts/creation.js`、新增 `src/tools/prompts/project.js` — 修改/新增：需求+所选素材描述/服务器引用+参考文本 → 剧情；剧情+素材 → 分镜；不擅自选择未选库内素材，不生成后直接启动视频 → AC-3、4、6、7。
4. `src/client/workbench/projects.js`、`src/client/workbench/storyboard.js` — 修改：展示并可编辑剧情、分镜；镜头包括顺序、时长、人物/场景/道具引用、动作、景别、运镜、光线、对白/声音、生成提示；生成失败可重试且保留用户修改 → AC-4～7。

剧情服务端按去除空白后的 Unicode 字符计数（含标点）限制 200 字；超长返回明确错误要求 AI 修订，不直接截断。分镜分别保存创作字段和编译参数，展示总时长；参数按当前视频后端能力验证。

验证：模拟 AI 写回覆盖合规/超长剧情、结构错误、跨项目和过期结果、重复请求；实际 Harness 点击下一步确认使用现有配置模型且只推进当前一步。

### 阶段 4：人工提交与视频交付

1. `src/server/projects/workflow.js`、`src/server/routes/projects.js` — 修改：显式提交保存审核快照和版本，编译快照后启动；上游变更令旧审核失效；重复点击复用同一任务 → AC-7、8。
2. `src/tools/media/video.js`、`src/server/workflows/videos/service.js` — 修改：项目工作流生成入口校验人工提交状态与版本，不能绕过审核；历史任务恢复保持原语义 → AC-7～9。
3. `src/server/projects/workflow.js`、`src/client/workbench/delivery.js`、`projects.js` — 修改：把已审核分镜编译成现有 provider 接口支持的 shots/引用/时长，复用合片，回写任务与成品；显示失败、恢复及播放 → AC-8、9。

所选多个人物/道具全部进入分镜规划与逐镜头素材分配，但单镜头图片输入遵循平台上限；不能静默丢弃必需参考或假装平台支持无限参考。能力不满足时提交前给出可操作校验信息。

验证：未审核调用被拒、修改后旧审批被拒、双击仅创建一个任务、失败恢复沿用任务、编译总时长和引用正确；真实生成一条短视频并在项目成品阶段播放。

## 验证结果

插件 194 项、Harness 10 项回归已通过；真实页面已完成聊天创建项目、自动导航、素材配置、AI 剧情、AI 分镜、人工修改、提交生成 3 秒视频。最终版本构建、打包、重启及浏览器播放验收通过；3 秒、480×854、readyState=4、error=null。详见实施记录。

实施核实：宿主 sessions.scope(id).get('conversation').send 为当前会话公共发送接口；旧预设没有隐藏标记，采用关闭 ui-agent-preset 界面、保留历史预设身份的兼容方式。Web 装配文件同步修改。修复 _base 人设配置 text→prefix 以兼容已安装 Harness，否则新会话无法建立。单镜头三方模型采用标准参数，多个分镜仅交给支持合片的后端，提交前说明模型限制。
