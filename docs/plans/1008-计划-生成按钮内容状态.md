# 生成按钮内容状态
- 类型：Bug 修复，完整流程
- 目标：剧情到成片的生成按钮按内容显示 AI生成／重新生成，提交模式一致。
- 非目标：改变镜头表审核前置、自动开始真实生成。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 状态 | 依据 |
|---|---|---|---|
| AC-1 | 无内容（含失败无稿）→ AI生成和generate | 未验收 | workflow-review.js失败状态强制regenerate；paintSeconds写死文案 |
| AC-2 | 已有或部分已有内容→ 重新生成和regenerate | 未验收 | 依据对应阶段正文、镜头、每秒正文、提示词、视频结果判断 |
| AC-3 | 忙碌、请求失败、提交修改→ 保持忙碌/恢复原文案/modify | 未验收 | 各阶段操作及共用审核组件 |
| AC-4 | 仅有镜头表 → 每秒指令和成片页无占位卡；部分生成 → 只显示已有数据的镜号 | 未验收 | 用户补充：不需要列表骨架；按各自独立字段展示 |
