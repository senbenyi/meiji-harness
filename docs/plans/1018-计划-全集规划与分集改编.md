## 字段方案（用户已确认）
script-split输出改为剧集[{序号、本集规划、预估时长秒}]，删除起始段落/结束段落/排除段落。episodes[].plot改为本集规划文本。story_outline.segments结构不变，body为改编剧情；正文派生拼接，不另存副本。HTTP分集改编输入增加原剧本与全集/相邻集上下文（不新增持久化项目字段）。内部业务名及任务字段保留。

## 调用链与证据
面板 → TaskService → node-inputs → script-split/outline路由与PromptModel → handler program/AI review → commitContent。
buildSplit原本强制段落覆盖并按原文拼接；outline原规则强制原事件和对白全保留。两者需原位替换，不保留旧新双轨。

## 改动
1. 路由、script-split handler及PromptModel改为全集规划契约；删除旧切点和回推段落逻辑。
2. 共享分集上下文用于输入/hash，outline PromptModel及审核允许受约束改编；修改前集后传播过期。
3. UI、节点名称及正文派生；保留镜头表实际消费分集改编segments。
4. 更新受影响测试与工作流文档；按授权清空旧项目，通过既有项目删除生命周期执行。
