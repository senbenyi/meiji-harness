# 恢复输入输出折叠箭头

- 类型：小改动，单个CSS文件。
- 目标：输入依赖、任务输出恢复原生details展开/收起箭头，保留右侧复制按钮。
- 原因：summary使用run-record-head的display:flex，隐藏了浏览器原生list-item标记。
- 改动：packages/task/ui/styles.js为这两个summary恢复display:list-item，复制按钮右浮动。
- AC：两处标题左侧有折叠三角，点击可展开/收起，复制按钮在右侧且不触发切换。
- 图谱：status有效，jsonRecord影响查询UNKNOWN，源码核对其仅用于输入/输出两个展示位置，不视为无影响。
- 验证：浏览器操作及截图、git diff --check、detect_changes及索引更新；仅样式不新增业务测试。

## 验证结果
浏览器两处summary均为list-item，标记分别为disclosure-closed/open；点击输出可收起，复制成功且保持收起。截图/tmp/task-input-output-disclosure-1022.png。git diff --check通过。detect_changes包含既有未提交差异：46符号/13文件/496流程，critical，无partial/truncated。最终索引更新记录/tmp/task-disclosure-index.log。
