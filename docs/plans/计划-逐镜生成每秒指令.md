# 逐镜生成每秒指令

- 类型：重构
- 目标：从一次生成整集改为按镜头顺序逐镜生成、自审、必要时修订并保存。
- 非目标：不改镜头表生成方式，不新增人工审核，不更改持久化协议。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 判定与依据 |
|---|---|---|
| AC-1 | 提交 N 镜每秒指令 → 顺序执行 N 组生成/自审，前镜通过才开始后镜 | 当前未满足：generateAllSeconds 一次请求整集 |
| AC-2 | 生成/审核/修订某镜 → 资料为本镜镜头表、上一镜完整已通过每秒指令、大纲；不带后镜与其他镜头表 | 当前未满足：buildSecondsPrompts 使用相邻镜头表及首尾节拍 |
| AC-3 | 某镜复审失败、接口异常或取消 → 停止后镜，已保存结果保留；历史步骤归属具体镜头 | 实施后测试验收 |
| AC-4 | 重新生成或按意见修改 → 不带旧稿或按本镜基稿/意见修订；新输入意见不丢失 | 保留现有生产模式与意见所有权机制 |
| AC-5 | 所有分镜入口与提示词预览 → 同样使用逐镜路径；删除整集请求和局部合并逻辑 | 源码确认两个批量调用入口及预览测试夹具 |
