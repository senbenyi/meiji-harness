# 项目关联对话与全剧推进

- 类型：新功能；用户已明确按方案修改。
- 目标：Harness 导航在最左侧；左工作台保留项目列表、素材、设置；中间项目专属对话；右侧项目详情按全剧推进。

## 文件、改动和验收
1. `src/client/workbench/index.js`、`styles.js`：拆分左右面板、保留宿主导航，响应式布局与草稿保护。AC-1：四区互不遮挡，左右面板保持所选项目。
2. `src/client/workbench/projects.js`：列表和详情独立，列表选中态；新增项目后选中并展示右侧。AC-2：素材/设置完整保留，切 Tab 不清空选中项目。
3. `src/client/workbench/project-generation.js`、`src/server/projects/workflow.js`、`src/database/managers/projects.js`、`src/index.js`：持久化项目专属会话、切换会话与项目、系统提示绑定项目。AC-3：切换项目后对话上下文正确，拒绝对其他项目的误写。
4. `src/server/projects/workflow.js`、`src/tools/project/workflow.js`、`src/tools/prompts/creation.js`：全剧分镜请求与原子回写、全剧视频审核提交和完成确认。AC-4：缺一集不可推进，失败能继续且完成任务不重复生成。
5. `src/client/workbench/episode-ui.js`、`episode-workflow.js`：流程卡片下一步、全剧进度与未完成提示。AC-5：配置→全部剧情→全部分镜→全部成片→完成；点击等于当前阶段人工审核。
6. 对应工作台、工作流、会话及工具测试：验证项目隔离、并发/重复提交、过期与不完整分集回写、失败恢复；构建打包、浏览器验收与 Harness 重启。

路径均相对 `dsh-elysium/`。不新增视频自动合片功能，不在 UI 验收中付费生成视频。

## 验证结果
2026-09-19 已完成。AC-1～AC-5 通过；198 项插件测试、10 项 Harness 测试及布局复验通过。真实 AI 两集剧情/分镜已生成并显示全剧进度，视频提交使用模拟任务验证完整性和失败恢复。构建打包和 Harness 重启完成。详见 `docs/implement/实施-项目关联对话与全剧推进.md`。
