# 面板操作会话体验

- 类型：完整流程，输入记录补齐与UI交互调整。
- 目标：一次操作呈现清楚的请求、执行过程与最终结果，历史输入取真实快照，空/正常会话展示一致。
- 非目标：修改宿主源码、伪造用户/AI消息、增加模型调用、重跑旧任务。

## 调用链与证据
面板 → Service.optimizeScript → metadata.input_snapshot / TaskManager → step.prompt.input / result → log-only display → task-messages读取 → 项目注入的会话组件。
命令Node由宿主command Definition以conversationContextKey(command,id)形成key，并在ChatNodeSeat公开data-chat-node-key。正常会话组件附加在匹配程序命令的原生座位内，仅隐藏该操作的原生展示子树；步骤/结果同组其余原生座位隐藏。原事件/数据与其他聊天不删除。空会话放在原聊天滚动区，使用同一组件。
读取时按消息归属核对本会话的task/group，补齐任务事实；旧消息不重写。完整输入/输出按需读取，poll返回描述及状态。
