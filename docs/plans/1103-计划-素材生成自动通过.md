# 素材生成自动通过

- 类型：完整流程，素材阶段完成判定调整。
- 目标：所需素材图片生成成功后直接通过，不再要求人工审核/选图才能通过。
- 非目标：不自动改变选图、不修改图片生成服务、分镜参考仍按已选图片执行；不把失败或缺图显示为成功。
