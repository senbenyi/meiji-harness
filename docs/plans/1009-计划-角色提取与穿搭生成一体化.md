# 角色提取与穿搭生成一体化

- 类型：新功能
- 目标：人物提取经审核后，一次任务自动完成基准人物图和全部服装穿搭图并入库。
- 非目标：不对真实项目自动发起付费生成，不改背景群演筛选，不生成视频本身。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 状态 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 全剧提取通过 → 本轮可见角色逐个生图并自动保存；仅声音角色不生图 | 已确认断点 | run-planner.js project-characters 只有文本步骤 |
| AC-2 | 角色有多套服装 → 独立基准图，每套穿搭均引用基准图；不把衣服与人留到视频时合成 | 已确认断点 | image-files.js 把第一套图当主图 |
| AC-3 | 剧集提取 → 同样完成图片；项目与剧集提取范围不混淆 | 未验收 | 现有 characters expand |
| AC-4 | 已有完整图片 → 复用；失败/取消/资料变化 → 不发布残缺图片，不覆盖原图 | 未验收 | 图片入库已有快照检查及清理 |
| AC-5 | 单独点击生图 → 仍保留候选确认；集成提取流程不等待人工图片确认 | 未验收 | runLibraryImage 目前只支持候选 |

project-characters → review → publishProjectCharacters；characters → review → images expand → startImage → submitAssetImage → applyImageDraft。库图走 runLibraryImage → pendingImages → entry-image-confirm。
