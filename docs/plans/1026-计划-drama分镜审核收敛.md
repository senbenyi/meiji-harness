# drama 分镜审核收敛

- 类型：完整流程，关键生成与审核流程调整。
- 目标：仅有据的阻断问题触发分镜修订，建议不阻断；无效输出与审核误报在独立预算内修复。
- 非目标：放松ID/覆盖/结构约束、扩大其他盒子审核契约、无限重试、改写剧情、重做现有媒体。

## 验收标准与证据

| AC | 输入 → 结果 | 依据/验证 |
|---|---|---|
| AC-1 | 摄影丰富度等建议 → 通过并保留建议，不触发内容修订 | 分镜专属审核契约、报告/历史及测试 |
| AC-2 | 阻断问题 → 必须有来源与当前候选的路径及逐字引用；不存在引用不能使候选未通过 | 月界旅行历史将万倍/万万说反，以及无视最新时间/空间修订；证据校验回归 |
| AC-3 | 复审 → 逐项核对上一轮阻断问题，已解决项不得继续阻断 | previous_issue_checks与当前候选证据验证 |
| AC-4 | 空shots/格式/引用错误 → 同动作追加有限修复步骤，不覆盖旧结果；耗尽才失败 | 最新真实模型返回shots=[]；独立预算、取消/并发测试 |
| AC-5 | 无效审核 → 只修复审核响应，不无据修订正文、不自动通过 | 证据错误、预算耗尽、保留候选测试 |
| AC-6 | 当前项目 → 经授权的新审核标准实际生效，保留旧规则备份、意见、补充规则与任务历史 | 更新默认规则与当前月界旅行项目；停服期间落盘并重启 |
