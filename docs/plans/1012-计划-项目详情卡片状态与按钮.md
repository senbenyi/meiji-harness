# 项目详情卡片状态与按钮

- 类型：展示改动（详情页四张卡片，按完整流程记录）
- 目标：项目详情的项目大纲、剧本、剧集、角色卡在标题旁显示状态，生成按钮按内容显示对应操作，重新拆分剧集和提取角色与标题同一行，并去掉人工添加角色。
