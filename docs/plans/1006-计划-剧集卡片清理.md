# 剧集卡片清理

- 类型：小改动
- 目标：项目详情页的剧集卡片只保留封面、集数与时长、摘要，并支持点击整张卡片进入详情。
- 非目标：不改变剧集删除请求和详情页内容。

## 验收标准

| AC | 输入/状态 → 可观测结果 | 状态 | 依据 |
|---|---|---|---|
| AC-1 | 打开项目详情页 → 剧集卡片按“封面 → 集数/时长 → 摘要”纵向展示 | 已确认 | 已移除删除按钮、状态、复制 JSON、编辑和重新生成等附加操作，时长保留并使用小字号 |
| AC-2 | 点击剧集卡片 → 进入对应剧集详情 | 已确认 | 卡片点击回归测试通过 |
| AC-3 | 剧集卡片 → 不显示删除按钮 | 已确认 | UI 回归测试确认卡片内没有删除入口 |

## 改动

### 阶段 1：清理剧集卡片

1. `meiji/client/project-overview-view.js` — 删除卡片内删除按钮、状态、复制、编辑和重新生成元素，保留封面、集数、时长和摘要 → AC-1、AC-2、AC-3。
2. `meiji/client/panel-styles.css` — 将剧集卡片改为纵向布局，封面占满卡片宽度，调整集数/删除/摘要间距 → AC-1。
3. `meiji/tests/model-ui.test.js` — 增加卡片结构和点击行为回归断言 → AC-1、AC-2、AC-3。

验证：`node --test tests/model-ui.test.js`、`git diff --check`。
