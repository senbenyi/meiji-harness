# 动作前置状态与声画时间修订

- 类型：完整流程；修改共用规则及三个节点模板，沿实际规则对象注入链同步目标节点。
- 目标：可见人物允许不绑定；动作开始状态可执行，声画串并行与转写时间一致。
- 非目标：修正道具、补角色绑定、生成视频、改变JSON结构。

## 验收与取证
- AC-1：删除具名可见人物必须绑定的规则；已有绑定继续校验ID和服装归属。缺绑定不作为语义拒绝理由。
- AC-2：上马等动作先核对起始状态与动作结果，不能先骑乘再上马；上游已成立状态不重演。
- AC-3：对白优先占用正常发声区间，允许与不互斥的反应及运镜并行；转写保留实际区间，不将发声时长追加为发声后的静默。
- AC-4：实际修订S02切镜标记、S06问话时间、S09对白容量和S16上马，后续受依赖影响节点正常生成至多模态，无视频任务。

调用链：shared/prompt-models常量 → rule-defaults → 项目节点rules → HTTP按动作注入 → 原生生成/审核/修订 → dependencyHash及编排。GitNexus actionTimingRule impact为UNKNOWN，源码已核对shots/seconds引用；storyboard独立转写规则同步修改。前轮最后全量测试604/0/0作为本轮基线。

## 改动与验证
common.js原位加强动作前置和声画容量；shots.js移除强制绑定条款；seconds.js与storyboard.js明确卡外可见人物、正常发声和忠实转写。独立补充规则不相互引用，仅按用户意见去除强制绑定内容。生产先备份，通过正常项目/任务命令修订，保留道具状态。全量npm test、diff check、最终图谱更新、逐镜人工复核及视频任务数核对。
