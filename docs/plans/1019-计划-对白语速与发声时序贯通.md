# 对白语速与发声时序贯通

- 类型：完整流程；共用提示规则、视频请求编排及依赖投影。
- 目标：默认以自然交流语速约1.1倍表达，并保留对白发声起止、区分发声和画面停留，防止短句拉满镜头。
- 非目标：精确音频变速、后期加速、改镜头/视频时长、修改现有生产结果、自动覆盖保存的规则、增加项目或task/step/group固定字段。

## 改动
1. common.js唯一维护dialoguePaceRule，seconds/storyboard三动作及video生成修订引用；不对上游已有1.1目标逐层累乘。
2. seconds原位调整beat规则，按1.1目标自然交流时长分配audio起止，余下画面动作另述，审核检查明显拖长而不按字数或要求精确倍率。
3. storyboard原位替换sceneSetupRules与transcribeRules里的时序措辞，明确对白开始/结束需自然语言写出，画面停留不能写成发声时长；保留[Shot 1]无剪辑时间戳规则，不禁止对白相对秒数。审核共享同一语义。
4. video-inputs新增videoSpeechTiming(shot)，仅选有对白节拍，投影time_range/audio及去重speaker_name；media-handler和video hash共用。video路由接受可选speechTiming，编排只增加原声音安排作为时序依据，不改三段、不重复台词、不解析推算起止。
5. 新增speech-timing测试验证实际handler网关输入、三模式含packed、空对白及格式、hash与原时长台词不变；业务流程文档同步。
