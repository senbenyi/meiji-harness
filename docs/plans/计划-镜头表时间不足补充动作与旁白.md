# 镜头表时间不足补充动作与旁白

- 类型：完整流程。
- 目标：镜头表剧情容量不足时，通过有剧情作用的行动、反应、环境互动和旁白补足时长，审核与每秒指令一致接受。
- 非目标：不改既定主线、结果与跨集衔接，不增加人物卡/地点/关键道具，不更改存储字段或现有项目，不调用付费接口。

## 验收标准与证据

| AC | 输入 → 结果 | 调研结论 |
|---|---|---|
| AC-1 | 大纲基础呈现时间不足 → 生成/修订主动补充合理细节与必要旁白，达到本集预算，单段仍 1–15 秒且不过度碎分 | 未验收：当前规则禁止扩充容量，预算不足仅报告缺口 |
| AC-2 | 合理动作/旁白扩展 → 审核按设定、作用、时间及因果检查，不仅因大纲未逐字写出而失败 | 未验收：镜头表审核笼统禁止增加大纲事件；单镜修订需同步区分细化与改主线 |
| AC-3 | 镜头表确定扩展动作与旁白 → 每秒指令保留并计时，不另行扩写；既定台词/结果/交接不变 | 未验收：每秒需说明锁定镜头表确定的扩展，不按大纲缺失拒绝 |
| AC-4 | 纯画外旁白 → 可以校验、保存、展示、编译，只有画外声，不产生可见身体或参考素材 | 未验收：speakerId 当前只接受人物 ID，编译直接取角色名称 |
| AC-5 | 相关链路 → 现有人物对白与严格时间检查继续通过，未知说话人/画内旁白仍拒绝 | 基线七份相关测试 84 通过、0 失败、0 取消；快照 28 场景 |

## 改动

1. 镜头表生成/审核/单镜修订审核：预算不足主动扩充动作、反应、环境互动与旁白；保护事实与主线，禁止无意义重复和剧透 → AC-1/2。
2. 每秒生成/审核：镜头表确定的扩展视为本镜依据，完整继承旁白和动作；不在每秒步骤独立增补 → AC-3。
3. output-protocols：镜头表声音条目支持旁白；每秒 dialogue.speakerId 支持 NARRATOR，delivery 固定 off → AC-4。
4. shared/seconds-content.js、video-prompt-renderer.js：受限旁白校验、可读显示与纯声音编译，旁白不进入人物/素材清单 → AC-4/5。
5. 相关测试与开发指引：提示词三类编排、旁白保存、编译原文、人物对白与未知 ID 拒绝 → AC-5。
