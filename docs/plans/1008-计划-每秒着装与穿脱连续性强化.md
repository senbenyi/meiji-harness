# 每秒着装与穿脱连续性强化

- 类型：小改动，仅强化每秒生成与审核两份规则。
- 目标：每秒指令增加必要着装描述，穿脱、衣物层次与裸体状态依剧情和动作连续呈现，不能无故跳变。
- 非目标：新建多造型角色、改变结构协议、编造服装或穿脱剧情、改写用户已有每秒指令、提交真实模型请求。

## 改动
- `meiji/skills/task/generate-seconds-instructions-skill.md`：在服装状态规则补充具体着装/衣物层次、穿脱前后状态及过程、裸体起点依据、参考图不得决定剧情衣着。→ AC-1/2/3
- `meiji/skills/review/review-seconds-instructions-skill.md`：同步审核无动作突然脱衣/裸体、脱外套推断裸身、无依据换装或跨镜恢复等问题。→ AC-2/3

## 验收标准
- AC-1：生成、修改、自动修订请求 → 明确本镜起点及变化后的必要着装描述，不将不同穿着当成新角色。
- AC-2：穿脱与裸体变化 → 有剧情依据及动作过程、完成时点、剩余衣物和交接状态；保持一般动作与状态连续性，不增加针对脱外套、解扣或切镜的特殊限制。
- AC-3：已明确的开场裸体/前镜已脱衣 → 按明确上游状态承接，不要求虚构新动作；缺依据或裸身参考图 → 不推断无衣，审核指出具体跳变。
