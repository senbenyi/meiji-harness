# 人物单一造型

- 类型：功能删减（完整流程：涉及人物库、剧情输出协议、图片确认和服务端操作）
- 目标：删除人物多造型相关 UI 与生成/关联逻辑，人物仅保留单一资料和主图。
- 非目标：不删除场景状态、道具样式等非人物库能力；不破坏旧项目历史数据的读取。

## 验收标准与调研结论

| AC | 输入/状态 → 可观测结果 | 已确认/未确认 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 打开人物库或人物卡关联 → 不出现新增、切换、删除造型入口 | 已确认 | `client/project-library-view.js` 已按人物类型隐藏造型控件 |
| AC-2 | 生成人物资料 → 输出协议只要求单一人物资料和 `libraryId`，不要求变体/部位字段 | 已确认 | `server/prompts/models/story-model.js`、`shared/story-content.js` |
| AC-3 | 调用人物造型变体或部位图片操作 → 不再注册/执行 | 已确认 | 操作注册移除部位导入/编辑；人物变体服务端拒绝 |
| AC-4 | 场景和道具库操作 → 原有状态/样式变体能力保持 | 已确认 | `library-rules.js` 仅对 `characters` 禁止新增变体 |
| AC-5 | 旧项目含历史变体/部位字段 → 可继续读取，不在新 UI/生成链路中使用 | 已确认 | 兼容字段保留，人物目录和新协议不再输出这些字段 |

## 改动

1. 人物库与人物卡关联改为单一默认资料，隐藏造型管理和本集新增造型入口。
2. 人物生成协议、镜头上下文和参考图收敛为单一人物实体。
3. 移除人物部位导入/编辑操作和确认候选图的部位分支；保留普通人物主图、参考图及场景/道具能力。
