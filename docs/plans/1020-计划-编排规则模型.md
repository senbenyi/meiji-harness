# 编排规则模型

- 类型：新功能，完整流程。
- 目标：在 prompt-composer 提供独立 RulesModel，统一三个动作的规则结构和补充规则能力开关。
- 非目标：不迁移 meiji 数据、不提供业务规则、不执行动作、不接入 UI 或存储。
