# 项目标题删除入口

- 类型：完整流程，新UI操作及持久化入口。
- 目标：项目标题右侧显示删除按钮，经确认删除当前业务项目，列表/当前及其他绑定页面刷新。
- 非目标：删除用户已有真实项目用于验证、删除会话/工作区文件/HTTP或任务历史、修改公共包/宿主控制器。
