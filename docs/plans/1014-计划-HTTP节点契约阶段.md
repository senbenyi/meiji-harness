# HTTP 节点契约阶段

- 类型：接口重构；完整流程。
- 目标：按制作工作流节点对齐计划完成 HTTP 输入/输出契约、提示词和请求编排。
- 非目标：角色分支自动调度、绑定持久化、视频类型策略、尾帧原子提交、界面与迁移。

## 交付阶段
1. HTTP（本轮）：两个文本来源单例继续复用；补镜头角色识别候选接口；收窄文生提示词输入；视频显式类型与互斥参数；输出校验；同步现有调用方。
2. 任务接入：绑定 Model 与映射、任务目录、seconds 程序审核、执行时视频类型和编排任务。
3. 视频后处理：视频/实测/尾帧配对，程序审核和修订，移除新任务独立 tail。
4. 集成：实际依赖、任务组、界面、显式迁移。
