# 人物图修改接口

- 类型：新功能
- 目标：人物原图和人工意见通过 model 生成提示词，提交新版图片编辑接口。
- 调研：docs/research/调研-人物图修改接口.md

## 待用户决定
无。用户追加指示：原图使用 Base64 字符串，返回仍用 b64_json；先不展开接口协议。当前沿用 multipart 容器，人物修改 image[] 使用 Base64 data URL 文本。固定扮演“人物角色设计师”，职责写在最终 prompt，不增加接口 role 字段。
