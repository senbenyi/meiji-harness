# 免安装重启

- 类型：新功能
- 目标：提供独立的免安装重启脚本。
- 调研：docs/research/调研-免安装重启.md

## 待用户决定
无。

## 改动
1. `restart-harness.sh`：新增环境与源码链接预检、监听进程归属校验、SIGTERM 与等待退出、前台启动 → AC-1～4。
2. `tests/restart-harness.test.mjs`：新增隔离的命令模拟测试，不操作真实服务 → AC-1～4。
3. `.agents/architecture.md`：登记新脚本 → AC-1。

## 验收标准
- AC-1：不执行安装、构建、插件注册。
- AC-2：启动沿用已指向本仓库的源码链接，加载新的代码和 skill。
- AC-3：仅关闭当前 Harness 的 web 监听进程；等待正常退出；无服务直接启动；未知占用拒绝操作。
- AC-4：预检失败不关闭现有服务。

## 验证结果
- 基线与改动后：`cd meiji && npm test` 均为 350 通过，0 失败，0 取消。
- `node --test tests/restart-harness.test.mjs`：6 通过，0 失败，0 取消。
- `bash -n restart-harness.sh`、`git diff --check`：通过。
- 未实际重启用户服务；正常重启路径使用隔离进程与模拟命令验证。
