# 全流程提示词审计

- 类型：测试与只读审计。本轮不修改生产代码和现有生成内容。
- 目标：检查所有实际提示词入口、生成/修改/自审/自动修订/复审及图片视频各模式的合理性。
- 范围：摘要、大纲、人物、场景、道具、镜头表、单镜修订、每秒指令、人工分镜编辑审核、人物/场景/道具图、图片提示词改写、最终视频提示词；纯文件、尾帧与合成流程检查是否确实没有模型提示词。

## 验证标准

1. 实际组装请求中角色、任务、上游事实、补充规则、语言时长、基稿与意见、输出协议职责清晰，无遗漏或互相冲突。
2. 重生成不带旧稿，人工修改和自动修订有正确基稿/意见，复审针对最新稿，预览与实际发送一致。
3. 图片检查原图/参考图用途、年龄规则、服装与风格边界；视频检查素材编号、台词、时段和尾帧用途。
4. 每类审核使用明确的正常/错误对照，实际模型输出只作该次结果；不将规则存在、模拟测试通过当作语义审核有效。
5. 产出完整覆盖矩阵、可复现请求快照、问题优先级和修改建议；未测项明确注明。

## 方法

- 从 stageCatalog、操作/任务注册和实际 Model 入口核对，扩展已有 27 个 prompt-scenarios 的覆盖缺口。
- 所有运行项目只读，模型对照使用内存样例；不重生成主项目成片。人物年龄风险仅检查文本，禁止发送不合适的图片请求。
- 全量自动化回归检查现有修复，保存不含凭据/媒体 Base64 的提示词快照和模型判定证据。
