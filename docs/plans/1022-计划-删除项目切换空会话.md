# 删除项目切换空会话

- 类型：完整流程，删除后会话交接。
- 目标：删除项目成功后创建并切换到不关联任何项目的新空会话。
- 非目标：立即删除用户现有项目、删除旧会话/磁盘文件/任务记录、影响其他项目。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 状态 | 依据 |
|---|---|---|---|
| AC-1 | 删除成功 → 新空会话，无project绑定/工作区归属，原会话保留 | 已确认缺口 | remove仅标记删除；startSession已有独立cwd且不传workspaceId |
| AC-2 | 重复/并发/重启后重试删除 → 复用同一新会话 | 已确认可实现 | draft_requests幂等会话请求；项目请求行需保存后继request ID |
| AC-3 | 删除后建会话失败 → 明确项目已删，可重试建会话，不恢复旧项目 | 已确认缺口 | 前端目前只清空面板 |
| AC-4 | 删除失败或用户已切换会话 → 不错误新建/抢切；其他项目、历史记录保留 | 已有保护需回归 | workspace删除异常/活动任务保护及ownerSession检查 |

## 调用链与证据
面板确认 → DELETE harness-http → ProjectService.remove串行删除登记与落盘 → 在写队列外接续startSession（避免嵌套死锁）→ 标准空会话独立cwd → 前端activate。
startSession仅sessionController.create({sessionId,cwd,agentPreset})，不调用workspaceController.create，不写sessions项目绑定，configure主Agent不触发推理。
GitNexus索引有效；mount LOW/3、remove LOW/1；SSE并发刷新及宿主动态create/delete关系通过源码和集成测试补查。
