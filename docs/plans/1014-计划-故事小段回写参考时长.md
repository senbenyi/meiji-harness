# 故事小段回写参考时长

- 类型：Bug 修复，完整流程。
- 目标：故事大纲成功保存后，以小段时长总和更新本集参考时长，供镜头表生成和程序审核共用。
- 非目标：不修改镜头±30秒容差，不追溯改写已有数据，不修改视频实际时长。

## 验收标准与调研
- AC-1：生成/修订成功保存后，剧集参考时长等于所有小段时长之和，保留小数。当前缺少回写，已确认。
- AC-2：审核中的候选和最终拒绝不改变参考时长；原参考仍用于本轮大纲程序审核。已有 passed=false 分支可隔离，已确认。
- AC-3：人工编辑成功、人工放行通过原参考的程序审核后，同步回写；放行失败不回写。
- AC-4：回写后再记录大纲依赖 hash，节点保持有效；镜头表输入和审核读新参考，下游按原机制过期。
