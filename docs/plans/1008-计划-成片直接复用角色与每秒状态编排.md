# 成片直接复用角色与每秒状态编排

- 类型：完整流程，制作依赖及生成规则整改。
- 目标：全部成片与单镜成片直接按每秒 participants 读取项目已有角色；服装穿脱、情绪及当下表演由每秒分镜生成，最终提示词程序转换。
- 非目标：删除历史记录、修改已有每秒正文、自动生成人物资料/图片、改变独立人物生成入口、改变固定声线/身份、提交真实媒体请求。
