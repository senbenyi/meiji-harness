# 改编规划直读剧本原件

- 类型：输入流程调整，完整流程。
- 目标：改编规划生成、审核、修订直接读取导入的剧本原件，不依赖原著解析产物。
- 非目标：其他制作节点的输入流程、原稿存储格式、模型供应商配置。

## 验收标准与依据
| AC | 输入/状态 → 可观测结果 | 调研结论 |
|---|---|---|
| AC-1 | 已导入原稿且原著解析为空/未确认 → 可启动改编规划 | 当前pipeline有解析前置检查，需移除 |
| AC-2 | 原件和解析内容不同 → read_source返回原件，范围覆盖整份原件 | 当前agent_tools优先readChapterText，需按改编节点直读文件 |
| AC-3 | 仅读取解析正文/摘要/搜索片段 → 不能满足原件完整阅读要求 | 当前recordSnapshotRead会登记解析正文，需排除此节点 |
| AC-4 | 分页完整读取原件 → 生成/审核/修订可提交；未读全或预算拒绝不计已读 | 复用已有source_ranges及读取预算机制 |
| AC-5 | 其他节点读取策略与当前保存/UI保持有效 | 仅改编规划采用原件读取，定向及全量回归 |
