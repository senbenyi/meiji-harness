## 改动
### 阶段 1：公共接口与 HTTP
1. 新建并列 agent-modules/packages/http-client：请求、JSON/二进制读取、超时dispatcher、脱敏、记录上下文、OpenAI兼容文本响应和 llm-server 异步任务协议适配。按用户进一步明确，图片/视频生成本身也属于公共能力：完整提取 GPT/Krea 图片与 MiniMax H3 三模式视频的参数、校验、请求、返回解析和下载，并保留 Elysium 媒体协议的独立公共入口 → AC-1/3/4。
2. meiji/server/http/chat-transport.js、llm-server/task-request.js、llm-server/client.js、gateway/{redact,gateway-trace,model-gateway}.js：保留业务入口，调用通用模块；任务取消原因与 step 映射留在 meiji → AC-3/4/5。
3. meiji/package.json、package-lock.json：显式本地包依赖；公共包可 npm pack 后安装，不依赖 meiji 路径 → AC-1。
4. 根据用户明确的密钥归属，`models/model-config.js:normalizeModels` 不再要求旧媒体密钥/地址；配置字段仍保留兼容，默认旧地址改为本机，当前调用继续隔离为占位凭据。新增无旧媒体连接配置测试 → AC-6。

验证：公共包 node:test；gateway、task-recovery、video-service、media-images、gpu 测试。

### 阶段 2：提示词编排

2. meiji/server/prompts/render.js：保留 outputFormat、业务章节策略、provider 响应约定及动作语义，调用通用包 → AC-2/5。
