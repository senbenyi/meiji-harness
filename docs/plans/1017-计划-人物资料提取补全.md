# 人物资料提取补全

- 状态：实现、自动回归及真实面板验证完成（2026-10-17）。

- 类型：规则缺陷修复；完整流程（生成、修订、审核、输出契约与回归联动）。
- 目标：具名重要角色按原口径提取；资料原文有则提取，缺项依据剧本自由补充，不加来源标签；AI可优化描述，审核不以补充本身、措辞偏好或人物简介不够全面反复拒绝。
- 非目标：不改变具名重要角色筛选、ID/合并与图片失效规则、审核开关或修订上限；不生成定妆照或视频；不改上一轮未提交的历史改造。
