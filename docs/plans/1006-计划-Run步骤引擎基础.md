| 事项 | 规则 |
| --- | --- |

**数据结构**（`shared/run-model.js`，存 `history/runs/<id>.json`）

```js
Run  { schemaVersion:1, id, projectId, episodeId|null, initiator:'panel'|'session', sessionId?,
       goal:{ to, from?, scope:{tracks?,itemIds?,only?,fromEpisode?}, mode:'generate'|'regenerate'|'review', feedback? },
       policy:{ review:true, maxRevisions:2 }, prereq:{ required:[key], authorized:[key] },
       affectedEpisodes:[id], status, pause:{ reasons:[Reason] }|null, steps:[Step], events:[Event],
       createdAt, startedAt, endedAt, revision }
Step { id, key:'kind@target', kind, target, scope:'project'|'episode', after:[stepId], queue:'text'|'image'|'video'|null,
       actor:'model'|'human'|'program', status, origin, round?, input?, output?,
       prompts:[id], responses:[id], startedAt, endedAt, error? }
Event{ at, type, actor:'user'|'session'|'engine', stepIds?, payload }
Reason{ code, stepId, target, message, actions:[action] }
```

- Step.kind：`generate` `review` `revise` `re_review` `manual_edit` `override` `image` `wait_confirm` `wait_script_confirm` `storyboard` `video` `tail` `assemble` `sync` `expand`
- Step.status：`pending` `ready` `running` `done` `paused` `superseded` `skipped` `cancelled`
- Step.origin：`plan` `prereq` `review-fail` `feedback` `manual` `cascade` `retry`
- Event.type：`created` `confirmed` `paused` `resumed` `feedback` `manual_edit` `goal_amended` `prereq_authorized` `deletions_confirmed` `cancelled` `completed`
- Step 不删除，作废即 `superseded`。Run.status 由步骤推导。

**状态**

| 状态 | 推导与调度规则 |
| --- | --- |
| draft | confirmed 事件写入前仅预览；不执行，参与同集归属（防止并发双建） |
| running | 已确认且存在 pending/ready/running；锁或队列等待保持 running；独立分支继续 |
| paused | 用户暂停优先停止新调度；普通暂停原因只阻断所在步骤及下游；可执行独立分支期间状态仍可为 paused |
| completed | 所有有效步骤 done/skipped（空计划确认后也 completed）；写 endedAt |
| cancelled | 全任务取消或取消分支后剩余有效步骤全部终态且含 cancelled；取消不视为依赖成功 |

`endedAt` 只属于 completed/cancelled，暂停不结束 Run。superseded 不参与完成计数，但依赖引用必须先改接到替代步骤，不能把作废视为完成。非法/缺失依赖、重复 stepId、循环依赖均在写入前拒绝。用户暂停为协作式：已运行步骤收尾，后续不再启动；远端请求不能取消的事实保持如实记录。

**暂停原因 → 可用动作**（面板按钮与会话工具都只从 `Reason.actions` 取）

| code | actions |
| --- | --- |
| `review_exhausted` | feedback · edit · override · regenerate · cancel-branch |
| `step_failed` | retry · cancel-branch |
| `wait_confirm` | 面板确认 · 放弃并重生成 |
| `wait_script_confirm` | 剧本页勾选写入 · 放弃 |
| `prereq_required` | authorize · cancel-branch |
| `deletions_pending` | confirm-delete · revert |
| `script_pending` | 处理剧本待办后自动恢复 |
| `interrupted` | retry |
| `user_paused` | resume |

**锁**

| 锁 | 规则 |
| --- | --- |
| 集归属 | 持久在 Run 记录：一集一个 running/paused Run；项目级 Run 的 episodeId 为 null |
| 执行 | 内存，步骤 running 时持有；项目级步骤（摘要、剧情、项目摘要、剧本修改/回写、增删剧集、项目资料）与一切互斥；其余按集互斥 |
