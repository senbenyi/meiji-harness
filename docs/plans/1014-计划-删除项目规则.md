# 删除项目规则

- 类型：重构
- 目标：去掉设置页「规则」及其保存、筛选、提示词注入和依赖指纹。
- 非目标：不改各节点 PromptModel 里的基础规则；不恢复 v8 及更早数据库。

| AC-1 | 打开设置页 → 没有规则编辑 | 已确认 | `task-panel.js` 渲染「编辑规则」 |
