# 团队设定独立盒子

- 类型：完整流程；节点拆分、接口与数据结构调整。
- 目标：团队设定成为 group_setting 独立AI盒子，保持场景在角色前及角色页三卡片；人物仅引用团队资料。
- 非目标：不实现场景/镜头/视频执行器，不自动生图，不修改运行项目私有规则，不重启或提交推送。

## 调用链与证据
- 面板workbench → harness_server/project_routes → Service → Executor → llm-http → ProjectManager，主Agent Tool复用Service。
- node_definition_registry + createNode/createProject初始化；node_state通用读取；execution_state/box_report/records标签/会话history及UI需显式登记。
- character_extraction当前保存groups/characters；costume_image指纹读取其中groups。拆分后唯一团队来源group_setting.groups。
- ProjectManager只在model.update落盘；旧数据补齐可先保持内存投影，不启动迁移任务、不改历史快照。
- GitNexus MCP读取已绑定绝对路径；impact时Transport closed，回退本地CLI。UNKNOWN/动态注册靠实际import、静态资源表、Tool/Service及输入链补查，不视为无影响。
