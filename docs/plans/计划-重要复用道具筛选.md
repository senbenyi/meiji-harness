# 重要复用道具筛选

- 类型：小改动（skill 文案）
- 目标：只将预计后续反复出现的重要物品提取为道具卡。
- 调研：无。
- 待用户决定：无。

## 改动
1. `meiji/skills/task/extract-story-props-skill.md` — 从全部明确物件改为先评估重要性及后续复用需求；普通一次性物件仍留在剧情中，不单独建卡；同步限定空集合与遗漏判定。
2. `meiji/skills/review/review-story-props-skill.md` — 同步当前审核规则的入选、遗漏和空集合标准，避免审核要求补建普通物件；保留已有其他审核规则。

## 验收标准
- AC-1：规则明确同时满足重要性和后续反复出现的复用需要，不能虚构后续事件来建卡。
- AC-2：明确出现但不符合筛选条件的物品无需建卡，允许空集合，保留原有事实来源限制。
- AC-3：生成、修订和审核实际提示词包含一致的新筛选规则；剧情整包编辑审核同步道具标准，其他无关编排不变。
