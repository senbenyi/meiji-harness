# 每秒分镜改为节拍分镜

- 类型：新功能（提示词与校验规则调整）
- 目标：每秒分镜节点从“每秒一格”改为按节拍切格，持续动作或停留可以合并为一个多秒节拍；总时长与镜头参考时长精确一致。
- 非目标：
  - 不改节点名“每秒分镜”、业务键 `seconds`、任务标签与历史显示。
  - 不改镜头表（`body` 仍只写整镜安排），不新增节拍或切法模式字段，不改 schema、不写迁移；现有项目数据不追溯修正。
  - 不改视频节点实测时长的 ±5 秒误差，另行处理。
  - 不涉及多模态 Ref2VA 提示词格式，另开任务。
  - 不借用广告技能的节拍数量参数、“开场不能空”与文案、音乐卡点规则。
