# 拆分剧集直接执行

- 类型：Bug 修复，完整流程。
- 目标：面板点击拆分并保存后直接执行，无需额外点击开始。
- 非目标：不修改其他业务的暂停队列行为，不重试旧失败任务，不调整模型网关。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 判定 | 依据 |
|---|---|---|---|
| AC-1 | 面板提交拆分，项目无其他未结束任务、队列已暂停 → 新拆分直接执行并落盘 | 已确认问题 | command submit 只新增；pump 遇 queue_stopped 返回 |
| AC-2 | 有排队拆分 → 点击拆分复用原任务并开始，不重复创建 | 未验收 | 现有 submit 复用 unfinished 任务，但未恢复执行 |
| AC-3 | 有其他排队/运行任务 → 拆分受理明确冲突，不自动恢复其他任务 | 未验收 | 保持项目串行，避免解除暂停后先执行其他队首任务 |
| AC-4 | 其他业务或会话提交 → 保留现有排队规则；模型失败仍暂停、旧失败任务终态不变 | 未验收 | 保持默认 submit 和 finish 分支 |
| AC-5 | 概要拆分反馈 → 状态/失败原因/详情入口保留，不再要求到详情点开始 | 未验收 | renderOverview 中暂停提示移除 |
