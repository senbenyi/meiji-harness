# 基础画面表达与空间连续性

- 类型：提示词优化，完整流程。
- 目标：让基础规则按剧情与补充需求形成可执行的画面设计，并在切镜后保持真实空间关系。
- 非目标：不预设具体剧情或风格；不改字段、存储、硬约束或视频审核；不重跑生产内容、不生成视频。

## 调用链与证据
TaskService → text-handler → taskNodeInput → composeNodePrompt → models规则 → renderPrompt → gateway；生成与审核使用requirements，修订保留原生成消息与本轮opinion。多模态编排消费storyboard已通过文本。
现有空间规则有不瞬移和机位变化不等于移动，但缺少统一场景坐标、反打左右和视线/轴线判定；现有补充需求传参无缺口，不改执行器。
图谱status有效；query执行。impact对模型常量返回CRITICAL（204直接关联、86流程），结果混有task-store等无关符号，不能作为精确范围；实际以源码导入和nodeRoutes动态注册补查，仍按高影响全量验证。
