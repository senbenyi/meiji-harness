- 类型：完整流程，存储、导入接口及优化执行输入变更。

## 调用链及边界
创建Tool/弹窗 → ProjectService → CreateProjectExecutor → 项目JSON、素材库、沙盒；导入 → Service统一校验/保存来源文件 → editProject；ProjectExecutor摘要步骤读取当次导入正文，保存时校验当前工作稿与输出快照。ScriptRevisionService只从script_revision.output解析输入；原文件路径仅作来源标识，模型不读取原稿。文件路径由程序根据内容hash及验证文件名生成，读取校验相对路径、realpath和项目边界，禁止路径穿越/符号链接越界。
