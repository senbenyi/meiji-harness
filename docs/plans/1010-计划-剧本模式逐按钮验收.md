## 验收中追加：剧情不依赖项目摘要

- 类型：完整流程 Bug 修复；用户明确要求剧本模式仅需剧本，自由模式仅需 AI 创作方向。
- B-8：项目摘要为空、失败或过期时，剧本模式有非空剧本、自由模式有非空创作方向 → 剧情生成/重新生成和审核正常执行；对应模式必需资料为空 → precheck 失败，不调用模型。
- 入口：面板/会话 → TaskService.command → executeStep → precheck → createTextHandler → outline 的生成/重生成/审核 YAML。

- 改动：`meiji/server/flow/tasks/precheck.js` 删除仅 outline 分支的摘要检查；`meiji/dev_docs/in_puts/outline-{generate,regenerate,review}.yaml` 删除创作背景中的摘要；新增独立回归测试覆盖两种模式、无摘要生成/重生成、无必需输入失败以及其他下游门禁不变；同步开发指引和总纲的制作链。
