# 人物自动生图保存

- 类型：完整流程，业务流程修改
- 目标：本集资产人物提取审核通过后，为所有人物调用 AI 生图并自动入库使用。
- 非目标：剧情页触发人物；单卡手动生图、库手动生图的确认规则；对既有任务批量追溯执行。
