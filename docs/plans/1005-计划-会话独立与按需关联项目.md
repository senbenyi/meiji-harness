# 会话独立与按需关联项目

- 类型：Bug 修复及关联流程重构（完整流程）
- 目标：新会话默认不关联项目，明确创建或选择项目后只绑定当前会话；恢复会话模型凭据，使创建请求能够到达工具。
- 非目标：不移动或删除已有会话，不修改上游 Harness 源码，不改已有项目内容。

## 调用链与证据
会话 → meiji_context_query → linkStore.projectForSession → session-projects 显式选择或 workspace-links 隐式继承。
创建 → meiji_project_manage → createProject → opCreate → ensureProject → selectProject。
面板 → link/turn create → enterProject → 工作区首会话或新会话 → 当前依赖隐式关联。
