# 项目分镜自动生成闭环

- 类型：Bug 修复
- 目标：让空项目从锚点步骤继续时自动生成并持久化可提交的分镜内容。
- 调研来源：`docs/research/调研-项目分镜自动生成断点.md`

## 人工决策

无。根据用户“执行”，按“自动生成分镜文本，用户审核后再提交视频任务”实施。

## 验收标准

- AC-1：给定标题、导演、至少一个锚点且分镜为空的项目 → 点击“继续到分镜”后生成并持久化至少一幕、一个镜头，然后进入分镜页。
- AC-2：给定自动生成的分镜 → 每个镜头有非空动作描述、有效角色引用或空角色、合法生成模式、`pending` 状态与空 `job_id`，“生成全部待处理镜头”可成功受理。
- AC-3：给定聊天模型连接或输出失败 → 项目不写入部分分镜，页面停留在锚点步骤并显示可重试错误。
- AC-4：给定已有任意幕或镜头的项目 → 点击继续只进入分镜页，不请求聊天模型，不覆盖原内容。
