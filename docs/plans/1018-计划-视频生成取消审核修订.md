# 视频生成取消审核修订

- 类型：完整流程，视频执行链变更。
- 目标：停止当前修订，保留视频；新视频生成后不再审核或自动重生成。按官方接口尝试取消远端任务。
- 非目标：不改字段、不删除历史、不新增生成视频，不取消必要下载、解码、实测和尾帧保存。
- AC-1：当前修订任务为 cancelled，无本地排队任务；保留历史结果与视频地址。
- AC-2：video programReview=false、retryRounds=0，执行仅 precheck/generate/apply；15.1秒产物不会触发时长审核或重生成。
- AC-3：取消时若远端排队，调用 DELETE /v2/video_generation/{task_id}；running 官方不允许取消，明确报告实际结果，不把本地断连当远端取消。
- 证据：当前任务 review 因实测15.1秒拒绝；node-definitions 开启视频审核与2轮修订，node-state assertProgramReview 实现时长范围审核。
- 影响：assertProgramReview 上游图谱 CRITICAL，视频与其他文本审核共用；BUSINESS_DEFINITIONS UNKNOWN，已从 task-plan、task-manager、node-rules 源码确认动态引用。
- 改动：node-definitions 关闭视频审核和重试；node-state 删除视频数值业务审核；handler-registry 删除视频审核分派；media-handler 删除已失效的视频修订意见拼装；对应测试及工作流、节点规则文案更新。llm-server 无代码修改；官方接口已直接调用。
- 验证：相关阶段测试基线/改后对比，真实当前任务取消与视频链接可用性，差异检查与图谱索引。
