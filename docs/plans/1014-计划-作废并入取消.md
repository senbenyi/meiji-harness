# 作废并入取消

- 类型：完整流程
- 目标：已作废与已取消合并，界面和之后的结算都使用已取消。
- 非目标：不删除库里已有的 `superseded` 值，旧记录仍能读取。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 已确认/未确认/未验收 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 重启、组内后序停止、未执行步骤 → 写成 cancelled，原因不再写已作废 | 已确认 | `task-manager.js` 的 `recover` 和 `#finish` 仍写 superseded |
| AC-2 | 历史里旧的 superseded → 状态文案是已取消，筛选里不再单独有已作废 | 已确认 | 历史和项目页把 superseded 标成已作废 |
