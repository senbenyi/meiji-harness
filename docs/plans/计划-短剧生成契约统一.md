- 类型：新功能（生成契约统一）
- 目标：四步创作使用一致的结构化生成、Markdown 渲染与保存校验链路。
- 调研来源：`docs/research/调研-短剧生成契约统一.md`

## 人工决策

- 当前工作区另有香港部署相关未提交改动，实施时不覆盖、不提交这些文件。

## 统一契约

| 步骤 | 模型返回字段 | 代码固定或校验 | Skill 负责 |
|---|---|---|---|
| 立项 | `title`、`genre`、`synopsis` | 生成 Markdown frontmatter，导演 ID 由项目选择注入；校验必填与字段格式 | 取名、题材与梗概篇幅 |
| 总览 | `logline`、`world`、角色、场景、分集数组 | 必填角色字段、主角、名称唯一、连续分集；从导演 `references/series.md` 的固定集数规则校验条目数 | 人物关系、定妆、场景和钩子写法 |
| 剧本 | 场数组及每场的动作、音效、台词行 | 场号连续、场景和角色引用有效、每场非空；渲染原有剧本行格式 | 分场、节奏、画面动作与对白 |
| 分镜 | 每场的必填 `first_shot` 与可选后续切镜 | 按剧本场生成必填属性；首镜起点由 `first_line` 注入，额外切镜须在本场范围内；镜头号由代码生成 | 景别、运镜、人物顺序、视频和首帧描写 |

机器约束只覆盖可计算的结构与引用；叙事质量、风格和画面效果继续由 Skill 指导并人工验收。
