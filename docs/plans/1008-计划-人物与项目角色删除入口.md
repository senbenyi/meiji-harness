# 人物与项目角色删除入口

- 类型：完整流程，新增删除操作及跨集关联清理。用户明确要求两处入口。
- 目标：本集人物卡和项目角色库均可删除 AI 提取的角色，预览与执行使用一致删除范围。
- 非目标：实际删除用户角色、重提取或重写每秒指令、删除共用素材文件、改变场景/道具库删除语义。

## 验收标准与调研
| AC | 输入/状态 → 结果 | 整改前 |
|---|---|---|
| AC-1 | 本集卡/详情删除 → 移除选定人物及其候选，其他集和角色库保留 | 无人物删除操作 |
| AC-2 | 项目角色删除 → 删除库条目及跨集关联卡，清理关联编排/视频/尾帧，未关联人物保留 | 已有删除条目，但有关联时禁止 |
| AC-3 | v2指令/稳定别名称谓 → 上游正文不改写，删除预览与实际下游一致 | card-delete 沿用通用级联，需覆盖sourceName和纯库绑定 |
