## 调用链与证据
`ai-routes.composeNodePrompt → nodeAction(route.promptModel + output) → reviewPolicy（review 追加修复定位）→ render.renderPrompt(stage.system/user)`；`node-rules.nodeRules → route.promptModel[action] + output.requirements`。render 与 node-rules 只读 promptModel，不修改对象，字符串改为共享常量引用不改变渲染结果；对象键顺序决定章节顺序，重构必须保持键顺序。

| 来源（文件:行） | 支持的结论 |
|---|---|
| `meiji/server/prompts/render.js:6-9` | system 按 stage.system 键顺序渲染 |
| `meiji/server/prompts/review-policy.js:22-28` | review 规则以展开方式生成新对象，不改原模型 |
| `meiji/server/http/node-rules.js:25-30` | video 规则硬编码 |
