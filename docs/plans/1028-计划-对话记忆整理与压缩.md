# 对话记忆整理与压缩

- 类型：完整流程，视频制作记忆自动提炼/去重/冲突/失效管理及有界压缩。
- 目标：主Agent会话增量持久化、自动按阈值提炼，明确用户决定入记忆；长记忆分块归并并保留来源，模型使用冻结压缩视图。
- 非目标：不保存代码开发偏好、不压缩覆盖原稿/正式产物、不把助手建议或旧审核意见当用户决定、不修改宿主或其他项目源码。
