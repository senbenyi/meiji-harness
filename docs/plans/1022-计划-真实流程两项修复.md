## 调用链
- 会话Tool → ProjectService.create → CreateProjectExecutor.onCreated → harness-http events → workbench.syncEvents → refresh → activate。
- 现有首次项目GET等待applyMainAgent/snapshot，SSE仅sessionReady后打开；cursor初始null，间隙created不回放。创建事件的激活还依赖异步refresh后的流身份，重连会丢交接。
- 计划在project响应头返回请求开始时事件游标（不改JSON结构），客户端以该游标订阅；created交接先验证来源/导航，再激活，不依赖无关项目刷新完成。
- modelClient.complete返回原content → parseNodeOutput → validateNodeOutput。仅在严格解析失败后将字符串内部的未转义LF/CR/TAB编码成等价JSON转义，之后仍严格解析/schema校验。
