# 镜头叙事与交接简化

- 类型：完整流程 / 提示词优化
- 目标：镜头表以简洁直接叙事表达剧情，后镜仅参考前镜交接摘要，降低重复事实和无关过程的负担。
- 非目标：不改变 shots / seconds 存储结构、编号、时长、对白协议、Run 调度和视频接口；不迁移或清空已保存内容；不承诺未经实测的模型成功率。

1. meiji/skills/output-protocols.js:protocols.shots / shot-revise 与 task/generate-shot-table-skill.md — 七栏目 → 一段或少量自然段直接叙事；seconds 协议明确末段 endState 包含必要位置、朝向、持物与未完成动作，确保摘要可独立交接 → AC-1、AC-2、AC-5。
