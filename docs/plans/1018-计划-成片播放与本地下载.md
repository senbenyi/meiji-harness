# 成片播放与本地下载

- 类型：新功能
- 目标：成片列表里的视频可点击弹框播放；视频生成后增加下载步骤，项目同时保存服务端地址和本地地址。
- 非目标：不改合片、不改尾帧、不生成视频、不重命名已有 `video.address`。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 已确认/未确认/未验收 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 成片列表卡片已有视频时，点击预览弹出带控制条的播放框 | 已确认 | `project-ui.js` 的 `shotResultStrip` 只放了无点击的 `video` |
| AC-2 | 视频生成任务步骤为前置、生成、下载到本地、校验截帧 | 已确认 | `task-plan.js` 现为 precheck、generate、apply |
| AC-3 | 生成只记录服务端地址；下载把文件写入媒体库 | 已确认 | MiniMax 在 `generateVideo` 内立刻下载；网关在 `retrieveGatewayVideo` 内下载 |
| AC-4 | 项目镜头 `video.address` 仍是本地媒体地址，新增 `video.server_address`；旧项目补空字符串 | 已确认 | 用户要求同时记录两个地址。`address` 已被播放、校验、合片使用，不改名 |

## 调用链与证据
成片卡片 `shotResultStrip` → 点击。视频任务 `stepKinds` → generate（`ai-routes` 取得服务端地址）→ download（`media-handler` 拉取并 `media.put`）→ apply（测时长、截尾帧）→ `commitContent` 写入 `address` 与 `server_address`。

| 来源（文件:行） | 支持的结论 |
|---|---|
| `meiji/client/project-ui.js:175` | 列表视频没有点击播放 |
| `meiji/shared/task-plan.js:23` | 视频步骤在 generate 后直接 apply |
| `meiji/server/http/llm-server/client.js:81` | 服务端 URL 在生成函数里被下载后丢弃 |
| `meiji/shared/models/video_model.js:3` | 视频节点只有 `address` |

## 问题
| AC | 预期 | 实际 | 根因 |
|---|---|---|---|
| AC-1 | 点击弹框播放 | 预览不能点开 | 卡片没有播放对话框 |
| AC-2 | 下载是独立步骤 | 下载藏在生成请求里 | 生成函数直接 GET 文件 |
| AC-4 | 两个地址都在项目里 | 只保存本地 `address` | 服务端 URL 未写入节点 |

## 待用户决定
无。用户已要求记录服务端地址和本地地址，并在生成后增加下载步骤。本地地址继续用现有 `video.address`，新增 `video.server_address`。步骤 `kind` 增加 `download`，其余步骤字段不变。
