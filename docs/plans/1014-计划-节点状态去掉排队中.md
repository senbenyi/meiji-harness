# 节点状态去掉排队中

- 类型：重构
- 目标：节点状态不再包含排队中；任务入队不改写节点，排队仍只记在任务上。
- 非目标：不取消任务、任务组、步骤的 `queued`；不改变开始、移除、取消按钮。

图谱：仓库 `llm-dsh-plugins`，索引提交 `81acb1a`，工作区内容相对索引已过期。`setNodeState` 上游影响 37，风险 CRITICAL（直接调用方是 `TaskService`、`enqueueNode`、`restoreQueued` 和阶段测试）。`NODE_STATUS` 图谱为 UNKNOWN；文本确认用于 `validateNode` 和 `stage01-contracts.test.js`，`project_contract.js` 另有一份相同枚举。

## 调用链与证据
面板或会话提交 → `TaskService` 创建 `task_status=queued` → `enqueueNode` 把节点写成 queued → 开始时 `setNodeState(running)` → 未开始取消时 `restoreQueued`。
