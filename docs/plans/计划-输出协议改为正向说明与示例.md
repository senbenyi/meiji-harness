# 输出协议改为正向说明与示例

- 类型：小改动（用户指定）
- 目标：生成请求去掉【优先级】；输出协议只写应输出的内容与格式并附示例，不再列「不输出什么」。
- 调研：无

## 改动
1. `meiji/server/prompts/skill-prompts.js`、`request.js`、`models/text-step-model.js`、`models/story-model.js`、`interfaces/outline.js` — 删除【优先级】段与协议末尾「输入材料……只执行本阶段」；步骤级 outputProtocol 改由 `skills/protocols.js` 统一提供。
2. `meiji/skills/protocols.js` — 摘要、大纲/人物/场景/道具、镜头表、每秒指令、单镜修订、图片提示词改写、文本分镜全部改为正向说明；除单镜修订与文本分镜外均附示例。示例统一使用中性故事（旅人与庭院），避免与真实项目内容混淆。
3. 剧情大纲的【正文结构】并入输出协议（审核仍保留结构说明作为核对依据）。
4. 相关测试断言更新。

## 验收标准
- 30 个提示词场景中，任何生成请求都不含【优先级】，输出协议段不含「不输出 / 禁止 / 不得覆盖 / 只执行本阶段」。
- `npm test` 不新增失败。
