# 提取角色不保留定妆照

- 类型：Bug 修复，完整流程。
- 目标：提取剧本重要角色通过后，本次返回的角色不再带着已有定妆照。
- 非目标：不改未返回角色的定妆照、不改人工放行只标过期的行为、不删素材库文件、不清用户上传的参考图。

## 验收
- AC1：生成、重新生成、修订通过后，本次返回角色的定妆照地址为空，状态为未生成。
- AC2：本次没有返回的角色仍保留原定妆照。
- AC3：清空前先按原依赖把用过这些照片的下游标为已过期。

## 调用链
提取保存 → `prepareContent` 按姓名合并并保留图片 → `commitContent` 写回角色库 → `expireCharacterImages`。头像只要 `address` 还在就会显示。

## 改动
`commitContent` 在提取任务通过并完成过期传播后，清空本次返回角色的定妆照地址和状态。

## 验证结果
AC1–AC3 由角色保存测试覆盖并通过。全量 435 项中 434 通过；既有失败「恢复组合failed时旧失败组不再提示继续」与本次无关。`git diff --check` 通过。
