# 剧情仅提取人物

- 类型：完整流程，业务流程与场景数据清理。
- 目标：剧情统一生成只生成/审核大纲、提取/审核人物及人物补图，取消场景和道具自动提取及展示，删除已有场景数据。
- 非目标：不取消人物审核与补图，不重构文本/图片协议，不删除人物和任务历史，不扩大为重做媒体系统。
