# 故事段取消内部滚动

- 类型：小改动，单处明确样式原因，仅改故事大纲会话模块。
- 目标：展开大纲后，故事段自动撑开高度，随会话滚动。
- 原因：task-operation共享pre样式设置max-height:340px与overflow:auto；故事段通过renderRecordedRows渲染为pre。
- 改动：story_segments/ui/conversation/index.js用本节点包装渲染函数，只覆盖本节点记录内容的maxHeight与overflow。覆盖输入大纲、步骤输出及查看当次大纲；不改共享文本和其他盒子。
- AC-1：长故事段展开后max-height:none、overflow:visible，文字保留并自动换行。
- AC-2：不改变任务行为、字段内容及展开折叠交互。
- 图谱：已status、更新索引、query/context/impact；renderStepOutput为UNKNOWN，源码确认node-registry注册和task-operation动态调用，不将无调用边视作安全结论。
