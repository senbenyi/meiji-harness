# 字段与每秒分镜统一

- 类型：重构
- 目标：文档、英文 Model 和提示词返回结构使用同一套字段；每秒分镜只保留 H3 写提示词需要的五项，再加上项目绑定角色所需的对白。
- 非目标：不把仍使用中文项目对象的执行层整表改写。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 已确认/未确认/未验收 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 阅读每秒分镜文档、project_detail、Model → 保存为 `storyboard[]` 的 `time_range`、`action`、`camera`、`space`、`audio`、`handoff`，对白为 `dialogue[]` 的 `speaker_id`、`speaker_name`、`mode`、`dialogue_text` | 未验收 | H3 `base-en.txt` 要时间线里的动作、镜头、空间、声音和交接；环境声总述与配乐属于文生提示词 |
| AC-2 | 阅读镜头表、大纲、角色的保存段和对应 Model → 字段名与 `project_detail.json` 一致 | 未验收 | 文档仍用中文保存名；Model 缺景别、钩子、因果和角色定位等字段 |
| AC-3 | 阅读工作流、视频节点、step_model、README、panel、开发指引 → 只有首尾帧使用上一镜尾帧；成片组含合片；修订用尽后保留产出 | 未验收 | 工作流仍有“后一镜都用尾帧” |

## 改动
1. 每秒分镜 Model、校验、迁移、`project_detail.json`、节点文档和 seconds YAML → AC-1
2. 镜头、大纲、角色 Model 与节点文档、对应 YAML 返回结构 → AC-2
3. 工作流、视频节点、step_model、README、panel、开发指引，以及文生/摘要/角色的修订用尽保存 → AC-3

验证：`node --test tests/stage01-models.test.js`；阅读上述文档字段。

## 验证结果
`node --test tests/stage01-models.test.js`：2 通过，0 失败。每秒分镜保存为 `storyboard[]` 五项加 `dialogue[]`；镜头、大纲、角色的文档字段与 Model、`project_detail.json` 对齐。工作流改为只有首尾帧使用上一镜尾帧，成片组包含合片。执行层仍按中文项目对象读写，不在本次范围。
