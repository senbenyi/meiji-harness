# 联合改编规划覆盖校验

- 类型：完整流程，缺陷修复。
- 目标：有原稿的联合改编必须提交人物与关键场景规划，生成/审核/修订明确核对原著覆盖，防止空规划被审核放行。
- 非目标：不强制编造团队，不靠程序猜测全部人物，不改变产物Schema，不改写已有短剧或自动调用真实模型。
