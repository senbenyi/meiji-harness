# 角色库引用与审核分离

- 类型：Bug 修复，完整流程。
- 目标：已有角色只提取和审核引用，程序读取固定资料；本轮新增角色完整审核，保存/恢复不改变分类。
- 非目标：更改图片规则、重写项目角色、修改角色删除算法、自动处理真实失败任务或调用付费模型。
