# GPT 文生图接入

- 类型：新功能，完整流程。
- 目标：设置的图片模型增加 GPT（Codex 套餐），制作定妆照经本地 llm-server 的 `POST /v1/images/generations` 生成，不携带媒体网关密钥。
- 非目标：不改 llm-server 接口、不改图片节点契约和提示词模板、不改 `elysium-image` 与视频、不改默认 `models.json`、不重启生产、不改项目数据。

## 调用链与证据
设置图片模型 → `modelRoute(config, 'image')` → `createAiRoutes` 图片分支 → `llmServerClient.generateImage` → `POST /v1/images/generations` → `b64_json` → 定妆照媒体文件。

`elysium-image` 仍走 `generateGatewayImage`（无参考图 `images/generations`，有参考图 `images/edits`）。

| 来源（文件:行） | 支持的结论 |
|---|---|
| `meiji/shared/models/settings_model.js:8` | 图片选项只有 `elysium-image`，设置页按 `modelOptions.image` 渲染 |
| `meiji/models/model-config.js:38-46` | 本地路由目前只覆盖文本模型；图片始终用 `baseUrl` 与媒体 `apiKey` |
| `meiji/server/http/ai-routes.js:87-88` | 图片一律 `generateGatewayImage`，提示词为 `prompt.body`，参考图先解码 |
| `meiji/server/handlers/media-handler.js:92-114` | 定妆照最多一张参考图，并传入项目 `aspect_ratio` |
| `llm-server/src/gpt-image.js:40-60` | `model` 必须是 `gpt-image`；`size` 只能 `auto`；参考图最多 5 张 data URL |
| `llm-server/docs/调用接口文档.md:443-497` | 成功时图片在 `data[0].b64_json`，PNG，无 URL；与聊天共用取消和 60 分钟超时 |

GitNexus（仓库 llm-dsh-plugins，索引已按当前工作区重建）：`modelRoute` CRITICAL（直接调用方 createAiRoutes、syncChatModel 及设置测试），`SettingsModel` CRITICAL，`createAiRoutes` HIGH，`generateGatewayImage` LOW。动态 `gateway.image || generateGatewayImage` 以源码核对。改动保持既有模型的路由和请求不变。

## 改动
### 阶段 1：设置与路由
1. `meiji/shared/models/settings_model.js:modelOptions.image` — 增加 `{ value: 'gpt-image', label: 'GPT（Codex 套餐）' }`，保留 `elysium-image` → AC1
2. `meiji/models/model-config.js:modelRoute` — 仅 `gpt-image` 使用 `textBaseUrl` 与占位密钥 `ollama` → AC1

验证：`node --test tests/stage12-settings.test.js tests/stage19-codex.test.js tests/stage07-ui-restore.test.js` — GPT 图片可选；`elysium-image` 仍用媒体网关密钥；文本路由不变。

### 阶段 2：文生图请求
1. `meiji/server/http/llm-server/params.js` — 新增 `imageParameters`：固定 `gpt-image` 与 `auto/png`，参考图转 data URL，画幅写入提示词，可选 `X-Task-ID` → AC2、AC3、AC4
2. `meiji/server/http/llm-server/client.js` — `generateImage` 发送该请求，记录脱敏传输，空图或失败抛错，60 分钟超时并透传取消 → AC2、AC4
3. `meiji/server/http/ai-routes.js` — `gpt-image` 且未注入 `gateway.image` 时调用 `generateImage`；其他图片模型仍调用 `generateGatewayImage` → AC2、AC3

验证：新增 `tests/stage20-gpt-image.test.js`。mock llm-server 收到官方字段与参考图，响应 base64 成为图片结果；空图失败；`elysium-image` 仍请求媒体网关像素尺寸。

### 阶段 3：说明
1. `meiji/dev_docs/制作工作流.md`、`.agents/meiji-dev.md`、`meiji/README.md` — 写明图片 GPT 选项、本地文生图地址和画幅写法 → AC1–AC3
