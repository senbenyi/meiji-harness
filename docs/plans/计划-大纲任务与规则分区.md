# 大纲任务与规则分区

- 类型：完整流程，提示词调整。
- 调研：docs/research/调研-大纲任务与规则分区.md
- 待用户决定：无。

## 改动
1. `meiji/server/prompts/models/story-model.js`：大纲任务去掉 target 拼接与重复规则；仅描述根据摘要生成/修订大纲，引用基础和补充规则。大纲 system 基础标题统一基础规则、补充节点标题统一补充规则；不修改其他功能。AC-1、AC-2。
2. `meiji/tests/story-model.test.js`：回归任务无重复规则、补充正文与来源保留、跨集节点隔离、审核不执行补充创作命令。AC-1 至 AC-3。
3. `.agents/meiji-dev.md`、`meiji/docs/story-model.md`：写明任务、规则、协议各自职责。AC-1、AC-2。
4. `story-model.js`、`interfaces/outline.js`：按追加要求，剧情生成及审核角色只保留身份，原审核边界移入审核范围。AC-4：角色不包含任务、事实遵循或输出要求。

## 验证结果
基线 story-model、prompt-nodes、skill 共 38 项通过；新增两项先失败、修改后共 40 项通过，另跑 generation-mode 11 项通过，共 51 项相关测试，0 失败、0 取消。30 场景差集核对了 11 句删除的去向：角色只留身份，任务规则已由基础规则或输出协议承担，重生成数据隔离仍由调用方保证，修订范围由 system 和基稿/意见承担。实际项目只读编排确认角色和任务各一句，摘要仍存在。未调用真实模型，未改用户数据。
