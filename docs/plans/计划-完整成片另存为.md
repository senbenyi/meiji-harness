# 完整成片另存为

- 类型：新功能
- 目标：在完整成片详情添加下载按钮，用户选择保存位置后将视频保存到本地。
- 调研来源：production-workflow.js、client/api/media.js、server/routes/media.js；当前下载按 job_id 查任务，合片导出没有对应生成任务，不能直接复用；跨域访问媒体服务器返回 403。

## 人工决策
用户已明确要求本地下载，本次按该要求实现，不以 .claude/standards.md 中禁止本地媒体保存的通用约定阻止本次功能。支持系统保存对话框的浏览器优先选择位置后流式保存；不支持时使用浏览器下载，并明确提示保存位置由浏览器设置决定。

## 执行步骤
1. `dsh-elysium/src/server/routes/media.js:createMediaHandler/registerMediaRoutes` — 新增成片下载入口，以 project_id/export_id 查服务器已保存的已完成导出；校验媒体服务器归属，认证后流式转发，不接受任意 URL，不写入服务端本地文件 → AC-1、AC-2。
2. `dsh-elysium/src/client/api/media.js` — 新增成片下载地址和保存操作，点击时先打开 showSaveFilePicker，选定后读取同源下载流并写入目标文件；取消静默返回，失败中止写入；不支持时走普通下载 → AC-1、AC-3。
3. `dsh-elysium/src/client/workbench/production-workflow.js:export` — 新增“下载成片”按钮，默认文件名项目名-第N集.mp4；显示保存中、成功、失败，未完成成片不可下载 → AC-1、AC-3。
4. `dsh-elysium/tests/media-http.test.js`、`dsh-elysium/tests/production-ui.test.js` — 新增下载归属/认证/未完成拒绝、按钮调用、选择/取消/写入错误验证 → AC-1、AC-2、AC-3。

## 验收标准
- AC-1：完成的每集视频可以从播放详情点击下载并选择本地保存位置（浏览器支持保存对话框时）。
- AC-2：仅允许下载已有项目中已完成导出的实际媒体；同源认证，流式传输，不缓存整段视频到服务端磁盘。
- AC-3：用户取消不报错；失败明确提示且可重试；不支持保存对话框时按浏览器下载设置保存，并明确说明。

## 验证结果
已实施并重启 Harness。211 项插件测试、10 项 Harness 测试通过；浏览器确认按钮；真实成片下载完整（7,539,042 字节，30.032 秒，H.264/AAC）。系统保存对话框因用户窗口切换未完成实测，其选择/取消/写入逻辑自动化通过。
