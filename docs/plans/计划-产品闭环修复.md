### 阶段 2：AC-4 成片下载

#### 2.1 服务端：download 端点

1. `dsh-elysium-tools/src/http/media-jobs.js` — 修改：

   在 `createMediaHandler` 函数中，当 `url.pathname === MEDIA_ROUTE + '/download'` 时：
   - 复用现有 token 校验和 call→job 查找
   - 确认 `summary.has_video || summary.has_image`，否则返回 404
   - 用 `fetch(job.result.comfyui_view_url)` 请求上游文件
   - 设置响应头：
     ```
     Content-Disposition: attachment; filename="elysium-{job_id}.{ext}"
     Content-Type: （转发上游）
     Content-Length: （转发上游，若有）
     Cache-Control: no-store

### 阶段 3：AC-5 资产面板

#### 3.1 服务端：资产列表端点

1. `dsh-elysium-tools/src/http/media-jobs.js` — 修改：在 `createMediaHandler` 中新增 `/list` 路径处理：
   - Token 校验（复用现有逻辑）
   - 读取 query 参数 `limit`（默认 50，最大 200）和 `offset`（默认 0）
   - 用 `readdir` 扫描 `$ELYSIUM_TOOLS_STATE_ROOT/jobs/`
   - 逐个读取 `status.json`，用 `jobSummary` 转换
   - 过滤 `status === 'succeeded'`
   - 按 `status.json` 的 mtime 倒序排列
   - 返回 `{ items: [...], total, has_more }`
   - `items` 中每项额外包含 `created_at`（mtime 毫秒时间戳）

2. `dsh-elysium-tools/src/http/media-jobs.js` 第 68 行 — 修改：suffix 列表加入 `'list'`（阶段 2 已加 download，此处追加）：

   for (const suffix of ['status', 'video', 'image', 'credentials', 'download', 'list'])
   ```

**注意**：`/list` 不需要 session/call 参数，直接扫描全部 jobs。需在 handler 中单独处理（跳过 findCall 查找）。

### 阶段 4：AC-6 分镜管理

#### 4.1 服务端：分镜存储与端点

1. `dsh-elysium-tools/src/http/storyboard.js` — 新增：分镜 CRUD 模块

   存储路径：`$ELYSIUM_TOOLS_STATE_ROOT/storyboards/{id}/manifest.json`

   数据结构：
   ```json
   {
     "id": "a1b2c3d4",
     "title": "...",
     "created_at": 1726099200000,
     "updated_at": 1726099500000,
     "shots": [
       { "index": 1, "label": "...", "prompt": "...", "job_id": null, "status": "pending", "notes": "" }
     ]
   }
   ```

   导出 `registerStoryboardRoutes(ctx, runtime)` 函数：
   - 复用媒体 token（通过参数传入或从 ctx 获取）
   - 路由前缀：`/plugins/dsh-elysium/storyboard`
   - 5 个端点：

   | 方法 | 路径 | 功能 |
   |------|------|------|
   | GET | `/list` | 扫描 storyboards 目录，返回摘要数组 |
   | GET | `/get?id=X` | 返回完整 manifest |
   | POST | `/create` | body `{ title }`，生成 8 位 hex ID，创建目录和 manifest |
   | POST | `/update` | body `{ id, title?, shots? }`，合并更新，写入 updated_at |
   | POST | `/delete` | body `{ id }`，删除目录（`rm -rf`） |

   所有端点共用 token 校验。写操作统一用 POST + JSON body（避免 DELETE 方法在某些代理下受限）。
   文件写入使用 write-tmp-rename 模式（与 call-index.js 一致）。

2. `dsh-elysium-tools/src/index.js` — 修改：导入并注册分镜路由：
   ```js
   import { registerStoryboardRoutes } from './http/storyboard.js'
   ```
   在 `ctx.inject(['webServer'], ...)` 回调中追加：
   ```js
   withConfig(runtime, () => registerStoryboardRoutes(mediaContext, runtime))
   ```

#### 4.2 客户端：分镜标签页

1. `dsh-elysium-tools/src/client/panel/storyboard.js` — 新增：分镜管理组件（`elysium-tools/storyboard`）

   API 函数：
   - `fetchStoryboards()` — GET `/storyboard/list`
   - `fetchStoryboard(id)` — GET `/storyboard/get?id=X`
   - `createStoryboard(title)` — POST `/storyboard/create`
   - `updateStoryboard(id, patch)` — POST `/storyboard/update`
   - `deleteStoryboard(id)` — POST `/storyboard/delete`

   组件：
   - `StoryboardList` — 分镜列表（+ 新建按钮），每项显示 title、镜头数、完成数、更新时间
   - `StoryboardDetail` — 分镜详情：
     - 返回按钮 + 标题
     - 镜头列表：每镜显示 label、缩略图/空位、状态、notes
     - 操作按钮：上移 [↑]、下移 [↓]、替换（清空 job_id，状态回 pending）、移除
     - 底部"添加镜头"按钮
     - 所有变更立即 POST `/storyboard/update`

2. `dsh-elysium-tools/src/client/panel/asset-panel.js` — 修改：
   - 面板头部添加标签页切换：**资产** | **分镜**
   - `activeTab` 状态（'assets' | 'storyboard'）
   - 按 activeTab 渲染 `AssetList` 或 `StoryboardList`/`StoryboardDetail`

3. `dsh-elysium-tools/scripts/client-source.mjs` — 修改：模块列表追加：
   ```js

   ```
   完整顺序：`media/api.js`, `media/model.js`, `media/styles.js`, `media/card.js`, `media/results.js`, `creation-commands.js`, `panel/panel-styles.js`, `panel/asset-list.js`, `panel/storyboard.js`, `panel/asset-panel.js`, `index.js`
