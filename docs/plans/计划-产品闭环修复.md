# 产品闭环修复

- 类型：功能 + 重构
- 目标：闭合 AC-4（成片下载）、AC-5（素材管理）、AC-6（项目管理）三个产品断裂点
- 调研来源：`docs/research/调研-产品闭环完整性.md`（2026-09-12）
- 版本：v2（经《第三杯咖啡》120 镜实际制作验证后重新设计）

## 人工决策

1. 铁律不变。铁律禁止的是 AI 自动下载，用户点击下载按钮是正常交互。
2. 删除 `旧 UI 插件` 插件（v1 已完成）。
3. 素材和项目管理统一归入 `dsh-elysium`。
4. 三层资产架构：素材（公共池）→ 项目（导演模式）→ 交付（成片）。
5. 教学/自由/标准模式生成物归入素材；导演模式项目内生成物归入项目。

## 术语

| 术语 | 含义 |
|------|------|
| **素材** | 公共资产池，所有非项目内的生成物 |
| **项目** | 导演模式下的结构化制作单元 |
| **锚点** | 角色/场景的定型参考图，镜头自动引用 |
| **幕** | 分镜表的章节分组 |
| **镜** | 分镜表最小单位，一次生成 = 一镜 |
| **交付** | 成片及附属产出 |

### 阶段 4：项目 CRUD + 锚点管理

#### 4.1 服务端：项目端点

1. `dsh-elysium/src/http/project.js` — 新增（替代 v1 的 `storyboard.js`）

   存储路径：`$ELYSIUM_STATE_ROOT/projects/{projectId}/project.json`

   数据模型：
   ```json
   {
     “id”: “a1b2c3d4”,
     “title”: “第三杯咖啡”,
     “profile”: “preview”,
     “created_at”: 1726099200000,
     “updated_at”: 1726099500000,
     “anchors”: [
       {
         “role”: “lin”,
         “label”: “林夏”,
         “description”: “28岁，齐肩直黑发，米色风衣”,
         “source”: { “type”: “job”, “job_id”: “310987b5...” },
         “image_url”: “https://...lin_00001_.png”
       }
     ],
     “acts”: [],
     “deliverables”: []
   }
   ```

   路由前缀：`/plugins/dsh-elysium/project`

   | 方法 | 路径 | 功能 |
   |------|------|------|
   | GET | `/list` | 项目列表（摘要：id、title、锚点数、镜数、完成数） |
   | GET | `/get?id=X` | 完整项目数据 |
   | POST | `/create` | `{ title, profile }` |
   | POST | `/update` | `{ id, ...patch }` 合并更新 |
   | POST | `/delete` | `{ id }` 确认后删除 |
   | POST | `/import` | `{ id, job_id, as }` 将素材引入（as: “anchor”） |

   Token 校验复用媒体 token。写操作串行化。原子写入（write-tmp-rename）。

2. `dsh-elysium/src/http/storyboard.js` — 删除（由 `project.js` 替代）

3. `dsh-elysium/src/index.js` — 修改：
   - 移除 `storyboard.js` 导入，替换为 `project.js`
   - 注册项目路由

#### 4.2 客户端：项目列表与锚点视图

1. `dsh-elysium/src/client/workbench/projects.js` — 新增（替代 v1 的 `storyboard.js`）

   API 函数：
   - `fetchProjects()` — GET `/project/list`
   - `fetchProject(id)` — GET `/project/get?id=X`
   - `createProject(title, profile)` — POST `/project/create`
   - `updateProject(id, patch)` — POST `/project/update`
   - `deleteProject(id)` — POST `/project/delete`（删除前确认提示）
   - `importMaterial(id, jobId, as)` — POST `/project/import`

   组件：
   - `ProjectList` — 项目列表 + 新建按钮，每项显示 title、档次、锚点数、镜数/完成数、更新时间
   - `ProjectDetail` — 项目详情容器，含子视图标签 `[锚点] [分镜] [交付]`
   - `AnchorView` — 锚点管理：列表展示角色/场景参考图，操作：替换、从素材选择、添加锚点

2. `dsh-elysium/src/client/workbench/storyboard.js` — 删除

3. `dsh-elysium/scripts/client-source.mjs` — 修改：
   模块列表中 `'panel/storyboard.js'` 替换为 `'panel/project.js'`

验证：
- `cd dsh-elysium && pnpm build && pnpm test` 通过
- 项目标签页可新建/删除项目
- 项目详情显示锚点列表，可添加和替换锚点
