# HTTP业务摘要标题

- 类型：完整流程，公共标题生成与记录结算修改。
- 目标：模型会话请求按本次用户输入生成简短业务标题，成功返回明确名称时补充，不新增模型请求。
- 非目标：不更改请求/返回正文，不让公共包包含drama规则，不按普通回答开头覆盖标题。

## 验收标准与调研结论
| AC | 输入/状态 → 结果 | 状态/依据 |
|---|---|---|
| AC-1 | 发送会话请求 → 用最后用户文本压缩摘要作标题，最多30 Unicode字符 | 待验收；messages支持字符串及text块 |
| AC-2 | 成功返回tool-call名称参数或结构化JSON名称 → 完善原摘要并持久化；普通文本/失败不覆盖 | 待验收；content blocks含name和arguments |
| AC-3 | 内部用途/显式title → 保持调用方或用途标题 | 待验收；purpose=session-title/compaction |
| AC-4 | 历史会话回复记录 → 自动补算，正文时间不变，自定义标题保留 | 待验收；构造器对通用title补算 |
