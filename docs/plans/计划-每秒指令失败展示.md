# 每秒指令失败展示

- 类型：Bug 修复
- 目标：修复未保存正文时自审失败 UI 缺失。
- 调研：docs/research/调研-每秒指令失败展示.md
- 待用户决定：无。

## 改动
1. `meiji/client/workflow-review.js:appendWorkflowReview` — 正文为空即隐藏 → 真实失败或 error 仍显示详情，并说明没有可用正文；无正文不允许提交修改/忽略 → AC-1、AC-3。
2. `meiji/shared/feedback.js:feedbackOf(seconds)` — 只聚合单镜 → 包含整集失败与问题，保持运行/暂停/错误状态，去重 → AC-2。
3. `meiji/tests/model-ui.test.js`、`all-seconds.test.js`、`review-checks.test.js` — 无正文错误 UI、格式失败后实际数据渲染、整集问题去重、修复后正常状态回归 → AC-1 至 AC-4。
4. `.agents/meiji-dev.md` — 明确失败详情不依赖正文已保存 → AC-1。

## 验证
只运行 model-ui、all-seconds、review-checks 和直接受影响审核相关测试；新增回归先确认失败，再实施。

## 验证结果
- 基线：model-ui、all-seconds、review-checks 共 81 项通过。
- 新增回归先失败：空正文失败卡片、整集状态、整集审核意见遗漏均复现。
- 修改后相关测试共 86 项通过（上述三份 84 项，feedback-migration 2 项），未运行全套测试。
- 使用截图项目的实际数据只读渲染：失败卡片可见，完整时长错误可见，提交修改禁用，无人工放行按钮；镜头正文仍未发布。
