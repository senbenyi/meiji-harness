# 摘要成功后误标停止

- 类型：小改动
- 目标：接口已返回并通过审核时，摘要保持已通过，不再写成「任务已停止，请重新发起」，剧集状态也不再停在生成中。

## 改动
1. `meiji/server/flow/actions.js` 的 `runOperation` 收尾：任务未失败、未中止，且节点已有审核结论时，只解除 operation，按 `check.passed` 写状态并清空 error；真正停止或失败时才写停止原因。随后用 `modelPatch` 重算剧集状态。
2. `meiji/tests/episode.test.js`：新建、重新生成、按意见修改三种摘要都断言 `passed`、error 为空、剧集和项目状态不是 `generating`。

验证：`cd meiji && npm test`
