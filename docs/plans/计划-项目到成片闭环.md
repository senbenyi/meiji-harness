# 项目到成片闭环

- 类型：Bug 修复 + 新功能
- 目标：自有模型路径打通完整 AI 短剧生产流程；人工只需定稿剧情总览、确认锚点、审看成片。
- 调研来源：`docs/research/调研-项目到成片闭环审查.md`

## 人工决策

已定（2026-09-21）：
- 修订媒体保存铁律：模型产物由 Worker 经 `saveMedia` 保存到所属项目目录。
- 自动推进：批准；流水线为唯一生产路径。
- 聊天 Agent 闭环：不做；仅按新数据结构调整项目工具参数。
- 不兼容旧数据与旧路径；不符合新规范的本机项目由用户手动清理。
- 仓库与本机 `pools/skills/` 的规划说明同步修改：批准。
- 真实 GPU 验收：用户手动执行（见「用户验收清单」）。

- 参考图上传：批准（2026-09-21），铁律放开为「仅 Worker 可向模型服务器上传任务参考图」。

## 目标流程

```
新建项目（名称/题材/梗概/导演，封面可选）
→ 生成并定稿剧情总览【人工 1】 ─→ 自动：角色锚点出图
→ 一键生产（全部 / 到第 N 集）
   自动：逐集 时间线 → 分镜 → 逐镜提示词（生成并定稿）
→ 查看锚点图，必要时重生成/替换 → 确认锚点【人工 2】
   自动：逐镜 首帧 → 视频（失败换种子重拍 1 次）→ 本集全部成功 → 合成（字幕、响度）+ SRT
→ 审看成片【人工 3】 → 需要时重拍单镜 → 自动重新合成新版本
```

3. `dsh-elysium/src/server/projects/pipeline.js` — 新增 `createPipelineDriver(store)`：每 tick 对账一次，规划步骤复用 `store.planning.generate/finalize`，全局最多一个进行中的 LLM 调用且 tick 不 await 它：
   - 范围内按集升序：时间线 → 分镜 → 逐镜提示词，仅处理「无定稿」或「需复核」；已有未定稿的最新版本则定稿该版本，否则生成后定稿「本次生成的版本号」；定稿前重读，若期间该步骤已被人工定稿则放弃本次结果；
   - 某集需复核且已有镜头任务、`cascade_confirmed=false` → 暂停并显示影响集数与镜数；「继续」置 `cascade_confirmed=true`；
   - 分镜重新定稿遇 409（镜头生成中）→ 等待，不暂停；
   - `anchors_confirmed=false`，或所需锚点图未完成 / 需复核 → 等待，不提交镜头；锚点出图失败 → 暂停；
   - 待生成镜头 → `produce`；
   - 镜头失败 → 尝试次数 < 2 时换种子重拍，否则暂停；
   - 本集全部成功且无对应当前任务集合的成片 → `requestEpisodeFilm`；合成失败 → 暂停；
   - 范围内全部集的成片与当前镜头一致 → 空闲，`cascade_confirmed` 复位；保持开启，重拍后自动重合成 → AC-9

## 用户验收清单（用户手动执行）

1. 新建项目（不选封面，填题材、梗概、导演）。
2. 剧本页生成并定稿剧情总览 → 角色锚点自动出图（正面站姿）。
3. 点「一键生产 · 到第 1 集」→ 时间线、分镜、提示词自动定稿；未确认锚点前不提交镜头。
4. 锚点页查看，必要时重生成或替换 → 点「确认锚点」→ 镜头自动提交，每镜先出首帧再出视频。
5. 成片页出现第 1 集：`ffprobe` 单一分辨率、含音轨、时长约等于各镜之和；字幕与对白一致；SRT 可下载；关闭 AutoDL 后仍可播放。
6. 对任意一镜点「重拍此镜」→ 新画面与原画面不同 → 自动生成第 1 集新版本成片并默认显示。
7. 修改第 1 集时间线并定稿 → 流水线暂停并提示影响范围 → 继续后级联重做。
8. 重启 Harness → 流水线从中断处续跑，无重复任务。
