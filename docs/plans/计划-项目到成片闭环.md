# 项目到成片闭环

- 类型：Bug 修复 + 新功能
- 目标：自有模型路径打通到每集成片；人工只需定稿剧情总览并审看成片；修正首帧、锚点、字幕三处质量短板。
- 调研来源：`docs/research/调研-项目到成片闭环审查.md`

## 人工决策

已定（2026-09-21）：
- 批准修订媒体保存铁律：模型产物由 Worker 经 `saveMedia` 保存到所属项目目录。
- 批准自动推进。
- 聊天 Agent 闭环本轮不做。

待定：
1. **本机 Skill 同步**：阶段 3/4 修改仓库 `harness/.dsh/storages/elysium/pools/skills/{drama-planning,shot-planning}` 的步骤说明，本机 `~/.dsh/storages/elysium/pools/skills/` 同名文件需同步（当前两处内容一致）。执行前确认。
2. **旧不分集路径删除**（阶段 7.3）：依赖「计划-短剧生产级」人工决策 3 的旧项目迁移；未迁移则本轮跳过。
3. **真实验收**：用 1 集 × 2–3 镜小项目在 AutoDL 跑全流程，占用 qwen3.8 与 H3 GPU 约 10–20 分钟。执行前确认。
