# 剧情取消道具生成

- 类型：流程调整
- 目标：剧情生成链路只生成大纲、角色和场景，道具在其他流程中统一按空集合处理。
- 非目标：不删除已有道具数据、道具素材或兼容已有道具卡的读取与编辑能力。

## 验收标准与调研结论

| AC | 输入/状态 → 可观测结果 | 状态 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 进入剧情生成页面并执行剧情生成 → 不展示“提取道具”，规划步骤不包含道具生成/审核/修订 | 已确认 | 剧情阶段视图、运行规划器和任务注册表已调整 |
| AC-2 | 道具字段缺失或为空时生成镜头 → 不因道具缺失阻塞，按空集合继续 | 已确认 | 生成门禁和镜头前置校验已移除道具要求 |
| AC-3 | 项目中已有历史道具数据 → 不影响已有数据读取和兼容编辑 | 已确认 | 仅移除剧情自动生成入口，保留历史数据结构与兼容模块 |

## 改动

### 阶段 1：移除剧情道具生成链路

1. `meiji/shared/run-planner.js`、`meiji/shared/run-templates.js` — 剧情 DAG、目标范围和文本目标去掉 props → AC-1
2. `meiji/client/generation-stage-views.js`、`meiji/client/flow-view.js`、`meiji/client/goal-request.js` — 剧情页面和请求不再提供道具生成入口 → AC-1
3. `meiji/server/flow/tasks/text-step-registry.js`、`meiji/server/flow/tasks/task-registry.js` — 自动任务注册表不再注册道具步骤 → AC-1

### 阶段 2：按空集合兼容下游流程

1. `meiji/shared/generation-gates.js`、`meiji/server/runtime/run-execution.js`、`meiji/server/data/content-records.js` — 剧情和镜头前置校验不再要求 props → AC-2
2. `meiji/server/flow/shared/story-content.js`、`meiji/server/flow/runs/run-service.js` — 新剧情编排只处理角色和场景，道具结果保持空集合 → AC-2、AC-3
3. `meiji/shared/review-feedback.js`、`meiji/client/panel-app.js`、`meiji/server/http/skill-routes.js` — 剧情审核、路由和页面阶段范围同步 → AC-1、AC-3

验证：运行 `node --test meiji/tests/*.test.js`、`git diff --check`，预期无新增失败且差异无空白错误。
