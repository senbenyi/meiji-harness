# 删除全屏图片确认浮层

- 类型：完整流程，删除跨页面共享UI与相关样式、测试。
- 目标：移除截图中的图片生成/确认全屏浮层，生成和候选不再自动遮挡正在浏览的页面。
- 非目标：不删除素材、候选或后台任务，不取消卡片内图片操作。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 状态 | 依据 |
|---|---|---|---|
| AC-1 | 生成中、候选就绪或孤立历史候选 → 不出现全屏图片确认页 | 已确认断点 | renderSession 的兜底 renderImageReview |
| AC-2 | 人物/场景卡候选 → 卡片/详情确认放弃仍工作 | 未验收 | renderDetailImageActions 独立实现 |
| AC-3 | 删除旧页 → 无残留页面函数、import及专用样式 | 未验收 | image-review.js 和 panel-styles.css |

## 调用链与证据
renderSession → syncImageGate → 当前卡未匹配人物/场景 → renderImageReview，因自动任务锁可推断成通用图片而误显示截图页面。
GitNexus renderImageReview 风险 HIGH，renderSession 为 CRITICAL；调用者包含面板刷新与UI测试。保留详情内的状态同步，仅移除兜底浮层。
