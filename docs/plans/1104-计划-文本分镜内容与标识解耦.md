# 文本分镜内容与标识解耦

- 类型：完整流程，模型接口与产物编译。
- 目标：生成、审核、修订均使用名称和内容，模型不生成/抄写领域ID；程序维护镜头/节拍/对白ID及资产关联，素材与提示词下游保持实际引用。
- 非目标：删除持久化ID、旧数据迁移、模糊匹配或自动猜测歧义名称、修改其他节点产物格式、自动调用真实模型。
