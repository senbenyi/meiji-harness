# 剧集规划与移动式导航

- 类型：新功能
- 状态：已完成（2026-09-19）；用户确认实施，并要求删除旧项目、不兼容旧 UI。
- 目标：项目内按剧集组织剧情、分镜与成片，以横向剧集卡片和逐级详情导航呈现。
- 调研来源：当前 projects schema/manager、project workflow 服务与工具、ProjectWorkflow/ProjectDetail/DeliveryView。

## 当前证据
- workflow.plot 是单份剧情；workflow.request/approval/job_id 是项目级单值。
- acts 是幕列表且生成结果会整体替换；deliverables 不带 episode_id。
- 现有详情同时展示项目标题栏和步骤标题栏；分镜全部表单在一页展开。

## 已确认方案
- 项目配置增加计划集数，默认 1 集；AI 根据集数生成分集标题和剧情，每集暂沿用 200 字限制。
- 全剧共用项目素材，每集独立剧情、分镜、审核版本、任务与成片关联。
- 删除旧项目及旧 UI，仅支持新剧集结构；保留独立素材库。
- 单集操作，不自动批量提交全剧视频；修改单集只使该集下游失效，全局素材修改标记受影响剧集待更新。

## 验收标准
- AC-1：剧情按剧集持久化，支持标题和剧情编辑、计划集数及 AI 分集生成；按要求清空旧项目并保留素材库。
- AC-2：总览剧情、分镜、成片三区均为横向剧集列表，可触控板/触摸滑动并有左右按钮；卡片显示关键摘要和真实状态。
- AC-3：点击分镜剧集进入镜头列表，再点击镜头进入独立编辑页；保存结果归属正确剧集和镜头。
- AC-4：成片按集关联，点击选中成片直接进入播放详情，不默认播放其他集；无成片时展示该集状态。
- AC-5：一条顶部导航栏展示返回与当前标题，逐级返回并恢复列表位置；正文滚动、操作栏固定；未保存离开确认。
- AC-6：生成请求、版本校验、审核、提交、重试和刷新均绑定剧集，重复提交幂等、过期回写被拒绝；各集互不覆盖。
