# 剧本详情入口

- 类型：小改动
- 目标：项目详情页仅保留剧本标题作为详情入口，并在标题后提供箭头按钮；剧本编辑与后续剧情修改统一在剧本详情页完成。
- 非目标：不改变剧本详情页的编辑、版本、回写方案或 AI 修改逻辑。

## 验收标准

| AC | 输入/状态 → 可观测结果 | 状态 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 打开项目详情页 → 剧本区域不显示“查看全部详情”和“修改后续剧情”按钮 | 已确认 | `meiji/client/project-overview-view.js` 已删除两个独立操作按钮，并由相关 UI 测试断言 |
| AC-2 | 点击剧本标题或标题后的箭头 → 打开剧本详情页 | 已确认 | 标题按钮与箭头按钮均调用 `actions.openScript`，相关 UI 测试通过 |
| AC-3 | 打开剧本详情页 → 仍可编辑正文、提交修改说明、修改后续剧情 | 已确认 | `meiji/client/script-view.js` 当前保留编辑表单和 AI 修改表单 |

## 改动

### 阶段 1：调整项目详情页入口

1. `meiji/client/project-overview-view.js:renderOverview` — 删除项目详情页的两个剧本操作按钮，保留可点击剧本标题，并追加箭头按钮 → AC-1、AC-2。
2. `meiji/client/panel-styles.css` — 增加标题与箭头的横向布局样式 → AC-2。
3. `meiji/tests/script-ui.test.js` — 补充入口文案、点击标题和箭头的回归断言 → AC-1、AC-2。

验证：`node --test tests/script-ui.test.js`；预期入口按钮仅剩标题和箭头，二者都进入剧本详情。

## 验证结果

`node --test tests/script-ui.test.js`：9/9 通过；`npm test`：9/9 通过；`git diff --check` 通过。
