# 人物服装精简提取

- 类型：规则修复，完整流程；涉及生成、修订、审核及验证。
- 目标：无服装信息只设计一套，同类服装归并，仅剧本明确该人物实际换装或不同套穿着才增加。
- 非目标：不批量删除历史服装或重绑镜头，不生成定妆照，不调整人物外貌资料补全能力。
