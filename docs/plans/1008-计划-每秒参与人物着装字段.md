# 每秒参与人物着装字段

- 类型：完整流程，返回结构与编译依赖改动。
- 目标：每秒 participants 列出人物并新增一段 outfit 着装描述，保存、展示、审核和视频提示词直接消费。
- 用户决定：只列一段着装描述，不增加起始/结束两个字段。
- 非目标：角色多变体、新人物生成、自动生图、覆盖角色库固定资料、给仅声音角色编造着装、改写现有历史指令。
