# 拆分只保留剧情

- 类型：完整流程
- 目标：拆分剧集前去掉剧情之前的人物说明和分场间隔，只把实际剧情切进各集。
- 非目标：不改写对白和动作原文，不改参考时长的切分方式。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 已确认/未确认/未验收 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 剧本在第一场之前有人物说明，场与场之间有间隔线 → 编号剧本和写入的剧情都不含这些内容 | 已确认 | `scriptParagraphs` 现在保留全部原文，审核要求拼接与原剧本逐字一致 |
| AC-2 | 没有这些说明的剧本 → 段落编号和拼接结果与现在一致 | 已确认 | `stage09` 用「第一场 酒馆」整段作为剧本 |

## 改动
1. `meiji/server/handlers/script-split.js` — 编号和拼接前只保留从第一场开始的剧情，去掉间隔线、场次说明和计时标记 → AC-1、AC-2
2. `meiji/server/prompts/models/script-split.js`、`meiji/dev_docs/dots/项目-提取剧集.md` — 规则改为只切剩余剧情 → AC-1
3. `meiji/tests/stage09-script-split.test.js` — 用带人物说明和间隔线的样例核对 → AC-1

验证：`cd meiji && node --test tests/stage09-script-split.test.js` — 通过。
