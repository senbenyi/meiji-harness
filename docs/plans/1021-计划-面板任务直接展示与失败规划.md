# 面板任务直接展示与失败规划

- 类型：新功能，完整流程。
- 目标：面板任务在已有会话直接展示开始与结果；成功不请求主Agent，rejected/failed才交给模型规划。
- 非目标：不新增会话；不把程序结果伪造成AI输出；取消任务只展示取消，不自动恢复；保留会话创建项目后原目标交接。

## 验收标准与依据

| AC | 输入/状态 → 可观测结果 | 依据 |
|---|---|---|
| AC-1 | 面板任务受理 → 执行前追加开始展示消息，不进入模型上下文 | Harness公开session.append(command/run、command/done)为log-only；参考meiji展示实现，复制思路到drama，不跨项目依赖 |
| AC-2 | 盒子completed → 追加结果展示，零followup/主Agent模型调用 | 当前dispatcher所有终态都followup，需分离展示与规划 |
| AC-3 | rejected/failed → 先展示失败结果，再followup报告至同会话 | 原有程序报告、任务目标与规则授权保留 |
| AC-4 | 取消/重启/部分投递失败 → 不误唤醒；开始与结果各用独立随机ID、不互相关联；仅规划报告维持现有去重 | 用户补充要求不做展示消息关联；不增加展示阶段账本，不改任务终态 |
