# 角色团队设定与三卡片布局

- 类型：数据结构与业务UI扩展，完整流程。
- 目标：场景tab在角色之前；角色页分团队设定、人物提取、定妆照三卡片，统一生成团队/人物资料及充分服装设定，定妆输入继承团队完整形象。
- 非目标：不另建团队执行器、不自动生图、不迁移存量私有规则、不重启或提交推送、不实现尚未具备的场景生成执行器。

## 实施
1. character_extraction定义groups、人物group_ids、服装团队来源及适用故事段；同步project_detail。旧资料只在输入投影补空字段，不改写旧项目。
2. 统一提取规则补齐团队整体形象、个人及团体完整服装；可用场景资料进入输入/指纹/会话投影；校验重复、成员与制服引用、适用段。
3. 保存groups、保留照片；相关团队更新参与照片过期判断、输入快照与指纹。镜头增加团队引用，服装/视频规则只落实已确认形象。
4. 角色page共享一次生成/审核，三卡片分别展示团队、人物、定妆照；照片卡集中单张及批量功能，旧项目空团队兼容。tab场景前移。
5. 新增/更新功能测试：联合保存与审核、纯团队、引用错误、相关/无关团队对图片的影响、场景输入变化、历史展示、三卡片及顺序和连点幂等。跑相关及全量业务测试，diff检查与最终索引。
