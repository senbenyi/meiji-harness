# 按要求优化剧本

- 类型：完整流程，新增Tool、执行器、任务/模型调用与UI执行入口。
- 目标：会话或页面按用户明确意见优化当前项目剧本，经结构校验、本地审核/修订及项目审核后保存完整优化稿、摘要和时长，任务可追踪。
- 非目标：不执行其他制作节点、不自动生成视频、不改项目规则、不修改外部Harness；验证只用模拟模型。

## 调用链与证据
会话drama-optimize-script / 面板POST script-optimization → ProjectService.optimizeScript → 公共TaskManager单组单节点 → ScriptRevisionExecutor。
步骤：generate/revise（保存合法候选）→ review → project_review；content_issue追加revise/review再项目审核；passed结束，upstream_issue/rule_conflict/repeated failure停止，保留候选。不会引入固定回合预算。
模型worker使用独立的有界上下文，无会话全历史和其他节点；项目审核使用session所选模型，普通生成/审核使用text所选模型。公共任务新增通用nextSteps结果，不包含业务规则。
并发保护：优化入队、编辑/删除和结果保存共用服务队列；执行中的输入类编辑拒绝，结果保存核对输入/候选指纹与信号。任务ID按会话和请求ID派生，任务metadata只保存业务目标/指纹/意见。
