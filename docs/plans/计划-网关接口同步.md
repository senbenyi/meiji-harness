# 网关接口同步

- 类型：重构（接口契约同步）
- 目标：插件调用网关的方式与 `下游接入接口文档.md` 一致；删除依赖网关文件接口的 `imageUrl` / `file` 字段。
- 调研：`docs/research/调研-网关接口同步.md`

## 待用户决定
无。用户补充决定（2026-09-30）：原来放图片 URL 的位置直接改为 base64 data URL，`<Picture N>` 引用方式不变。落实为：视频请求 `reference_images` 按原顺序放 data URL；分镜文本请求不传图片也不传地址，参考列表只写 `<Picture N> 标签`（用户确认：图片只在本地，只传给生成视频）；项目数据不保存 base64。

## 改动
### 阶段 1：网关层
1. `meiji/server/generate/gateway.js:generateGatewayImage` — `images/tasks` 异步提交 + 轮询 → 无参考图时 `POST images/generations`（JSON，含 `seed`），有参考图时 `POST images/edits`（multipart，`image[]`）；读取 `data[0].b64_json`；使用任务信号中断 → AC-2、AC-3
2. `gateway.js:uploadGatewayFile / cancelGatewayTask / cancelOnStop` — 删除 → AC-5、AC-6
3. `gateway.js:submitGatewayVideo` — 增加 `size`（`videoSize(aspectRatio)`：`1344x768`→`1024x576`，`768x1344`→`576x1024`）；请求体超过 64 MiB 时本地报错；提交后如任务已停止，报「网关不提供取消接口，远端视频任务（id）可能仍在运行」 → AC-4、AC-5
4. `gateway.js:retrieveGatewayVideo` — 只处理视频；停止或超时不再取消，错误写明远端任务 ID → AC-5
5. `gateway.js:publicData / writeApiLog` — 日志隐藏多参考素材与 multipart 文件内容；去掉已删除函数的用途名 → AC-4
6. `meiji/server/generate/film.js:submitH3` — 传递 `aspectRatio` 给视频提交 → AC-4
7. `meiji/index.js`、`meiji/server/flow/tasks/restart.js:interruptRunning` — 删除 `cancelRemote`；遗留远端任务记录「网关不提供取消接口，远端任务（id）可能仍在运行」 → AC-5

### 阶段 2：图片与视频流程
1. `meiji/server/generate/image.js:submitAssetImage` — `referenceImage`（data URL）→ `referenceBytes` + `referenceMime` 传给网关 edits；`pictureRecord / imageAsset / importAssetImage` 不再产生 `imageUrl` / `file`，以 `localPath` 或 `assetId` 判定通过 → AC-3、AC-7
2. `meiji/server/flow/operations/images.js:startImage / opConfirmImage / opImportImage / opPartImport` — 删除上传；确认与导入不再要求配置视频网关 → AC-6、AC-7
3. `meiji/server/data/pictures.js:pictureReference / readPicture`、`server/data/library.js` — 不再保存或读出 `imageUrl`；新增 `referenceImageData(home, project, image)` 读取素材库图片、旧版剧集图片或尾帧并返回 data URL → AC-4、AC-7
4. `meiji/server/flow/operations/films.js` — 删除 `publishLocalReferences`；提交前把参考图转成 data URL，记录与日志只写本地地址；尾帧不上传；删除提交参数展示里的 `quality`，增加 `size` → AC-4、AC-6
5. `meiji/server/generate/shot-text.js:generateShotStoryboard` — 尾帧参考地址改为 `tail-frame:<视频文件>`；不再要求 http 地址；`tailReference` 不含 `imageUrl` → AC-7
6. `meiji/shared/reference-images.js`、`shared/tail-frame.js`、`shared/drama-model.js:cardModel / refreshReferences` — 只用本地地址；尾帧以 `localPath` 判定；读取含 `imageUrl` 的剧集时报 `OLD_IMAGE_URL` → AC-7
7. `meiji/server/generate/story.js`、`server/data/story-package.js`、`server/data/task-store.js` — 删除 `imageUrl` / `file` 字段 → AC-7

### 阶段 3：界面与接口
1. `meiji/server/http/routes.js` — 删除 `/character-image-url`；`/reference-preview` 改为本地读取 → AC-9
2. 删除 `meiji/server/generate/image-access.js` 及其测试 → AC-9
3. `meiji/client/character.js`、`client/asset-cards.js`、`client/overview.js`、`client/app.js`、`client/styles.css` — 删除「人物图片 URL」段落与 `imageUrl` 判断 → AC-9

### 阶段 4：迁移与文档
1. 新增 `meiji/scripts/migrate-image-url.js` — 备份项目索引与剧集、剥除 `imageUrl` / `file`（对象形式）、快照远端地址换成本地地址（尾帧为 `tail-frame:<视频文件>`）、没有本地图片的图片节点清空并在结果中列出；读回核对；素材元数据同样剥除；可重复执行 → AC-8
2. `configure-harness.sh` — 启动前调用迁移脚本 → AC-8
3. `meiji/docs/gateway-api.md` — 替换为新接口文档；`.agents/architecture.md` — 删除 `image-access`，脚本列表加 `migrate-image-url` → AC-10
