# 统一场景与视频参考

- 类型：新功能，完整流程（项目数据结构、节点、迁移与视频链路）。
- 目标：大纲后选择性提取反复出现、重要或用户指定的项目场景，镜头绑定场景与本镜状态，多次视频请求复用场景参考。
- 非目标：三维重建、保证模型绝对一致、自动付费生成全部图片/视频、覆盖历史提示词。

## 设计

project.scene_library.scenes保存{id,name,description,layout,materials,lighting,reference_image:{address,node_state}}。episode.scene_catalog保存scene_ids、has_result与节点状态。shots新增scene_id、scene_state、scene_transition（连续接拍/切换机位/换场）。状态描述昼夜、天气、损坏等，固定空间不因机位不同另建地点。scene-image任务以scene为target；episode-scenes以episode为target。

场景提取优先按已有ID复用，同名可唯一合并，别名由模型对照上下文复用ID；已有固定设定由项目统一维护，不能因本集夜景改写全项目基础光照。参考图为无人物的空间设定图；基础图加镜头状态共同约束输出。一次性不重要地点不建档，提取可为空且has_result记录已完成选择。未绑定场景的镜头不要求场景参考图；绑定重要场景的视频需要有效场景参考图。一张场景图按需生成，不因机位/昼夜/天气增图。

调用链：面板→TaskService→precheck→episode-scenes路由/PromptModel→prepare/commit→scene_library+scene_catalog→shots→shotTextInputs→storyboard→videoImages/videoRequest→meiji-server。
