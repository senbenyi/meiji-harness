## 4. server/flow/ 目录（v3：文件名前缀 + 分层）

命名规则：操作文件以 `operation-` 开头，任务文件以 `task-` 开头；两层的基础设施放各自目录根部，业务定义放子目录；共用代码统一放 `flow/shared/`。
合并规则：同一业务的「单镜/单卡/整集」「生成/按意见修改」「成片只做分镜/只做视频/只重做尾帧」都是同一操作的参数（track、itemId、mode、parts），不再单独建文件。

```
server/flow/
  operations/
    operation-registry.js     汇总操作定义：id、label、scope、agent、kind、参数校验、显示名；旧 action 名对照表（过渡期）
    operation-runner.js       执行一个操作（原 run-operation.js）：生成类建操作记录 → 经 task-registry 按序提交任务 → 失败/审核不通过/停止时取消其余任务；直接类写 1 条操作记录 + 1 个 save 任务
    operation-manager.js      面板与会话、生成与直接操作的唯一入口（原 flow/tasks/task-manager.js）：start 生成 operationId 并加锁（唯一一把锁：生成类按剧集，含排队中；项目级按项目），生成类入队、直接类立即执行；维护每集「占用」（operationId、名称、状态、发起方），入队即占用、结束释放；current、list、get、wait；占用信息供面板置灰与会话 busy 返回
    operation-cancel.js       停止按钮：按 operationId 或 taskId 停止整个操作，不建记录
    generate/                 生成类操作：只声明 tasks(project, op)
      operation-summary.js          1 剧集摘要（mode：generate / modify / draft）
      operation-story.js            2 剧集剧情：outline → characters → scenes → props；`only` 参数只跑其中一个（替代 characters、scenes、props 三个修订操作）
      operation-character-image.js  3 角色图（modify = 重绘）
      operation-scene-image.js      4 场景图
      operation-prop-image.js       5 道具图
      operation-shot-table.js       6 镜头表（track = 按意见重写单镜，替代 revise-shot）
      operation-seconds.js          7 每秒指令：每镜一个任务；track = 单镜（替代 shot-seconds）；modify 从第一个未通过/缺失的镜到末镜建任务
      operation-film.js             8 成片：每镜 storyboard-prompt → video；track = 单镜；parts = storyboard / video / tail（替代 produce、produce-all、film、films、shot-storyboard、storyboard-bind、storyboard、tail-frame）
    direct/                   直接操作：不排队，改动内容的写一条 task-save 留痕
      operation-project-create.js  operation-project-open.js  operation-project-overview.js  operation-project-delete.js
      operation-library-import.js
      operation-episode-save.js（新增/编辑）  operation-episode-delete.js  operation-source-edit.js
      operation-outline-edit.js  operation-character-edit.js  operation-scene-edit.js  operation-prop-delete.js
      operation-storyboard-edit.js  operation-shot-assets.js  operation-assemble.js
      operation-image-import.js  operation-image-part-import.js  operation-image-part-text.js
      operation-image-reference.js（设置/移除参考图）  operation-image-use-asset.js  operation-image-clear.js
      operation-image-candidate.js（确认/放弃候选图）  operation-review-override.js
  tasks/
    task-registry.js          汇总任务定义：type、label、queue、target、nodes、maxRevisions、run
    task-queue.js             text / image / video 限流（原 flow/tasks/task-queue.js）
    task-interrupt.js         服务重启取消未结束的操作与任务（原 cancel-interrupted-tasks.js）
    text/                     maxRevisions 默认 2
      task-summary.js  task-outline.js  task-characters.js  task-scenes.js  task-props.js
      task-shot-table.js  task-shot-seconds.js
      task-storyboard-prompt.js（程序编排，maxRevisions 0）
      task-save.js（直接操作留痕：save，必要时 review）
    media/                    maxRevisions 0
      task-character-image.js  task-scene-image.js  task-prop-image.js（候选图保存即 completed，确认/放弃为直接操作）  task-video.js
  shared/                     任务与操作共用，不含操作或任务定义
    text-task.js              文本任务公共执行：调 runTextSteps 并传 maxRevisions，保存草稿与内容节点
    story-content.js          剧情四个任务共用的上游资料读取与卡片校验
    seconds-results.js        每秒指令结果保存
    image-files.js            图片生成、下载、候选与入库
    video-submit.js           视频提交、轮询结果保存、尾帧
    incoming.js               上传暂存
```

删除：阶段 1 的 operations/tasks/、operations/actions/、operations/shared/、plan-steps.js、operation-registry.js（旧）、run-operation.js、5 个 `*-operations.js` 兼容出口；原 server/flow/tasks/ 整个目录（内容迁入上表）。

数量：操作 4 个基础 + 8 个生成 + 23 个直接；任务 3 个基础 + 13 个定义；共用 6 个。最深两级目录。
