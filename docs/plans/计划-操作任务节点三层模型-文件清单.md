# 操作、任务、节点三层模型文件清单

本清单以接续 C1～E 的最终实现为准；规格与验收见同目录主计划。

| 目录或文件 | 最终职责 |
|---|---|
| `meiji/server/flow/operations/operation-manager.js` | 唯一发起、当前查询、等待、停止；操作持有占用，各任务独立排队 |
| `operations/operation-runner.js`、`operation-registry.js` | 校验、展开任务、建立操作与任务记录；登记规范操作 ID |
| `operations/operation-occupancy.js`、`operation-cancel.js` | 剧集/项目占用与整操作停止 |
| `operations/generate/operation-*.js` | 8 个生成操作，只声明任务范围与顺序 |
| `operations/direct/operation-*.js` | 编辑、选图、候选确认、删除、人工放行等直接操作 |
| `meiji/server/flow/tasks/task-registry.js` | 13 种任务的队列、target、nodes、修订上限与执行函数 |
| `tasks/text/task-*.js` | 摘要、大纲、人物、场景、道具、镜头表、单镜每秒指令、程序分镜提示词和保存任务 |
| `tasks/media/task-*.js` | 人物图、场景图、道具图和视频任务 |
| `tasks/task-queue.js`、`task-interrupt.js` | 按 text/image/video 限流，服务重启取消遗留记录 |
| `meiji/server/flow/shared/` | task-executor、story-content、seconds-results、image-generation、image-files、video-submit、film-freshness、incoming 等职责模块 |
| `meiji/server/runtime/` | 独立任务上下文、动态节点、实际请求快照及结束处理 |
| `meiji/server/data/content-records.js`、`task-store.js`、`operation-history.js` | 四类剧情版本独立；操作/任务/节点留痕与按 target 查询 |
| `meiji/shared/task-nodes.js`、`task-plans.js` | 统一状态推导与基础节点计划 |
| `meiji/shared/drama-model.js`、`content-state.js`、`generation-gates.js` | 内容状态统一转换、上游条件与过期处理 |
| `meiji/server/http/panel-routes.js`、`meiji/tools/` | 面板与会话统一调用 manager.start；发起等待记录准备；查看与控制接口分开 |
| `meiji/client/task-detail.js`、`task-nodes.js`、`execution-history.js`、`current-task.js` | 共用操作/任务/节点详情、实际提示词、快照和刷新 |
| `meiji/client/operation-request.js` | 把页面动作转换成规范请求；服务端不保留旧操作别名 |
| `meiji/client/live-activity.js`、`panel-app.js`、`task-group.js` | 实时占用、状态、查看与停止 |
| `meiji/client/character-views.js`、`asset-cards.js`、`generation-stage-views.js`、`workflow-review.js` | 各节点历史与 skill 入口、图片操作、失败详情 |
| `meiji/scripts/reset-runtime-data.js` | 停止服务后按用户授权清空旧项目与生成文件，保留素材库和配置 |
| `.agents/meiji-dev.md` | 后续开发指引，与最终目录、记录和接口一致 |

8 个生成操作：summary、story、character-image、scene-image、prop-image、shot-table、seconds、film。

13 种任务：summary、outline、characters、scenes、props、shot-table、shot-seconds、storyboard-prompt、character-image、scene-image、prop-image、video、save。

## 删除与替代

- 删除 `shot-boards`、铅笔分镜入口、Model、skill 与领域字段。
- 删除 `operations/tasks/`、`operations/shared/`、`run-operation.js`、`plan-steps.js` 及旧 `*-operations.js` 兼容出口。
- `shared/task-steps.js`、`client/task-steps.js` 合并到各自 task-nodes；执行记录统一使用 nodes/nodeId。
- 删除旧 task-steps 迁移脚本与启动调用。用户已授权清空旧数据，本次不新增旧记录兼容或迁移。
- 仅供提示词回归的整包模拟流程放在 `tests/fixtures/`，运行代码不导出旧整包执行入口。
