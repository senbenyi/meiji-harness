# 镜头表单次生成锁定时长

- 类型：完整流程，提示规则调整。
- 目标：一次生成内部先按小段规划、锁定镜头和时长，再填充字段。
- 范围：只改生成、修订、审核及输出说明，保持接口、输出字段、持久化、程序审核阈值不变。
- 用户明确：不增加程序预算分配步骤；小数预算通过提示指导统一分配为整数，整集舍入误差不超过0.5秒。

## 验收标准
- AC-1：生成与修订要求先锁定骨架，再填内容，最后校验；只输出完整镜头表。

- AC-3：整数小段保持原预算；小数预算按累计舍入差值分配，整集仅舍入一次。填充不改变预算。
- AC-4：审核要求在本段预算内修复剧情，不能要求扩时；原消息条数及返回结构不变。
