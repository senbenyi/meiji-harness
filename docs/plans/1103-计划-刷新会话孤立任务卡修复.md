# 刷新会话孤立任务卡修复

- 类型：完整流程，缺陷修复。
- 目标：刷新会话时不再将已清理任务的历史受理消息恢复为正在创建短剧。
- 非目标：不改创建按钮/弹框，不新建或删除短剧，不修改宿主原始会话日志，不覆盖工作区此前改造。

## 调用链与证据
mountTaskMessages刷新→task-messages接口→createPanelTaskDisplay.read→session.snapshotEvents里的drama-task-display→关联Task/Step→groupTaskMessages→createTaskOperation。
旧read在Task关联缺失时以空context保留历史start卡的operation_status=running，造成不存在的任务仍转圈。默认宿主会话未随短剧工作区清空，旧创建受理消息仍留在默认会话。
原始JSONL为多Zstandard frame；使用宿主官方scanZstdFrames扫描逐frame解码确认2条卡片，不把仅首frame读取结果当作无消息证据。
