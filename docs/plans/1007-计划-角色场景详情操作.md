# 角色场景详情操作

- 类型：功能调整
- 目标：项目详情页点击角色或场景后直接进入对应详情页，并在详情页提供资料编辑、重新生成图片和从素材库导入。
- 非目标：不改变项目库数据模型、素材库文件存储和已有剧集卡片关联规则。

|---|---|---|---|
| AC-1 | 项目详情页点击角色/场景卡 → 直接打开对应条目详情，不先展示库条目列表 | 已确认 | `project-overview-view.js` 已传递 `entryId`，`project-library-view.js` 需区分直达详情 |
| AC-2 | 角色/场景详情页 → 可编辑名称、资料字段并保存 | 已确认 | `libraryEditor` 和 `entry-edit` 已存在，需在直达详情页保留并明确入口 |

## 改动

### 阶段 1：直达角色/场景详情

1. `meiji/client/project-library-view.js` — 传入 `entryId` 时隐藏库列表，标题和返回行为收敛为条目详情 → AC-1。

### 阶段 2：补齐详情操作

1. `meiji/client/project-library-view.js` — 详情中明确展示“编辑资料”“重新生成”“从素材库导入”，复用现有保存和图片操作 → AC-2、AC-3、AC-4。
2. `meiji/tests/library-ui.test.js`、`meiji/tests/script-ui.test.js` — 覆盖项目详情点击直达与详情操作入口 → AC-1、AC-5。

验证：运行相关 UI/库测试、全量 `node --test meiji/tests/*.test.js`、`git diff --check`。
