# 任务与HTTP记录入口

- 类型：完整流程，新页面与公共组件提取。
- 目标：标题下提供HTTP记录、任务记录入口；公共HTTP列表与详情归http-client；drama独立接入存储。

## 调用链与证据
workbench→createTaskHistory→renderRecord；其中HTTP分支迁入http-client/ui。HTTP列表通过source.list/read读取HttpRecords；任务通过TaskManager.historySource读取SQLiteTaskStore。drama通过独立records服务统一持有数据库及记录入口。未实现的执行器不造记录，后续执行调用该服务。

GitNexus索引已刷新。MCP transport closed，CLI query有结果；context及impact对createTaskHistory、mount、createProjectHttpHandler、apply返回UNKNOWN。已补读调用方、动态注册、任务UI测试和浏览器静态模块路由，不将UNKNOWN解释为无影响。
