# 项目删除不受进度限制

- 类型：关键流程调整，完整流程。
- 目标：任何项目进度均可删除，自动取消本项目未结束任务，清理完成后删除。
- 非目标：不主动删除任何用户项目，不更改媒体提供商远端取消能力。

## 验收标准与调研结论
| AC | 状态 → 结果 | 调研 |
|---|---|---|
| AC-1 | 运行中概要页、片库 → 删除入口可用 | project-ui.js 默认 button freeze=busy 导致拦截 |
| AC-2 | 排队、运行、暂停、终态 → 均可删除项目 | model-repository.js remove 拒绝未结束任务 |
| AC-3 | 删除期间 → 拒绝新增任务；取消当前执行；晚到结果不能写回；其他项目不受影响 | TaskService 现有 AbortController、串行 model.update 与 idle 可复用 |
| AC-4 | 删除成功 → 项目、绑定清除；后续查询不存在 | runtime 现有删除路径与 UI 清上下文可复用 |

## 调用链与证据
概要/片库 → project-command → runtime.projectCommand → repository.remove。
新路径由 TaskService.removeProject 负责封闭提交入口、暂停及取消队列、abort 并等待本地清理，随后 repository.remove。
GitNexus 索引已刷新；remove 与 renderOverview 风险 CRITICAL，TaskService/createAppRuntime LOW。源码补查动态调用确认 repository.remove 业务入口仅 runtime。
