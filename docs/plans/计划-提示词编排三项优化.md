## 改动
1. meiji/server/prompts/shot-prompts.js、skill-prompts.js、models/（含视频与附属图） 与 interfaces/character-image.js、flow/operations/images.js：分离任务和资料；过滤空上下文；补齐场景字段；人物图统一 Model；各输出协议只包含当前步骤 → AC-1。
2. meiji/server/generate/shot-text.js、data/review-checks.js、shared/feedback.js：总时长纳入步骤审核，反馈按镜头分配与去重；审核强调具体证据 → AC-2。
3. models/story-*.js、generate/story.js、skills/task/ 与相关测试：大纲提供可检测的小节骨架；人物和场景提取明确边界，审核使用同一标准 → AC-3。
4. .agents/meiji-dev.md 与验收报告：记录新约定和新项目实际请求检查 → AC-1/2/3。

## 验收标准
- AC-1：生成、审核、修订资料一致，无空上下文或跨阶段协议，人物图首次生成和参考模式使用 Model。
- AC-2：AI PASS 但总时长超差时步骤仍不通过并自动修订；整集反馈仅保留一次，单镜只保存关联错误。
- AC-3：大纲分节换行不再拼成一段；纯画外人物不生成视觉卡；场景卡为无人物环境。新项目按门禁复测下游，真实失败保留。

## 验证
仅相关功能测试（遵从用户要求），新增回归测试、提示词差集、Harness 新项目请求验收，git diff --check，最后更新代码图谱。
