# 剧集角色同步删除与项目优先复用

- 类型：业务流程修正
- 目标：剧集删除人物同步删除对应项目角色；人物提取先匹配项目库，存在直接引用固定资料与已用图片。
- 非目标：修改每秒人物/着装协议、改成片编译、清理素材文件、按语义猜测未登记别名、恢复被删人物。
