# 创建页剧本摘要预生成

- 类型：完整流程，新功能。
- 目标：创建页独立展示「剧本」，导入或选择剧本后自动生成下方项目摘要，确认后创建项目。
- 非目标：不调整分集、剧情与媒体生成，不重复建立摘要 Model。

## 调用链与证据

创建弹窗 → 上传/选择 scripts → project-summary 草稿操作 → 独立 text task → ProjectSummaryModel → 生成/自审/修订 → 回填摘要 → createProject 验证草稿归属与剧本 → 创建并保留任务快照。

GitNexus 当前索引有效，query/context/impact 已核对 projectDialog、createProject、runProjectSummary。动态 registry、HTTP 和会话分支以源码补查。现有摘要任务只接受已创建项目；因此草稿要独立存储，不能提前创建空项目或绕过任务队列。基线702项全通过。
