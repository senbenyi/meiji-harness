# 本集角色审核防误判

- 类型：提示词契约修正
- 目标：避免把项目角色库中的 `必出` 标记误当作本集必须出场，并阻止审核结论与原因自相矛盾。
- 非目标：不改变项目级重要角色筛选、不自动增加或删除本集资产、不增加模型调用或改动任务状态流程。

## 验收标准与调研结论

| AC | 输入/状态 → 可观测结果 | 已确认/未确认/未验收 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 项目角色目录含 `必出=true`，但角色仅在本集告示/背景资料中被提及且未出镜、未发声 → 审核规则明确不得仅据 `必出` 判遗漏 | 已确认 | `projectNumberCatalog` 保留 `必出` 传入目录；旧审核模板未说明该标记的项目级范围 |
| AC-2 | 本集角色清单无可证实问题 → 模型输出通过且原因为空；若不通过 → 原因须指出同时符合本集出镜/发声及独立剧情作用的遗漏证据 | 已确认 | 用户提供的结果在 `通过=false` 后又认定清单正确；代码只校验输出结构 |
| AC-3 | 角色目录标记和单集纳入规则 → 项目文档、生成模板、审核模板口径一致 | 已确认 | 项目角色从完整剧本筛选；本集资产由单集故事小段生成 |
