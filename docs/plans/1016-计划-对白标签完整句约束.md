# 对白标签完整句约束

- 类型：规则与程序校验修复，完整流程。
- 目标：最终提示词一句台词不可拆成两个 `<d>`；多句连续发言可以整体保留，也可以在完整句之间分开。
- 非目标：不调整节拍时长、不补标点、不生成媒体、不批量改写已有项目。

| AC | 输入 → 可观测结果 | 调研状态 | 依据 |
|---|---|---|---|
| AC-1 | 同一句跨两个标签 → 拒绝并进入原修订通路 | 已确认缺口 | assertPromptDialogue 原仅拼接比较 |
