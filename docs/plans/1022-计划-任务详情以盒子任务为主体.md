# 任务详情以盒子任务为主体

- 类型：完整流程，任务历史展示及查询粒度调整。
- 目标：列表逐Task展示、详情只显示选中Task；隐藏TaskGroup身份与进度，保留底层组织调度。
- 非目标：不删除任务组、不修改任务Model/数据库结构或执行器。

## 验收标准与取证
| AC | 输入/状态 → 可观测结果 | 已确认路径 |
|---|---|---|
| AC-1 | 点击列表任务 → 标题只显示任务名，副信息含可复制ID、业务类型、时间；状态标签保留样式 | 公共task/ui当前标题是任务组详情并重复任务标题 |
| AC-2 | 详情 → 仅本任务输入、步骤、输出，无任务组ID、组标题、1/1进度或任务序号 | renderDetail目前循环所有Task，需按taskId选择 |
