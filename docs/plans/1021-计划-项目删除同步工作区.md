# 项目删除同步工作区

- 类型：完整流程，接口与删除流程修改。
- 目标：删除业务项目时同步移除对应 Harness 工作区登记。
- 非目标：不删除会话、磁盘文件及历史记录，不批量清理旧项目，不修改外部宿主。
