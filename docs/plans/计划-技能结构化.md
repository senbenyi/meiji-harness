- 类型：重构 + 新功能
- 目标：技能按字段结构化存储并由代码直接读取；新增五个指导技能；面板查看与修改基础技能（替换内置）、为本剧增补；生成、审核、修订请求按统一规则合并各层内容，规则不丢失。
- 调研与设计：`docs/research/调研-技能结构化.md`

## 约束
- 各阶段独立提交；每阶段 `npm test` 全部通过（核对失败与取消计数）、ESLint 无新增问题、架构测试通过。

## 改动

### 阶段 1：格式与加载器（输出不变）
1. `meiji/skills/stages/<id>/`、`meiji/skills/shared/` — 每个阶段技能一个目录（`skill.json` + `common.md` / `generate.md` / `review.md` / `revise.md`），按原文顺序机械拆分，内容不改 → AC-1
2. `meiji/skills/load.js` — 按字段读取；`skillText(id)` 按原顺序拼回整段供现有调用方使用；缺少字段、未知字段、未引用的文件报错 → AC-1
3. `meiji/tests/skill.test.js` — 结构校验；全部阶段三类请求与改造前逐字相同（快照对比）→ AC-1

### 阶段 2：按请求类型组装
1. `meiji/server/prompts/text-prompts.js` — 按调研第 5 节组装生成、人工意见修改、审核、自动修订；审核不再附整份生成技能 → AC-2
2. 程序解析依赖的格式说明移入代码持有的协议；流程说明不再发给模型 → AC-4、AC-11
3. `meiji/scripts/prompt-diff.js`（开发脚本）— 按阶段与请求类型输出新旧提示词的句子差集 → AC-6

### 阶段 3：共享模块与通用审核拆分
1. `skill-gongyong-content-review` → `shared/review-protocol.md` 与 `shared/camera-review.md`；阶段专属条目并入各阶段 `review.md`；尾帧协议、修订边界、修订范围审核合并为共享模块 → AC-3、AC-4

### 阶段 4：官方参考按模式注入、图片技能清理
1. `skill.json` 的 `references` 按模式登记，文本分镜只带当前模式参考；审核不带官方参考 → AC-5
2. 人物、场景、部件、铅笔分镜技能只保留画面要求，去掉面向文本模型的说明与官方工作流原文 → AC-7
3. 删除 `skill-chengpian-video-generate`，不重复条目并入文本分镜；Harness 只注册 `skill-gongyong-panel-generate` → AC-8

### 阶段 5：指导技能
1. `meiji/skills/guidance/{action,martial,dialogue,expression,sound}/` — `skill.json`（阶段落点、素材分类、默认启用）、`common.md`、`review.md`、`stages/<阶段>.md` → AC-14
2. 从阶段技能与通用审核中移出动作、台词、表情、声音相关条目到对应指导技能；武术指导新写 → AC-14、AC-6
3. `meiji/shared/guidance.js` — 素材分类增加「武术」，阶段落点改由指导技能提供 → AC-14
4. `text-prompts.js` — 组装时加入启用且适用本阶段的指导技能（生成要求进 system，审核条目进验收标准，素材按指导分组进 user）→ AC-14

### 阶段 6：基础修改层（全局）

## 验收标准
- AC-1：技能按字段结构化存储，加载器直接读取；结构错误在测试中报错；阶段 1 全部提示词与改造前逐字相同。
- AC-2：生成、审核、修订请求只包含各自需要的内容；审核请求不再附整份生成技能与官方参考。
- AC-3：通用审核只含跨阶段协议；各阶段审核只含本阶段规则。
- AC-4：重复段落只保留一份共享模块；流程说明不再发给模型。
- AC-5：文本分镜只注入当前模式的官方参考。
- AC-6：差集报告中每个删除或移动的条目都有去向或理由，记入实施记录。
- AC-7：图片接口提示词不含面向文本模型的说明。
- AC-8：Harness 只注册会话 agent 使用的技能。
- AC-9：文档与代码一致；请求次数、顺序、输出协议与解析不变。
- AC-10：基础修改存于运行数据目录，按字段替换内置；插件升级不覆盖；可恢复内置与撤回上一版。
- AC-11：程序解析依赖的协议不可编辑，任何修改都不改变输出格式与解析。
- AC-12：同一任务内所有请求使用同一技能组合版本；任务记录与历史显示所用技能与层。
- AC-13：各阶段「查看 skill」进入详情页，可查看、编辑基础、增补本剧、启用指导、预览三种请求；会话 agent 不能修改技能。
- AC-14：五个指导技能独立维护，按阶段落点加入启用它们的请求；指导素材按指导分组；武术分类可用。
- AC-15：本剧补充按「基础 + 本剧」合并，优先级按调研第 3 节写入提示词；现有按集的补充迁移后内容不丢失。
