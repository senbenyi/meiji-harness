# 彻底删除本集资产

- 类型：重构
- 目标：移除“本集资产”节点和工作流，镜头表提示词直接使用项目人物库资料。
- 非目标：不重写后续每秒分镜、视频的人物关联行为；保留不可变历史任务记录。

## 调用链与证据
项目 JSON 由 `SQLiteStore.read` 读出，`ModelRepository.#read` 立即执行 `validateSnapshot` / `validateProject`；项目结构变化需要在 SQLite 启动升级时清除旧剧集字段，不能只改新建模型。面板 `renderEpisode` 通过 `episodeTabs` 显示镜头表及当前资产卡片。任务业务由 `task-contract` 定位节点、`precheck` 校验前置、`node-state` 建立节点状态、`node-dependencies` 传播过期；`TaskService` 建任务组并追加 workflow，`content` 写回及派生图片。文本入口 `createTextHandler → promptValues → renderTemplate` 向 shots YAML 注入本集资产和项目角色库目录。

GitNexus `shotTableForPrompt` upstream impact：risk `CRITICAL`、90 个符号、12 个模块；shared axes `MEDIUM`。这是共享文本 handler 引起的宽影响估算，本次保持局限于 shots promptValues 资料构建器。

## 待用户决定
无。保留终态历史任务记录，不再提供本集资产任务入口；SQLite 升级删除每集字段和对应规则引用，将活动资产任务及未完成步骤标为已作废。

## 改动
### 阶段 1：数据结构与存储
1. `meiji/shared/project-contract.js` — 空剧集、验证及字段映射中删除节点；`project_detail.json` 同步删除 → AC-1。
2. `meiji/server/data/sqlite-store.js`、`schema.sql` — 新库升至 version 2；旧 version 1 事务性地移除 `projects.data_json` 各集资产字段及规则引用、增加受影响项目 revision、作废活动资产任务并记录迁移 → AC-2、AC-6。

### 阶段 2：任务执行链
1. `meiji/server/flow/tasks/precheck.js`、`shared/node-state.js`、`shared/node-dependencies.js` — 删除资产节点，镜头表只需大纲、每秒分镜只需镜头表 → AC-4、AC-6。
2. `shared/task-contract.js`、`shared/task-labels.js`、`server/flow/tasks/task-service.js`、`server/handlers/content.js`、客户端历史名称 — 阻止创建资产任务，去掉工作流及图片派生；旧历史组继续时跳过已移除业务，保留历史读取 → AC-6。

### 阶段 3：界面、提示词与文档
1. `meiji/client/project-ui.js` — 镜头表标签只渲染镜头表，人物资料只保留项目角色区 → AC-3。
2. `meiji/server/handlers/text-handler.js`、`meiji/dev_docs/in_puts/shots-*.yaml` — 移除资产占位符，人物目录使用项目角色库 → AC-5。
3. 三份开发契约、`step_model.json`、README、节点/任务/提示词测试 — 同步移除已废弃业务 → AC-6、AC-7。
