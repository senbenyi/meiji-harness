# 共用项目弹框与双入口导入

- 类型：完整流程，UI共用表单及基础资料/原稿联合原子保存。
- 目标：编辑与添加共用projectDialog，项目原稿页只有本地导入/素材库导入，不提供正文编辑。
- 非目标：不清空/迁移数据、不改既有来源/下游引用、模型流程及图片素材库，不自动删除旧原稿。
