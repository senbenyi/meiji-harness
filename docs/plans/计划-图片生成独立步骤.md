## 改动
1. meiji/server/flow/operations/registry.js — 四种图片操作共用四步计划 → AC-1。
2. meiji/server/generate/gateway.js — 可选 stepTarget，POST、下载和编码各用 runStep；不传目标的直接调用保持行为 → AC-2。
3. meiji/server/generate/image.js — 三个生成函数传递 stepTarget、onSaved，保存处理及候选登记由 image_save 包含；ComfyUI 用 image_generate → AC-2、AC-3。
4. meiji/server/flow/operations/images.js — 移除包住整个流程的生成步骤，传递步骤目标和候选登记回调 → AC-1、AC-3。
5. meiji/client/task-steps.js — 四个中文标签 → AC-3。
6. meiji/tests/character-image-edit.test.js、operations.test.js、api-failure-state.test.js、gateway.test.js、image.test.js — 更新计划与注入依赖，验证成功顺序、错误定位、跳过和保存 → AC-1/2/3。
7. meiji/docs/tasks-and-steps.md、.agents/architecture.md — 记录图片四步执行语义 → AC-3。

## 验收标准
- AC-1：图片、修改、部件及铅笔分镜计划依次包含调用 API、下载图片、转 Base64、保存候选图片，目标匹配且不产生计划外步骤。
- AC-2：URL 分支四步顺序执行，失败和取消定位到当前步骤，后续不执行；旧 b64_json 和 ComfyUI 不需要的步骤正常跳过。
- AC-3：保存步骤覆盖图片处理、候选文件保存与项目候选登记；UI 显示四步中文名称；输入、确认使用和生成结果保持原有行为。
