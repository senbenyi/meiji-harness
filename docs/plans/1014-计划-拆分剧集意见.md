# 拆分剧集意见

- 类型：完整流程
- 目标：剧本模式的剧集卡可以填写本次执行意见，拆分和重新拆分都把这段意见交给本次任务。
- 非目标：不给任务组加意见框，不把意见写入项目。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 已确认/未确认/未验收 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 剧本模式的剧集卡有「本次执行意见」；提交拆分或重新拆分时，非空意见写入本次 `script-split` 任务 | 已确认 | 按钮现在只提交时长和动作，命令不带 `opinion`。重新拆分的提示已有修改意见；首次拆分的生成提示没有 |
| AC-2 | 意见只留在当前页面。任务成功后清空；失败或未通过保留；刷新后消失 | 已确认 | 节点意见存在 `state.opinions`，不写入项目 |

## 改动
1. `meiji/client/project-ui.js:renderOverview` — 剧集卡增加意见输入，提交时附上 → AC-1、AC-2
2. `meiji/server/prompts/models/script-split.js` 与 `meiji/server/http/nodes/script-split.js` — 首次拆分的生成提示也能写入修改意见，空意见不出现 → AC-1
3. `meiji/server/handlers/node-inputs.js:taskNodeInput` — 首次拆分把任务意见放进生成输入 → AC-1
4. `meiji/tests/stage09-script-split.test.js` — 面板提交带意见，生成提示含意见 → AC-1

验证：`cd meiji && node --test tests/stage09-script-split.test.js tests/stage07-panel.test.js` — 通过。
