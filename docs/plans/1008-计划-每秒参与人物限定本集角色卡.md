# 每秒参与人物限定本集角色卡

- 类型：业务规则修正
- 目标：每秒指令participants只从本集角色卡中选取本镜实际参与的人物。
- 非目标：自动创建人物、修改镜头表、输出固定人物资料、改历史指令/对白、全项目角色自动加入本集。
