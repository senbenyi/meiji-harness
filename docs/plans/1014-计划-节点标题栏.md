# 节点标题栏

- 类型：新功能
- 目标：节点卡片标题下复用同一块公共 UI；逐镜头成片和生成定妆照两处复用组任务 UI。
- 非目标：不恢复已删除的项目规则；不改各节点的生成、审核和保存逻辑；项目概要上的角色格子不放节点标题栏；不增加开始、移除，也不把继续放到单个节点上；不从数据模型和大纲提示里删除已有的 `episode_requirements`。

## 节点公共 UI
卡片标题旁不再放状态。标题下面，从上到下各占一排：

1. 状态
2. 操作按钮
3. 一行输入框，占位文字「本次执行意见」
4. 未通过或失败时的说明

按钮从左到右只放该节点用得到的项：

1. 节点状态：未生成、生成中、已生成、未通过、失败、已取消、已过期
2. 任务状态：仅当这个节点自己有排队或正在运行的任务时显示排队中或生成中
3. 主操作
4. 按意见修改
5. 人工编辑
6. 人工放行
7. 任务历史
8. 取消

排队或运行时藏起主操作、按意见修改、人工编辑和人工放行。取消只在该节点有排队或运行中的任务时出现，并且仍可点。任务历史始终可点。

节点上不放开始、移除、继续。流程由程序排定，不从节点上把排队任务抽走。

项目摘要和本集摘要不放人工编辑，也不放人工放行。补充规则不进入这块 UI。

### 本次执行意见
输入框只留在当前页面内存。点主操作或按意见修改时，把框里的文字作为这一次任务的意见提交。任务记录上仍保存这一次执行带上的意见，供当次生成使用。节点和项目模型不新增字段保存这份草稿。

任务成功后清空输入框。失败或未通过时保留框里的字，方便原样再提交。刷新或重新打开页面后输入框为空。

未通过时，程序仍把节点 `reason` 拼进这一次意见。`fail_message` 不拼进去。

### 未通过和失败说明
放在本次执行意见下方。未通过展示 `reason`。失败展示 `fail_message`。已取消和已过期不在这里展示。

`node_state` 增加 `fail_message`：

| 状态 | `reason` | `fail_message` |
|---|---|---|
| 未生成、生成中、已生成 | 空 | 空 |
| 未通过 | 交给 AI 的原因，时长不合适这类程序审核也写在这里 | 空 |
| 失败 | 空 | 前置不足、接口、解析等不能交给 AI 的原因 |
| 已取消、已过期 | 沿用现在的原因 | 空 |

已有失败节点在打开时把原来的 `reason` 移到 `fail_message`，并清空 `reason`，避免旧的失败说明被当成修改意见。未通过节点的 `reason` 保持不动。排队快照一并带上 `fail_message`，取消排队时按快照写回。

## 组任务 UI
只给两个任务组用：

| 组 | 放在哪里 | 现在的提交 |
|---|---|---|
| 逐镜头成片 | 成片页镜头列表上方 | `submit-group`，`group_type=episode-film`，一次安排本集各镜 |
| 生成定妆照 | 项目详情里，提取人物卡后面单独一张卡 | `submit-costumes`，按人物顺序逐个提交，每人再按服装成组 |

标题下面各占一排：状态、操作按钮、失败或未通过原因。没有本次执行意见。

状态用组状态：排队中、生成中、已通过、未通过、失败、已取消、已作废。按钮是主操作、继续、任务历史、取消。组停在失败、未通过、已取消或已作废，且组内没有排队或运行中的任务时出现继续。组内有排队或运行中的任务时出现取消。失败或未通过时，第三排展示停下的那个节点的 `fail_message` 或 `reason`。

组标题栏不放开始、移除、人工编辑、人工放行，也不放本次执行意见。继续只出现在这里。任务历史页里查看某一组时，仍可对该组继续；历史列表不再放开始和移除。

组正在排队或运行时，藏起主操作和继续。

## 每个节点的按钮

文字节点的公共一组是：主操作、按意见修改、人工编辑、人工放行、任务历史、取消，再加上本次执行意见，以及未通过或失败时的说明。项目摘要和本集摘要从按钮里拿掉人工编辑和人工放行，意见输入和说明仍在。

### 项目概要
| 卡片 | 组件 | 主操作 | 其余 |
|---|---|---|---|
| 项目摘要 | 节点公共 UI | 无内容：AI生成；有内容：重新生成 | 按意见修改、任务历史、取消、本次执行意见、未通过或失败说明 |
| 剧本 | 不用 | 无 | 只保留打开剧本 |
| 剧集 | 不用在每一集上 | 剧本模式：拆分剧集或重新拆分剧集；自由模式：新增剧集 | 拆分任务的状态和任务历史留在「剧集」这一组的标题上 |
| 提取人物 | 节点公共 UI，按文本节点 | 无角色：AI生成；已有角色：重新生成 | 按意见修改、人工编辑、人工放行、任务历史、取消、本次执行意见、未通过或失败说明。内容区是人物格子：头像、名字、进入详情。格上没有标题栏，也没有生成定妆照 |
| 生成定妆照 | 单独卡片，紧跟提取人物卡，组任务 UI | 尚无定妆照：生成定妆照；已有定妆照：重新生成定妆照 | 组状态、进度、继续、任务历史、取消。这张卡不画人物格子，生成结果写回提取人物卡里已有的人物 |

### 人物

| 历史未绑定定妆照 | 节点公共 UI，只读 | 无 | 节点状态和任务历史。不放意见输入 |

剧集页顶部的「编辑本集要求」去掉。该对话框里的参考时长若仍要修改，单独留编辑时长。新增剧集对话框不再收集本集要求。已保存的 `episode_requirements` 和大纲提示里的本集要求这次不删。

### 成片
镜头列表上方是逐镜头成片的组任务 UI。主操作是生成本集成片或重新生成本集成片。停住后用继续从停点接着做。取消作用在组内当前任务上。

每个镜头是一张独立节点卡，用节点公共 UI：

| 卡片 | 主操作 | 其余 |
|---|---|---|
| 成片列表中的一个镜头 | 该镜还没有视频：生成；已有视频：重新生成 | 节点状态取该镜视频；任务状态取该镜自己的视频任务；任务历史；打开镜头；本次执行意见；未通过或失败说明。识别、每秒、文本和尾帧的状态写在卡片正文里 |

打开某一个镜头后，里面的步骤各自再用节点公共 UI：

| 卡片 | 主操作 | 其余 |
|---|---|---|
| 镜头角色与服装 | AI生成或重新生成 | 文字节点公共一组 |
| 每秒分镜 | 同上 | 文字节点公共一组 |
| 分镜提示词 | 同上 | 文字节点公共一组 |
| 首尾帧参数编排或多模态参数编排 | 无结果：执行编排；已有结果：重新编排 | 任务历史、取消、本次执行意见、未通过或失败说明 |
| 视频 | 无视频：生成；已有视频：重新生成。提交的是这一镜 | 按意见修改、人工编辑（导入视频）、人工放行、任务历史、取消、本次执行意见、未通过或失败说明 |
| 尾帧 | 无 | 只读：节点状态和任务历史 |

文生镜头不显示参数编排卡。首尾帧只显示首尾帧编排，多模态只显示多模态编排。
