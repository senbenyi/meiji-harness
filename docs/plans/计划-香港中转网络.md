# 香港中转网络

- 类型：新功能（基础设施）
- 目标：香港作为网关——GPU 服务经反向隧道汇聚到香港，nginx:80 按路径对外；本机 Harness 直连 `http://43.154.247.11/{comfy,qwen}`，本机不再依赖任何 SSH 隧道。
- 调研来源：`docs/research/调研-香港中转网络.md`
- 约束：**任何服务器（香港、两台 GPU 容器）都不重启**；香港只做 `systemctl reload`、运行时 sysctl、新增服务；GPU 只重启隧道进程，不触碰 ComfyUI（6016）、llama-server（8000）。

#### 4.2 香港 nginx 网关
1. 香港 — 新增：`apt-get install nginx`；`/etc/nginx/sites-available/gateway`；删除 `sites-enabled/default`；只 `reload` → AC-8
2. 香港 — 删除：`gost-gateway.service`（`disable --now`、删 unit、`daemon-reload`）→ AC-5

执行（本机）：
```bash
ssh veo-hk 'set -e
sudo DEBIAN_FRONTEND=noninteractive apt-get install -y -qq nginx >/dev/null
sudo tee /etc/nginx/sites-available/gateway >/dev/null <<"EOF"
# 香港网关：80 按路径转发到 GPU 反向隧道（127.0.0.1:26016 comfyui / 28000 qwen38）
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    client_max_body_size 512m;
    proxy_http_version 1.1;
    proxy_buffering off;
    proxy_request_buffering off;
    proxy_read_timeout 600s;
    proxy_send_timeout 600s;
    location /comfy/ { proxy_pass http://127.0.0.1:26016/; }
    location /qwen/  { proxy_pass http://127.0.0.1:28000/; }
    location / { return 404; }
}
EOF
sudo rm -f /etc/nginx/sites-enabled/default
sudo ln -sf /etc/nginx/sites-available/gateway /etc/nginx/sites-enabled/gateway
sudo nginx -t
sudo systemctl reload nginx
sudo systemctl disable --now gost-gateway
sudo rm -f /etc/systemd/system/gost-gateway.service
sudo systemctl daemon-reload'
```

## 验收标准
- AC-1：两台 GPU 机向香港建立反向隧道；杀掉 GPU 端隧道进程或断开香港端 `tunnel` 会话后，60 秒内无人工介入自动恢复。
- AC-2：隧道进程全部停止后，经任一入口登录一次即自动拉起且只运行一份；不重启服务器，以模拟方式验证。
- AC-3：本机 `ssh veo-comfyui` / `ssh veo-qwen38` 经 `veo-hk` 跳转登录成功（运维用途），主机密钥校验不降级。
- AC-4：本机 Harness 的 ComfyUI 与聊天模型均直连 `http://43.154.247.11/...`；设置页"连接"后 `pgrep -fl 'ssh -M'` 为空；两地址各 100 次 0 失败、p95 < 1s。
- AC-5：香港公网只监听 22、80；`22001/22002/26016/28000/7890` 均绑 127.0.0.1；`tunnel` 密钥不能取得 shell，只能监听各自端口。
- AC-6：`-direct` 别名直连可用。
- AC-7（可选）：`veo-comfyui` 经香港代理访问 GitHub、HuggingFace 返回 200。
- AC-8：nginx `/comfy/` → 6016、`/qwen/` → 8000，其他路径 404；流式输出与大文件不被截断。
- AC-9：聊天 `tunnel.transport: 'http'` 通过校验、不解析 SSH 身份、不建隧道；`ssh` 行为不变。
