# 香港中转网络

- 类型：新功能（基础设施）
- 目标：GPU 机主动向香港建立反向 SSH 隧道，本机只经香港跳转，消除跨境丢包；项目代码不变。
- 调研来源：`docs/research/调研-香港中转网络.md`
- 约束：**任何服务器（香港、两台 GPU 容器）都不重启**；香港只做 `systemctl reload ssh` 与运行时 sysctl，GPU 只新增后台进程，不触碰 ComfyUI、llama-server。

### 阶段 2：GPU 端反向隧道（comfyui 先做，验证后复制到 qwen38）
1. GPU `/root/.ssh/id_ed25519_relay` — 新增：在 GPU 上本地生成，私钥不离开该机 → AC-5
2. 香港 `~tunnel/.ssh/authorized_keys` — 新增一行/机：`permitlisten="127.0.0.1:2200x" ssh-ed25519 …`（comfyui=22001，qwen38=22002）→ AC-5
3. GPU `/root/autodl-tmp/relay/tunnel.sh` — 新增守护循环（纯 ssh，不依赖 autossh，不受代理变量影响）：
   ```bash
   #!/bin/bash
   # 职责：保持到香港中转的反向 SSH 隧道，断开后自动重连。
   exec 9>/tmp/relay-tunnel.lock; flock -n 9 || exit 0
   while true; do
     ssh -N -i /root/.ssh/id_ed25519_relay -o BatchMode=yes -o ExitOnForwardFailure=yes \
       -o ServerAliveInterval=15 -o ServerAliveCountMax=3 -o ConnectTimeout=10 \
       -o StrictHostKeyChecking=yes -R 127.0.0.1:${RELAY_PORT}:127.0.0.1:22 tunnel@43.154.247.11
     sleep 10
   done
   ```
   香港主机密钥预先写入 GPU `known_hosts`（指纹须为 `SHA256:WIGLYIOwQuWfD2gcqnQYYwby47Pd+6zt/QRta2bWOaw`）→ AC-1
4. GPU `/root/.bashrc` — 在文件顶部（非交互提前返回的判断之前）新增一行，带 `# relay-tunnel` 标记便于回滚：`(RELAY_PORT=2200x setsid nohup /root/autodl-tmp/relay/tunnel.sh >>/root/autodl-tmp/relay/tunnel.log 2>&1 &)`；子 shell 形式避免交互终端打印作业号，`setsid` 使其脱离登录会话；`flock` 保证多次登录只运行一份；首次部署时直接执行同一命令启动 → AC-2
5. 验证 `tunnel` 受限：GPU 上 `ssh … tunnel@hk` 无法得到 shell，`-R 127.0.0.1:22009` 被拒 → AC-5

验证：
- 香港 `ss -ltn | grep 2200` 只见 `127.0.0.1:22001/22002` → AC-1、AC-5
- GPU 上 `pkill -f 'ssh -N -i /root/.ssh/id_ed25519_relay'`（只杀 ssh 子进程），守护循环 60 秒内重连，香港重新出现监听；香港 `sudo pkill -u tunnel sshd`（只断隧道会话）后同样恢复 → AC-1

## 验收标准
- AC-1：两台 GPU 机向香港建立反向隧道；杀掉 GPU 端隧道进程或断开香港端 `tunnel` 会话后，60 秒内无人工介入自动恢复。
- AC-2：隧道进程全部停止后，经任一入口（直连 SSH、AutoDL 网页终端）登录一次即自动拉起且只运行一份；不重启服务器，以模拟方式验证。
- AC-3：本机 `ssh veo-comfyui` / `ssh veo-qwen38` 经 `veo-hk` 跳转登录成功，`ssh -G` 显示 `proxyjump veo-hk`，主机密钥校验不降级。
- AC-4：不改代码，项目按需建立的 18000（`/v1/models`）与 16016（`/system_stats`）隧道可用；各连续 100 次请求 0 失败，p95 < 1s。
- AC-5：香港公网端口不新增；反向监听只绑定 `127.0.0.1`；GPU 端密钥在香港不能取得 shell，只能监听各自端口。
- AC-6：`veo-comfyui-direct` / `veo-qwen38-direct` 直连可用；恢复 `~/.ssh/config.bak` 即回退。
- AC-7（可选）：`veo-comfyui` 经香港代理访问 GitHub、HuggingFace 返回 200。
