# 角色图规则精简

- 类型：提示词调整，完整流程（模板、测试、文档）。
- 目标：角色图生成和重新生成只保留必要要求，删除重复及矛盾指令。
- 非目标：不改图片供应商、人物资料、定妆照/视频规则及用户自定义补充规则。

## 验收标准与取证
| AC | 输入 → 输出 | 证据 |
|---|---|---|
| AC-1 | 角色图生成 → 人物依据、单人全身 3/4、纯色背景、身材呈现、无文字只各说明一次 | 实际历史请求多处重复一张、裸露、身材，且无字与语言要求矛盾 |
| AC-2 | 参考图或修改意见 → 资料与必要限制保留 | media-handler 已单独注入参考图片说明；regenerate 使用意见字段 |
| AC-3 | 渲染后 → 字数明显减少，图片返回类型不变 | 渲染测试与原请求对比 |

## 调用链
createMediaHandler → loadTemplate(character-image-generate/regenerate) → renderTemplate → gateway.image(prompt.body)。只修改配置内容，不改执行函数。
