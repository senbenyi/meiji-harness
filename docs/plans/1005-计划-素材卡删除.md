# 素材卡删除

- 类型：新功能（完整流程）
- 目标：素材库七类卡片均可删除；按用户选择仅移出素材库，保留项目已有引用及原文件。
- 非目标：不删除项目库条目、不清理磁盘文件、不改变项目基调、不修改已有项目或历史快照。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 状态 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 七类素材卡 → 均提供删除按钮；取消不请求，确认执行删除 | 已确认 | client/asset-library-view.js 共用 assetLibrary 渲染循环，目前仅下载 |
| AC-2 | 删除成功 → 当前分类刷新、空列表有提示；切换分类不会串页；失败保留卡片并可重试 | 未验收 | 需补交互测试 |
| AC-3 | 素材删除 → 新列表不显示，重新打开仍不显示，已有引用和原文件可读 | 已确认 | 用户选择仅从库移除；data/asset-library-store.js 的 list 与 file 分离，可以只过滤列表 |

## 调用链与证据
当前：renderLibrary → assetLibrary → GET assets → assetStore.list；图片/指导/剧本通过 assetStore.file/script 读取原文件。
新增：卡片 → actions.deleteLibrary → bridge.perform → /turn → operation-manager → library-delete → assetStore.remove。
