# 大纲审核证据边界

- 类型：完整流程，业务规则与实际提示词调整。
- 目标：只按最新候选当前存在且有据可核的问题审核；修订先核实意见，避免无依据改动。
- 非目标：不以历史意见作为最新候选约束，不改变输出结构、轮次上限、模型或大纲内容，不自动重新生成。

## 验收与依据
| AC | 输入/状态 → 结果 | 证据 |
|---|---|---|
| AC-1 | 最新候选已明确犬只数量 → 不因措辞差异重复否决 | 真实记录最后已写各一匹共两匹，仍被判数量不清 |
| AC-2 | 门关闭后无相反动作 → 不强制反复声明关闭；合理补充不因原稿未写否决 | 真实记录上一轮要求补持续关闭，后一轮要求删 |
| AC-3 | 时间信息有歧义 → 区分实际自相矛盾与未明确的时间关系，不擅自锁定原稿未明确的秒点 | 原稿给月球经过时刻及倒数台词，未逐一约束动作时间 |
| AC-4 | 修订收到意见 → 先按最新候选和工作稿核实，只修仍成立的问题 | 原整轮修订提示要求逐项执行全部review_issues |
| AC-5 | 当前项目与新项目 → 均使用新规则；原稿/大纲/历史记录及补充规则保留 | 默认仅影响新节点，须显式更新目标项目保存规则 |
