# 多模态前镜尾帧衔接

- 类型：完整流程；公共素材选择、程序编排与依赖传播。
- 目标：同场景同状态连续接拍的多模态镜头，在人物/场景图后附有效前镜尾帧，由程序填写首帧衔接引用及职责，不增加AI调用。
- 非目标：更改项目/task/step/group字段定义、供应商接口强制首帧、自动修改当前生产镜头、额外视觉识别或改写已审核三段。

## 验收标准与调研结论
