# 摘要保存与后台回写

- 类型：业务流程修复（完整流程）
- 目标：剧本模式保存摘要不自动回写，自由模式后台回写，新增/编辑剧集弹框不显示步骤和执行状态、保存成功立即关闭。
- 非目标：不删除任务历史，不改摘要生成协议，不改变自由模式修改旧剧本须确认方案的规则，不改其他素材生成流程。

## 调用链与证据
新增剧集 → episodeDialog → generateEpisodeDraft（草稿 Run，无回写）→ 用户保存 → bridge.perform → turn → immediate-service → opEpisodeAdd → runs.contentChanged → plan/confirm(script-sync) → 后台引擎。
当前弹框通过 observeSync 等待后台 Run，并展示进度、待确认方案按钮；直接生成摘要也通过 planRun 自动追加回写。
