删句人工核对（prompt-diff 标注的 126 条为多个请求重复统计）：
| 原规则类别 | 去向/合并理由 |
|---|---|
| 本镜事实、直接叙事、不补栏目、意见冲突与前镜范围 | 保留模型 secondsBoundary/secondsReviewMethod；skill 仅留阶段依据与必要交接 |
| durationMs 正整数及合计、逐句唯一引用、JSON 字段、实体 ID 标注 | 现有 output-protocols.seconds 与程序校验保持；skill 保留时点一致性与跨段延续 |
| 整镜 beat、拆段条件、微动作、无固定配额 | 生成“分段与时间”、审核“分段验收”合并 |
| 起止状态、切点、持物、动作完成、声音继承 | 时间状态条目合并，不删除真实连续性约束 |
| 动作、打斗、空间、地标、光位、身体身份 | 各归并到动作空间条目，去掉重复例举 |
| 机位、景别、构图、露脸、cut/continue、人物上限 | 摄影条目保留；连续拍摄可含多动作由首条 beat 定义覆盖 |
| 对白、旁白、声源、静默、特效、简洁执行正文 | 声音与执行规则合并；旁白字段与协议一致 |
| 审核证据、去重、location、不得改上游、程序与语义职责 | secondsReviewMethod 继续注入；审核 skill 留实质矛盾与最小修正原则 |
