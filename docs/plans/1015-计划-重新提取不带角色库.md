# 提取角色不提交已有角色库

- 类型：Bug 修复，完整流程。
- 目标：首次生成和重新生成提取剧本重要角色时使用同一提示词，只按完整剧本提取，不提交已有角色库。
- 非目标：不改定妆照提示词、不改已保存角色与图片、不因模型未返回而删除旧角色。

## 验收
- AC1：已有角色库时，首次生成和重新生成的首轮提示词完全相同。
- AC2：该提示词没有「项目角色库目录」和库内人物资料，只有完整剧本等本次资料。
- AC3：输出约定要求返回剧本中应保留的全部重要角色。程序仍按姓名合并，未返回的旧角色不删除。审核不对照角色库判断遗漏。

## 调用链
面板 AI生成 / 重新生成 → TaskService → text-handler（两按钮的首轮都走 generate）→ taskNodeInput → renderPrompt。原先 generate 用户消息写入「项目角色库目录」。

## 改动
1. `meiji/server/prompts/models/project-characters.js` — 生成提示词去掉角色库目录，规则改为只依据剧本返回全部重要角色。
2. `meiji/server/http/nodes/project-characters.js` — 不再把角色库编进提示词资料；输出要求改为完整名单。
3. `meiji/server/handlers/text-handler.js` — 生成与修订清空角色库输入；审核仍可读取，但提示词模板不再使用。
4. 规格与测试同步。

## 验证结果
AC1–AC3 由 `tests/stage05-text-tasks.test.js` 覆盖并通过。全量 435 项中 434 通过；既有失败「恢复组合failed时旧失败组不再提示继续」与本次无关。`git diff --check` 通过。
