# 重新提取角色不提交已有角色库

- 类型：Bug 修复，完整流程。
- 目标：点击「重新生成」提取剧本重要角色时，提示词不包含已有项目角色库。
- 非目标：不改首次生成的增量匹配、不改审核仍对照角色库、不改定妆照提示词、不改已保存的角色与图片。

## 验收
- AC1：`task.action=regenerate` 的首轮生成提示词没有「项目角色库目录」和库内人物资料。
- AC2：首次 `generate` 仍提交角色库目录。审核仍提交角色库目录。
- AC3：未提供目录时，输出约定要求按剧本返回应保留的全部重要角色，而不是空增量。程序仍按姓名合并，未返回的旧角色不删除。

## 调用链
面板重新生成 → TaskService → text-handler（重新生成的首轮仍走 generate）→ taskNodeInput 读入 `projectNumberCatalog` → renderPrompt 写入「项目角色库目录」。

最新一次生产任务 `t_3ac92377` 的 generate 提示词含 7 名已有角色，字段包括 `costume_images`。
