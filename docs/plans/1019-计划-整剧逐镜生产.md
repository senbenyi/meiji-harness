# 整剧逐镜生产

- 类型：完整流程，项目契约、任务编排、提示词和界面改动。
- 目标：导入完整剧本后提供非约束性参考时长，整剧改编不设总预算，逐镜完成镜头设计→每秒分镜→文本提示词，媒体编排和视频独立展示与执行。
- 非目标：自动合并或删除旧多集项目的镜头与媒体；把参考时长作为生成/审核限制；为降低返工牺牲原文重要描述和对白容量；生成实际媒体进行验证。
- 当前基线：4466a866（671测试通过），分支feat/whole-script-shot-workflow。

## 待确认字段方案（确认前不修改契约、模型或持久化逻辑）
1. 新增script.estimated_duration_seconds：非负数，默认0代表未估计；导入AI估算，只展示，不入时长预算。
2. 删除project.reference_episode_duration_seconds、episodes[].duration_seconds、episodes[].story_outline.segments[].duration_seconds；保留shot.duration_seconds及actual_duration_seconds。旧值随完整备份保留，不伪装成新的估计结果。
3. 新增shots[].source_progress={segment_sequence:0,offset:0}，两个非负整数；指向整剧改编正文中首个尚未完整覆盖的位置，offset按该段原字符串UTF-16索引。新镜可在同一句动作未完成时保持游标，由既有end_state/pending_actions/pending_dialogue说明镜内进度；对话按实际已说原文推进。程序校验范围与单调性，AI审核实际内容覆盖；不因游标数值正确就认为剧情已完成。旧镜默认0表示尚未建立进度，不猜测回填。
4. 保留episodes作为单一生产容器，不迁动镜头/媒体层级；新导入仅1个。outline整剧改编作为下游唯一改编正文；script.body保持当前源正文，停止新执行script-review和script-split，旧任务仍可只读识别，历史结果不重写；其规则字段保留为历史快照，不参与新流程。outline.rules继续对应生成/审核/修订。
5. group_type枚举新增episode-text和shot-text：分别继续整剧文本链、修复当前镜文本；新提交episode-film只编排媒体，不再生成文本。已存任务组的任务顺序和prompt/http不改。Task/step无新增字段，业务类型shots沿用episode目标，但新生成仅提交一镜候选并原子追加；修订只针对当前镜，不重排已完成镜头。

## 验证计划
- 参考估计极大/极小不改变改编、分镜的接受结果；原预算边界不再阻断。
- 一句话跨多镜/对白跨镜，进度可保持或前进，未完对白不会重复也不会漏；越界/倒退/直接空跳完成拒绝。
- 下一镜添加不使前镜过期；已有镜修改触发真实依赖变化；失败候选不覆盖有效前镜。
- 节点运行期间刷新、重启恢复、重复请求，只有同一当前镜和既有任务，不重复追加。
- 文本失败不提交媒体；媒体继续不重新执行有效文本；全部正文覆盖且无遗漏才允许完结/最终合片。
