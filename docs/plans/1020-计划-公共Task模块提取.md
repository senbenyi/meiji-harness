# 公共 Task 模块提取

- 类型：重构 / 新公共能力，完整流程。
- 目标：提供独立 task 包，覆盖四个 Model、历史全套 UI、任务组调度与执行记录。
- 非目标：按用户后续明确要求，不兼容、不修改 meiji 运行链和持久化数据；业务规则、节点定位、视频编排、项目资料均不进入公共包。

## 调用链与证据
GitNexus query/context 确认 renderHistory 由 renderTaskPanel 与历史/记录测试调用，内部依赖项目标签、路由和 task-records 缓存。TaskService 同时引用业务 repair-policy、video-inputs、node-dependencies，不整体照搬。新包注册节点执行计划与执行器，存储和 scope 从外部传入。

公共 http-client/request.js 先 record(transfer) 再原对象更新，失败/成功还会再次回调；公共 task 为每次请求赋 ID 并按对象身份更新，避免保存两条。提示词由 recordPrompt 接受 composer messages，只保留实际消息，不重新渲染历史。

新增公共代码无现有符号可做 impact。改动工程验证入口前执行文件 impact；verify-install 为 UNKNOWN，源码确认 package.json 的 npm 入口。不修改 meiji 的原 Model、数据库或 UI。

## 待用户决定
无。使用 MemoryTaskStore / SQLiteTaskStore；队列隔离 scope 是存储/调用参数，不加入 Model，不解析 metadata.project_id。业务结果的同步 commit 回调与 SQLite task 事务可共享数据库连接；不对外部系统写入承诺跨库原子性。
