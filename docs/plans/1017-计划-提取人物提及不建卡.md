# 提取人物：仅被提及不建卡

## 问题

生成规则要求仅被提及的人不建卡。审核规则又把「遗漏原文明示的具名重要角色」判为不通过，并把修改意见当成剧本事实。只被借用方法的姓名会被反复要求补入，修订再按生成规则删掉。

## 规则

生成、重新生成和审核使用同一纳入口径：须有明确姓名，且在剧本中实际出镜或发声，并承担独立剧情作用。仅被提及、名单展示、背景介绍，或只被借用其方法、发明、言论的人，不建卡。

审核不得因未列入这类人判不通过，也不得因修改意见要求补入而判遗漏。待审核内容已经列出某人时，不得再写遗漏该人。多建了仅被提及的人时判不通过并要求删除该卡。修改意见与纳入规则冲突时以纳入规则为准。

## 验证

规则投影测试覆盖生成与审核文案。`git diff --check`，GitNexus `detect-changes` 与 `analyze --index-only`。不提交真实提取任务。
