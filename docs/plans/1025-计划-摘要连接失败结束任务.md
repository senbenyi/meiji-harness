# 摘要连接失败结束任务

- 类型：完整流程，公共异步请求错误处理及集成回归。
- 目标：HTTP连接失败等待1秒重试一次，再失败跳出盒子，返回“网络连接失败”，保留已保存项目，不审核或修订。
- 非目标：不改连接成功后的60分钟等待，不修改用户项目或旧任务数据。
