# 提取人物补齐可拍摄外观

## 结论

实际出镜或发声的重要角色，定妆或分镜在字段为空时会自行猜测的外观，改为在提取时写好，句末标「背景补」。原文已有的不改写。仅被提及的人不建卡。姓名、定位、签名道具、伤疤残疾只保留原文。

## 改动

- 生成、重新生成和审核规则按上述口径补性别、年代、年龄粗段、身材、发型、面部、身高观感、国籍、声线和至少一套服装的名称、颜色、材质、可见配件。
- 返回结构增加 `facial_features`、`height`、`nationality`、`voice`。
- 合并角色时保存这四项；旧的人工编辑载荷没有这些键时不把已有值清空。
- 定妆人物句带上面部、身高、国籍。声线不进定妆。

## 验证

规则投影、角色合并和定妆人物句测试。`git diff --check`，GitNexus `detect-changes` 与 `analyze --index-only`。不在正式项目上重新提取。
