# 人物遗漏审核门槛

- 类型：审核规则修复，完整流程（关键业务审核，规则、回归与工作流同步）。
- 目标：无姓名出镜人物按规则排除，不能因其重要、人数明确或历史意见而误报遗漏。
- 非目标：不新增无名人物卡，不放宽具名重要人物完整性，不屏蔽真实服装问题，不修改生产候选或历史记录。
