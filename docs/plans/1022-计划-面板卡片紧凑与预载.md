## 调用链与证据
接口基线实测：compact 5次中位2.6ms/13383字节；单条详情5次中位1.3ms/52103字节。服务端读取很快，但浏览器独立详情请求可能受连接排队影响，无法保证用户展开即时，因此改为会话响应直接携带详情。
Service → 稳定程序事件 → display.read → task-messages响应 → 客户端缓存 → 同步展开渲染。新eager模式返回compact messages、首次/新增details与cursor。pending任务转终态时补齐对应已缓存详情，防止旧final_output空值沿用。
GitNexus索引有效，已query及逐符号impact，动态SSE竞争以源码补查；不修改宿主或全局连接策略。
