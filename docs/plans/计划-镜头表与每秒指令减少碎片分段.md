# 镜头表与每秒指令减少碎片分段

- 类型：完整流程，重写生成与审核约束。
- 目标：镜头表按完整小剧情规划时间与视频片段，每秒指令按必要变化设计连续节拍，减少微动作拆段。
- 非目标：不改逐镜调用、毫秒结构、存储与界面，不重写已有镜头，不调用付费生成。

## 验收标准与调研结论

| AC | 输入 → 可观测结果 | 结论与证据 |
|---|---|---|
| AC-1 | 同场、同目标的连续行动 → 优先合并在可容纳的 1–15 秒视频片段，动作完成、反应或摄影切镜不自动拆片段 | 未验收：现有镜头表仍将动作结果、反应列为优先分段点 |
| AC-2 | 大纲事件与预算 → 先估必要行动、完整对白和转场时间，按内容分配；长小剧情同名加 1/2…，不凑 15 秒、不用固定镜数 | 已有时间优先与分段命名，需补合并检查和短片段的合理边界 |
| AC-3 | 每秒指令 → 节拍可覆盖整镜，不按每秒或 1–5 秒固定细分，不以篇幅配额填充；只在剪辑或需要独立交代的关键变化处拆 beat | 未验收：生成 skill 与输出协议仍有 1–5 秒范围，生成还有 350–650 字参考 |
| AC-4 | 生成/审核/单镜修订 → 同样接受连续粗分段，不因省略无因果作用的微动作、节拍少或没有面部特写而失败；真实事件/对白/交接/空间冲突仍阻塞 | 未验收：旧审核逐项要求动作过程，未区分必要交接和无关微动作 |
| AC-5 | 编排与保存 → 标题/编号/时长及毫秒协议不变，少量长 beat 能生成、审核和保存 | 基线相关 74 通过、0 失败、0 取消；快照 28 场景 |

## 改动

1. 重写镜头表生成/审核 skill：小剧情目标、时间估计、连续合并、必要拆段、同名尾数、剧情交接 → AC-1/2/4。
2. 重写每秒生成/审核 skill：完整连续节拍、自主摄影、必要过程和状态、声音对白与毫秒时间；取消固定篇幅和 1–5 秒范围 → AC-3/4。
3. 单镜修订审核补充边界：不要求跨片段合并，不因微动作略写强迫拆分 → AC-4。
4. 输出协议同步合并规则与整镜一个 beat 的示例，保持所有字段和解析格式 → AC-3/5。
5. 相关测试及开发指引：三类实际提示词无旧诱导；整镜单 beat / 多个长 beat 可保存；生成镜头正文不强制细动作边界 → AC-5。
