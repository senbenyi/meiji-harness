# 镜头编号与统一修订

## 方案
程序按播放顺序生成镜头编号；AI 只返回既有镜头 id（新增为空），替换逻辑按 id 保留资源，拒绝未知或重复非空 id。UI 人工编辑同样使用 id，编号只读展示。无需改变持久化结构或迁移用户数据，旧表在下次保存时重编展示编号。直接复用大纲小段时长，审核全集合计等于小段累计舍入，不增加独立预算输入。所有内容组装契约错误接入原有两轮修订，并去重意见。

## 影响
replaceShots、assertProgramReview 风险 CRITICAL；taskNodeInput HIGH；createTextHandler LOW。更新契约、输入、提示词、人工编辑及相关测试，保留历史记录。

## 验收
- 编号由程序生成；重排保留对应 id 和资源，新增创建 id；未知和重复 id 可修订。
- 小段时长直接作为依据，程序与提示词合计口径一致。
- 组装业务校验携原候选进入修订，意见不重复，耗尽保留旧稿；网络异常保持失败。

## 验证结果
全部验收通过。相关测试87项通过；最终全量497项、486通过、11项原有失败、0取消，较基线491项新增6项均通过。新增测试涵盖重排保留资源、新镜头ID、未知/重复镜头ID的修订恢复及耗尽、意见去重。git diff --check 通过；无活动任务时重启服务。
