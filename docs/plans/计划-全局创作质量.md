# 全局创作质量计划

## 目标

将三档创作能力从聊天命令迁入设置，以一个全局选择统一控制图片、视频和短剧质量，并彻底删除客户端命令注册链路。

## 实施范围

1. 在统一设置中加入带独立 revision 的 `creation.quality`，默认 `regular`。
2. 设置页加入“创作质量”下拉框：快速创作、常规创作、高清创作。
3. 图片、视频、短剧任务在 Worker 准备阶段读取全局档位。
4. AutoDL、Runpod、百炼和火山适配器将档位转换为各自真实规格；无法区分档位时明确拒绝。
5. 从工具参数和项目元数据中移除新质量入口，仅保留旧任务兼容读取。
6. 删除 `src/client/commands` 及所有命令加载、注册、文案和测试引用。

## 验证

- 搜索确认命令目录与三个斜杠命令均不存在。
- 覆盖设置持久化、UI、工具 schema、图片/视频/短剧规格和供应商映射。
- 运行插件全量测试、Harness 预设测试、构建和 Registry 打包。
