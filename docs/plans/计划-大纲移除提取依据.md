# 大纲移除提取依据

- 类型：重构（skill 职责调整，涉及 3 个文件，按完整流程）
- 目标：大纲生成与审核不再承担「为提取提供场景、着装、道具文字依据」的职责，该职责由人物、场景、道具提取 skill 负责。
- 非目标：不改七小节结构、提取 Model、输出协议、数据结构或流程；不在提取 skill 中重复已有规则。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 状态 | 依据 |
|---|---|---|---|
| AC-1 | 大纲生成 skill 不再含「提取依据」节，结尾状态恢复为人物位置、身份、情绪、关键物件和未解决矛盾 | 已确认 | 修改后正文 |
| AC-2 | 大纲审核 skill 不再因场景布局、着装、道具描述不足或着装持物连续判失败 | 已确认 | 删除「提取依据」「着装与持物连续」两项及审核依据中的提取说明 |
| AC-3 | 大纲 reviewTarget 不再要求核对必要着装、地点与道具的明确描述 | 已确认 | `server/prompts/models/story-model.js:28` |
| AC-4 | 提取侧覆盖原提取依据的要求 | 已确认 | 见下表，均已有对应规则，未新增 |
| AC-5 | 相关测试不新增失败 | 已确认 | 见验证结果 |

## 原提取依据 → 提取 skill 对应规则
| 原大纲要求 | 提取侧已有规则 |
|---|---|
| 地点环境布局与光照 | extract-story-scenes：landmark、light、space 仅整理大纲明确内容，缺失写「大纲未说明」 |
| 人物首次出现的主要着装 | extract-story-characters：服装只沿用大纲，未写时 costume/look 写「大纲未说明」 |
| 道具名称、使用者、位置、对行动影响 | extract-story-props：name 沿用原文、ownerId 按大纲归属、description 含用途、evidence 引用原句 |
| 只写「饮茶」「落座」「烛光」不推导物件 | extract-story-props 同句规则；review-story-props「新增实体」 |
| 不为凑卡片添加陈设、服饰、装备 | extract-story-props / extract-story-scenes 不补造、不凑数规则 |

## 改动
1. `meiji/skills/task/generate-story-outline-skill.md` — 删除「提取依据」节；结尾状态去掉着装、持物、场景状态 → AC-1
2. `meiji/skills/review/review-story-outline-skill.md` — 删除审核依据中提取说明、「提取依据」「着装与持物连续」两项及「未为丰富画面添加陈设或装备」不判失败项 → AC-2
3. `meiji/server/prompts/models/story-model.js` outline `reviewTarget` — 去掉「必要着装、地点与道具的明确描述」 → AC-3

验证：相关测试与全量 `npm test`，预期不新增失败。
