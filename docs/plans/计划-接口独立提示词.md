# 接口独立提示词

- 类型：重构
- 目标：各生成接口独立决定提示词结构，公共层只提供可选片段和请求传输。
- 调研：docs/research/调研-接口独立提示词.md

## 待用户决定
无。

## 改动
1. `meiji/server/prompts/skill-prompts.js`：从统一拼装改为可选技能片段、来源标注和渲染工具，不决定最终角色与段落顺序 → AC-1、AC-3。
2. `meiji/server/prompts/interfaces/*.js`：新增七个文本阶段、四个图片阶段、视频的独立模块，各自定义完整请求结构；注册表只按 ID 分发，没有通用结构回退 → AC-1、AC-2。
3. `meiji/server/prompts/text-prompts.js`：移除通用包装和 JSON 推断，只分发、序列化接口定义；`image.js` 与 `films.js` 改用独立模块 → AC-1～3。
4. `meiji/server/prompts/preview.js`：与实际生成复用独立接口模块 → AC-4。
5. `meiji/tests/prompt-interfaces.test.js`：覆盖独立角色/顺序、真实请求与预览一致、无隐式包装、未知接口报错与覆盖层保留 → AC-1～4。
6. `.agents/architecture.md`、`.agents/development.md`、`meiji/docs/tasks-and-steps.md` 与 `meiji/docs/prompt-interfaces.md`：同步职责与修改入口；以用户已明确要求取代原统一组装约束 → AC-1、AC-2。

## 验收标准
见调研 AC-1～4。各模块显式选择所需共享片段；不复制 skill 正文。默认请求内容保持一致，用户可在单个模块修改结构。

## 验证
- 改动前 `npm test` 基线；生成提示词场景快照。
- 阶段完成后运行定向测试、提示词快照差异检查。
- 最终 `cd meiji && npm test` 无新增失败/取消；`git diff --check`。
