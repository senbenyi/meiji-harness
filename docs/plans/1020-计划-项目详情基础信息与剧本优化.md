## 调用链与证据

创建面板 projectDialog → projectCommand(create/edit) → emptyProjectModel/validateProject → ModelRepository/SQLiteStore；详情 renderTaskPanel → renderOverview → 公共 script-review 节点卡；生成通过 node-inputs 读取当前优化稿或原稿，commitContent 覆盖优化正文。

- basic_info 替代项目平铺资料；全部生产读取方、创建/编辑输入及测试同步。
- script_revision.rules 使用原剧本改编规则；既有全集规划独立规则迁入已确认的 story_segments.rules，保留现有规划执行方式，本步不实现新版故事分段生成。
- 项目摘要从详情页移除；其已有后台业务及历史兼容暂保留，避免扩大到其他制作节点退役。
- 存储版本升级需显式处理结构变更；历史任务提示词/HTTP/结果保持原样。旧项目迁移能够保留的正文作为原稿基准，真实原稿无法恢复时不伪造历史。
