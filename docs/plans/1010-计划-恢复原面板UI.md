## 改动

1. `meiji/client/project-forms.js` — 原创建、项目/剧集编辑、模型配置表单重建 → UI-1/5。
2. `meiji/client/content-forms.js` — 人工正文、集合及规则按字段编辑，不要求用户输入 JSON → UI-3/4/5。
