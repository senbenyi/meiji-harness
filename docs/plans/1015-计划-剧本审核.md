# 剧本审核

- 类型：新功能（完整流程）
- 目标：剧本模式导入剧本后自动执行一次「剧本审核」AI 任务，评估剧情是否连续、是否适合拍成视频；不适合时节点未通过并给出修改意见，且拦截提取剧集与提取人物；剧本卡片下方展示该节点的公共节点状态 UI。
- 非目标：不提供剧本在线编辑（现有系统无此命令）；不改提取剧集/人物的提示词；不自动修订剧本；项目摘要不受拦截；不对剧本审核做 AI 二次审核或自动修订轮次。

## 用户决定
- 第三轮：不展示审核说明、状态标签与版本；未通过原因下方加「修改」，按原因 AI 改写剧本后继续审核，两轮循环；修改与审核都属于剧本节点。
- 剧本本身是节点，剧本审核是作用于剧本节点的任务，不设独立审核节点；状态 UI 放在剧本卡片内、剧本信息下方（第二轮调整）。
- 不适合拍摄 → 节点「未通过」，未通过原因为修改意见；适合 → 「已生成」。
- 审核未通过或未审核时拦截「提取剧集」「提取人物」。为避免无法继续，提供「人工放行」（只校验审核结果结构，不要求结论为适合）。

## 调用链
创建项目 `projectCommand(create)` → `repository.create` → `open` 绑定会话 → `runtime.command(submit script-review)` → `TaskService` 排队并自动调度 → precheck(`project-text`) → text handler(`ai('script-review','generate')`) → `prepareContent` → 程序审核(handler-registry：`assertProgramReview` 判定结论) → 通过/未通过 → `commitContent` 写 `project.script_review` → `setNodeState`。
提取剧集/人物 precheck → `requireScriptReview`。
