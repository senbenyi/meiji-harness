# 短剧创作闭环设计

- 类型：新功能（流程重新设计）
- 目标：用最少的概念让“项目 → 成片”闭环：每一步都能人工编辑，也有自动生成入口；每个事实只存一处；底层稳定。
- 调研来源：`docs/research/调研-短剧创作方案闭环.md`
- 交互设计：`docs/design/设计-分集工作台交互.md`（页面布局、操作细节、线框图以该文档为准，本计划不再重复）
- 状态：**计划待开工（第四版）**。已确认：口径、D1～D7（D1 已被 U2 取代）、N1～N5、U1～U5。S1～S7 在上一轮未单独答复，本版按采纳处理，有异议请指出。

## 0. 设计机制

### 0.1 优先级

1. **现有流程闭环**：项目 → 总览 → 分集 → 成片，每一步都能人工修改，也能自动生成，改完能一路走到成片。
2. **底层稳定**：不改 `worker/` 任务层；生产只做机械动作，重启后能继续，不重复提交任务。
3. **最简单**：能删的概念都删掉，这次用不到的都不做。

### 0.2 六条规则

| # | 规则 | 检查方式 |
|---|---|---|
| M1 | **同名约定**：步骤 `<x>` 对应 `drama/steps/<x>.md`、导演 `references/<x>.md`、数据 `<x>.md`；拼接提示词只有一条规则。**唯一例外**：storyboard 步骤把镜头标记写进 `script.md`（U3） | 测试：步骤清单与文件名一致 |
| M2 | **人写 Markdown，系统写 JSON**：创作内容存 Markdown；任务、状态、成片只写 `state.json`；两边互不写入对方 | 测试：生产代码不写 `.md`；保存文本不写 `state.json` |
| M3 | **引用而不复制**：下游只写名称或位置，用到时读原文 | 评审：一个事实只出现在一个文件里 |
| M4 | **状态只从事实推出**：不存版本、定稿、复核、确认标记 | 测试：`src` 中不出现 `needs_review / finalized / versions / cascade` |
| M5 | **两个拼装点**：`assemble(步骤)` 生成文本；`compileShot(镜头)` 生成出画面的输入 | 评审：其他地方不拼接提示词 |
| M6 | **概念预算**：加一个概念就删一个 | 对照 0.3 节 |

### 0.3 概念清单

全部保留的概念如下：

```text
页面（3）：项目 · 总览（含角色定妆图）· 分集（剧本 + 分镜 + 画面 + 成片）
步骤（4）：project · series · script · storyboard
文件（4）：project.md · series.md · episodes/N/script.md（剧本行 + 镜头标记）· state.json
编号（1）：镜头号 [S..]
Skill（2 包）：drama/{SKILL.md, steps/4 个} · director-x/{SKILL.md, references/最多 3 个}
代码（4）：解析(md) · assemble · compileShot · 生产(fill / produce)
状态：只从事实推出，包括镜头任务状态、成片是否存在、暂停原因
```

已删除的概念：

- **流程状态**：版本、定稿、依据版本、需复核、级联暂停与确认、提示词定稿、锚点确认、锚点需复核、剧集停用、生产范围。
- **数据**：时间线、`episode_count / series.genre / episode_seconds`、技术 ID、行号 `[L..]`、`storyboard.md`、`anchor.md`、“引用已删除”、台词 / 字幕 / 锚点描述副本、中文外观（与英文定妆重复）、封面字段、历史成片选择。
- **界面**：锚点页、分镜页、成片页、剧本页中的“分集时间线”和“提示词”子页签、镜头下拉框、大文本框加保存按钮、“未保存确定离开”弹窗、各页面分别记录的选中集数。
- **Skill**：`drama-planning`、`shot-planning`、两份检查清单、导演 `shot-prompt-example.md`。
- **代码**：结构化 JSON schema × 5、内容规则校验、前端“JSON ⇄ 文本”的双向转换、流水线中的规划推进、“恢复原任务”、数据迁移。

## 2. 流程

```text
 ┌──────┐   ┌─────────────────────────┐   ┌──────────────────────────────────────────┐
 │ 项目  │──▶│ 总览                      │──▶│ 分集（一集一屏）                             │
 │project│   │ series + 角色定妆图         │   │ 左：剧本 script ｜ 右：镜头 storyboard        │
 └──────┘   └─────────────────────────┘   │ 镜头卡片上：画面状态 · 重拍 · 播放；顶部：成片   │
     ▲                   ▲                 └──────────────────────────────────────────┘
     └───────────────────┴──────── 不满意：原地改文字 / 🤖 重新生成 → 重拍 → 自动重新合成 ──┘
```

每一步的交互都一样：

```text
 内容为空？─是─▶ [🤖 自动生成] ─▶ assemble(步骤) ─▶ LLM 输出 Markdown ─▶ 解析通过 ─▶ 写入
    │否                                                  └ 解析失败 ─▶ 原文和行号交给人修改
    ▼
 原地编辑 ─▶ 失焦自动保存 ─▶ 生效（不动下游，不动 state.json）
 已有内容时点 🤖：先确认覆盖
```

## 3. Skill

### 3.1 两个包

```text
drama/                           流程：写什么、按什么格式
  SKILL.md                       总则：人工内容优先；只用总览中已有的名称；只输出 Markdown
  steps/project.md               立项
  steps/series.md                总览（含定妆规则：英文、单人、成年、正面全身、不写背景）
  steps/script.md                单集剧本：场 → 行，不写时间码、不写镜头
  steps/storyboard.md            分镜：按带序号的剧本行切镜头，输出“从第几行开始 + 镜头字段 + 视频 + 首帧”；
                                 包含 H3 语法和范例；换模型只改这一节

director-xxx/                    风格与规模
  SKILL.md                       总纲：题材、人物、声音、禁忌（每一步都读）
  references/series.md           集数（一条确定规则）· 单集秒数 · 分集结构 · 服装色系与标志物
  references/script.md           节奏 · 单集结构 · 钩子 · 对白风格
  references/storyboard.md       镜头语言 · 单镜时长范围 · 提示词风格要求
```

```text
system = drama/SKILL.md + drama/steps/<步骤>.md + director/SKILL.md + director/references/<步骤>.md（缺失按空处理）
user   = 该步骤的输入（见 4.2 节）
output = { markdown: string }
```

**分镜步骤的输入输出**：

- 代码把本集剧本行临时编号为 1..n，再交给 LLM。这个编号只出现在提示词里，**不存储**。
- LLM 按下面的格式输出镜头块：

  ```text
  ### 从第 3 行｜特写｜固定｜5 秒
  视频：……
  首帧：……
  ```

- 代码校验：起始行号递增、不跨场。然后把 `### [S..] 景别｜运镜｜时长` 与视频、首帧两行插入到对应剧本行之前，**剧本行一字不改**。
- “🤖 重写这一镜”：同一步骤，只提供本镜的剧本行，只替换本镜的块。

### 3.2 职责边界

| 文件 | 只写 | 不得写 |
|---|---|---|
| `drama/steps/*` | 输出模板、结构规则、模型语法 | 集数、时长这类由导演决定的数值；风格偏好 |
| 导演 `SKILL.md` | 题材、人物、声音、禁忌 | 格式、模型语法 |
| 导演 `references/<步骤>.md` | 该步骤的风格和数量规则 | 其他步骤的内容；互相矛盾的规则 |

优先级：人工编辑 > 导演 > `drama` 的默认建议。

## 4. 数据

### 4.1 文件

```text
projects/<id>/
  project.md                人   frontmatter{title, director, genre} + 梗概
  series.md                 人   一句话故事 · 世界观 · 角色 · 场景 · 分集
  episodes/N/script.md      人   场 → 镜头标记 [S..] + 剧本行（镜头标记由分镜步骤或人插入）
  state.json                系统
  materials.json · media/   系统（不变）
```

```json
{ "created_at": 0, "updated_at": 0,
  "auto": { "task": null, "paused": null, "attempts": {} },
  "anchors": { "林晚": { "image_job_id": null, "source_job_id": null } },
  "episodes": { "3": {
    "shots": { "S01": { "take": 1, "keyframe_job_id": null, "job_id": null, "status": "pending" } },
    "film_task": null, "film": null } } }
```

- `auto.task` 取 `fill`、`produce` 或 `null`。
- `film` 只保留最新一份。
- 角色和场景以名称作为 ID（N1）。

### 4.2 数据依赖

```text
director/SKILL.md + references/<步骤>.md ─────── 每次 assemble 时读取

project.md ──(题材/梗概)──▶ assemble(series) ──▶ series.md
                                                   │ 角色{简介, 定妆, 音色} · 场景 · 分集
              ┌────────────────────────────────────┼──────────────────────────┐
              ▼                                    ▼                          ▼
   总览角色卡：定妆 ─▶ SDXL 出图         assemble(script)               项目列表
     └▶ state.anchors[名称]            输入：series + 分集条目 N          N = 分集数 · 主演
              │                              + 第 N−1 集最后一场
              │                                    ▼
              │                         episodes/N/script.md（剧本行）
              │                                    ▼
              │                         assemble(storyboard)：带序号的剧本行 + 角色名 + 场景
              │                                    ▼  代码插入镜头标记（剧本行不变）
              │                         episodes/N/script.md（剧本行 + [S..]）
              ▼                                    ▼
 ┌──────────────────────────── compileShot(S) ─────────────────────────────┐
 │ 首帧 = 首帧 + 出镜角色的「定妆」；参考图 = 主角（本镜第一位出场角色）的定妆图 │
 │ 视频 = 视频 + 台词段：本镜对白行按顺序，写成「角色（语气；音色）：原文」      │
 └─────────────────────────────────────────────────────────────────────────┘
                                         ▼
               state.episodes[N].shots[S] ─▶ 合成 ─▶ film（字幕取自各镜对白行）
```

| 事实 | 唯一所在 | 读取方 |
|---|---|---|
| 集数、单集秒数 | 导演 `series.md`；落实为 `series.md` 中的分集条目 | 列表分母 = 分集条目数 |
| 题材、梗概 | `project.md` | assemble(series)、列表 |
| 角色简介、定妆、音色、主角标记 | `series.md` | 剧本、分镜、出图、编译、列表 |
| 场景描述 | `series.md` | 剧本、分镜 |
| 分集标题、梗概、钩子 | `series.md` | assemble(script)、分集页顶部、成片标题 |
| 台词、动作、音效 | `script.md` 的剧本行 | 编译台词段、字幕 |
| 镜头语言、时长、视频与首帧描述 | `script.md` 的镜头标记块 | 编译；时间码由时长累加得出 |
| 任务、定妆图、成片 | `state.json` | 列表、总览、分集页、流水线 |

**镜头的出场角色**：取本镜对白行的说话人，以及动作行里出现的角色名（按出现顺序），第一位即为主角。镜头标记中可以写 `｜人物：林晚、苏晴` 手动指定，此时覆盖自动推断。

### 4.3 格式

`series.md`：

```text
一句话故事：……
## 世界观
……
## 角色
### 林晚（主角）
简介：28 岁插画师，外柔内刚，标志物是旧黄铜钥匙。
定妆：adult Chinese woman, about 28, oval face, long straight black hair, cream knit cardigan, slim build
音色：清亮偏轻，激动时哽咽
## 场景
### 咖啡馆
街角咖啡馆，靠窗座位，雨天冷光。
## 分集
### 第 1 集 · 未署名的信
梗概：……
钩子：……
```

`episodes/3/script.md`：

```text
## 场 1｜咖啡馆｜林晚、苏晴
### [S01] 双人近景｜缓推｜6 秒
视频：【0–2 秒】苏晴把照片推过桌面……【2–6 秒】缓推至林晚近景，2 秒处苏晴开口。
首帧：Two women face each other across a cafe table by a rain-streaked window…
动作：苏晴把旧照片放在桌上，林晚没有伸手。
苏晴（低声）：她已经不在了。
### [S02] 特写｜固定｜5 秒
视频：……
首帧：……
音效：雨声压住尾音。
林晚（发颤）：那我算什么？
```

解析规则：

1. 镜头从它的标记开始，到下一个镜头标记或下一场为止。
2. 场开始后、第一个镜头标记之前的剧本行，属于“未入镜”。
3. 没有编号的镜头标记会被补上 `[S..]`。
4. 解析失败时报告行号，不写入文件。
5. 只做结构解析，不做内容判断。

## 5. 各页面

界面布局与操作细节以 `docs/design/设计-分集工作台交互.md` 为准，本节只列出字段、Skill 和约束。

### 5.1 项目列表

| 字段 | 核心作用 | 来源 |
|---|---|---|
| 主角定妆图（封面） | 识别项目 | `state.anchors` |
| 名称 · 导演 · 题材 | 识别与分类 | `project.md` |
| 主演 | 谁演 | `series.md` 中标记“（主角）”的角色 |
| 成片 M / N 集 | 核心进度 | `state.json` 中的 film / `series.md` 分集数 |
| 镜头 完成 / 总数 | 生产细节 | `state.json` / 各集 `script.md` |
| 状态 | 筛选 | 未开始（无任务）/ 进行中（`auto.task` 不为空或有运行中的任务）/ 已暂停 / 已完成（M = N） |
| 暂停原因 | 卡在哪里，点击直达对应集和镜头 | `auto.paused` |

入口：

| 入口 | 行为 |
|---|---|
| ＋ 新建 | 打开新建表单 |
| 🤖 一键补全 | `fill`：只补空白：总览 → 各集剧本 → 各集分镜；不覆盖，不出片 |
| ▶ 一键生产 / ⏸ / 继续 | `produce`：为缺图的角色出图 → 从第 1 集起提交镜头 → 合成 |
| ⬇ 下载全部成片 | 打包下载 |
| 删除 | 删除项目 |

```text
🤖 一键补全 ─▶ 找第一处空白（series → 第 1..N 集剧本 → 第 1..N 集分镜）─▶ assemble ─▶ 解析 ─▶ 写入 ─▶ 下一处
      └ 生成或解析失败 ─▶ 重试 1 次 ─▶ 暂停：“第 N 集分镜生成失败：原因”

▶ 一键生产 ─▶ 出场角色缺定妆图？─是─▶ 出图（失败重试 1 次，仍失败则暂停：去总览）
      └否─▶ 第 N 集没有镜头？─是─▶ 暂停：“第 N 集还没有分镜”
               └否─▶ 提交还没有任务的镜头 ─▶ 失败重拍 1 次，仍失败则暂停：第 N 集 S0x
                        ─▶ 本集全部完成 ─▶ 合成（失败重试 1 次）─▶ 下一集 ─▶ 全部完成 ─▶ task = null
```

### 5.2 项目

| 字段 | 核心作用 | 约束 |
|---|---|---|
| 导演 | 决定风格与规模 | 必选；中途更换只影响之后的生成 |
| 名称 | 标识 | 必填 |
| 题材 | 列表展示；作为总览的输入 | 单行 |
| 梗概 | 故事梗概、主角与冲突 | 不写逐集走向，不写集数 |

- **Skill**：`drama/steps/project.md` + 导演 `SKILL.md`。
- **必须约束**：只输出 frontmatter（title、genre）和梗概；题材符合导演风格；原创，不涉及真实人物和品牌。
- **修改**：新写 `steps/project.md`；删除 `planning.js:46` 中要求写“故事走向”的指令。

```text
选导演 ─┬─ 🤖 assemble(project) ─▶ 填入名称/题材/梗概 ─┐
        └─ 手工填写 ─────────────────────────────────┤
                                                     ▼
                                      保存 ─▶ project.md ─▶ 总览
```

### 5.3 总览（含角色定妆图）

- **核心内容**：
  - 一句话故事、世界观。
  - 角色卡片：简介、定妆、音色、主角标记，以及 **定妆图**（🤖 出图 / 替换 / 查看）。
  - 场景。
  - 分集条目：标题、梗概、钩子；分集条数即集数。点击某一集可跳到分集页。
- **交互**：每个区块点击后原地编辑，失焦自动保存。页头有“🤖 生成总览”和“为缺图的角色出图”。
- **Skill**：`drama/steps/series.md` + 导演 `SKILL.md` + `references/series.md`；输入为 `project.md`。
- **必须约束**：
  - 分集条数严格等于导演的规定。
  - 至少一名主角。
  - 定妆用英文，只写单人、成年、正面全身，不写背景。
  - 服装色系遵循导演设定。
  - 音色写清楚，跨集不变。
- **一致性**：
  - 主角定妆图作为每个镜头首帧的参考图。
  - 所有出镜角色的定妆文本都进入首帧编译。
  - 音色进入视频的台词段。
  - 剧情连贯由分集钩子和“上一集最后一场”共同保证。

```text
总览为空？─是─▶ 🤖 assemble(series) ─▶ 写入 ─┐
   │否 ◀──────────────────────────────────────┘
   ▼
原地编辑（失焦保存）─▶ 改了定妆？─▶ 该角色卡片提示“定妆已改，可重新出图”（只是提示，不做任何自动操作）
   │
角色缺图 ─▶ 🤖 出图 / 从素材库替换 ─▶ state.anchors[名称]
```

### 5.4 分集（剧本 + 分镜 + 画面 + 成片，一集一屏）

布局见设计文档第 2 节：左侧是分集目录（全项目共用一个“当前集”），中间左栏是剧本、右栏是镜头卡片，顶部显示成片。

**剧本（左栏）**

- **核心内容**：场（场景名、出场角色）→ 剧本行（动作 / 对白（角色、语气）/ 音效）。不写时间码。
- **Skill**：`drama/steps/script.md` + 导演 `SKILL.md` + `references/script.md`；输入为 `series.md` + 分集条目 N + 第 N−1 集最后一场。
- **必须约束**：
  - 承接上一集的钩子，结尾落在本集的钩子上。
  - 只使用总览中的名称。
  - 对白注明角色和语气。
  - 不写时间码，不写镜头语言。
  - 篇幅与单集秒数相称。
- **编辑**：逐行原地编辑，回车新增一行，在空行上按退格删除该行，也可以切换到全文编辑。改台词后，所在镜头的编译结果和字幕自动更新。

**镜头（右栏）**

- **核心内容**：`[S..]`、景别、运镜、时长、`视频`（分秒动作与开口时刻，不写台词原文、外观和场景）、`首帧`（英文静止画面）。
- **派生显示**（不存储）：时间码、本集总时长、未入镜的行、实际发送的提示词（编译预览）。
- **Skill**：`drama/steps/storyboard.md` + 导演 `SKILL.md` + `references/storyboard.md`；输入为带序号的本集剧本行 + 角色名 + 场景。
- **必须约束**：
  - 覆盖本集全部剧本行，镜头不跨场。
  - 台词字数不超过时长 × 5。
  - 单镜时长在导演规定的范围内。
  - 总时长接近单集秒数。
  - `视频` 描述中不出现文字画面。
  - `首帧` 只描述静止画面，用英文。
- **编辑**：
  - 拆镜：在两行之间点“✂ 从这里开始新镜头”。
  - 并镜、插入空镜、删镜：用镜头菜单 ⋯。
  - 景别、运镜、时长、视频、首帧：在卡片内原地修改。
  - 修改已经拍好的镜头，不会清除它的任务；要不要重拍由人决定。

**画面与成片（镜头卡片 + 顶部）**

- **镜头卡片**：缩略图、状态、失败原因，以及“▶ 播放 / 重拍 / ⋯ 查看实际提示词”。
- **顶部**：画面进度 x/y、“▶ 生产本集”、“▶ 播放成片”（从侧边滑出播放器，可下载视频和字幕；时间码与镜头同步，点击即可定位到对应镜头卡片）。
- **约束**：
  - 按镜头顺序合成。
  - 字幕取自各镜的对白行，时间按实际视频时长分配（沿用 `film.js`）。
  - 全部镜头完成后自动合成，也可以手动点“合成本集”。
  - 成片只保留最新一份，旧文件留在素材库。

```text
选集 ─▶ 剧本为空？─是─▶ 🤖 生成剧本 / 直接写
   │否
   ▼
左栏逐行修改（失焦保存）─▶ 没有镜头？─是─▶ 🤖 生成分镜（只插入镜头，不改剧本行）
   │否
   ▼
右栏调整：拆 / 并 / 插 / 删，修改字段，或 🤖 重写这一镜
   ▼
▶ 生产本集 ─▶ 卡片状态实时变化 ─▶ 全部完成 ─▶ 自动合成 ─▶ ▶ 播放成片
   ▼
看成片，点有问题的镜头 ─▶ 定位到卡片 ─┬─ 改剧本行 ─────┐
                                   ├─ 改镜头描述 ───├─▶ 重拍 ─▶ 自动重新合成
                                   └─ 只是运气不好 ─┘
```

## 7. 验收标准

| 编号 | 操作 | 期望 |
|---|---|---|
| AC-1 集数 | 每位导演各生成 3 次总览 | 集数都等于导演 `series.md` 的规定；列表分母一致 |
| AC-2 台词只存一处 | 修改一句台词 | 编译预览、重拍、字幕都使用新台词；全项目只有 `script.md` 里有这句原文 |

| AC-6 全流程 | 新建 → 一键补全 → 总览出图 → 分集逐集修改 → 一键生产 → 看成片 → 改 1 镜并重拍 | 每一步都能编辑，也都有 🤖 入口；重拍后成片自动更新 |
| AC-7 Skill 分离 | 检查 Skill 文本 | 集数只出现在导演 `series.md`；H3 语法只出现在 `drama/steps/storyboard.md` |
| AC-8 概念预算 | `npm test` | 旧概念关键字不出现；同名约定检查通过；已删除的前端模块不再被引用 |
| AC-9 稳定性 | 一键生产过程中重启 Harness | 从断点继续，不重复提交同一 take |
| AC-10 一屏完成 | 写好、检查、重拍、播放第 3 集 | 不离开分集页；不用重复选集；没有保存按钮，也没有“未保存”弹窗 |
