# 拆分规则交给模型

- 类型：完整流程
- 目标：与剧情无关的内容由模型按提示词判断并列入排除段落，程序只编号全文并核对覆盖，不事先删除。
- 非目标：不改对白和动作原文，不改参考时长的切分方式。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 已确认/未确认/未验收 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 剧本含人物说明和分场间隔 → 编号剧本仍保留这些原文；模型把它们列入排除段落后，写入的剧情不含这些内容 | 已确认 | 当前 `plotSource` 在编号前按正则删除，提示词写成「已去掉」 |
| AC-2 | 模型未排除这些段落就跳过 → 程序审核报告遗漏，不替模型判断 | 已确认 | `buildSplit` 现在要求从第一段连续覆盖到结尾 |
| AC-3 | 没有无关内容、排除段落为空 → 编号和拼接与现在一致 | 已确认 | `stage09`「第一场 酒馆」整段都是剧情 |

## 调用链与证据
拆分入口提交 `script-split` → 程序把完整剧本编号后写入提示词 → 模型返回各集起止段落 → `buildSplit` 按段落原文拼接。
