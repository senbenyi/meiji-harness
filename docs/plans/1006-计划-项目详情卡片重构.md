# 项目详情卡片重构

- 类型：UI 重构
- 目标：简化自由模式项目详情内容，并重排剧集、角色、场景、道具卡片布局。
- 非目标：不修改生成、编辑、删除、跳转和素材关联业务逻辑。

|---|---|---|---|
| AC-1 | 自由模式项目详情 → 不展示剧本卡片 | 已确认 | `project-overview-view.js` 当前无模式条件的剧本卡片 |

## 改动

### 阶段 1：项目详情结构

1. `meiji/client/project-overview-view.js` — 自由模式跳过剧本卡片；AI 创作方向移除说明文字，编辑动作改为标题旁图标 → AC-1、AC-2。
2. `meiji/client/project-overview-view.js` — 保持剧集卡数据和点击行为不变，仅配合宽卡布局 → AC-3。

### 阶段 2：卡片布局

1. `meiji/client/panel-styles.css` — 剧集卡改为宽卡片左右结构；角色卡上下结构并将头像改为圆形；场景卡左右结构；道具卡使用圆形图标与名称 → AC-3、AC-4、AC-5。

验证：项目详情页面人工检查不同模式和有/无图片状态；相关客户端测试与 `git diff --check`。
