# 拆分保存立即关闭弹框

- 类型：小改动，拆分弹框等待两次请求后才关闭，原因明确；修改概要入口及对应测试。
- 目标：拆分弹框点击有效保存后立即关闭，请求继续执行。
- 非目标：不改其他编辑弹框、不修改任务执行和持久化流程。

## 验收标准

- AC-1：有效时长点击保存 → 弹框同步关闭并移除，不等待保存时长或拆分请求返回。
- AC-2：关闭后仍按顺序提交时长与拆分，提交失败由现有面板 onError 显示，不丢失错误。
- AC-3：保存时长失败 → 不提交拆分；其他弹框关闭行为保持原样。

- `meiji/client/project-ui.js:renderOverview`：拆分回调捕获本弹框，在执行异步 act 前关闭。
