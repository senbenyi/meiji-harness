- 类型：Bug 修复
- 调研：docs/research/调研-剧情旧错误残留.md
- 目标：消除新结果被旧执行错误污染，保留真实当前错误与审核意见。
## 改动
先在 story-model.test.js 复现旧错误后重试；依证据修复剧情保存/节点生命周期路径。测试覆盖审核失败与当前接口失败。备份后通过领域存储修复已确认的残留状态，不改历史任务或正文。
## 验证
基线 npm test、回归及全量无新增失败、diff 检查、图谱同步、重启验证。

根因已复现：prepareChecks 返回的 project 快照仍带旧 activityError；opOutline 初始 save 清除数据库标记但后续 replaceFrom(project) 重带旧值，wrapped.save 将其当作当前错误写入所有剧情节点。在 prepareChecks 的新执行初始化中清空 activityError，使所有调用方拿到已清理的快照。回归测试同时种入节点 error 和剧集 activityError，改前稳定失败。
