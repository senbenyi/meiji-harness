# 清理本地模型隧道

- 类型：Bug 修复
- 目标：三个私有模型只使用远程 HTTP(S)，清理本机模型隧道和连接按钮，保留模型选择。
- 调研来源：`docs/research/调研-清理本地模型隧道.md`

## 人工决策
- 旧任务快照可能指向本地端口。实施时先按服务器身份和原地址审计；只有能确认同一远端实例的记录才制定定向迁移，不能盲目把历史 URL 改成当前网关。无法确认的记录保持原样并报告访问影响。

## 执行步骤

### 阶段 1：配置和传输
1. `dsh-elysium/src/worker/models/catalog/transport.js`、`catalog/registry-schema.js`、`catalog/servers.js`、`protocols/comfyui/adapter.js` — 删除本机 SSH 控制连接、SSH 服务分支及旧聊天隧道解析；服务仅取 HTTP(S) `base_url` → AC-3。
2. `dsh-elysium/src/worker/models/index.js`、`src/worker/index.js`、`src/worker/models/catalog/loader.js` 及模型执行/媒体读取调用点 — 清除因隧道存在的 `connectBackend`/提供者 `connect` 调用与导出，保留远端服务检查及任务快照校验 → AC-3。
3. `dsh-elysium/config/defaults.json`、`src/database/managers/settings.js`、`src/worker/models/providers/manual/definition.json`、`src/worker/models/providers/autodl/server.example.json` — 默认改为网关 HTTP 地址，删除聊天 `tunnel` 字段与 SSH 示例；读取现有统一设置时安全去除旧 `chat.tunnel` 字段，保留其余设置和修订号 → AC-4/5。

验证：注册 SSH 服务返回配置错误，远端 HTTP 服务可用；执行路径代码搜索无 `ssh -M`/`ensureConnection`，现有设置加载成功。

### 阶段 2：设置页与接口
1. `dsh-elysium/src/client/workbench/settings.js`、`styles.js` — 删除三项连接按钮、连接状态、探测与相关样式；图片/视频选择直接提交并处理版本冲突，聊天保留只读模型显示 → AC-1/2。
2. `dsh-elysium/src/server/routes/settings.js`、`src/worker/models/catalog/check.js` — 删除 `tunnel-*`、`model-status`、`model-connect` 接口；提供模型选择接口，仍在保存前检查远端模型能力并更新 `selection.selected` → AC-1/2。

验证：设置页不渲染连接按钮；选图片/视频后刷新回读选择；旧连接接口返回 404。

### 阶段 3：旧任务、示例与验证
1. `dsh-elysium/src/server/routes/media.js`、`src/server/projects/film.js` 及受影响的执行调用点 — 移除旧快照触发本机隧道的路径；只对可确认同一远端实例的旧媒体地址制定定向转换或明确报告不可访问项 → AC-3/5。
2. 删除 `dsh-elysium/src/worker/models/providers/manual/legacy/tunnel.mjs`、过时的本地隧道测试；更新设置、模型选择、配置、媒体路由的专项测试及 `dsh-elysium/README.md` 中的本机隧道说明 → AC-1–5。

验证：专项测试、插件构建、包检查；运行设置回读；真实聊天及图片/视频远端请求与历史媒体读取；确认本机无由插件新建的 `ssh -M` 进程。

## 验收标准
- AC-1：设置页不显示三个私有模型的连接按钮，不再发起连接状态或连接请求。
- AC-2：图片、视频模型下拉选择可直接保存，刷新后回读一致；聊天模型继续显示配置值。
- AC-3：模型服务登记仅接受 HTTP(S)；新任务、恢复任务及历史媒体读取不创建本机 SSH 隧道。
- AC-4：仓库默认配置、示例、说明与测试不再引导本地模型隧道。
- AC-5：现有运行设置可加载；旧任务本地 URL 的处理结果明确且经过验证。
