# 无工作区会话与项目绑定

- 类型：新功能，完整流程（接口、索引、宿主输入限制与业务流程）。
- 目标：无工作区也可启动 drama 会话，创建项目后新建同名工作区与新会话，原会话归属及消息不变。
- 非目标：修改已发布会话日志格式、搬移现有会话目录、改变原会话所属项目。
