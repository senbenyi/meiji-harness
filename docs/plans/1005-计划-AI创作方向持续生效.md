# AI 创作方向持续生效

- 类型：重构（完整流程）
- 目标：未导入原始剧本的项目展示可编辑的 AI 创作方向，首集及后续各集摘要持续使用最新方向。
- 非目标：不重写已有剧情、不删除项目数据、不改变导入剧本的分集模式、不修改素材删除。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 状态 | 依据或缺口 |
|---|---|---|---|
| AC-1 | 未导入剧本（含已有自动回写剧本）→ 始终显示 AI 创作方向并可编辑；导入剧本 → 不显示、不使用该方向 | 已确认 | scriptKind 区分 imported/assembled；不以 script 正文是否为空区分创作模式 |
| AC-2 | 首集、第二集及以后自动生成/重新生成/修订/审核 → 输入最新创作方向，明确持续指导各集 | 已确认 | EpisodeSummaryModel 现有上下文一直携带 premise，但正文一旦非空就切换剧本推进指令 |
| AC-3 | 改方向后生成下一集 → 新方向生效；保留前集事实、本次要求优先，回写文本不被当作完整预定剧本 | 未验收 | 需真实操作通路的请求快照回归 |

2. `client/project-overview-view.js` 按来源显示 AI 创作方向、编辑说明，移除首集保存方向选项 → AC-1、4。
3. `server/prompts/models/episode-summary-model.js` 以来源区分模式；生成/修订/审核均持续遵循方向，明确回写文本用途；task/review 摘要 skill 同步优先级 → AC-2、3。

6. UI、摘要提示词、真实操作通路及会话测试；README/开发指引更新 → AC-1–4。
