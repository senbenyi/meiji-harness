# 每秒参与清单程序过滤

- 类型：Bug修复
- 目标：AI即使误列卡外人物，程序也只保存和审核本集角色卡内participants，保留全部动作及对白。
- 非目标：自动建卡、改变人物出场剧情/台词、修改任务历史或真实项目数据、放宽卡内类型/字段校验。
