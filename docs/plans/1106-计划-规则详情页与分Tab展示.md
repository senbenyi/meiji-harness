# 规则详情页与分Tab展示

- 类型：前端交互调整，完整流程。
- 目标：查看规则恢复为面板内详情页，分tab展示生成、审核、修订和输出格式。
- 非目标：修改规则内容、生成流程、补充规则编辑方式。
