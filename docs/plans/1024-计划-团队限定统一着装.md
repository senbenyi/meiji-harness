# 团队限定统一着装

- 类型：规则与字段说明调整，完整流程。
- 目标：仅提取有组织归属且需要统一着装的实际出场团队，简短描述团队形象、状态和统一服装。
- 非目标：新增字段、删除已有候选或资产、重写剧情、真实模型调用、自动重启。

## 验收标准
| AC | 输入/状态 → 可观测结果 | 证据 |

| AC-1 | 群众、观众、临时聚集者、仅同职业人员 → 不建团队；无合格者输出空groups | 旧规则明确纳入背景群体和非制服群体，需收紧三动作 |

## 证据与影响
入口skills/group_setting.json经node_initializer复制至项目私有node_state，运行executor读取项目私有规则。因此仅改模板不会修复当前项目。group_setting定义和project_detail文字仍写背景群体，须同步描述但不变Schema形状。人物旧规则存在团队缺口上报，镜头已支持无资产称谓与ID为空，需明确非制服群众不属缺口。
GitNexus已status、更新索引、query/context/impact，createNode为UNKNOWN（符号未解析）；经源码核对初始化与executor读取链，不能将UNKNOWN当无影响。仅改技能文案和字段说明，数据结构与执行服务不改。

## 改动
1. group_setting.json三动作：严格纳入范围、简洁程度、动态状态与服装版本边界，旧不合格群体从新输出剔除。
2. character_extraction.json、shot_design.json：统一着装团队边界、非团队群众下游表达。
3. group_setting/definition.js、docs/project_detail.json：名称/形象/标识/服装说明简化并与规则一致，字段结构保留。
4. 开发方向同步；当前项目通过ProjectManager有备份更新对应基础规则，检查无运行任务，不自动删除旧数据。
