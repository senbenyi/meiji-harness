# 删除项目面板刷新

- 类型：完整流程Bug修复
- 目标：删除当前项目成功后立即清除旧上下文和订阅，显示最新片库；失败/取消保留当前项目。
- 非目标：删除协议/存储变更、其他UI改版、永久删除生产测试项目。

## 验收标准与调研结论
| AC | 输入/状态 → 可观测结果 | 状态 | 依据 |
|---|---|---|---|
| AC-1 | 从片库删除当前项目成功 → 清除快照、关闭旧订阅、刷新片库；点标题不恢复已删除项目 | 已确认 | workbench.removeProject仅catalog，未清context/stream；brand重新paint旧snapshot |
| AC-2 | 从概要删除成功，refresh返回空context → 片库及中性标题，订阅关闭 | 已确认 | task-panel.act调用refresh；无snapshot分支未清stream/header及未await catalog |
| AC-3 | 删除失败/用户取消 → 当前项目不变；删除成功前发出的旧refresh晚到 → 不恢复旧项目 | 已确认 | PanelContext.select的epoch可拒绝晚到，删除成功时未select |
| AC-4 | 从片库删除其他项目 → 列表更新，不清当前项目；会话切换后旧删除完成不清新项目 | 已确认 | 删除回调应仅清同一session/project |
