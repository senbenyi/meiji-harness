# 盒子任务与执行步骤职责划分

- 类型：重构，完整流程。
- 目标：Service只受理/提交/等待任务及提供数据写入能力；项目Executor声明和执行步骤，公共TaskManager统一持久化生命周期；在真实任务历史核对一个盒子任务的各步骤。
- 非目标：不改任务/任务组/步骤公共Model或数据库，不重写历史，不把摘要独立成盒子，不新增人工资料编辑任务或更改公共历史UI。
