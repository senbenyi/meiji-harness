# 强化每秒指令时间约束

- 类型：小改动
- 目标：让每镜时间轴、节拍时长与正文中的动作/对白/声音时点保持一致。
- 范围：仅更新两份技能正文，不修改校验代码、数据格式或执行流程。

## 验收标准
- AC-1：生成及修订请求明确本镜从零计时、毫秒单位、节拍累计总时长严格等于本镜时长，并在输出前复算。
- AC-2：生成规则明确动作正文、段末状态、对白及声音必须落在相应时间范围；审核规则检查语义时间矛盾，不与程序算术检查混淆。
- AC-3：实际请求快照包含上述规则，全量测试无新增失败。

## 改动
1. `meiji/skills/task/generate-seconds-instructions-skill.md:分段前` — 泛化时间要求 → 单镜时间硬约束和输出前核对 → AC-1/2。
2. `meiji/skills/review/review-seconds-instructions-skill.md:不通过情形` — 增加正文与时间轴矛盾的具体判定 → AC-2。

## 依据
`shared/seconds-content.js:validateSeconds` 已检查正整数毫秒、总时长、对白起点与音轨范围；`models/text-step-model.js` 将生产规则用于生成/修订、审核规则用于自审/复审。当前缺口是提示词对局部时间和文字时点一致性的强调不足，具体历史输出错误根因未经运行样本确认。

## 验证
提示词场景改前/改后快照与 prompt-diff；检查四类实际请求；npm test；git diff --check。

## 验证结果
基线与修改后 npm test 均为 581 通过、0 失败、0 取消。实际生成、人工修改、自动修订和审核请求快照均包含对应时间规则；复审使用同一审核编排。prompt-diff 无原规则删除。AC-1 至 AC-3 通过；未调用真实模型验证输出质量。
