# 按总集数自动合片

- 类型：新功能
- 目标：设置总集数并点击自动合片，由程序分配已有 Segment 并输出每集视频。
- 调研来源：当前 production-workflow.js、composition.js、production schema 和现有合片测试。

## 人工决策
确认以下默认规则：总集数默认 1，最大不超过有效 Segment 数；按剧情时间线顺序、完整 Segment 边界分集，尽量均衡时长；不裁切段内动作，不调用 AI 再规划。所有片段的当前审核版本完成后允许自动合片，保留原音频，直接拼接。

## 执行步骤
### 阶段 1：简化配置和输出
1. `dsh-elysium/src/client/workbench/production-workflow.js:overview/timeline` — 修改：手工裁切/排序/字幕/音乐编辑 → 总集数、预计每集时长、自动合片按钮；成片按集横向展示并进入播放详情 → AC-1、AC-3。
2. `dsh-elysium/src/database/schemas/production.js:initialProduction` — 修改：保存总集数配置，默认 1 → AC-1。
3. `dsh-elysium/src/server/projects/composition.js:submit/refresh` — 修改：用户时间线输入 → 校验已完成的当前视频，按顺序完整分段、均衡分集，一次提交生成每集独立合片记录，保存集序号和批次并逐集执行；保留历史导出 → AC-2、AC-3。
4. `dsh-elysium/tests/production.test.js`、`dsh-elysium/tests/production-ui.test.js` — 修改：验证自动分集、当前视频校验、失败反馈和播放入口 → AC-1、AC-2、AC-3。

验证：插件测试、构建、浏览器操作验证、Harness 重启。

## 验收标准
- AC-1：用户只设置总集数并点击自动合片；无手工时间线编辑要求。
- AC-2：每个 Segment 恰好使用一次、顺序不变、不截断，集数正确且非空；未完成或过期视频不能合片。
- AC-3：每集显示等待/合成中/完成/失败状态，完成后可进入播放详情；历史版本保留。

## 验证结果
已完成。209 项插件测试、10 项 Harness 测试通过；浏览器验证简化表单；真实服务器按 2 集完成 20.032 秒和 10.032 秒合片。详见对应实施记录。
