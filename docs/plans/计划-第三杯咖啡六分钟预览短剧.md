# 《第三杯咖啡》六分钟预览短剧

状态：2026-09-12 已完成实施与技术验收。120镜、360秒本地预览成片已交付；画质与连续性缺陷见 [实施报告](../implement/实施-第三杯咖啡六分钟预览短剧.md)。先完成流程审核与10镜头试片，再继续全片。

## 目标与规格

成年虚构人物三角恋，竖屏 384×512、24fps、最终 360 秒。120 个独立镜头，每镜头沿用 preview 的 73 帧/8 步，再裁成 72 帧即 3 秒。保留既有默认模型、音视频联合采样，不安装模型或配音系统。交付静音中文字幕预览，避免生成音轨的随机对白破坏故事。生成原片与参考帧留在 veo-comfyui；项目根目录的独立制作脚本读取结果 URL，在本地 out/third-cup-preview/ 生成字幕层、剪辑片段与成片。工具插件仍只处理服务器 URL，文档仅保存清单、计时、回执与链接。

林夏（28）：齐肩黑发、米色风衣，赴外地就职。陈默（30）：短发、深灰西装，前任，试图挽回。周予（29）：微卷短发、白衬衫和深色围裙，咖啡馆老板，一直暗恋林夏。

## 六段剧情

| 时间 | 内容 | 核心对白 |
|---|---|---|
| 0–60秒 | 雨夜咖啡馆，林夏带行李告别，陈默到来 | 明天早上，我就走了。 |
| 60–120秒 | 陈默用旧合照与安排好的未来挽留 | 这次，我把我们的以后都安排好了。 |
| 120–180秒 | 周予放下第三杯咖啡，说出多年心意 | 我不是今天才想留住你。 |
| 180–240秒 | 两种挽留变成争执，林夏沉默 | 你说的以后，问过她吗？ |
| 240–300秒 | 林夏说出工作与离开的真正意义 | 你们都在问我选谁，却没人问我想去哪。 |
| 300–360秒 | 两人接受她的决定，咖啡、告别和开放结尾 | 等我安顿好，请你喝咖啡。 |

## 实施与验收

1. 阅读真实入口、任务创建与恢复、图构建、媒体返回逻辑，保留所有已有修改；CLAUDE.md 当前不存在，执行 AGENTS.md。
2. 修复单镜脚本启动后才保存回执的中断窗口：先保存任务身份再启动；回执原子写、同一回执互斥。恢复只复用原 job_id，不整段重跑。
3. 编写固定顺序的 120 镜头清单、中文字幕与请求。每次只启动一个镜头。先生成少量角色/场景锚点，由本地脚本通过 ComfyUI 已有 LoadVideo/GetVideoComponents/ImageFromBatch/SaveImage 节点提取参考图；后续按人物/景别使用 I2VA 复用锚点，减少逐镜随机换脸，不无限接力累积漂移。
4. 先制作 10 镜头/30 秒试片，检查可辨人物、实际动作、字幕安全区、画面比例、解码及顺序。人物一致性仅作观察，不保证模型已解决跨角度身份问题。
5. 继续剩余镜头，每镜头最多自动恢复两次；状态不明确时停止对应镜头并查找原任务，不盲目重发。严重画质问题记录并限量修复，不无限挑片。
6. 本地 scripts/third-cup-edit.py 读取服务器 URL，逐段裁切72帧并叠加本地绘制的中文字幕、统一静音，然后按数字编号无重编码拼接。生成360秒/8640帧成片与SRT字幕。
7. 本地通过服务器 URL 对每段及最终成片 ffprobe、完整解码；确认120个唯一job、真实采样、实际规格、时长与服务器耗时。浏览器查看试片和最终成片，并对剧情段落抽查。记录观察到的缺陷、尚未验证的对白口型与长期身份一致性。

## 自审修正

- 120×73帧直接拼接是365秒，不是6分钟：固定每段72帧，最终8640帧。
- 三秒频繁换字幕难读：对白可跨相邻镜头持续6秒或更长，限制行长。
- 不能让每镜随机生成人脸：后续复用服务器角色锚点；建立镜头与角色特写仍需核对差异。
- 不能把启动脚本的成功当生成成功：读取最终结果、history及媒体流验证。
- 不能在网络中断后丢失身份新建任务：先写回执再启动，并发调用同一回执拒绝。
- 服务端路径和 /view URL 分开：参考帧通过本地提交的现有节点图完成；剪辑由项目根目录独立脚本在本地完成，插件不下载媒体。
- 本地脚本复用插件任务链，不冒充 Harness LLM 已自动规划完成全片；最终提供 Harness 用法及可恢复清单。

## 时间估算

历史单镜29.1秒×120≈58分钟服务器生成；不含冷启动、队列、网络、检查与剪辑。实际耗时以后续执行记录为准，无速度保证。单GPU依次提交，不启动其他主机。SSH 仅用于出错后的排查修复和进度日志监控，不作为制作入口，不通过 SSH 执行提帧/剪辑脚本。

## 本地执行入口

- `COMFYUI_URL=既有地址 node scripts/third-cup-preview.mjs 10`：试片生成及锚点提取；参数120继续全片，相同回执自动复用。
- `python scripts/third-cup-edit.py --limit 10`：本地剪辑验收；参数120输出6分钟成片。Python需Pillow，使用本机已有Codex依赖环境；ffmpeg/ffprobe使用本机已有安装。
- runner只通过HTTP API提交与查询，不包含ssh命令。重试预算按镜头写入attempts，跨脚本重启累计，不无限重试。

## 完成结果

120个唯一生成任务均首次成功，120次真实采样；最终384×512、24fps、8640帧、360秒静音中文字幕视频。服务器生成累计52分35.783秒，首次本地提交至成片验证约67分23.458秒。所有镜头按编号剪辑，每镜抽查0/1/2秒画面，完整片段及成片解码通过。精确道具数量、跨镜头空间/光线连续性、表演情绪与对白口型仍有限，不将技术验收等同正式画质验收。
