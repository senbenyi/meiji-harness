1. `meiji/shared/steps.js:latestVerdicts/reviewFailures/reviewPassed/deriveTaskStatus` — 私有 latestReviews 统一选择最新完成的审核步骤，状态与失败理由复用 → AC-1/2。

4. `meiji/server/flow/operations/run.js:trace.status` — 删除无消费者的派生状态，直接返回执行结果 → AC-1。
5. `meiji/tests/task-steps.test.js`、`meiji/tests/tasks.test.js` — 验证多目标复审、取消优先级、内容失败不重复补步骤、内存任务与当前任务快照隔离 → AC-3。
6. `meiji/docs/tasks-and-steps.md` — 记录唯一状态来源与保留字段职责 → AC-1。

## 验收标准
- AC-1：无第二套任务状态，保持任务状态优先级。
- AC-2：审核归并和步骤创建无重复实现；快照不重复计算或覆盖。
- AC-3：指定回归通过；全量无新增失败/取消。
