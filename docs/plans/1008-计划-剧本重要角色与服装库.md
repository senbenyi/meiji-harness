# 剧本重要角色与服装库

- 类型：新功能（完整流程）
- 目标：统一重要角色筛选及明确外貌提取，支持剧本全量角色入库和稳定服装 ID。
- 非目标：不按群演人数建卡，不修改人物图片生成规则，不自动生成整部剧本角色图片，不新增分镜换装功能。
