# 短剧项目

适用于一个 Harness 实例供一个用户使用；页面凭据沿用实例信任边界，不提供多人账号或聊天隔离。项目服务在工具插件，页面在 UI 插件，两者需要一起发布；部署命令见 [Harness 说明](harness.md)。

## 操作流程

1. 侧边栏底部点击“我的短剧”，输入名称后“新建短剧”。
2. 项目固定关联一个 `elysium` 主创作会话，打开失败时项目仍保留，重新点击即可重试。
3. 在会话中描述故事、时长和风格；AI 使用 `creation-drama`，已确定要求用 `drama_save_brief` 保存。仅创建、上传或保存不会生成视频。
4. 点击“素材与成片”打开右侧项目面板，上传参考图片、视频或音频。每个素材最多100MB，支持 PNG、JPG、WebP、MP4、MP3、WAV。
5. 授权制作后，任务自动关联当前项目。任务卡和项目面板显示进度，完成后可预览；“采用成片”才将该版本保存为已采用作品并提供下载。
6. 改稿继续使用同一会话，保留已采用镜头，生成新版本。刷新或重启后再次打开同一项目，不另建会话。

项目面板提供重命名、移除参考素材、删除项目。重命名不移动目录；移除素材仅移出当前参考列表，保留原文件供已有制作任务恢复使用。删除项目会从列表隐藏并停止该项目的继续使用，保留原目录、聊天与历史产物，不执行物理清理。正在制作或状态无法确认时禁止删除。

## 存储

默认目录为 `/root/autodl-fs/artifacts/projects/dramas/<projectId>/`；设置 `ARTIFACTS_ROOT` 时使用 `${ARTIFACTS_ROOT}/dramas/<projectId>/`，需要与模型工作流使用相同的产物根目录。

```text
<projectId>/
├── project.json   # 实例所有者、名称、固定会话ID、时间、素材与采用版本
├── brief.md       # 已定创作要求
├── shots.json     # 制作任务ID、调用ID及各次完整输入方案
├── assets/        # 上传素材，磁盘名称为生成的ID
└── exports/       # 点击采用后复制保存的成片
```

项目目录独立于插件代码和部署镜像同步目录。会话以项目目录作为 cwd，预设固定为 `elysium`；技能继续由现有全局技能路径提供。聊天使用 Harness 原有持久化。运行状态仍位于 `ELYSIUM_TOOLS_STATE_ROOT`（默认 `/root/autodl-tmp/elysium-tools`），生成文件沿用模型产物目录，采用后另存成片；备份项目目录不等于备份聊天和所有任务恢复数据。

服务器根据会话头的 cwd、会话ID与预设核对项目归属，模型参数不接受项目ID。恢复任务、预览与采用均验证任务属于当前项目。项目 JSON 使用临时文件原子替换，并串行处理同一项目内的写操作。

## 验收

自动测试覆盖项目持久化、固定会话、重命名、跨项目任务拒绝、上传和范围下载、采用幂等、并发写入、删除拦截与界面恢复。测试使用临时目录和模拟宿主接口；它们不等于服务器会话或GPU推理验收。

发布后验收：新建两部短剧，分别上传素材；在第一部中发起制作并刷新确认恢复；采用成片后下载；切换第二部确认无第一部任务或素材；重命名并重启确认仍打开原会话。未执行这些步骤前不标记运行可用。
