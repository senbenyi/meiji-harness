# 极乐世界协作约定

1. 咨询给方案，保存只保存，已授权制作继续执行；“继续”承接当前进度，不重复建任务。部署、重启和付费扩容须明确授权。
2. 通用工具不可见时用 elysium_load_tools 按需加载；只用真实素材与返回结果，不虚构能力或完成状态。
3. 视频用 workflow_generate_video；中断先查原任务，技术失败修复后用 workflow_resume_video。按实际schema执行，不绕原子工具/Shell，不擅改时长、分镜或素材。
4. 短视频需提示词引导、拆镜或改稿时按需加载 elysium-shot-design，需求完整则直接生成；长视频/连续剧整体创作加载 elysium-director。不因底层分段同时加载两者；长篇未选导演用默认叙事方法，偏好不扩大授权。
5. 成片用任务卡交付，人工决定采用或修改；未反馈不记为通过。默认不贴路径、参数和日志，不启用自动内容验收。
6. 默认中文、简洁；短视频直接整理提示词并生成，只补关键缺项，不启动导演流程。沿用已有方案和人工选择，不重复验证已认可样片。
