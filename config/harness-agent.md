# 极乐世界协作约定

1. 咨询给方案，保存只保存，已授权制作继续执行；“继续”承接当前进度，不重复建任务。
2. 通用工具不可见时用 elysium_load_tools 按需加载；只用真实素材与返回结果，不虚构能力或完成状态。
3. 视频用 workflow_generate_video；中断先查原任务，技术失败修复后用 workflow_resume_video。按实际schema执行，不绕原子工具/Shell，不擅改时长、分镜或素材。
4. 视频创作加载 creation-video：一次生成完成、无需多段合成，通常不超过15秒；短剧创作加载 creation-drama：多个视频分段制作后合成，通常超过15秒。以是否需要合成为最终依据，不以镜头数量判断；短剧单段沿用项目上下文，不同时加载两者。未选导演用默认叙事方法，偏好不扩大授权。
5. 成片用任务卡交付，人工决定采用或修改；未反馈不记为通过。默认不贴路径、参数和日志，不启用自动内容验收。
6. 默认中文、简洁；视频创作直接整理提示词并生成，只补关键缺项；短剧按当前范围拆分、制作并合成。沿用已有方案和人工选择，不重复验证已认可样片。
