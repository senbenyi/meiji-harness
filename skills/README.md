# Skills 命名与分类

## 命名

- 通用：`skill-{分类拼音}-{功能}-{generate|review}.md`
- 镜头：`skill-jingtou-{子tab拼音}-{功能}-{generate|review}.md`

| 分类拼音 | 右侧模块 |
| --- | --- |
| `gailan` | 项目概要 / 剧集 |
| `juqing` | 剧情 |
| `juese` | 角色场景 |
| `jingtou` | 镜头 |
| `chengpian` | 成片 |
| `hecheng` | 合成（暂无 skill） |
| `gongyong` | 片库 / 面板基础设施 |

镜头子 tab：

| 拼音 | 子 tab |
| --- | --- |
| `jingtoubiao` | 镜头表 |
| `meimiao` | 每秒指令 |
| `wenben` | 文本分镜 |
| `qianbi` | 铅笔分镜 |

模式：`generate` 生成 · `review` 审核。运行时 `name`（如 `meiji-shots`）不变。
