# llm-dsh-plugins

## 项目介绍

`llm-dsh-plugins` 是面向 AI 短剧创作的 DeepSeek Harness 插件仓库，包含 Elysium 创作预设、图片与视频工作流、任务管理和创作工作台。

## 核心功能

- **多模式创作**：提供教学、自由和导演三种 Elysium 创作模式，以及 Harness 标准模式。
- **三档视频生成**：提供预览创作、常规创作和高清创作。
- **任务管理**：支持任务提交、状态查询、结果获取、取消和失败恢复。
- **创作工作台**：管理素材、项目、锚点、分镜和交付物。

## 产品说明

产品按“素材 → 项目 → 分镜 → 交付”组织创作过程：

1. **素材**：浏览服务器上的图片和视频结果，并引用到项目。
2. **项目**：集中管理生成档位、角色锚点、幕、镜头和交付物。
3. **锚点**：维护角色描述和服务器参考图，保持角色一致性。
4. **分镜**：编排镜头，维护动作、字幕、角色、任务状态和重拍备注。
5. **交付**：登记成片或字幕的任务 ID、服务器 URL 与规格信息。

## 使用方法

### 选择教学、自由或导演模式

| 模式 | 适用场景 |
|---|---|
| 极乐世界 · 教学 | 默认模式，适合首次使用，由 Agent 分步骤引导创作 |
| 极乐世界 · 自由 | 适合熟悉流程的用户，开放完整能力并减少确认步骤 |
| 极乐世界 · 导演 | 适合短剧策划、剧本拆解和分镜设计 |

### 使用预览创作、常规创作或高清创作

```text
/预览创作 成年角色在咖啡馆拿起信封，抬头微笑
/常规创作 成年角色在咖啡馆拿起信封，抬头微笑
/高清创作 成年角色在咖啡馆拿起信封，抬头微笑
```

| 指令 | 用途 | 支持模式 |
|---|---|---|
| `/预览创作` | 快速检查构图和动作，生成约 3 秒预览 | `t2va`、`i2va` |
| `/常规创作` | 兼顾清晰度和速度，时长按需 | `t2va`、`i2va` |
| `/高清创作` | 使用原生高质量工作流，适合正式制作 | 五种 MiniMax H3 模式 |
