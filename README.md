# llm-dsh-plugins

DeepSeek Harness 插件仓库。

## dsh-comfyui

AI-first 合同制 ComfyUI 驱动器，支持工作流合同扫描、生成前节点与模型校验、任务查询，以及模板和 LoRA 管理。

详见 [dsh-comfyui/README.md](./dsh-comfyui/README.md)。

```sh
cd dsh-comfyui
npm install
npm test
```

## dsh-elysium

AI 短剧可视化工作台，集成项目管理、角色与分镜、图片/视频生成，以及文件、终端、Git、浏览器等侧边栏能力。

详见 [dsh-elysium/README.md](./dsh-elysium/README.md)。

```sh
cd dsh-elysium
pnpm install
pnpm build
pnpm test
```
