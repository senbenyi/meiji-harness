# llm-dsh-plugins

## 项目介绍

`llm-dsh-plugins` 是面向 AI 短剧创作的 DeepSeek Harness 插件仓库，提供 Elysium 创作预设、图片与视频工作流、任务管理、创作工作台和本机部署能力。

Harness 只在本机运行，远端服务器只提供 Qwen、ComfyUI 等模型服务。插件中的图片、视频和其他媒体统一使用服务器 URL，不上传、下载或保存媒体文件，也不读取远端服务器的本地路径。

## 核心功能

- **多模式创作**：提供教学、自由和导演三种 Elysium 创作模式，以及 Harness 标准模式。
- **三档视频生成**：通过预览创作、常规创作和高清创作，在生成速度、时长和画质之间选择合适档位。
- **任务管理**：支持生成任务提交、状态查询、结果获取、ComfyUI 队列查看、任务取消，以及失败任务的受控恢复。
- **创作工作台**：围绕素材、项目、锚点、分镜和交付物管理短剧制作过程。
- **一键部署**：统一安装工具插件、Harness 配置、Web profile 和项目预设。

## 产品说明

产品按“素材 → 项目 → 分镜 → 交付”组织创作过程：

1. **素材**：浏览服务器上已有的图片和视频任务结果，按关键词、档次和类型筛选，并将需要的素材引用到项目。
2. **项目**：集中管理一部短剧的创作数据，包括生成档位、角色锚点、幕、镜头和交付物。
3. **锚点**：维护角色名称、描述和服务器参考图，为后续镜头提供一致的角色信息。
4. **分镜**：按幕编排镜头，维护动作、字幕、生成模式、角色关联、任务状态和重拍备注。
5. **交付**：登记成片或字幕的任务 ID、服务器 URL 与规格信息，供最终预览和交付。

## 使用方法

### 环境要求

- Node.js 20.16 或更高版本
- pnpm
- 已安装并可运行的 DeepSeek Harness CLI（`dsh`）

### 安装与部署

```sh
bash app/deploy_dsh_elysium_tools_local.sh
```
### 启动 Harness

```sh
dsh web
```

### 快速开始

| 模式 | 适用场景 |
|---|---|
| 极乐世界 · 教学 | 默认模式，适合首次使用，由 Agent 分步骤引导创作 |
| 极乐世界 · 自由 | 适合熟悉流程的用户，开放完整能力并减少确认步骤 |
| 极乐世界 · 导演 | 适合 AI 短剧策划、剧本拆解和分镜设计 |


### 选择模式

```text
/预览创作 成年角色在咖啡馆拿起信封，抬头微笑
/常规创作 成年角色在咖啡馆拿起信封，抬头微笑
/高清创作 成年角色在咖啡馆拿起信封，抬头微笑
```

| 指令 | 用途 | 支持模式 |
|---|---|---|
| `/预览创作` | 快速检查构图和动作，生成约 3 秒预览 | `t2va`、`i2va` |
| `/常规创作` | 兼顾清晰度和速度，时长按需 | `t2va`、`i2va` |
| `/高清创作` | 使用原生高质量工作流，适合正式制作 | 五种 MiniMax H3 模式 |
